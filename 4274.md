# Plan (muse-spark-1.3-contributor, medium)

## Goal

Add `luau/tools/reference-host.mjs`, a plain-Node (no dependencies) script that drives the built C module (`jackioh_wasm_c.wasm`) through its raw C ABI exactly as any non-JS host does. It has two modes: `fixture`, which folds the hotseat fixture with `fold` and replays its log step by step with `reduce`, holding both final hashes to `HOTSEAT_HASH` read from `crates/engine/src/testkit/golden.rs`; and `traces`, which replays a `cargo jackioh golden record` file step by step, holding `hash_state` to `begin.s` and each step's `s`, ignoring `l`, `v`, `e`, and exiting 1 on the first mismatch. Both modes print a short report (module size, load and `init` times, games, steps, median and worst per-step `reduce` + `hash_state` time).
