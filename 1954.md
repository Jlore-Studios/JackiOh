# Plan (opus, strong)

## Goal

On a fine pointer, the cursor becomes an original cartoon gauntlet:
- `glove` is the default.
- `glove-point` replaces every `cursor: pointer`.
- `glove-grab` replaces every `grab` and `grabbing`.

All three are defined once in `index.css`. A press on the empty field taps exactly once per press, with one mark set and one sound, and the drag trail is removed. Each playmat taps with its family's mark and sound, looked up in one `TAP_FAMILY` table that falls back to `sand`. The six new `tap*` SFX ids use the same rapid path as `sand`.
