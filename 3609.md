     - `Object.is(prev, next)` returns `next`.
     - Arrays: if `prev` is not an array, return `next`.

       - For each `next[i]`, the partner is `byId.get(item.instanceId)` when `item` has a string `instanceId`, else `prev[i]`.
       - Map each item to `shareEqual(partner, item)`.
       - Return `prev` itself when the lengths match and every mapped item `=== prev[i]`; else return the mapped array.
       - Pairing by `instanceId` is what keeps the later hand cards identical when an earlier one is played.
     - Plain objects (non-null, non-array `typeof "object"`): if `prev` is not plain, return `next`.
       - Map each key of `next` through `shareEqual(prev[key], next[key])`.

## Risks

- **Identity.** Sharing makes equal cards the same object across views. No code compares a card's identity across views (a grep found none), but run the whole web suite. Also check that no test asserts `toBe` on the `view` a child received. The root stays a new object whenever anything was shared. A first view and a changed viewer return the incoming object itself.
- **Events.** `newEventsSince` returns events by identity, and the sound director matches the runner's entries that way. Sharing `events` could reuse an old event object for a new equal one, so only `you`, `opponent` and `trades` are shared.
- **Hidden information.** The share reuses only objects deep-equal to ones the same viewer already received, and it skips a viewer change. Nothing new reaches the client.
- **Stale draws.** A card skips a redraw only when every highlight key it reads is unchanged. If a test shows a stale `data-*` attribute, a read is missing from `sameHighlightAt`; add it there with a test.
- **Residual redraws.** If test 1 shows some card still redrawing, log which key differs inside `sameCardProps` (a prop or a `Card`-read context), fix that cause, and keep the test.
- **Purity.** No Rust crate changes, so rule 4 is unaffected. No new numeric constants (rule 9).
