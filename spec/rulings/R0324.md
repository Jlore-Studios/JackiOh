A code this browser holds no verifier for was opened on another device or browser, or after its storage was cleared. The provider sends a code only after it has confirmed the address, so `/login` says "Your email is confirmed. Sign in to continue." rather than showing an error; a reset link opened there cannot be used, and the forgot-password form asks for a new one. A code the provider refuses (spent or expired) reads as [[R193]]'s spent link, with its ways forward. A link mailed before the switch, or mailed to a browser that could not hash (no `crypto.subtle` outside a secure context, where the mailer sends no challenge), carries the implicit flow's tokens in its fragment and is read exactly as before. The Supabase project's Site URL (`https://jackioh.vercel.app`) and Redirect URLs (`https://jackioh.vercel.app/**`, `http://localhost:5173/**`) are dashboard settings, listed in docs/architecture.md's bring-up checklist
