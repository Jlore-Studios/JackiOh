title: A card of a set that ships names no card of a set that has not
cards: "§5, R279, R388, R646, R1240, R1420, #95, C+ #73, Meditative #95"
proven_in:
  - crates/cards/tests/cross/references.rs
---
[[R279]]'s `refs` of a card of a set that ships leave out the cards of a set that has not shipped ([[R1420]]), which no player meets, and its proof reads the texts so. So the "Call to Chaos" #95's and C+ #73's texts print names Meditative #95 ([[R1240]]) only once the Meditative set ships: until then neither lists `meditative-095` in its `refs`, and the patch that ships the set adds it to `core-095`'s and `classicplus-073`'s, claimed by that patch's fragment ([[R646]], [[R388]]). A card of a set that has not shipped lists every card its texts name, of any set: Meditative #95's `refs` name #95, C+ #73, itself and its tokens.
