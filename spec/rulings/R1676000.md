**Why.** The card statistics' development source ([[R378]]) was the gather lane's `cargo jackioh stats` run, one game at a time on the training box, which is being given back to the night bot (#682's audit). The learn lane plays the same kind of game, AI against AI on [[R258]]'s All Random deals at the browser's budget, 100,000 a week, and exports it ([[R1006001]]).

**The command.** `cargo jackioh stats from-selfplay <log>… --out <file>` files each game of the `selfplay` files named as one development record ([[R378]]), one per line, in the order the files are named and the games read. `stats report`, `stats report --games` and `jackioh-server stats-import` read the file as they read a `stats --out` file.

**What it leaves out, each counted.** A game is folded from its seed under the catalog it was played on and its final hash and result checked, as `positions` does ([[R767000]], [[R1006003]]). It files nothing, and the run's counts say why, when:

- the line is not a game (`unreadable`);
- it was played on a catalog version this build neither is nor carries (`earlierPatch`);
- it ended without a result (`noResult`);
- its self-play run marked it with faults, an action refused, a fallback or a caught panic ([[R1489000]]; `unclean`);
- an action of its log is refused, or the fold reaches another hash or result (`notReplayed`).

A run that files nothing still ends well and prints `filed: 0`.

**The record.** `source: "dev"`, `mode: "random"`, both pilots `ai`, the game as `summarize_game` reads it off the log ([[R376]]) and the patch the game's catalog names as it is named now ([[R1371000]]).

**Its build** ([[R1367000]]) is the commit and the AI generation the log carries; a log written by a binary without git (`unknown`) files no build, and a line without a generation files the commit alone. No git history is read, so every checkout writes the same file from the same logs.

**Its id** is `dev:<patch>:selfplay:<seed>`, the seed being the export's `<base>:<n>`. `stats --series` refuses a series that begins `selfplay:`, so no `stats` run files an id of this shape, and it differs from the gather lane's `dev:<patch>:gather:<n>` and the arena's `dev:<patch>:arena:…` by what lies between the patch and the game number. It never reads as a forced run's ([[R1284000]]), so `stats-import` takes it. The command does not deduplicate: a shard is named once.

**The order.** Records are folded in parallel and written in game order, so the file is byte-identical whatever the thread count, like `selfplay`'s own.

Rejected: filing the id as `dev:<patch>:<seed>`, as `stats` files it, which collides with `stats --series <base>` since `selfplay` allows the bases `dev` and `gather`; reading the AI generation of the log's commit from git, which makes the output depend on the checkout; counting a game that files nothing as a failed run, which would stop a weekly export for a patch that outgrew its games.
