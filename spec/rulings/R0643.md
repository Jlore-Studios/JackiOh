An emote is a top-level client message `{ type: "emote", emote }` — `emote` one of ten ids, the five voice lines `greetings`, `wellPlayed`, `oops`, `thanks`, `threaten` and the five shared emoji `sob`, `yawn`, `laugh`, `angry`, `wahWah` — never an `ActionBody`, so it reaches neither `reduce`, the action log, the replay hash nor a game record; an unknown id is `malformed`. The actor relays it to the opponent alone as `{ type: "emote", from, emote }`, and the sender sees their own locally without waiting. Both ends enforce one limit out of one shared configuration — 1.5 s between a player's emotes and at most 5 in any rolling 20 s, the client's greyed menu items and the server's drop reading the same values — and a rate-limited emote is dropped silently: no error, and it does not count toward the rejected-action alert. Practice and hotseat run the same limit locally. One emote per player is on screen at a time, a new one replacing that player's own at once. Clicking the opponent's portrait when it is not a legal target opens the hero's inspect view ([[R1330]]), which holds a one-item "Mute emotes" menu that hides and silences that player's emotes for the rest of the match, and the device's "Mute opponent emotes" setting mutes every opponent in every match
