A face-down play and a summon landing face-down both place the card in its controller's backrow still face-down ([[§10.5]] step 4 places every arrival, [[R227]]), emitting the one arrival event — so one trigger on it answers each set exactly once. Face-up arrivals never answer it ([[R61]]).
