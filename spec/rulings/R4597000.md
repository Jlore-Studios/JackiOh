The release (issue #4597) turns the browser's content, the WebAssembly module's `assault_content()`, from `assault_placeholder_content` to `assault_catalog_content` over the build's catalog ([[R4579001]]): the set's cards by tag and the twelve Commanders of `assault.json`. `assault_content_at` ([[R3496000]]) answers a carried version with the same content, the build's own. A patch's snapshot holds only the sets that ship ([[R1420]]), so no carried catalog holds an Infinite Assault card, and the Assault's content is that set's cards alone. Answering from the carried catalog would deal an empty day, and an attempt left open across a daily patch would no longer fold ([[R4581000]]). Answering the placeholder was rejected too: until the release no production build served `/assault` (`ASSAULT_OPEN`), so no player holds an attempt dealt from it.
