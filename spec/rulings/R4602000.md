IA #236 is named "Infinite Assault", so every "Infinite Assault card", "Infinite Assault Unit" and
"Infinite Assault Spell" in a card's text would name it under [[R279]]. None does: the phrase is
[[IA11]] rule 5's set-named pool ([[R4577000]]), which reaches the set while it is held, holding the
card's name without naming it, as [[R961]]'s "Jade Counter" holds "Jade". The three phrases join
`RULES_PHRASES`, so neither IA #1's refs nor IA #236's own hold `infiniteassault-236` for them.
