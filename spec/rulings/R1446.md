#97 Zephyrs and C+ #27 Zephrys Zealotism draw on one pool: every non-token card of every set that ships, a pool that names no set ([[R380]], [[R1420]]), less the asking card's own definition ids, a fused card's ingredients included ([[R387]]). Until patch v0.3.6 they printed "from the Core set" and "of Classic and Classic+ cards", as the source notes read (*only from the core set*, *only using cards from Classic & Classic+*); the designer widened both in issue #577, so neither card lists a set and a set joins both pools the day its release adds it to `SHIPPED_SETS`, with no change to either card. A set the catalog holds before it ships stays out until it ships, as in every pool that names no set ([[R1420]]). Zephyrs may offer Zephrys Zealotism and Zealotism may deal Zephyrs: each leaves out only its own ids. Tokens stay out ([[§5.1]]). Nothing else changes: the dry-run scoring and its weights, Zephyrs' top 3 and its exile ([[R29]]), Zealotism's hand size and Refresh ([[R416]], [[R364]]), the faces (Radiant picks score and arrive on the Radiant face) and the tie-breaks. An index now repeats inside the pool ([[§5]]), and #97's last tie-break, the id, settles it, as Zealotism's ties by id already did.
