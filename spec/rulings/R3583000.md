The map was rows of 2 or 3 nodes, any of which the player could step onto from any node of the row below, so every route held the same fights and no path was chosen. Issue #3583 makes it a path map, as the mode's model has (the plan's DR0: a run in the style of Slay the Spire): each step closes off the paths it does not lead to, and the bosses are choke points every path passes through. The issue sets the shape; this note settles what it leaves open.

- **The walks.** Each act's `RUN_MAP_PATHS` walks start on distinct columns, shuffled from the grid's, so each act's first row holds exactly that many starts. Each step goes to the column left, the same or right, picked from those that cross no edge an earlier walk took between the same two rows. Going straight up crosses no edge, since no edge spans more than a column, so a step always has a choice. Every node a walk visits and every edge it takes is kept; two walks on one node merge there.
- **The bosses.** A boss's lone node stands on the grid's middle column. Every node of its act's last row leads to it, and a mini-boss leads to every node of the next act's first row. These fans are the only edges wider than a column, and none of them crosses another, since each fan shares its boss.
- **Edges by index.** A node's `next` holds the indices, in the next row, of the nodes it leads to, and its `column` its place on the grid, for drawing. `Go`'s `col` stays a node's index in its row, as the fight's seed (`"{seed}-{row}-{col}"`, [[§15.6]]) and the screens' ids do, so neither changes for a sparse row.
- **The step.** Before the first step any node of the first row may be chosen; after it, only one the node stood on leads to. Any other is refused with "no path leads there from here", the run unchanged (`run_next_cols` names the open ones).
- **A kept run.** A run kept from before this change is folded on the map its seed deals today. It ends lost at its first refused step and banks what it had extracted, as any run that does not fold does ([[R3496000]]); one whose every step that map accepts plays on.
