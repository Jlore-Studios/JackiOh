title: "No self-play export plays a training gate's hold-out deals or the improve lane's dev set (issue #1006)"
cards: "§9.9, R850001, R1006001"
proven_in:
  - crates/tools/src/selfplay.rs

`cargo jackioh selfplay` refuses a seed base that names a training gate's hold-out deals (`improve`, `unban` or any lane's name, alone or followed by `:`, as `arena` refuses one, [[R850001]]) or the improve lane's dev set (`improve-dev`, alone or followed by `:`), whose deals every screen plays. A network fitted to games on those deals would be measured on the games it learned from: its screens and its gate would read higher than it plays. Any other base is allowed.
