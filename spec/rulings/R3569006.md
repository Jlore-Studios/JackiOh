The designer's list asks that Bob's Plan get "a custom card" for S+ #79. That card is a later issue's to design, so Bob's Plan's plan table ([[R1185000]]) names the one card that answers what #79 costs its owner: Core #75 Infinite Reserves, whose "Drawing from an empty deck gives you a Rush Token card instead of fatigue" is what the exiled deck needs. The table's line is for S+ #79 and reads one plan, so there is no Discover, and the plan is added Radiant on the Radiant face as every plan is. #79 is a card of the held set, so no pool that names no set offers it ([[R1420]]) and the line changes no game until the set ships; Bob's Plan's printed text and any custom card are the release's.

Rejected: a new catalog card for the plan now (a catalog change of a shipped card's text for a held card, and a design nobody has asked for yet); and no plan at all (a Bob's Plan that picked #79 would hand a deck-exiler no answer to fatigue).
