The practice setup's Play today's deal ([[§9.9]]) starts a free game on the deal of the UTC day it is clicked in, which changes at midnight UTC: the seed `daily-` and the day (`daily-2026-11-03`), the human in p1 on an even UTC day counted from 1970-01-01 and in p2 on an odd one, so the seat alternates every day, month ends included, and a fresh random deck leaning on the setup's "More cards from" pick ([[R1373]], [[R924000]]) at the setup's difficulty, whatever deck the picker shows. A sandbox, a custom card and the e2e fixture pool never apply to it.

Both decks are dealt from the seed as every practice game's are ([[R433]]), and the game brings no last board ([[R508]]), so players who pick the same difficulty and pick on the same catalog version are dealt the same game, and the AI, whose budget counts `reduce` calls ([[R2575000]]), decides the same on every device where `PRACTICE_AI_CLOCK_MS` cuts no decision short. The config marks the game `dailyDeal`, which survives a reload ([[R668]]), so Play again deals the day's deal again, the new day's after UTC midnight. It is a free game, not a mode: it is saved, kept, replayed and downloaded as any free game is ([[R668]], [[R768]], [[R1141000]]), and a catalog change never deals it again under new cards: a game in progress saved on another catalog version is dropped by the save's rule ([[R668]]), and a kept game of an earlier day replays from the setup it kept ([[R767000]]).

It asks for no server seed and earns nothing: [[§14.8]] pays only a game on a seed the server issued to that account ([[R1303000]]), and a seed every player shares cannot be issued to one.

Hearthstone semantics: a Tavern Brawl deals every player the same setup for its run, on a clock all share.

Rejected: earning on the shared seed (it needs a daily seed issued to each account and a migration, which issue #2882 rules out); a random seat (two devices would play different games); always p1 (the human would never go second); the day of the month's parity (two odd days fall together at a month's end); switching off the AI's clock for the deal (a slow device could stall); a fixed difficulty or no lean (the issue asks for the player's own).
