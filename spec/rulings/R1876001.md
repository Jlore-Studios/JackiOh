"Activate your Universities" ([[§8.10]] Stinkyscape #26 ZolarKeth's Activate) runs, for each University its controller has acting on the field (unit tops in lane order, then the Units standing in the backrow), that University's Activate as an effect of ZolarKeth's ability (`run_activation`): the University is the effect's `self`, on the face it wears, so it Buffs each of *its* other permanents its own `times` ([[R386]]), ZolarKeth among them. No cost is paid and no use is spent: a University that has not used its Activate this turn may still use it, and the one whose own Activate is refused ([[R1876000]]) runs too (ST-S17-4). It is no play and no activation of the University's ([[R384]]): no `activated` event names it. An ability that declares a target or a mode is never run this way, having no choice to run with; a University's has none. The Universities are read as the effect reaches them, so one a Buff before it made Radiant or raised runs as it now is. The base face chooses between this and "summon a random Starship Piece" (two declared modes, [[R81]], [[R1878000]]'s pool narrowed to Units); the Radiant face does both, the piece Radiant and summoned first, so the Universities Buff it too. Rejected: running the ability as ZolarKeth's own text, which would read ZolarKeth's numbers and leave the University out of "its other permanents".

Amended by [[R2521003]] (issue #2521): ZolarKeth's run now spends one of each University's uses and passes by a University with none left this turn, so each University Activates at most once a turn, whether by itself or by any ZolarKeth.
