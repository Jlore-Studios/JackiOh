An "Activate N" that Buffs stepped, or KY's Constant set, past `ACTIVATE_UNLIMITED_CAP` (100) is used at most that many times per card per turn, as "Activate ♾️" is ([[R384]]). Its number still reads as tuned, and a Nerf counts down from the tuned number: only the uses are capped, and the Buff menu is unchanged. M #97.6 University's `times` is never above 5, its Radiant value. A Buff steps the base face's 2 up to 5, and at 5 the Number row offers it nothing, as YileGPT Unleashed's `picks` stops at 5 ([[R386]]).

Why: each use Buffs every permanent on its controller's side `times` times, University among them, and a Buff can step both University's own Activate N and its `times`. So every use funded more uses and more Buffs per use. A use gained mid-turn is usable that same turn, as in Hearthstone a Garrison Commander played after the Hero Power's first use allows a second use. On the old rules, a probe of a University on its third turn of uses reached an Activate N of 33,724 and a `times` of 33,807 by the 35th use, both still growing by about a third per use, and that one use took 8.9 s. Batch 18's game (`docs/v0.4.0/README.md` §5.8) never ended for this reason. With both bounds, the same probe stops at 100 uses with `times` 5, and every later turn does the same.

Rejected: (a) fixing the turn's uses at the count the first use saw. That is not Hearthstone's rule, and N and `times` would still compound from turn to turn, so it only delays the stall. (b) The cap alone: 100 uses in one turn would still multiply `times` by about a third per use, far past any number a turn can resolve. (c) A ceiling on every declared number, which would change every card to fix one. (d) Taking Activate off the Buff menu once its N reaches the cap: that changes the draws of any game with such a card, and the cap already bounds what the number can do.
