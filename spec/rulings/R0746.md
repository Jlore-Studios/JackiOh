The designer's comment (MaxGoetzmann, #354): balance patch 1 applied Bounce too widely, using it as shorthand for adding a card to its owner's hand from a zone that is not the field. Bounce is a permanent's return from the field ([[R692]]); #17 Flood, C #22 Mid Runner and C #14 Shadowstep were named as right, and C #66 EU Striker and #52's Radiant face, which return a card from the field, keep it too. Every face that returns a card to hand from anywhere else says "Return … to hand" again, as before patch v0.2.10: a Spell after it resolves or at the end of the turn (#23 Reoccurring Dream, #24 Efficiency Dividend, #31 KY's Math Equation, C+ #14 Forever&'s grant, C+ #21 Whirlwind's Radiant face) and a card from the graveyard or exile (C #34 Ancient Acquisition, C #47 Recurring Felinor). The face says "to hand", never "to your hand" ([[R366]]). Text only: each return keeps its semantics ([[§5.1]]'s `returnToHandAtEndOfTurn`, [[R684]]'s random draw, [[R68]]'s graveyard trigger, C+ #14's enchantment)
