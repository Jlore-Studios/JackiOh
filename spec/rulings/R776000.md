A server action a clock's expiry becomes ([[R79]], [[R268]]) whose row the store fails to write is tried again `MATCH_SERVER_ACTION_RETRY_MS` (1 s) later, and at that pace until it lands, the match ends or the actor stops. The clock that ran out runs out once more, and the action is derived again from the state then, stamped as [[R146]] stamps it. Its nonce `srv-<kind>-<seq>` stays the same while no other row has taken that seq. Whatever would stop that clock stops the retry too: a new turn, the prompt answered, the mulligans closed, the player back inside the grace, or the game over. Each clock holds one countdown, so one expiry is never logged twice.
The log answers a nonce it already holds at the same seq with that row and writes nothing, so a write that committed and whose answer was lost lands once. A row under another nonce at the seq the actor is about to write, or the actor's nonce at another seq, means the log has moved past the actor. The actor then lets go as [[R1437]]'s does, and the next socket rebuilds it by folding `(seed, log)` ([[§9.5]]), the missed row included. The action that met the clash is answered `internal` and not applied.
