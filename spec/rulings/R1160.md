One Buff or Nerf application on a card whose text makes Buffs or Nerfs N times as effective
(Meditative #84 Volatility, ME-TUNEMULT) is still one application: one row drawn ([[R442]]) and
one `upgraded` or `degraded` event, with the change N times as large. The cost row moves N steps (a
Nerf never above (4), a Buff never below (0)); the stats row splits N times the usual total; the
keyword row adds N different keywords the card lacks ([[R21]]'s pool) or removes N of its own
(never a harmful one), reported as `keyword` plus `also`, which is absent when one keyword moves;
an X moves N steps and a declared number N steps, each recording only what moved, so what a bound
refuses is lost. One event reports the whole change, so [[R440]]'s count of applications over a
hidden pile is unchanged. The multiplier is the running face's `tune_multiplier`, read in every
zone (field, hand, deck); a Vanilla card has none; a fused card's multipliers multiply ([[R102]]).
"Buffs" and "Nerfs" are the verbs only: a stat buff ("+2/+2") and KY's Constant are not multiplied.
