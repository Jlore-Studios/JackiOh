A custom card ([[§12]]) has no Rust script: its script is its creator's Luau, run by the Luau host, not the game's own code, and it is never in the catalog ([[R915000]]), so `crates/cards/build.rs` counts nothing for it. It has no code lines ([[R1846000]]: `code_lines_of` answers none for a custom id, whatever a table lists), it is neither BUSTED nor complicated, and no pool that asks for either finds one, as no catalog pool finds a custom card at all. It has no code block either ([[R1183004]]). A custom card's script may still ask for either pool, since the card kit's `J.query` and `J.pool` take the same query, and draws catalog cards from it.

Counting a custom card's Luau lines was rejected: a custom card is made after the build, so no compiled list can hold it (CLAUDE.md rule 4); its creator could make it BUSTED by padding its source; and a Luau line is not a Rust one.
