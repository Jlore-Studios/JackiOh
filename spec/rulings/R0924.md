## R924 — A face-down card passes its chooser's tag filters, then fizzles if it fails one

Built. A declared target that names a tag offers a face-down card its chooser cannot read whatever
its tags, so the picks reveal nothing about the opponent's armed cards — the only place the engine
lets a choice through a tag filter it would fail. Nothing else changes: the Jlockeed wording on
Core #2 and Classic+ #78 stays as printed, and M #35 tests the fizzle.

As built: only the tag check is skipped for such a card — the type check and everything else
still apply — and a target that carries the barred tag when the effect resolves fails its filter
and fizzles ([[R129]]'s shape for declarations).
