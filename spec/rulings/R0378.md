An internal AI development run (`cargo jackioh stats`) plays AI-against-AI games on the build in the checkout and files each finished one as a record of source `dev`, under the patch the run says it tests (the newest in `patches.json` unless it is told another), so a patch's run before it ships and its live games after compare by naming the patch in two queries, one of development data and one of live data. A development game is an All Random game ([[R258]]): both decks dealt by [[R258]]'s deal from `${seed}:p1-deck` and `${seed}:p2-deck`, both seats AI on this spec's resources (no handicap, [[R180]]) at the browser's budget, its seeds a series of their own that no gate or tuning run plays. A card the shadow ban keeps out of the AI's own decks ([[R186]]) is dealt like any other, and the AI is known to play it badly, so its development figures say more about the AI than about the card. Live data is the default and development data is never mixed in unless asked for: a query reads `live` unless it names `dev` or `all`, the source is kept beside every record, a development record's id is `dev:`, its patch and its game's seed (`dev:v0.2.5:dev:7`) where a live one's is its match id, so neither can take the other's place and the same seeds run for another patch are other records, and `stats-import`, the one way a run's file enters the database, refuses a file holding any record but a development one, writing none of it, and skips a game already imported
