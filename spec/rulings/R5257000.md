FvH #105 Maddended Felinor's Cry reads "This attacks each other Unit, one at a time in a random order" (Radiant: "each enemy Unit"). The owner's call of 2026-11-28 (FV2 #105) makes the order random and the run end with the Felinor.

**The rule.** As the Cry resolves ([[R1]]), the Units it will attack are read once: every Unit acting on either side's field but itself (Radiant: every Unit acting on the enemy's), Dormant cards being none. They are put in a random order by the match rng ([[R60]]), drawn as the effect resolves, never as the hook builds it, so a pause inside the run resumes over the same order. Each in turn is a forced attack ([[R53]]): no exertion spent, position, sickness and Taunt waived, its own combat and its own state check, the target striking back. On the base face its own side's Units are attacked too, the forced attack's side test waived ([[R5238012]], against [[R173]]); the order is the random one, not the enemy's Units first. A Unit that has left the field by its turn is passed by ([[R174]]), and once the Felinor dies or leaves the field every attack left is passed by, so the run stops there; a body Reborn returns is a new stay and attacks nothing. A Unit summoned during the run is none of those read and is not attacked.
