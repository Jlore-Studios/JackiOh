The power is stored on the instance (`memory.power`). Through v0.5.11o, at start of game every Heroic Power in either player's hand or library rolled its power, including one the mulligan returned; one created later rolled when it was created, and one that ended up in a hand or library with no `memory.power` (a bounced or reset instance, [[R78]]) rolled as it arrived ([[R151]]). Since issue #3134 the card's Cry Discovers its power as it is played, a copy in a hand or library has none, and only a copy that reaches the field with no Cry rolls one as it arrives ([[R3134002]]). Since the Heroic Power patch ([[R752]]) the card costs (0), playing it uses nothing, and each power is one of its Activate abilities, used once per turn for the power's X ([[R384]]); `activatePower` is an alias of the `activate` action that names the power the card rolled, kept so old logs replay. Expedition Map's "Recruit a permanent" is [[§6.3]]'s Recruit
