The power is stored on the instance (`memory.power`). At start of game every Heroic Power in either player's hand or library rolls its power, including one the mulligan returned; one created later rolls when it is created, and one that ends up in a hand or library with no `memory.power` (a bounced or reset instance, [[R78]]) rolls as it arrives ([[R151]]). Since the Heroic Power patch ([[R752]]) the card costs (0), playing it uses nothing, and each power is one of its Activate abilities, used once per turn for the power's X ([[R384]]); `activatePower` is an alias of the `activate` action that names the power the card rolled, kept so old logs replay. Expedition Map's "Recruit a permanent" is [[§6.3]]'s Recruit
