A practice game earns the XP the same game would earn on the ladder, times `XP_PRACTICE_SCALE`
([[§14.8]]). The ladder amount is worked out first, capped at `XP_GAME_CAP`, and the product is
rounded down to a whole number of XP, so a practice game never earns more than the same game on
the ladder and the cap holds. The reward hook ([[§14.8]]) takes the game's mode, so the practice
sub-issue pays through the same function; its Jlore is `JLORE_PRACTICE_WIN` for a win and
`JLORE_PRACTICE_LOSS` for a loss and a draw ([[R1302000]]).

Hearthstone semantics: Hearthstone's XP is a whole number; rounding down never pays beyond what
the spec's scale gives.
