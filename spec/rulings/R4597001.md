A deck may hold no card of a set that has not shipped ([[R1420]]), and a single-player set never ships ([[R1846001]]). An Assault enemy's deck is the Infinite Assault's cards ([[§16]]), so the release lets a seat hold a card of an open single-player set (`SINGLE_PLAYER_SETS`, a `SinglePlayer` row of the set table) when the game's setup names that set among the sets the seat's deck is dealt from (`deckSets`, [[R4595000]]): the Assault's fight names it for P2 (`AssaultFightSetup.enemy_sets`). A seat that names no such set is checked as before, so no saved deck, practice deck or random deck holds the set's cards, and a held set (`HeldSinglePlayer`, [[R4577000]]) stays out of every deck whatever a seat names. This amends [[R1420]] for the seat that names the set and no other.
