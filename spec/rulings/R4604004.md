Like those of [[R4508005]], some of the game's own rules run inside a Spell's run with no marker of their own, and the fuzz monitor's I21 (issue #4508) blamed them on the Spell.
**The state check's deaths.** [[§4.5]] destroys every Unit at 0 health or less, whatever doomed it. When an earlier run of the step did (a Burn tick, an attack, TG #30 Floodgates' Death), the deaths can land after the next Spell's marker. Now I21 allows a `destroyed` in a run that began after another card's marker, an attack, a turn edge or the AI's turn, or one the step resumed. A `destroyed` in a Spell's own first run of the step is still a reach.
**Exile auras.** S #115 Scornboi's aura exiles every Unit that is neither Human, a Starship Piece nor a Starship at each state check ([[R1850002]]). That is a rule standing on the board, not a Spell's effect. Now I21 allows an `exiled` while an exile aura stands, as the step begins or ends or from the arrival of a card that carries one: its `summoned` or `cardPlayed`, or a `transformed` into it (in the wave on 823 cards, S+ #104 Tireless Cultivation turned a Drone into Scornboi). S+ #77 Black Hole's pull at a turn's end, which swallowed an immune Unit in a hand Spell's run in one of this issue's seeds, is [[R4577008]]'s, which reads it more narrowly (the ended player's side, a lane next to the hole) and [[R4604007]] extends to a hole opened in the step, so this note allows no exile for an open hole alone.
**A Burn tick a Divine Shield takes.** M+ #7 Life Mage's Divine Shield takes a turn-end Burn tick whole ([[§4.4]] step 1), so the tick shows as `divineShieldLost` and then the Burn's removal, with no `damage` for R4508005's reading to see ([[R4154000]]). Now I21 allows a `divineShieldLost` right before its Unit's Burn removal, and that removal.
Rejected: tracking which run doomed each Unit, which the events do not carry. Judging a death only in a run no earlier run of the step could have doomed is looser, and it is the most the events tell.
