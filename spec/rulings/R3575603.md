The shadow-ban sweep banned Stinkyscape+ #47 Plastanium for a `timeout` ([[R977000]]) that came from another card in its deck. In pass 1's game `sweep:easy:stinkyscapeplus-047:4`, turn 12, the AI held Classic+ #47 Jogg's Box. Its random casts can cast Classic+ #27 Zephrys Zealotism, whose perfect-hand scorer ([[R29]]) dry-runs every shipped card's every play: 0.2 to 2 seconds on that board, inside one simulated step. The AI already charges such a step extra nodes ([[R1240]], #1347). But the lethal solver and the beam take the same first step on the same world, and lines are scored again, so the decision ran the same Box play, with the same random draws, up to four times: 39 s raw, 2991 ms on the sweep's yardstick against its 2000. No Hearthstone rule is involved: the search's choice does not change.

**What it does.** The decision's root counter keeps a memo (`SimMemo`) of the steps it simulated that it charged more than their one node for (`surcharge_nodes` or `announced_surcharge_nodes` above 0), at most `AI_SEARCH.memo_steps`, each with the state it stepped from, the seat and the action. A later `simulate` of the same action by the same seat from a state equal to a kept one, but for the nonce record (`GameState.applied`), takes the kept answer. A step is a function of its state and action: its draws read the state's seed and cursor (CLAUDE.md rule 4), under its game's pool hold ([[R2201001]]), and nothing in a step reads the nonces before it, which only the dedupe asks. So the kept answer is the one the engine would give. Its nonce record is rebuilt as the engine's `remember_nonce` builds it: the input's record, then this step's nonce with the events it produced, the oldest dropped past `NONCE_HISTORY`. The step is charged the same nodes as when it ran, so the search walks the same nodes and reaches the same decision ([[R186]]). On Plastanium's slow position the decision fell from 39 s to 20 s raw, and the sweep's re-timed decisions read 1711 and 1717 ms.

**What it does not do.** It keeps no cheap step, whose run costs about what a lookup does; no step from another decision; and no step from a world that differs in anything but nonces, another determinization's hidden cards among them.

**Rejected.** Loosening `AI_SWEEP.decision_ms`; charging the Box more nodes, which would change the search and still run its first scorer in full; skipping random casts in the simulation, which would misjudge every such card.
