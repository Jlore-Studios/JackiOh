A token is one by four signals, and they always agree: `token: true`, rarity Token, the Token tag and its row in [[§7]]. The catalog test holds every entry of every set to that, so a token a new set brings is held to it too, and a fused card carries the tag exactly when it is a token ([[R1177000]]). The client labels a face by `token`.

Every face of a token says Token, as a Magic token's type line does. A full face's type line prints the word before the type, "Token Unit", "Token Spell", "Token Field Spell" (on a Chinese face 衍生物 before the table's type, [[R1301]]); the tag row prints no Token chip, since the type line says it and a crowded row (Meditative #45.1 and #49.1's four tags) cut the chip off its end. Where the type line does not show, on a face under 150px (a small hand, the phone) and a full-art face ([[R1017001]]), the face wears a token mark in its place, a small plate reading "Token", or its first letter on a face 72px wide or less, and the board minion wears the mark under its name plate, between its attack and health. The compact face of a face-up backrow token keeps its type line and so its label. A token that prints a rarity keeps that rarity's frame, gem and crest ([[R503]]) and still says Token on its type line or mark; the Almanac names it "Token, printed Legendary". Glitch stays blank ([[R674]]): every word on it is corrupted, so it wears neither. The Created mark ([[R943]]) is unchanged, a token in play wearing both.
