A token is one by four signals, and they always agree: `token: true`, rarity Token, the Token tag and its row in [[§7]]. The catalog test holds every entry of every set to that, so a token a new set brings is held to it too, and a fused card carries the tag exactly when it is a token ([[R1177000]]). The client labels a face by `token`.

A token's full face says Token, as a Magic token's type line does. A full face's type line prints the word before the type, "Token Unit", "Token Spell", "Token Field Spell" (on a Chinese face 衍生物 before the table's type, [[R1301]]); the tag row prints no Token chip, since the type line says it and a crowded row (Meditative #45.1 and #49.1's four tags) cut the chip off its end. Where the type line does not show, on a face under 150px (a small hand, the phone, most face-up backrow cards), a full-art face ([[R1017001]]) and the board minion, nothing marks it: the hover preview's full face says it on its type line ([[R2647000]], which took off the token mark this ruling first gave those faces). The compact face of a face-up backrow token keeps its type line where it shows, widened to the face's width since a compact face has no stats in its corners. A token that prints a rarity keeps that rarity's frame, gem and crest ([[R503]]) and still says Token on its type line; the Almanac names it "Token, printed Legendary". Glitch stays blank ([[R674]]): every word on it is corrupted, so it wears no label. The Created mark ([[R943]]) left the faces with the token mark ([[R2647000]]).
