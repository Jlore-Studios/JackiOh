The owner asked for the shipped v0.5 line to be named by the tiers the classifier gives now ([[R2455000]], [[R2499000]]), so a patch number moves only when the cards' statistics broadly do ([[R1367000]]). Only the v0.5 line is renamed. v0.1.0 to v0.4.12d keep the names [[R1371000]] gave them. This overrides [[R1973001]]'s rejection of a second retcon and the history clause of [[R2455000]].

- **The map.** `cargo jackioh patches retcon --from v0.5.0` computes it, never by hand. Every version before v0.5.0 keeps its name, tier and plays. From v0.5.0 on, each takes the tier `patches ship` would name now ([[R1366000]]): its snapshot against the one before it, the families its record plays, and a rule every game meets where `--rule` names one. No record holds a rule's reach, so the three v0.5 patches that were patches by a rule alone were measured: stage 2 ([[R1365000]]) was replayed against the base build of each one's shipping commit, with its early stop off. v0.5.6 diverged without a card in 1 of the 200 unforced games, v0.5.8 in 1 and v0.5.10 in 2, all short of the 50 a rule needs ([[R2455000]]), so `--rule` names none.
- **The names.** v0.5.0 v0.5.0, v0.5.1 v0.5.0b, v0.5.2 v0.5.1, v0.5.2b v0.5.1b, v0.5.3 v0.5.2, v0.5.4 v0.5.3, v0.5.5 v0.5.4, v0.5.6 v0.5.4b, v0.5.6b v0.5.4c, v0.5.7 v0.5.5, v0.5.8 v0.5.5b, v0.5.9 v0.5.6, v0.5.9b v0.5.6b, v0.5.10 v0.5.6c, v0.5.10b v0.5.6d, v0.5.10c v0.5.6e, v0.5.10d v0.5.6f, v0.5.11 v0.5.7. Ten patches became six.
- **Scheme 3.** Old and new names overlap (the old v0.5.7 is Training Grounds' release, the new v0.5.7 the old v0.5.11), so `VERSIONS_SCHEME` is 3. A file names its versions by its marker: none is scheme 1, the names before [[R1371000]]; `versions: 2` is the v0.5 line as it was before this retcon; 3 is today's. `patches/aliases.json` keeps scheme 1's map, now to today's names, and adds `marked`, each older marked scheme's renamed names (`"2"`, the 17 above). A reader maps a name of an older scheme once (`version_name_from`, `versionNameFrom`): a game record, a self-play game, a `replay` or `think` input, a practice save or kept game, and a downloaded replay, whose format version is its scheme (3 now; a file of 1 or 2 still opens when its name maps to the live version).
- **What moves.** In the repository: the snapshots, the win-rate tables, the card lists, `patches.json` (each version's tier and plays), `shipped.json`, `index.json`, `technical.json`, every catalog-version site, and the string literals and data files that spell a v0.5 name, the carried scripts' versions ([[R767000]]) among them. In the database: migration 0068, generated from the map, renames every stored catalog version as 0049 did, and `game_totals` (0063) besides. Records outside the repository: `patches retcon --records <dir>` reads a directory marked `.jackioh-versions-2` as scheme 2 and marks it 3.
- **The deploy.** The first 0068 renamed each record id that a card's co-played map keeps with a PL/pgSQL call per id, over every row of `card_totals`. On production's season of totals, Render's `release` ran past its boot window on every deploy (issue #2548, fixed by issue #2625), the transaction rolled back each time, and the server stayed on the old v0.5.11, with every later version held back with it. 0068 now renames a text in one pass per name it holds, and touches only a renamed version's rows: a record names its own version, and its id names a series of that version or an earlier one. On a copy of 40 patches of totals it runs in 35 s, where the first took over 7 minutes, and it renames every value exactly as the first did (2,537 strings compared). The migration runner's `REWRITTEN` accepts the first checksum where a database applied it.
- **Not renamed.** Docs, comments, commit messages and the older issue and pull request titles keep the names they were written with. `docs/issues-and-patches.md` holds the map to translate them.

The new names reuse old ones: v0.5.7 now, and v0.5.8 to v0.5.11 as later patches ship. A tab still running a bundle of an old version that has not reached the server since the next one shipped passes the catalog check ([[R105]]) while the live version holds its old name. Any request such a tab made since was answered `update_required`, and a file it wrote is marked 2 and read through the map.
