title: Deck size for a handicapped seat

proven_in:
  - crates/engine/tests/rules/handicap.rs

A seat's deck holds exactly its handicap's `deckSize` cards (25 for Medium, 30 for Hard), an AI's dealt from the non-token cards of every set since patch v0.2.0 ([[R380]]), and still obeys [[§2.6]]'s other rules: no duplicate ids and no Token cards. [[§2.6]]'s 20 and [[§9.4]]'s loadout rules govern a player's loadout. An AI deck is never a loadout, so the validator is unchanged and a 30-card deck never reaches a server match
