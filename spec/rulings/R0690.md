Since balance patch 1, a Recruit scan takes the first matching card that is not (X)-cost, and only when nothing else matches takes the first (X)-cost one — recruited, never played, an (X)-cost card would arrive with no X behind it. "Recruit every permanent" leaves (X)-cost cards the same way unless nothing else is valid
