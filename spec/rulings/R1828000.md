Since issue #1828 the Radiant face of Meditative #21 API Key Fishing adds a Radiant API Key Fishing with its end-of-turn line, where [[R805]] added a base one. It is no exception to [[§5.2]]'s rule that a generated card is not Radiant unless said: the Radiant face's text now says it ("Add a Radiant API Key Fishing to your hand"). That face also rolls 4%, and 10% Embiggened (its `chance` and `paidChance`). The base face is unchanged: 2%, 5% Embiggened, and a base copy. The rest of [[R805]] holds on both faces: the line fires from the graveyard on the turn the card was played while the played card stays there, a named card is no pool, and against an empty hand nothing is rolled.

Through v0.4.9 the Radiant face added a base copy; `script_v0_4_9` keeps that for those versions' replays ([[R767000]]). It amends [[R805]].
