A news entry's reward ([[§14.13]]) is one of what the economy already grants, and each kind pays its own named amount:

- **Jlore**, `NEWS_REWARD_JLORE`, into the wallet ([[§14.1]]);
- **a card pack**, `NEWS_REWARD_CARD_PACKS` unopened, the global pack or the pack of a set that ships ([[§14.3]]), into the inventory;
- **a card token**, `NEWS_REWARD_CARD_TOKENS`, into the inventory ([[§14.5]]);
- **a cosmetic token** of a tier the cosmetic token cycle pays, Rare, Epic or Legendary, `NEWS_REWARD_COSMETIC_TOKENS`, into the inventory ([[§14.5]]);
- **a cosmetic pack**, `NEWS_REWARD_COSMETIC_PACKS` unopened, into the inventory ([[§14.6]]).

So no reward holds a token or a card of a set that has not shipped ([[R1420]]): a pack the server cannot sell is refused when the file is checked, as is a Common or Mythic token, a reward of another kind, or a pack or tier named on a kind that has none.

**The default.** The entry's author picks the reward. An entry that names none takes a global card pack when it is a patch that adds or reprints cards, read from its patch's record in `patches.json`: a card `added`, or a card `changed` that plays differently ([[R2499000]]'s reprint). Every other patch and every alert takes Jlore.

**The client** reads each reward in words, its amount past one counted, and computes none.

Hearthstone semantics: a patch or event that brings new cards gifts a pack, and the rest gift gold.

Rejected: the pack of the set a patch touched as the default, since a patch may touch many sets; a reward that grants cards outright, which would skip the packs' roll; and amounts written in the file, which would put numbers outside `config.rs` (CLAUDE.md rule 9).
