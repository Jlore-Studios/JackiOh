Presentation only (CLAUDE.md rule 7): no rule, state, event, endpoint or response changes.

**Why.** The page named only the patch it showed, in its games tile, so a reader on an older patch, or on a new patch's collecting tab ([[R3324000]]), could not tell which patch the game is on now. The owner asked in #3324 for the current patch on the screen.

**The rule.** Beside the page's title, the header shows "Current patch" and a version: the newest version `GET /api/stats/cards` lists (the last version of its newest patch, [[R1973002]]), micro included, since that is the version people play. A server with no list, or the page before its first answer, shows the client's own `CATALOG_VERSION`. It reads the same whichever patch, tab or mode the page shows. It is text, not a control, and stands outside the page's one title.

Rejected:

- The newest patch's name (its first version), which hides a micro the game has moved to.
- The client's `CATALOG_VERSION` alone, which a client cached across a deploy gets wrong while the figures are the server's.
- A tile of its own, which [[R1646000]] keeps the fixed top from gaining.
