The table CN Tech reads is `crates/cards/data/win_rates.json`, validated by `crates/cards/build.rs`
(a string `patch`, a `source` of `live` or `provisional`, unique row ids, `0 <= wins <= games` on
every row) and compiled in beside the catalog, so the pure crates keep their two statics and the one
table serves the server and WASM alike. It changes only with a card patch, and a game folds against
the table of the version it was played on ([[R1266000]]). `cargo jackioh winrates` writes it from a
`stats report --json` export or from JSONL game record files, never both; rows with 0 games are
dropped and rows are sorted by id. The command does not apply [[R654]]'s gate — the threshold lives
in the server, and the exporter picks `--source` there. It shipped empty through v0.3.7b; issue #1266
filled it for v0.3.15 from a development run (provisional).
