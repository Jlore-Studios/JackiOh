The policy of [[§10.7]] and [[R44]] never picks `concede`, `offerDraw` or `answerDraw`: those three are always on offer, so a literal uniform draw would have My Pawn resign or draw the game it is playing out, and [[§10.7]]'s uniform draw and its 0.1 end-turn rule both read on the set with these three removed. The skipped set is a named constant (`AI_SKIPPED_ACTIONS`), and the engine's own random-game harness and fuzz runs use the same one, so a fuzz game ends by hero death or the turn cap rather than by a conceding robot
