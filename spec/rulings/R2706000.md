A dungeon run's fight (`docs/dungeon-run.md` DR5) is a practice game ([[R187]], [[§9.9]]) started from the run's setup: its seed, the run deck, its handicap and its deck marks at the human's seat, and the enemy's deck and handicap at the AI's, whatever the start config's own seed, difficulty and deck say. It is a game of its own kind, so [[R417]] finds no last game for it: it brings no last board and leaves none ([[R508]]), and C+ #29 cast in it fizzles. Its deck is built over the run, not dealt, so no seat is counted dealt ([[R433]]). It is never saved ([[R668]]) and leaves the free game's save and the page's memory of it as they were, so a fight left unfinished is dealt again from its seed once the run, still on its fight, starts it again. It is not kept for replay ([[R768]]), and the page never puts it on a server seed, so it earns nothing ([[R1303000]]). Once it is over, and only then, the worker answers `runReport`: the run's fold of the game's setup and log (`runFightReport`) for the seat the human ended in ([[R677]]), the run's `FightOver` or its refusal, never the log itself. This follows Hearthstone's Dungeon Run, whose fights are apart from every other game: they count in the run alone.
