When the active player's turn clock ([[R79]]) has 30 seconds or less left, the board shows a visual timer effect for it, read off the deadline the server sends and still under reduced motion ([[R200]]). It is presentation: the server keeps the clock, and nothing changes in the game when the effect starts (CLAUDE.md rule 7)
