`cargo jackioh classify` replays games recorded on the head against the base build to find what a change to play code does ([[R1365000]]). A change that ships a set ([[R1420]]) records games whose decks hold that set's cards, and the base, which holds the set back, cannot set them up: its `golden check` panics in `create_game` on the first such card ("\"stinkyscape-156\" is a card of Stinkyscape, which has not shipped yet (§2.6 L3, R1420)"), so it reports no divergence at all, and classify failed with it, which held the Stinkyscape release's `rust (classify)` red ([[R1370000]]).

So when the head ships a set the base does not (`diff.sets`) and the base refuses the head's games for a card of a set it does not ship, the unforced replay ends there and finds nothing more: the release is already a major, the highest tier, and every card of the set is claimed by the catalog diff ([[R646]]). It is no rule every game meets, as [[R1705004]]'s refused deck size is: what moved is which cards a deck may hold, which the set's own claims already say. A refusal of that kind with no set shipping is still an error, as before. The forced games of a changed script that the base cannot set up already count that card as changed.
