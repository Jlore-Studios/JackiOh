After a finished co-op game the two people may go again together: either human seat offers Play
again, and once both seats have offered the server starts one new co-op match for the same two
people against the AI team. `POST /api/duos/matches/:matchId/again` (`{ leanSet? }`) records the
caller's offer and answers the new match's id once both seats have offered, else null;
`GET /api/duos/matches/:matchId/again` answers what each seat offered, whether the teammate is
still on the finished match, and the new game's id. Hearthstone has no co-op rematch to copy, so
the shape follows [[R672]]'s 1v1 rematch: offers in memory, not rows, swept past
`REMATCH_OFFER_TTL_MS`, an entry that made a game keeping its id so a late poller still learns
where to go, and two offers racing making exactly one match.

The new game keeps the same `a1` and `a2` (the host stays A1, [[§13.9]]) and the same `difficulty`,
and so the same AI team rules and handicaps ([[§13.7]]). It gets a fresh seed and is dealt and begun
under the server's catalog version ([[R767000]]). A seat that played a saved deck replays the frozen
deck from the finished match's `options` verbatim; a seat whose deck was dealt is dealt afresh,
leaning on the set its latest offer picked ([[R924000]], [[R2031000]]), as an All Random rematch
deals. The AI seats are dealt afresh by the AI's deck-builder, as a room's join deals them. The
start goes through the seat ledger, as every door into a game does ([[R1523000]]): it cancels both
people's open tickets and writes the match row in the one transaction the room's join writes them
in, and the offers live in memory beside [[R672]]'s, swept by the same reaper's tick.

Only a seat of a finished match may offer: anyone else, an unknown id and a live match get the
replay's answers (404 to a non-seat, 409 while it is live). An offer counts only within
`REMATCH_OFFER_TTL_MS` of the match's `ended_at`, the window a finished co-op match's socket
reopens in ([[§13.9]], [[R1398000]]); past it the offer lapses silently and makes nothing. The
teammate is read as here while their co-op socket on the finished match is open, and as gone with
no actor in memory. Each refusal uses the error body every route answers with: a match played on
another catalog version is `409 update_required` ([[R1638000]]), as the co-op room's join refuses;
a frozen deck holding a custom card is `loadout_invalid` ([[R915005]]); a seat in a 1v1 match, a
Conquest series that is not over or a live co-op match meets [[R1065000]]'s refusal; a pair with a
block either way reads as an unknown code ([[§13.9]]); and a seat emptied by a deleted account
([[R1497000]]) cannot be played again. Nothing in the client calls these routes yet: part 2 builds
the result panel's button on them, so players see nothing new until it lands.
