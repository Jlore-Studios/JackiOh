The policy prior (`crates/ai/src/policy.rs`) reads a move as a handful of text keys, `policy_keys(view, seat, action, rank)`: its kind, its rank among the non-End-Turn moves in the heuristic order (capped at `POLICY_RANK_CAP`), the card it plays or acts with, where it lands, its modes and the class of each thing it aims at (a hero, a side's row or pile, a zone, a mode). `view` is `redact(state, seat)` and nothing else ([[R185]]). A card is named by [[R1006000]]'s rule, where its definition is known and, in a backrow, where `backrow_is_public` lets the seat read it; elsewhere it is `hidden`, and a target the seat cannot name is aimed at by its place alone. No key holds an instance id, a hero's target id or a prompt's id, so two states that differ only in what the seat cannot see give every move the same keys.

A decision's label (`policy_label`), which `cargo jackioh positions --policy` writes on each decision row, is the keys of every candidate decide itself lists there, on its probe world (`AI_SEARCH.probe_seed`), in that order, and the position of the move played among them (none when it is none of them). The probe is a function of the redacted view, so replaying a log gives the same labels. A table of weights records the key layout it was fitted on, `keysVersion`, which must be this build's `POLICY_KEYS_VERSION`; any change to the keys bumps it.
