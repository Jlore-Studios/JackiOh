`cargo jackioh stats --force <id>` plays a development run ([[R378]]) in which the card is in one seat's deck in every game: p1's in an odd game, p2's in an even one. Both decks are [[R258]]'s deal with the card banned, so the other seat never holds it, and the holder's card at the slot `${seed}:force` picks is replaced by it. The deck stays 20 distinct cards. No deal depends on the card's own numbers, so a build before and after a change to the card deal the same decks. The sweep's `include` was rejected because it re-deals the holder's deck around the card's cost. The id is resolved as `golden record --force` resolves it: a token goes in through the card whose `refs` name it ([[R279]]), and an unknown id or a card of an unshipped set is refused ([[R1420]]), before any file is written. The records keep [[R376]]'s shape and [[R378]]'s source, id and patch, under the series `dev-force-<id>`; an explicit `--series` with `--force` is refused. The file is for `stats compare` and `stats report`, never for `stats-import`.

`cargo jackioh stats compare --before <file>… --after <file>… --card <id>` reads the games in which exactly one seat's deck holds the card; the rest are left out and counted. A draw is a game not won. It prints the holder's win rate on each side with a Wilson 95% interval (z = 1.96). It pairs the games by seed, the record's id less `dev:<patch>:`, taking each game's first record on each side. The paired difference is the mean of after less before over the games on both sides, with ±1.96 standard errors, as [[R850000]] reads its edge. When the card has a row in `SHADOW_BAN` ([[R186]]) or `SHADOW_WATCH` ([[R390]]), it adds a line saying the figure measures the AI as much as the card.
