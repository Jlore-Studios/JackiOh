Each player counts the cards of theirs that evolved this game (`PlayerState.evolutions`, read as `evolutionsOf`), which "for every card that Evolved this game" reads. An evolution counts for the evolved card's controller; a mark counts nothing until the card evolves. Absent until the first, so a game without one hashes as before. Rejected: counting the multiplier's repeat runs, since [[R3536000]] counts evolvings.
