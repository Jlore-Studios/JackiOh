Meditative #50 CN Tech and Meditative+ #2 NA Tech read the compiled win-rate table ([[R1100]], [[R1183000]]). When it names no card for an end, they took a random non-token card of the sets that ship ([[R380]], [[R142]]); since the owner's first Stinkyscape balance pass (issue #2521) they take hard-coded cards instead, the ends of the table every version since v0.4.0 has shipped (`crates/cards/patches/win_rates/v0.5.9b.json`, `crates/cards/data/win_rates.json`):

- **CN Tech.** With no leader it adds `FALLBACK_LEADER`, Core #35 Lunar Eclipse (33 wins in 48 games, the table's leader), Radiant on its Radiant face, and draws nothing from the match rng. With a leader it adds the leader as before.
- **NA Tech.** A missing highest end is `FALLBACK_LEADER`, Lunar Eclipse; a missing lowest end is `FALLBACK_TRAILER`, Core #75 Infinite Reserves (7 wins in 43, the table's trailer). With an empty table it fuses Infinite Reserves and Lunar Eclipse, trailer first ([[R1183001]]), both Radiant on its Radiant face ([[R469]]). The two ends stay distinct: when the end the table does name is the very card the missing end would fall back to, that end is a random non-token card of the sets that ship as before, never NA Tech ([[R387]]) and never the other ingredient.
- **Why these.** The table both cards read is v0.4.0's provisional run, a development run's figures ([[R1101]]), filed under v0.4.0 and carried unchanged by every version since: `.github/workflows/winrates-refresh.yml` replaces it with production's windowed figures once per patch ([[R1368000]]), but it reads production through `STATS_DATABASE_URL`, a secret no one has set yet, so it has never run. The fallbacks are that run's two ends, named so that a table that names nothing still plays a known card rather than a roll. They stay until the refreshed table names its own ends; a table that names an end never reads its fallback.
- **Replays.** A game folds against the table its version shipped with ([[R1266000]], [[R1329000]]); a version whose table was empty played the random fallback, and a replay of one that drew it is refused by its final hash.
