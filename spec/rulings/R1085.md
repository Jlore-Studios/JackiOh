The Radiant Death's receiver is random (MD-D22), as Hearthstone's Deathrattles pick: one random other Unit you control, and none with no other Unit. The keywords are the ones it had as it died ([[R78]]'s last-known state), so its 21 but Taunt, which it never has while it is Indestructible ([[R347]]), granted as keywords ([[§10.4]]), and `grant_keywords_random_unit` is the verb that grants a named list to one random acting Unit, drawing nothing with no Unit ([[R129]]). Reborn's return fires it again on the second death. Patch v0.3.7 (issue #781) took the Death off Keenus's Radiant face ([[R781004]]), so no card prints it now; the verb stays, proven in the engine's tests.
