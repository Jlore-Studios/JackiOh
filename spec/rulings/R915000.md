A custom card ([[§12]]) is a card a player makes: an id, a version, a frame and a script in the card kit. The spec made no such decision before #915; this note makes it.

- **The id space.** A custom id is `custom-` and 1 or more lowercase letters, digits and hyphens, `CUSTOM_ID_MAX_LENGTH` characters in all. No catalog id begins with `custom-` (`cargo jackioh catalog check` refuses one), so a custom card never shares an id with a catalog card or a token, and an id with the prefix is never read as a catalog id.
- **The definition** is built from the frame: set `Custom`, which never ships ([[R1420]]), so no random pool, Discover, random deck or catalog query finds a custom card; its index is its id; it has no tags and is never a token; its numbers are its params, better upward. A game holds its custom cards' definitions beside the catalog, as it holds a fused or crafted card's ([[R77]], [[R882]]), and every reader of a definition finds them there.
- **The version** counts the card's saves from 1; a game keeps the version it was dealt with.
