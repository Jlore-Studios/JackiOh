A pointer, focus or touch on an in-app link or a navigating button starts loading that route's
code, once per page load, and the route renders from that same request, with no loading panel.
Practice, Play, a match, a series, a Duos match and a watched game also start the engine, which
only matters if the boot download (#778) failed. Nothing is prefetched while the browser asks
to save data, and a production build never prefetches `/dev/hotseat` or `/dev/duos`. It is
presentation only (CLAUDE.md rule 7).
