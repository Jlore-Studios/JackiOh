The super run's `ai gates (2/4)` shard hung in one game: p1's face-up C #5 Tesla (a Field Trap,
its unit board full, so it never animates away) against a p2 Unit carrying C #14's Radiant
would-die Flicker, fused onto it by a Radiant M #47 饕餮 out of p1's library. A Unit p2 summoned
was zapped, flickered back at full health, re-summoned — and Tesla fired again, forever. Each
card is correct per its text: Tesla answers every Unit the opponent summons, and a Flicker
counts as summoned ([[§6.3]], C #14 radiant); the replacement meets every would-die ([[§6.2]],
[[§8]] row C 14); the copy joins the hand each time (burning at a full hand, [[§2.4]]); Lifesteal
heals each zap ([[§4.4]]). The spec does not say what ends a mandatory loop, so this follows
Hearthstone: the rope cuts the loop and play continues — the game is not drawn and nothing
panics. The engine has no clock (rule 4), so the rope is a count, kept where the loop lives
(`TRAP_IDENTICAL_ARRIVAL_ANSWERS`).

A trap answers an identical arrival twice per one action's resolution. Identical is the event as
the rules read it — `sourceId` ([[R1088]]), `absorbed` ([[R1360]]), `how` ([[R1366]]) and the like
already stripped, the same key the trigger loop's frontier holds an event by. The second
answering covers the finite return: the rules bring the same instance back at most once per
action without a new cause — the Reborn body ([[R83]]) — so it still answers, and so do two
Flicker re-summons of the same Unit in one resolution. The third identical twin in one action
is always the same stay coming back through a replacement loop, so it is declined as silently
as a `when` that does not hold ([[R99]]), and the victim stands at full health while the game
goes on. The count is per action, rebuilt by every answering action, and it is sink memory,
never state: no hash moves and no replay changes ([[R768]]). It covers the arrival events only
(`cardPlayed`, `summoned`, `cardResolved`, [[R119]]'s list), since other events repeat
legitimately — every round of a Blade Storm deals its same damage — while a played Unit carries
`arrivedDuring` and its Reborn body does not, so both still answer, as does every arrival of a
prompt-split chain, whose answer rebuilds the list. The fused face is no exception: a fused
card's Radiant face fuses every ingredient's Radiant face ([[R102]], [[R469]]), which is how a
base-face library Shadowstep still lends the Radiant Flicker.

Rejected: drawing the game, since neither hero is at 0 and Hearthstone plays on; panicking past
the settle cap, since each twin is a new event the uncapped inner dispatch takes, so the capped
outer loop never sees the loop — and a panic crashes a real game and fails an AI gate as thrown
and fallbacks; answering once, since the same trap answers the same summon twice in a finite
game — the golden `jackioh-fuzz-11` replays its Reborn return to the same Tesla — and once would
hand the second kill to whichever trap R68 offers next; a per-card iteration count past two,
since the texts promise every answering (Recruit's three, Clone Machine's board) and those are
different instances this count never touches. Two is the rule's shape, not a budget: the one
return the rules provide, answered, like [[R460]]'s one replacement of one event by one card.
