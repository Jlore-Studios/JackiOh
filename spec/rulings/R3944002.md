A patch with `includes` ([[R3944000]]) changes no card of its own, so where the page, the release art and the GitHub release read a patch's cards they read its micros': each card any of them names, once, in the order they first name it, as the patch's own snapshot holds it and against the snapshot before the first micro, a removed card drawn as that earlier snapshot held it ([[R507]], [[R3012001]]). Its art is a patch's, drawn from those cards, with card backs when they name none. Its GitHub release carries its own note, then a "Snapshots" section listing each micro it rolls up (version, date and title), then those cards with what changed on each. A micro that a major or patch includes, or that the next daily patch will roll up ([[R3944001]]), gets no GitHub release; a release already published for one is left as it is, since the releases run deletes nothing.
