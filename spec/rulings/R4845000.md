An audit of the Training Grounds card scripts found that the random Call to Chaos TG #39's ninth entry adds at the start of each of its caster's turns ([[R3135000]]) was never Glitch, whatever the match's count of System plays: its pick passed no Glitch odds. Reading its neighbour found the same of S #150's fourth entry, whose random Acclaimed Unit was picked with no Glitch roll ([[R1882002]]). Both are cards generated into a hand, added from a pool, and [[R673]] exempts only a card generated to be summoned or cast at once or transformed on the field. So each is Glitch instead on [[R673]]'s odds, drawn as one more number of the match rng after the pick (which its tally counts, [[R3563000]]), and only while the count is above 0. Entry 10's recast is a cast and is never Glitch. S #150's Refresh reads the card that reached the hand: a Glitch prints (0), so it refreshes nothing ([[R364]]); a full hand burns the card and refreshes nothing, as before.

Replays: no reading is kept. A game with no System play draws exactly as before. One that played a System card and then added one of these cards draws one more number and folds to another hash, so it is refused as `rules_changed` and never shown as another game ([[R767000]]), as [[R3135000]] accepted for this card's entries before.

Rejected: keeping the old reading for the catalogs a replay folds under, which would branch the engine's own start-of-turn step and entry by version for a draw made only after a System play; and refreshing the Acclaimed Unit's cost when the card added is Glitch, since "Refresh mana so you can play it" reads the card added.
