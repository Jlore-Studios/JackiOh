IA #84 Distributed Mind's "Once per turn" (Radiant "Twice per turn") means each player's turn (`state.turn`), counted in the card's own memory under the turn's number: another friendly Unit's death draws while this turn's count is under the cap, and the count with it. Deaths at the same moment are counted one by one ([[R2271000]]), the condition read again as each trigger runs, and leaving the field loses the count ([[R78]]).

Why: the cap sits on the card's text rather than in the engine, so each copy counts its own draws and a replay folds under the face it wore. Rejected: an engine trigger cap, which would count every copy's draws as one.
