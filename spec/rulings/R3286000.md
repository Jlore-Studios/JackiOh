A won mini-boss always offers a relic ([[§15.6]], [[§15.7]]): `RUN_ARTIFACT_PERCENT` is 100 for a mini-boss and for the final boss. Each mini-boss is dealt its drop when the map is made, from the same list of relics not yet held, so two of a run's mini-bosses can be dealt the same one, and a shop or a chest can sell a boss's drop before the boss. [[§15.7]] says a drop already held is replaced, but the code turned it into no reward at all, so a player who held the drop met an empty reward at the boss. The spec gave the replacement no tier. The plan made no decision; this note makes it, as Hearthstone's Dungeon Run does: a treasure the player already holds is never offered again, and the offer is drawn from the rest.

- **A held drop rolls like a node with no drop:** one draw under `RUN_ARTIFACT_PERCENT` of the node's kind (100 for a mini-boss and for the final boss), then a random Combat or Economic artifact that is neither Unobtainable nor held ([[§15.4]]).
- **A mini-boss's replacement is of `RUN_MINI_BOSS_DROP_TIER` or better,** as its own dealt drop is ([[§15.6]]). The final boss's replacement has no floor, though its drop is Unobtainable, which nothing else deals, so it is never held in play.
- **None left means none:** when no artifact of that tier is left to roll, the reward has no artifact and its packs are as before.
- **Stream:** the roll draws from the random stream only for a held drop. A node whose drop is not held draws nothing here, and a node with no drop draws in the order it always did, so a run that never meets a held drop deals and folds as before. A Sandbox run kept on a device that did meet one folds differently from its next action on; the client already drops one kept run the fold refuses, keeping its progress and history.

Rejected:

- **Dealing the two mini-bosses distinct drops when the map is made:** it moves every seed's map, the daily run's included, and does nothing for a drop a shop or a chest sells first.
- **No floor for the replacement:** a mini-boss would offer a Bronze relic where [[§15.6]] gives it Gold or better.
- **The held relic's own tier as the floor:** the issue fixes the floor at Gold, and a mini-boss's dealt drop is of at least that tier whatever the content names.
