The card creator edits a custom card's frame in a form and its script in either of two views: the builder, which writes card-kit Luau from blocks in the kit's own words, and the code view, which edits that script directly. Every script the builder writes is one the Luau module's check passes. A card whose script differs from the one its saved builder model writes is code-only, and the creator says why. The creator saves no card whose script the Luau module's check finds a problem in; the frame's issues are the engine validator's, and a refused save shows the server's issues and sentence unchanged (CLAUDE.md rule 7).
