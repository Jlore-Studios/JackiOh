IA #148 Quarantine's "The attacker has {attack} Attack this turn" is a set Attack this turn (`effects::firewall::set_attack_this_turn`): it is read after every other Attack layer ([[§10.4]]), so it beats buffs and aura sets, and touches no Health. It holds while the game's turn is the turn it was set on, then ends; it leaves with the Unit ([[R78]]), like Frozen does, and a Unit Immune to Spells is passed by, as Freeze passes one by, while an Immutable one is not, since a status is not text.
