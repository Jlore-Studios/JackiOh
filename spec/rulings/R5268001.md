Amends [[R1329000]] and [[R2173000]] on how their files are kept. Each table folder under `crates/cards/patches/` (`win_rates/`, a version's win-rate table, and `card_metrics/`, its BUSTED and complicated lists) holds `versions.json`, which maps every version that has a table to the file holding its bytes, and a version's own file only when its table differs from the version before it in `patches.json`'s order. A version's table is the file `versions.json` names for it; a version it does not list has none, as before, so the versions shipped before v0.3.15 and since #3049 keep no win-rate table ([[R3049000]]). `patches ship` and `patches cut` map a version to the file of the version before it when the lists they write are the same bytes, and write the version's own file otherwise; `patches retcon` renames the files a version holds and both sides of each map. `cargo jackioh patches encode` turns a folder kept the old way, a file a version, into this one, and a second run changes nothing ([[R5268000]]). `patches check` fails on a version's own file that `versions.json` does not list, on a version it maps to a file that is not there, and on a version's own file that repeats the table of the version before it. `shipped.json`'s `winRatesBlob` and `cardMetricsBlob` still hash each version's table, the bytes of the file it reads. The 90 win-rate files held 2 tables, and the 224 card-metrics files 26 lists.
