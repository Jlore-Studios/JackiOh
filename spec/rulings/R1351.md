Presentation only (CLAUDE.md rule 7). One intro ([[R1350]]) plays at a time. A second Legendary or Mythic played while one plays cuts the first short: it fades out over `MUSIC_INTRO_CUT_FADE_S` (0.15 s) as the second starts, and the bed stays ducked for the second's music. The same intro asked for again while its music runs, or while its file loads, changes nothing, as a theme asked for again does not restart ([[R631]]): copies of one card arriving together (Classic+ #46.1's Cry filling the board) play it once. The game's end cuts it the same way, since the result outranks everything ([[R631]]); so do a hotseat hand-over, whose arriving seat hears nothing the last seat's view produced ([[R203]]), turning dynamic music off, and the board leaving; each lets the bed straight back up. The viewer's hero taking a hit ends a theme ([[R631]]) and leaves the intro to finish. Muting, or the music at zero, silences it with the rest of the music. An intro asked for while the audio context is not running is dropped, never saved up for the resume, and one whose file is not ready `MUSIC_INTRO_LATE_S` (1 s) after its card's moment is dropped rather than heard late.
