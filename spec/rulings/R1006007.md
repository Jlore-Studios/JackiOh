`cargo jackioh selfplay` ends a game without a result after any decision during which the board ran to one of the engine's settle caps (§10.3: `SETTLE_PASS_CAP` in the resolution loop and the trap dispatch, the state check's own and R283's), raising its "did not settle" panic. That holds whether the panic came from a line the AI's search simulated, which the search catches and drops, or from anywhere else in the decision. The arena's own games and the gates' play on as before, and a throw from the true state's `reduce` still ends any game.

The cap stops a loop, but each pass can be slow. Game 31547 of `learned-v0.3.7b-20261018-5`, the learn lane's export in run 39088985993, reached a board whose resolution loop took about 11 minutes to reach its 24,000 passes. The search simulates the same line again at later decisions, each time at the whole cost, so the game held its shard past GitHub's 6-hour limit, and the export with it. A hook in front of the process's panic hook counts the cap's panics on the thread that raises them, and a game is played on one thread from start to end, so the count's rise across a decision is that decision's. The count follows from the seed alone, so the export stays byte-identical whatever the thread count ([[R1006001]]). The game ends there as one without a result, which `positions` drops and counts ([[R1006003]]), as at the turn ceiling ([[R1006005]]). The loop itself is the engine's and the cards' to answer, not the export's.
