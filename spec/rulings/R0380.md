Core, Classic and Classic+ are one format: a deck may mix all three under [[§2.6]]'s rules (20 cards, no duplicate ids, no Tokens), and a Conquest trio needs 60 distinct cards, now from 268 ([[R251]], [[R253]]). Nothing asks for a format per set, and the patch history keeps a later one that pins a version possible ([[R388]]). A random pool whose card names no set draws from every set that ships ([[R768]]: a set the catalog holds before it ships is in no such pool until it does), which is Hearthstone's reading of "a random card" and the only one that lets Core's generators see the new sets: #7, #54, #59, #67 (whose base pool gains C+ #22 Blood Moon, the one new (1) Cost Trap), #57 (whose KY pool gains C+ #41, C+ #42 and C+ #62), #83 ([[R35]]), #95 (its random Units, cards, Field Spells and Traps, and "cast a random Call to Chaos", [[R28]]), #98's Discover and Stitching ([[R352]]) and #99 reach every set, and so do the AI's decks and determinizations ([[R184]], [[R185]]). A card that names a set keeps to it: #82 KY's Trial and #97 Zephyrs stay Core, C+ #73 takes Classic cards, C+ #73.1 a Classic or Classic+ Unit, and C+ #27 and C+ #75.1 Classic and Classic+ cards. A card's `index` is unique only within its set, so every lookup by index names the set or goes by id ([[§5]]); a Token is still in no pool its card does not name ([[§5.1]]) but [[R382]]'s; and a token's printed rarity is display only, never a pool. The tutorial's fixed decks do not change ([[R291]])
