"Your evolutions trigger twice / thrice" (`Script.evolve_extra`) gives N extra runs of its controller's Evolve texts while it acts on their field, as the turn-hook and Cry/Death multipliers do ([[R820]], [[R821]]): the highest N holds, never the sum. The once-only rule counts evolvings, not repeats: the card evolves once, its text runs 1 + N times, and the game counts one evolution. The verb's first run is inline and the extra runs queue behind it, so a prompt in the text pauses the queue rather than dropping the rest; a standing evolution queues every run. A fusion drops `evolveExtra`, as it drops `tributeWhen`. Rejected: running the extra runs inline, where a prompt would drop them.
