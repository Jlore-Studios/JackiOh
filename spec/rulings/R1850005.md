"Upon reaching N keywords make this card Radiant" (`Script.radiant_at_keywords`, Rod of Ages' 10) is read at every state check ([[§4.5]]): a permanent not yet Radiant, face-up (a face-down card's text sleeps, [[R1487000]]), whose keywords through the layers ([[§10.4]]: printed, granted, conditional, aura and position keywords) reach N is made Radiant (Make Radiant, `radiantSet`), once, since a Radiant card stays Radiant ([[§5.2]]). Keywords are a set per unit ([[§6.1]]), so each kind counts once: a granted Taunt on a Taunt card, or two Armors, count one. A Field Spell's keywords count as a Unit's do.

Rejected: counting entries, which would let a stack of Armor or Lucky reach N alone.
