The cards of the newest shipped set ([[R1371]]) wear a small "New" ribbon in the Card Almanac and in the deck builder's pool, and their accessible name says "new", for the patch that ships the set and the one after it. The patch that ships the set is the first in `crates/cards/patches/patches.json` that adds one of its cards, and the window is counted in that file's patch order ([[R105]], [[R388]]): no version string is parsed or compared and no date is read, and a lettered patch counts as a patch. The build's patch is the catalog version. A set that has not shipped has no such patch, so no card wears the ribbon before the set does, and none does today (Classic+ shipped in v0.2.0). Presentation only (CLAUDE.md rule 7).
