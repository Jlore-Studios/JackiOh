Each player's own preference, on by default, as [[R82]] has it. `setAutoEndTurn {enabled}` sets it for its sender; it is accepted from either seat at any moment of a live game, the mulligans and an open prompt included; it emits nothing; and `legalActions` never offers it, so no policy ever sends it ([[§10.7]]). Off, a turn with nothing left in it but ending it, conceding and offering a draw waits for that player's End turn, and they may offer a draw on it ([[R36]]); the turn clock still runs ([[R79]]). Turned back on with nothing left to do, the turn ends at once, as [[R82]] says. It is part of the state, so a match folds exactly from its log ([[§9.3]]), and it is stored only while off, so a game in which nobody touched it hashes as before. The view carries the viewer's own preference only ([[§10.8]]), never the opponent's. The web client sends it from its "End turn automatically" setting whenever the view disagrees, and a tutorial lesson keeps it on, since its coach is written around [[R82]]
