S+ #166 Mindustrial Revolution since Stinkyscape+ Balance Changes V: "Add a random Mindustrial card to your hand now and at the start of each of your turns, for the rest of the game." (Radiant: "a random Radiant Mindustrial card … Each costs (1) less."). The designer's "make it also trigger it now" is one more add, as the Cry resolves, of exactly what each of its owner's turn starts adds ([[R3549004]]): one random card of the same pool, never this card ([[R387]]), Radiant and costing (1) less on the Radiant face, never below (0) ([[R65]]), a full hand burning it ([[§2.4]]). The add comes first and the rest-of-game effect ([[R458]]) is set after it, so the effect's first add is still its owner's next turn start ([[R62]]); two Revolutions add one each now and one each per turn. The badge stays the face's words. Rejected: firing the rest-of-game effect itself now, which would run it on the caster's turn as a delayed step; it is the same add either way. Through v0.6.8b the Cry added nothing until its owner's next turn, which `script_v0_6_8b` keeps for those replays ([[R767000]]).
