A card's code block is its own script's code: the lines `cargo jackioh catalog loc` counts ([[§5]] Lines of code) — above the file's `#[cfg(test)]`, comments, blank lines and `use` declarations left out — less its `pub const ID` line, the first `CODE_BLOCK_MAX_LINES` (12) of them, each keeping its indentation. Its card's own id is written `ID` and its own name `???` wherever the code spells them, so the block names neither. `crates/cards/build.rs` cuts one for every card but a token and compiles them in, sorted by id, and `register_all` hands them to the engine beside the catalog (`code_block_of`), so the pure crates read them at compile time only (CLAUDE.md rule 4); a fused, crafted or custom card has none. The block is the same on both faces. It is not the lines-of-code stat [[R693]] hides, which stays a number.
