Mind Games files its declared mode as a secret record, `state.secrets { id, owner, choice, revealed }` ([[§10.1]]), made from a declared mode ([[§6.3]] Keep a secret). Until the secret is revealed, no view, event or log line of the other player carries the choice: `secretChosen` names only the player and the id ([[§10.3]]), the other side's `SideView.secrets` lists only `{ id }`, `cardPlayed` carries no modes, and the engine's invariant I6 fails a view that sends the opponent a choice for an unrevealed record ([[§10.8]], [[R97]], [[R177]]). The owner's own view carries the choice, and the client's badge names it only where the view does — the opponent's badge says only "Secret".
