[[R185]]'s redaction sets the state's id counter (`nextId`) one past the highest number of an id the redaction still names: an instance's (`c<n>`), a prompt's (`q<n>`) or a secret choice's (`secret-<n>`) anywhere in it, and an Echo's waiting repeat on its queue (`e<n>`). The true counter counts every id the game has handed out, those minted where the seat cannot see among them: S+ #17 Smoothie's two Fruits as its owner draws it, which the other seat sees only as a hand one card larger. The AI's search numbers its simulated prompts, and with them the draw of the answers it tries, and every card it mints from that counter. So two states the seat's view could not tell apart gave two redactions and two decisions. Every id the redaction names stays below the counter, so no id a simulation mints is one the redaction holds, and a second redaction keeps the counter. Only the first action of the search's line is played, and it names ids the state already holds, so the ids the search numbers afresh never reach the game.
