[[§14.11]] says every roll is seeded and logged so it replays exactly, and each opening's seed is
drawn afresh. An opening of a card pack ([[§14.3]]):

- **Its seed** is 16 random bytes as hex, drawn by the server for that opening alone, as a match
  seed is, so no seed an account can read foretells a later roll.
- **Its draws** come from the engine's seeded generator from cursor 0, in this order and no other:
  the pity math's three (Epic, Legendary, Mythic, [[§14.4]]), one per filler slot ([[R1301000]]),
  then, slot by slot, the card's one and, for a duplicate, its cosmetic rarity's one and the pick's
  one when there is something to pick ([[R1301002]]). Every list it walks is in catalog or registry
  order.
- **Its log** is `{"pack","seed","draws"}`, the `ref` of every economy row the opening writes: the
  pack spent, each cosmetic, each pity counter that moved and each bar that gained. The collection's
  rows (`collection_grants`, reason `pack`) have no `ref` column; they share the opening's `at`.
- **A replay** is `roll_opening` (`crates/server/src/economy/roll.rs`) over the holdings as they
  stood before the opening (its cards, its per-card cosmetics and its pity counters), the pack's
  pool and the registry, with the logged seed: the same slots, the same counters, the same draws.
- **Its lock.** An opening first takes a lock on its account's economy for its transaction, so two
  openings at once run one after the other and cannot both roll on the same counters.
- **One transaction.** The pack spent, the cards, the cosmetics, the counters and the bars commit
  together or not at all.

Hearthstone semantics: Hearthstone rolls on its servers and shows only the result; the spec asks
for an audit trail, so the seed and the draw count are kept with the grants.

Rejected: a seed derived from the account and a count, which an account could foretell; logging
each draw's value, which the seed and the count already replay; and a table or column of its own
for the log, a migration the existing `ref` columns make unneeded.
