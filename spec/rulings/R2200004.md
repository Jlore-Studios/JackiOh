"Cast a random Call to Chaos" (every edition's tenth entry, a base form at the next chain depth, [[R28]]) and TG #39's own ninth entry draw from the pool that names no set ([[R380]]), so while Training Grounds is held ([[R1420]]) they never reach TG #39. S #4.6 The Big Crunch's "cast one of each Call to Chaos" names its five editions by id ([[R1870006]]), so it does not cast TG #39 while the set is held; the release (#2204) adds TG #39 to that list, in catalog order, with its fragment, as it claims every edition whose pool gains TG #39. So no shipped card plays differently while the set is held. Since the release (issue #2204) the set ships: every "random Call to Chaos" can reach TG #39, and The Big Crunch casts it sixth, after S #151.
