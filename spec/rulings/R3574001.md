A past version ([[R3538002]]) runs the script its game version kept ([[R767000]]'s covering rule), else its card's own script, and either may be newer than its definition: the covering rule hands a version the script kept for a later one, and a card's own script reads the numbers the card declares today. Stinkyscape+ fullsend 2's sweep of record found it: Stinkyscape #53 Flak v3's v0.5.8b version declares `damage`, the script covering it (v0.5.9f's) reads `least` and `most`, and the read panicked ([[R386]]'s "a number a card never declared panics"), 1,505 times in one game. 67 of the catalog's 619 past versions lack a number their card declares now.

So a past version reads each number by its own declaration first, and a number it never declared off its card's definition as the catalog has it now, moved by the instance's own tuning as any number is. A catalog card, a fused definition and a crafted one read only their own declarations, and a number no definition of the card declares still panics. A past version's view still prints only the numbers it declares. Hearthstone has no counterpart.
