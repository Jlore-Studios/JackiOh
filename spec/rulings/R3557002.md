S+ #51 reads "Dormant a permanent for 2 turns. When it awakens, Buff it 2 times if it's yours or Nerf it 2 times if it's an enemy's". Dormant's rules reach only a Unit ([[R1839000]]: nothing reaches a Dormant card, and a card is Dormant only as a Unit on the field), so the target is a Unit of either side. The verb `dormant_target` gives it the status a card that prints Dormant enters with, `count` turns of its controller's ([[R1839001]]); a Unit already Dormant is passed by and one beneath a Stack pile is not reached. The mark an earlier awakening wrote ([[R3039000]]) stops only a printed Dormant from starting again: an effect makes any Unit Dormant. The rider is a delayed step for the start of the controller's `count`th turn from now ([[R1181000]]), which runs after that start's awakening, so the Unit is awake when it is changed; it Buffs a Unit its caster controls at that moment `times` times and Nerfs any other `times2` times, and it is forgotten if the Unit left the field ([[R174]]).

Rejected: a target of any permanent (the engine has no Dormant backrow card, and the text's "permanent" would then offer cards the effect cannot touch); and reading whose Unit it is when the Spell is cast rather than when it awakens.
