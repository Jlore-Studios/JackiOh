FvH #112 Jilliax Deluxe is an X Unit printed 0/0 (X at least 1, [[R348]]). Its Cry is two chained Discovers ([[R352]]), each of the four dearest ([[R5239005]]) of the thirteen module tokens #112.1 to #112.13 printed at X or less. X is the X the play paid, read once as the Cry starts and carried to the second offer, the designer's "initial mana snapshot"; spending more mana makes the offer dearer, never a module's numbers bigger. No offer holds a module this Cry has picked or one already fused into the card, [[R387]]'s rule carried to the card's own ingredients, so one module never goes in twice.

After the second pick, one `fuse_cards` of both into this card ([[R77]]), each on the Radiant face when Jilliax is Radiant ([[R469]]). It is one fusion, so a Radiant Viral Module's Immutable ([[R23]]) lands only once both are in and never blocks the second. When nothing is left for the second offer, the one pick is fused alone.

The 0/0 body stands while the Discovers are open: a play paused on its Cry's prompt runs no state check until the prompt is answered (the check [[R156]] describes is one already under way when a prompt opens). Before the Cry, [[§10.5]]'s step-4 window holds [[§4.5]]'s check unless a trigger resolves in it; one that does (another card's "when a Unit is played or summoned") runs the check, which collects the 0/0 body before its Cry, as it would any Unit at 0 Health. FV2 prints the body 0/0, so the card keeps it.

Then, from the picks alone: a Starpiece Module's Starship Piece is granted to the fused card, which [[R1852001]] keeps as the kept card's own grant; a Twin Module summons copies of the whole fused card, one on the base face and two on the Radiant, each a summon with no Cry ([[R1]]) into an open unit zone ([[R64]]), none with none ([[R129]]). A copy of an Immutable fused card is a copy, which [[R23]] does not refuse. The Twin Module has no hook of its own, so alone it copies nothing.
