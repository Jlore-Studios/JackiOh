A short opaque string stamped on every `cards` row and mirrored in the server's settings. Since patch v0.2.0 it is the latest patch's version, which every patch bumps everywhere it lives, so each patch reseeds ([[R388]]); the Core set shipped as `core-1`. [[§9.4]] requires a version and a rejection when it is stale but never says what a version looks like, so nothing may parse or order it — it is compared for equality only, and the order of patches comes from the patch list, never from comparing versions ([[R388]])
