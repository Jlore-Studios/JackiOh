The public card figures split three ways internally and display merged. `GET /api/stats/cards`
(and the per-card drill-down) count every counted seat, human and bot alike, unless `?pilot=`
names a side: `?pilot=human` reads the people's sides only, `?pilot=ai` the bots'. The response
names its split (`pilot`, `pilotLabel`). `stats-cards`, the `stats report` command and the
compiled-in win-rate table count record files the same way. This amends [[R1451]]: the bot's side
is no longer left out of the display, and a bot game adds two decks like any game, so the
per-game deck tell [[R1452]] recorded is gone.
