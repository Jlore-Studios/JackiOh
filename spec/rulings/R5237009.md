FvH #88 Cattail is "a Felinor only when beneficial". It prints the Felinor tag, and its static flag `harmIgnoresTags: [Felinor]` makes every harmful effect whose card filter's `tags` name Felinor pass it by: a harmful target declaration or prompt never offers it, a harmful scope or card-scope walk never reaches it (`restrictions::tribal_hate_cannot_reach`, read where M #25's tribal-hate immunity is, [[R940]]). It holds in every zone, a hand's and a deck's walks included, since the card is not a Felinor to harm wherever it is. Only a filter that names the tag is passed: harm aimed at everything, at another tag or at what is not a Felinor (`notTags`) reaches it as it reaches any card, and helpful effects, counts and random pools read its Felinor tag as printed, so it is in Felinor pools and the enemy's Felinor counts see it. A Vanilla takes the flag with its text.
