A set is covered when the table holds a row of one of its deckable cards with at least `CN_TECH_MIN_GAMES` (20) games, which [[R1100]] and [[R1183000]] can pick. While [[R1368000]]'s window is short, a table filed outside it that leaves a shipped set uncovered is rewritten as R1368000 rewrites it ([[R1367000]]), but only when the input covers every shipped set. It is provisional, ships with the same claims and counts as the X's refresh, so a refresh is still never due twice in one X. The cards test makes a set's release bring its rows (`cargo jackioh stats`, then the refresh). Rejected: a live-only table, which keeps a new set unpickable until a window clears.
