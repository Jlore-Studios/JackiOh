Training Grounds #15 In a hurry summons Rush Tokens "that die at the end of this turn"; the designer's note says "give them brittle 1". Brittle 1 crumbles at its controller's next start of turn (`BRITTLE_FIRST_TICK_TURNS`), so the tokens would block through the opponent's turn, and Temporary is a hand keyword ([[R637]]): the text wins. Each token is destroyed at [[§2.2]]'s end-of-turn delayed-effect point of the turn the Spell resolves on, whoever's turn it is ([[R350]], not [[R241]], which would arm nothing for a cast on the opponent's turn): after the end-of-turn triggers and the end-of-turn trap window, before cleanup ([[R62]]). It is a destroy: Indestructible refuses it, and a Death fires. It is built from shipped verbs: each `summon` remembers its token on the Spell (`rememberAs`), and one `delay { at: { phase: end, player: turn } }` per token that arrived waits under the engine's destroy hook, watching the token, so a token that left the field is forgotten ([[R174]]; a unit token ceases to exist off it, [[R11]]) and nothing else is destroyed. A token the opponent took control of is still destroyed: a change of control is an entry for summoning sickness ([[R171]]) but no leaving of the field, so the watch holds. The tokens print no Brittle. It edits [[§6.3]] (Destroy).
