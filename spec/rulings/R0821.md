Each extra start- or end-of-turn trigger is its own queue entry right behind the original (MD-A11):
`queue_hooks_in_trigger_order` queues every `StartOfTurn` and `EndOfTurn` entry 1 + N times in a row
for a player with an acting Joint Filing. The count is read as queued — a multiplier that leaves
later changes nothing already queued — and `run_queued_trigger` re-reads each copy as it pops, so a
copy whose card is no longer in a zone that runs the hook fizzles ([[R153]]). A state check closes
each run ([[R59]]), and each copy gets fresh rng and prompts. The extra runs multiply the End of
turn effects M #12 triggers too. They do not reach C #62's start of the opponent's turn, delayed
effects, or the end-of-turn trap window ([[R62]]).
