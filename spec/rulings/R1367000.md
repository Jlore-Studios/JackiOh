A card's statistics **window** at a version runs from whichever came later: the start of its X (the newest major or patch, [[R1365000]]), or the last micro whose plays hold the card's family (a token counts with its card). A major or a patch opens a new window for every card; a micro opens one only for the families it plays. Windows are read from the tier and the play set `patches.json` records for each shipped version, in the file's order, and a version string is never parsed or ordered ([[R105]]). A version shipped before tiers were recorded is read from its `changes`: a family plays in it when a line adds or removes one of its cards, or changes a field of one other than the wording fields (`name`, `base.text`, `radiant.text`, `refs`, `printedRarity`, `index`); it is a major when it is the first version of a release line (`PRE_TIER_MAJORS`), a patch when `PATCH_MIN_CARDS` (10) families or more play in it, and a micro otherwise. A version the history does not hold is a window of its own.

This amends [[R654]]'s gate. `PUBLIC_STATS_MIN_LIVE_GAMES` (1000) counts every live game played on the versions inside the card's window, not only the games that hold the card, and not only the newest version's. A window at or above it shows its own live games alone. A window short of it shows the card's **previous window** (the window the card had at the version before its own opened) when that one is at or above the gate, labelled "Live games (previous patch)" (`source: "previous"`). Only when both are short do AI development games pad the card's own window, as "AI games + live games (provisional)". `?source=live` and `?source=dev` read the window's own live or development games below the gate, as before.

One function computes it, `windowed_card_stats` in the engine's stats module (`crates/engine/src/wire/stats/window.rs`), with the patch history passed in as data (`jackioh_cards::patch_history`): `GET /api/stats/cards` (and so the `/stats` page), `cargo jackioh stats report --window <version>` and `cargo jackioh winrates` all call it. `GET /api/stats/cards` gives each card its `window` (the version that opened it, its live games, its source and the versions its figures count); its top-level `gate` and `source` are the window every card shares, its X's. The card drill-down's per-patch rates stay per patch.

A game record carries an optional **build**: the git commit the server (its deployed commit) or tool that played the game was built from, and, when the AI played a seat, the AI generation that build holds (`crates/ai/generation.json`, `aiGeneration`). The server, `cargo jackioh stats` and the arena's records file it, and `cargo jackioh selfplay`'s games carry the generation beside their commit. A build is absent when the commit is not known, and a record without one, every record written before this ruling among them, reads as before. Migration 0048 holds its shape (`game_records_build_check`).
