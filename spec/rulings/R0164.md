title: Where L6's ban list lives
cards: "§9.4, R105"
proven_in:
  - crates/server/tests/api/catalog.rs
---
A ban is server state, not catalog data. Nothing in [[§8]] is banned at launch and a card definition carries no ban flag, so L6's two halves are answered from two places: catalog membership from the catalog both sides ship, and the ban list from the server alone. A flag on the card would put the ban inside the catalog data, so banning one card would mean a new [[R105]] version and [[§9.4]]'s stale-version rejection would invalidate every saved loadout in the game at once; it would also hand the client a copy of a list it has no business being able to disagree with. The shared validator therefore reads bannedness through the catalog handle and never off a card definition
