The cards that count a Unit's death read the dead card's definition, or, for a quest goal, the card where it lay after the death: they read the card as it is off the field, not as it was on it. Two deaths came out wrong. A Unit set face-down by its Cloaked is a backrow card and no Unit while it waits ([[R3777000]]), and destroyed before it reveals it is a Trap for those rules ([[R783008]]), yet it counted as a Unit's death. An Animated Field Spell, Trap or Field Trap standing in a unit zone is a Unit for every rule ([[R383]]), yet killed there it counted for none but C #14 Shadowstep ([[R4395001]]). In Hearthstone only a minion's death is a minion's death: a destroyed secret or weapon answers no "whenever a minion dies".

So a death counts as a Unit's by what the card was on the field as it died, read by [[§4.5]] step 1 before any collected card moves ([[R89]]):

- **The event.** A `destroyed` carries `diedAs`, the card's type as it died, only when that differs from its face's printed type: the Field Trap or Trap a card set by its Cloaked was set as, or Unit for a card standing in a unit zone. Every other death's event is what it was. Unlike `animated` ([[R4395001]]) the rules read it: the trigger loop holds it, and `query::is_unit_death` answers from it, else from the printed face. A viewer who cannot read the card has it removed with the card's identity ([[R97]]), and the golden texts leave it out of an event, since the state shows what it changes in play.
- **The cards.** Core #89 Corpse Eater and TG #56 Legacy: Corpse Eater gain nothing from such a set card's death and gain an Animated card's Attack and max Health. TG #35 Corpse Recycler summons no token for the first and one for the second. S+ #93 Recessive Replicators evolves on the second only, and M #60 Eschews counts the second only. S #7 The Greatest Heist's Stage 2 (`unitsDied`) counts no Acclaimed Unit set by its Cloaked: the goal reads the event, not the graveyard card, and still reads the tag off the card where it lies. C #14 Shadowstep's base face hands back no such set card, which supersedes [[R4395000]]'s "a Unit card set face-down as a Trap is read by its definition's type too", and reads an Animated card's death off the event it answers.
- **Recessive Replicators' "that Unit".** An Animated card whose death evolved it is remembered as its printed card, and its Death resummons that card, which a summon places in the backrow as the Field Spell or Trap it prints, as a set card reaches its graveyard as its printed card ([[R783008]]). This supersedes [[R3542002]]'s "whose definition is a Unit".
- **Both Corpse Eaters.** TG #56 is a frozen copy of Core #89 ([[R2195003]]), and this patch is meant for both, so it claims both ids.
- **Replays.** The games of v0.6.9l and before fold under the scripts they ran (`script_v0_6_9i`, kept under v0.6.9i and again under v0.6.9l, since v0.6.9j, v0.6.9k and v0.6.9l shipped on `main` after this branch's base and before it merged (#4496 re-keyed the second rows from v0.6.9k), and the Heist goal's `byPrint`; Shadowstep's covers v0.6.9h to v0.6.9l, since its fix of #4395 shipped in v0.6.9h and v0.6.9g and before keep `script_v0_6_9g`), which read the definition or the card where it lay ([[R767000]]). The field moves no hash of a state whose trigger loop holds no such death. A game recorded before this change whose last state still held one there hashes differently and is refused as `rules_changed` ([[R768]]).

Rejected: each script calling `card_type_of` after the death, when the card is in a graveyard and its set stamp is gone; a separate "a Unit died" event, which doubles every death's events and touches every consumer; making `animated` rules-read and adding a second flag for the set card, which answers one question with two fields; resummoning an Animated card as a Unit, which no summon of a Field Spell or Trap does.
