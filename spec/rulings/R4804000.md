[[R451]]'s counts record a face-down play by the card's tags, its single-player set ([[R4593000]]) and the type it was played as, while the other seat saw only a Trap being set ([[R33]], [[R448]]). So [[R185]]'s redaction takes every card it hides on the opponent's backrow that the opponent owns, on top or in a pile beneath it, for a face-down play of theirs: its tags and its set come off the opponent's per-game counts, no count going below 0 and a count at 0 removed, and a play of it this turn (its [[R227]] id among the turn's plays) counts as a Trap. Nothing comes off for a card waiting in the resolving zone to be set, which is not counted until [[§10.5]] step 4. The seat's own counts stay, and so do the face-up plays both seats watched (C+ #64 Mulch Muncher's Fruit, C+ T-AI-2 Scaling Law's AI, C+ #37 Wardrum's types). This reads the common case and keeps no record: a card set face-down by an effect (a Recruit, [[§6.3]]) was never counted but loses its tags all the same, and a face-down card that went back to a hand keeps them in the count. Rejected: dropping the opponent's counts whole, which loses the face-up history the seat watched; marking each counted face-down play on the state, which changes the hash of every game that holds one.
