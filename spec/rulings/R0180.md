A game's setup may give each seat a handicap: `deckSize`, `manaBonus`, `manaCap`, `extraOpeningCards` and `extraDrawsPerTurn` ([[§9.9]]). A seat without one plays with this spec's resources (`HUMAN_HANDICAP`: 20, 0, 4, 0, 0), and a handicap equal to that is not stored, so a game with none hashes and replays exactly as before. The handicap lives on the seat's `PlayerState`, and `fold` takes the handicaps `createGame` took, so a handicapped game replays from `(seed, decks, handicaps, log)`. Only practice sets one; the server never does. The three practice tiers are `AI_DIFFICULTY` in `config.ts` and differ in the handicap alone: the AI's search, evaluation and budget are the same at every tier
