A player who picks All Random ([[R258]]) may also pick "More cards from the newest set", which names the set ("More cards from the newest set (Classic+)", [[R1371]]). Their own dealt deck then leans on that set: at least half of it from the set ([[R1370]]), the rest dealt as without it. It is each player's choice for their own seat only, and the other seat is dealt as it asked.

It is intent, sent with the request that makes the game, and the server deals the deck (CLAUDE.md rule 7): `leanNewest: true` on the queue's enqueue in All Random, on an All Random room's create (the host) and join (the joiner), and on a rematch offer after an All Random match ([[R672]]). Absent or `null` is off, so a client from before it plays as before; anything but a boolean is refused as a malformed request. The ask waits where the choice waits: a ticket keeps it until it is paired, an open room keeps the host's until it is joined, and a rematch offer keeps its seat's (the latest offer's stands). A ticket that leans pairs with one that does not: the option changes a seat's deck, never who it may be paired with ([[R257]]). The server resolves the newest set when it deals, deals the asking seat's deck from the same seed and seat as ever (`{seed}:p1-deck`, `{seed}:p2-deck`), and freezes the dealt decks into the match as [[R258]] does, so `(seed, decks, log)` still replays. A Best-of-1 rematch replays its frozen decks and reads no lean; the rematch's status names the mode it plays, so the death screen offers the switch beside an All Random one only.

The lobby shows the switch under All Random, and the death screen beside an All Random rematch's buttons. The pick is kept on the device, as the lobby's other picks are, and the rematch starts from it; a private window or blocked storage starts it off.
