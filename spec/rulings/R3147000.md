Roblox is one of [[R666]]'s providers. Supabase has no built-in Roblox provider, so each project has a custom OIDC provider whose identifier is `custom:roblox` (issuer `https://apis.roblox.com/oauth/`, scopes `openid profile`), and that identifier is the name the build names in `VITE_AUTH_OAUTH_PROVIDERS` and the client sends as the provider: no other `custom:` name is offered. The sign-in screen shows "Continue with Roblox", which leaves for Roblox exactly as R666's redirect leaves for any provider (a PKCE challenge kept here, back to `/login`), and the account screen lists Roblox among the providers it links and unlinks ([[R3025000]]), an identity of the provider `custom:roblox` counting as Roblox linked. Beside the button the sign-in screen says that a player who played before without Roblox signs in the way they did then and links Roblox on the account page. Roblox gives third-party apps no email address, so a Roblox sign-in never matches an account by one: a sign-up is a new pending account with no address, which adds one before its invite code ([[R3147001]]), and one that meant an older account can go back to it ([[R3147002]]). The account is R666's in every other way: it starts `pending` and passes the invite gate like any other ([[§9.4]]).
