C+ #74 is a Field Trap (the designer wrote Trap), since a Trap is consumed when it fires, which would leave nothing to gain Brittle. It has no Brittle while it is face-down ([[R687]]): its printed Brittle starts when it first activates ([[R385]], [[R687]]). It counts the opponent's plays since it was set, and on each even count, after that card resolves, a copy of the card's definition is fused into this ([[R77]]: this is the kept instance and stays a Field Trap; on the Radiant face the copy is Radiant), and then this gains +1 Brittle. Since patch v0.3.10 the card is never consumed and the trap is Animated, so it animates as the last step of its firing ([[R831011]]; before, the base face fused the card itself, which ceased to exist, when it still existed). The texts fused in work for its controller where they can (an end-of-turn line runs on their side, an aura covers it), a fused Cry never runs, since this is already on the field, and it turns face-up the first time it activates ([[R33]], [[R687]])
