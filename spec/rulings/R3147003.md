[[R1435]]'s prompt after activation starts with its field holding the username the account's sign-in provider gave it, so keeping it is one press of Save: the token's `user_metadata` `preferred_username` (Roblox's username, [[R3147000]]), else `user_name`, else `nickname`, trimmed, and nothing when none is a string. A full name or an address is never used. The field asks the server's preview for it at once, as for a typed name, so the player sees the username a save would give, its tag, or why it is refused ([[R1432]]); it stays the player's to change, and Skip for now keeps `Player#n`. `user_metadata` is the user's to edit, so it decides nothing: the server judges the name as any other.
