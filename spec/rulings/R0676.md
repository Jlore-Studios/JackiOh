When Glitch resolves, one number of the match rng picks one of `GLITCH_OUTCOMES` uniformly — reset, swap, boards, void — and a public `glitched` event names it. A reset is owed until the action that drew it has settled, then the state becomes a new game made from the decks and dealt seats `createGame` began with (`GameState.opening`): the seats' handicaps, last boards, Glitch boards and seat swaps kept, and the nonce log, with fresh ids numbered on from where the old game stopped in an order of the reset's own stream ([[R223]]); then [[§2.1]]'s setup runs again on the match rng, so the shuffle and the mulligans are new and `(seed, log)` still folds to the same state. Life totals, hands, decks and the turn count all start over
