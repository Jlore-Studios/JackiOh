A Starship Piece that dies Radiant fuses into its Starship on its Radiant face, so its Radiant script runs there ([[R469]]); a number its text reads is then the Radiant face's too. `param` reads the face of the card the text runs on, the Starship's, which is not Radiant, so a piece's When launched reads its declared numbers through `piece_number(ctx, def_id, radiant, key)`: the piece's own declaration, on the face its script was built for, with the Starship's tuning as `param` reads it ([[R386]]). A Radiant After Burner fused into a Starship grants 4 keywords, a base one 2. No shipped card reads a piece's numbers, so no fused card that ships plays differently.
