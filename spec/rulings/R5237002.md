A player's Float is the mana they leave unspent as their turn ends, the `turnEnded` event's `unspentMana` ([[R1563000]]). "Your Float last turn" (FvH #16.2 Travertine Golem's Attack and Armor) is the last one: the mana the player held unspent at the cleanup of their last turn ([[§2.2]]), 0 for a player whose turn has not yet ended. `PlayerState.lastFloat` records it at each of their cleanups, beside `turnLog.unspentAtEnd`, and nothing resets it, so it holds through the opponent's turn and the player's own next turn, until that turn's cleanup writes the new one; a Float of 0 is 0. `query::float_last_turn(state, player)` reads it. An extra turn's cleanup is a cleanup like any other, so the Float last turn is that turn's. The record is kept only in a game holding a Felinors vs Humans card, either side's, in any zone (`recursion_log::fvh_kept`, the set named by `FVH_KEPT_SET`), as the recursion log is kept only for the cards that read it ([[R4589000]]): in any other game it stays absent and reads 0, so no other game's hash moves ([[R768]]).
