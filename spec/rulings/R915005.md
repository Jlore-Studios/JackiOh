- **Practice only.** A deck that names a custom card plays against the AI in practice and nowhere else. A game is dealt with such a deck only when it is given every custom card the decks name (each valid by [[R915001]], each once); the deck is judged by L2, L3 and L6 otherwise, a custom card counting as one card.
- **Saving.** Decks are drafts ([[R250]]): D3 accepts a well-formed custom id, which need not name a card the player still has.
- **Online.** Every queue, room (a co-op room's included, [[§13.9]]), rematch and ranked path judges decks with the validator, and the validator refuses a deck that names a custom card first, with its own rule, **L7**: "a deck with a custom card plays only in practice". No other rule judges that card.
- The AI's deck never holds one.
