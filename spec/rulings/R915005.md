title: "A game is dealt a custom card only when it is given it (issue #915)"
cards: "§12.6, §9.4, R250, R253"
proven_in:

---
- **Dealt.** A game is dealt a deck that names a custom card only when it is given every custom card the decks name (each valid by [[R915001]], each once); the deck is judged by L2, L3 and L6 otherwise, a custom card counting as one card. Nothing gives a game one any more: custom cards are removed (issue #3096, #2956), and only this check, which leaves with the engine's custom-card host, is left of the rule.
- **Saving and queueing.** The validator knows no custom card (issue #3096). D3 refuses a custom id as any id that is no card a deck can hold, so a draft that names one is not saved ([[R250]]), and a deck or trio that names one is refused by L6 as a card the catalog does not hold, as the validator refuses any unknown card ([[R253]]). L7, "a deck with a custom card plays only in practice", and D3's allowance of a well-formed custom id are gone.
- The AI's deck never holds one.
