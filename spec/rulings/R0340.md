Importing a trio code makes one new deck per filled slot and one new trio naming them in their slots; nothing the player has is changed. If that would pass `MAX_SAVED_DECKS` or `MAX_SAVED_TRIOS`, nothing is made, and one sentence from the shared validator says how many deck and trio slots the import needs, how many are free and how many to delete; the workshop says it before the player asks, and the server says it again, with the numbers in `details`. Unowned cards and cards the imported decks share are kept, because a trio is a draft ([[R252]]): the preview says so, and the trio editor marks each shared card ([[R251]])
