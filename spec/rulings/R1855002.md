A preset entry's riders (`memory`) are written into the laid card's memory as it lands, in the shape a card made with a memory has ([[R862]]), so only its own text reads them. A restricted Resource pool is one: under `resourcePool`, a list of Resource definitions, it replaces the pool the card's own "gain N random Resources" names, and [[R1840002]]'s roll runs over it. A rider is part of the card's stay: it goes with [[R78]]'s reset when the card leaves the field, and a Death still reads it on the card as it died ([[R89]]), so an asteroid laid with a pool mines only that pool's Resources.
