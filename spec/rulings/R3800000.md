A fused Spell keeps every ingredient's end-of-turn text ([[R77]]), but [[§10.5]] step 7 flags it for the end-of-turn return ([[R155]]) only when a Spell ingredient's own text has an end-of-turn hook, read through fused ingredients in turn, each on the form it went in on ([[R469]]): the return from the graveyard is a Spell's ([[R68]], [[R153]]). A Unit's, a Field Spell's or a Trap's end-of-turn text is a permanent's, which runs on the field or in the backrow, so a flagged fused Spell's graveyard run makes no effect from one, nor once its own return has moved it to its hand. On the field or in the backrow those texts run as before, and a card an earlier effect of the same run took off the field still runs its later parts ([[R174]]). Hearthstone runs no permanent's text from a graveyard. Rejected: flagging any Spell with the hook, which made S #16 Rod of Ages' keyword gain land on a fused C+ #65 Two Grapes in its graveyard (Duos seed 1628); and the flag alone, which leaves a fused return Spell (#23 with S #16) running the other text from its graveyard and its hand.
