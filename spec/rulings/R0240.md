[[§4.4]]'s zero rule leaves that hit no `damage` event, which would leave a visible change with none ([[§10.3]]), so the draw is reported by a `damage` event of 0 from no source on that hero. It is a report and not a damage instance ([[R63]]): no trap and no trigger answers it, and nothing else about the pipeline changes
