`boardReplaced` ([[R1855000]]) carried only its player, so a client could not tell which of Stinkyscape's ten Anomalies a replacement laid until the board's cards had landed, and the owner wants discovering one to be an event of its own (issue #3337, part of #3330). `replace_board`'s argument gains an optional `anomaly`, the code of the Anomaly the preset is (`WH`, `BF`, `AL`, `AT`, `SP`, `MT`, `DH`, `FO`, `AN` or `AA`, as `t_anomaly_found.rs` names its boards), and `boardReplaced` names it in a field of the same name.

- Anomaly Found!'s board, held ([[R2247000]]) or drawn as it resolves ([[R1879000]]), and Call to Chaos (Scape Edition)'s Anomaly entry, any of the ten, both lay a preset that names its code.
- Any other replacement names none: the field is absent, and it is written only when set, so an older log's `boardReplaced`, which has none, reads and writes back unchanged and folds as it did ([[R767000]]).
- Both seats read it, as they read the event: the board it names is laid face up in public zones, its Traps aside, whose zones alone show ([[R97]], [[R202]]), and the code names the whole board, which the cards' own `summoned` events go on to lay. It reveals nothing a seat could not read from the board as it lands.

No rule reads it: it moves no state, so no replay hash, and the client draws the Anomaly's moment from it ([[R3337003]]).
