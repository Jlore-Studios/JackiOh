S #150's third entry reads "Summon 3 random Quests or Wincons" (ST-S25-2).

- **The pool.** The Field Spells with the Quest or the Wincon tag ([[R1422]]'s `anyTags`). A Spell with either tag (M #8, M #20, S #148.1) cannot be summoned, so it is not in the pool. The pool names every set the catalog orders (`CATALOG_SETS`), so the held set's own Quests and Wincons reach it while the set is held ([[R1420]]): C #90 In Too Deep, S #7 The Greatest Heist, S #112 Job Application and S #148 Alteran Reach. Tokens are out, as in every pool ([[§5.1]]).
- **Three picks.** Each is its own `summon_random`, drawn from the match rng ([[R60]]), so repeats are allowed, and each is summoned into its caster's backrow per [[R64]]. A summon with no open backrow zone takes no draw ([[R129]]), so a full backrow summons none past it.
