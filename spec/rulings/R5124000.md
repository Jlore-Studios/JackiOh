A downloaded replay file ([[R1141000]]) and a downloaded co-op replay file ([[R1242000]]) held every
step's whole view, so a game's file was 0.5 to 3 MB, though each step's view differs from the one
before it by a few fields and a few new events. The spec said what the file holds, not how it is
written.

**Packing.** The file holds the same object as before, its `steps` replaced by `packedSteps`: the
first step whole, and each later step as its JSON change from the step before. A change is `[]`
for a key the step drops, `[value]` for a value set whole, an object of keyed changes for an
object, and `{ e: ops }` for an array, whose ops walk the old array's elements in order: a positive
n keeps n, a negative n drops n, an array inserts its elements and an object changes the next
element; elements past the last op are kept. The ops keep the longest run of elements the two
arrays share, so the view's sliding `events` window and a hand or board that shifts cost only what
is new; between kept elements, each dropped element is paired with an inserted one as a change
when the change is the shorter. That JSON is gzipped by the browser's own `CompressionStream`, and
the file is saved as `.json.gz` (`application/gzip`), a type a bug report can attach. Measured on
twelve games of 250 KB to 2.4 MB, the files are a forty-seventh to a hundred-and-twenty-sixth of
their plain JSON, 84 times smaller in all; gzip alone made them 46 times smaller. A browser without
`CompressionStream`, or one whose gzip fails, saves the plain JSON file as before, `.json`.

**Opening.** Open replay JSON reads either: bytes that start as gzip does are unzipped and held to
`REPLAY_JSON_MAX_BYTES` as they are, refused as too big the moment they pass it, and refused as no
replay when the gzip is broken or, where the browser cannot unzip, as an unsupported format.
`packedSteps` are held to `REPLAY_JSON_MAX_STEPS` before any step is rebuilt, and a change of any
other shape, or naming a key that may never become an object key, is refused as no replay. The
rebuilt steps then meet every check [[R1141000]] and [[R1242000]] put on a plain file's, and the
format, the version and the catalog gate are unchanged: a packed file is no new version.

Nothing else enters the file: no seed or log, though a game's seed and log are a few KB, since they
would show what a seat could not see ([[R1141000]]).

Rejected: brotli, about a quarter smaller again but with no `CompressionStream` in every browser,
so a library in the bundle; and pairing a gap's dropped and inserted array elements by their best
alignment, which saved about 1% after gzip.
