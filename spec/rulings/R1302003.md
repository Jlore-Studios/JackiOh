id: R1302003
title: "Older set tracks unlock nearest-older first, one per payout (issue #1302)"
cards: "§14.7, §14.8"
proven_in:
  - crates/server/tests/api/rewards.rs
---
Once the newest set's track reaches `SET_TRACK_UNLOCK_LEVEL` ([[§14.7]]), each payout unlocks
at most one older track: the nearest older shipped set without a row, in catalog order. The
payout that carries the newest track to the unlock level is the one that unlocks, reading the
newest track after the game's XP landed. The unlocked track counts as active from that payout,
carrying the game's XP, and the next payout unlocks the next nearest older one the same way.

Hearthstone semantics: no Hearthstone system to follow; the order follows the backlog's own
shape. Nearest-older first keeps the newest set's backlog adjacent: the player finishes the
newest set's early rewards, then opens the set they missed most recently, one set at a time,
instead of choosing among a backlog or opening the oldest first.

Rejected: unlocking every older track at once, which would split one game's XP across five
tracks and pay five first-level tables for it; and oldest-first, which opens the set the
player is least likely to care about while the rest wait.
