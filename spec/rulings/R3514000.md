[[R1143]] makes a hand size a setting and bounds it from above, at `HAND_CAP_MAX` (14), and says nothing of a
setting below 0. No card sets one: Meditative #79 Touched by KY sets the size its `handSize` names, 12, which
its tuning holds between 11 and 14. But `setHandCap` takes any whole number, so the engine has to read one.

**What it does.** `set_hand_cap` holds the size it sets to 0 or more, as it holds it to 14 or less: a size set
below 0 is 0. A hand of size 0 has no room (`room_in` is 0), so every card drawn, added or taken into it is
burned ([[R4]]), and a hand already holding cards keeps them, as under any lowered size ([[R1143]]).

Hearthstone semantics: no hand holds fewer than 0 cards, and a card that meets a full hand is burned.

Rejected: refusing the effect, which would make a card's text do nothing where its nearest reading is a hand
that holds nothing; keeping the earlier size, the same; and reading a negative size as no cap, which would turn
the smallest hand into the largest.
