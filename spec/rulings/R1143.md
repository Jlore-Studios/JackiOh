## R1143 — A hand size is a setting, not an increase, and is at most 14

Built (ME-HANDCAP, Meditative #79). "For the rest of the game, your hand size is N" sets that
player's hand cap to N (`set_hand_cap`), whether or not the card that set it stays on the field.
It is a setting, not an increase: the latest setting wins, and a second one changes nothing when
N is the same. The cap is at most `HAND_CAP_MAX` (14), the most cards the client lays out, and a
setting above it lands on 14. Every rule that reads the hand cap reads it — draws, adds, steals,
"fill your hand" and "your hand is full" — and a hand already above a lowered cap keeps its
cards; only what arrives past it burns ([[R4]]). It is public in both views, and absent until an
effect sets one, so a game that never sets one serialises and hashes as before.
