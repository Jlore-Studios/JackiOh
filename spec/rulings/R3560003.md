"The last Unit this damaged" (S+ #120 Crawler's Death) is the last Unit it dealt more than 0 to, remembered across turns ([[§4.4]]). It hits that Unit only while the Unit is on the field; heroes never count. A kill in the same pass as its own death counts ([[§4.5]]).

Rejected: its last target.
