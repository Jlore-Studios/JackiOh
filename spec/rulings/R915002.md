A custom card's script returns `Card { … }` in the card kit ([[§12.3]]): hooks (`cry`, `death`, `startOfTurn`, `endOfTurn`, `aura`, `activate`), a declared play-time `target`, verbs that record effects in order, target words, numbers read by name on the running face, and board readings. The kit is the only Luau a custom card sees: `require` is refused, and the engine's raw verbs stay underneath.

- The engine depends on no Luau host. A host that can build a custom card's scripts is lent to it for one call (`custom::with_custom_scripts`), and the engine asks it for the scripts of the custom card its state holds; with no host lent, a custom card has no script. The host holds compiled scripts only, keyed by the card's id and source, never game state, so a reduce under it is a pure function of its inputs (CLAUDE.md rule 4).
- The kit plays a card as an official card plays: a declared `target` is chosen as the card is played, and its effects resolve in the order the verbs recorded them once the hook returns.
