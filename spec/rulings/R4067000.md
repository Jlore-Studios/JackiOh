[[§15.9]] reads curses as distinct tiers chosen at the start, like Ascension, and [[R2922001]]
applies each curse's fight effect once, but [[§15.3]] never said distinct, so a repeated id summed
its points in `run_score`, multiplied the Embers, and applied the fight effect once per copy. As
Hearthstone's Dungeon Run takes each treasure at most once, each curse is taken at most once: a
setup listing one twice is refused with `{id} is taken twice`, worded as the relic refusal is,
since the start screen shows refusals word for word. `run_create` and `run_fold` refuse through
`run_check_setup` before building any state, so a refused setup changes nothing.

Rejected:

- **Silently dropping duplicates:** it would fold a hand-edited run file's corruption into a
  different run instead of refusing it, unlike the relic rule.
