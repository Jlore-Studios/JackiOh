Stinkyscape+ Balance Changes VI: S+ #77 Black Hole's "At the start of each player's turn, it draws their permanents one lane closer" becomes "At the end of each player's turn". The designer's line quotes the base face's words, so only the base face moves: the Radiant face's "At the start of your opponent's turn" stays as printed, pulling the opponent's permanents before they act. The hole the base face opens carries `atEnd` (`openBlackHole { atEnd }`, `BlackHole.at_end`), and at the end of each player's turn it draws that player's permanents one lane toward it, by [[R3554001]]'s walk unchanged; at a turn's start such a hole pulls nothing. The pull is a stage of the turn's end, not a trigger: the hole is no card, as at the start, where it follows the Toxic tick. It comes right after the Burn tick ([[R4154000]]), so after the end-of-turn triggers, the trap window and the delayed effects ([[R62]]), and settles with them before cleanup. The hole opens on its caster's turn, so their own permanents are the first it pulls, at the end of that turn, as Hearthstone's "at the end of each turn" counts the turn it is played on. Swallowing and closing are as before ([[R3554000]], [[R3561000]]). Rejected: moving the Radiant face too, which its text does not say. Through v0.6.9n the base face's hole pulled at the start of each player's turn, which `script_v0_6_9n` keeps for those replays ([[R767000]]).
