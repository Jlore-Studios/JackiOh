S #4 Olivian Expanse's "Discover a Terminus card" and S #154 Dice of Doom's "add every Terminus card" read the Terminus pool (`query::terminus_cards`, the `terminus` pool of `spec/CARDS.md`): every card and token tagged Terminus, from the sets that ship ([[R380]], [[R1420]]), tokens asked for since Terminus is no tag a pool's tokens join by ([[R382]]). Through v0.6.0g both named seven by id, Core #100 Ceaseless Void ([[R1837000]]) and S #4.1 to S #4.6 ([[R1857002]]), as they had to while the Stinkyscape set was held; the Stinkyscape+ set's Terminus cards and tokens never joined, though its own Terminus cards read the tag. Now a Terminus card any set prints joins both by itself. Olivian Expanse's Discover offers three different ones as before ([[R1870000]]). A Dice of Doom hit adds one of each in the pool's order (set by set, each set in §5 index order), each at (0), and a full hand burns the rest in that order ([[§2.4]]), so with sixteen in the pool an empty hand keeps the first ten. Games through v0.6.0g fold under the kept scripts ([[R767000]]). Rejected: keeping the seven as a designed list, which the cards' text does not name, and adding only as many as the hand holds, which would draw nothing to burn where Hearthstone burns.
