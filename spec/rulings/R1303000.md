A practice game ([[§9.9]]) pays ([[§14.8]]) only when an active account started it as a free game,
from the practice setup or from Play again, on a seed the server issued for that setup, and only
while the economy is live ([[§14.12]], [[R1302006]]). The page asks for the seed before the game
begins and keeps it in the game's config (`earning`); the worker answers the finished game's claim,
its seed, the result for the human and the whole log, and nothing else. No other practice game
asks for a seed or claims: never a tutorial lesson (its fixed seed and decks are the same for
everyone), a sandbox game (its tools build any board, [[R923000]]), a game with custom cards (the
server runs no Luau, [[R915005]]), the creator's Try it, a game whose seed the URL fixes, or a game
the e2e fixture pool deals the AI. The server holds the same line on its own: it folds every
claim as a plain game, so a sandbox tool or a custom card in a claim does not fold, and a game
Glitch voided ([[R679]]) pays nothing. Any other practice game records nothing, as [[R187]] says.

Hearthstone semantics: Hearthstone's Practice mode pays no gold and moves no quest, since the
server cannot see the game; a game the server can check, and only that, pays here.
