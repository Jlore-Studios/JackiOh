S+ #38 Arc reads "Deal 2 damage to a unit, this randomly chains to an adjacent unit". The spec says
neither which Units it may name nor what happens when there is none.

The target is a declared Unit ([[R81]]) on either side and in either row, never a hero, but never Arc
itself, as Hearthstone keeps a minion's own targeted text off the minion. The Activate is not offered
when there is no such Unit ([[R430]]), so a lone Arc has nothing to do. It is `damage` uses a turn
([[R384]]): 2 on the base face, 5 on the Radiant face. The chain is chain lightning ([[R3554006]]),
and it may still reach Arc: a Unit beside Arc that is struck jumps the chain onto it.

Rejected: Arc as its own target, which would let a lone Arc hurt itself for nothing.
