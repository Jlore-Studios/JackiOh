While `navigator.connection.saveData` is true the engine fetches no voice bytes except the
targeted `preloadVoices` keys for the cards in view and the file of a line asked to play
([[§10.11]]): the bulk prefetch of every manifest line's bytes never starts, and a schedule
already made fetches nothing when it comes due. Hearthstone makes no save-data decision; this
follows the browser signal per [[R2116000]]'s precedent. Rejected: prefetching anyway, since
the 17.6 MB bulk download is what the player asked to avoid.
