"Face-down card" is `preview::is_face_down`: a backrow Trap or Field Trap neither flipped face-up nor revealed. A Unit set by its Cloaked counts (it is the Trap it was set as); a Revealed one does not. Shell Game's draw counts its own Figment, which lands before the count ([[R61]]). The Lie Detector sets one Figment per card its destroy marked, as many as fit.
