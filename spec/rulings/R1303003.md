A practice game on a server seed ([[R1303000]]) brings the human's last board ([[R508]]) from the
server, not the device: the board of the account's last paid practice game, which the server
keeps once that claim pays (`last_boards`, kind `practice`, read from the seat the human ended
in, [[R417]]), sent with the seed and kept with the seed's setup, which the claim is folded from.
An account with no paid practice game brings none. A game that earns nothing still reads and
writes the device's board as [[R508]] says.

Rejected: the device's board. It is the client's word, and C+ #29 plays the board it is given,
so a forged one would buy a stronger start for a paying game.

Hearthstone semantics: Hearthstone has no last board; what a card reads of a past game is what
the server recorded of it.
