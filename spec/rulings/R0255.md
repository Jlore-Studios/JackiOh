A deck is shared as a code: `JKO`, `DECK_CODE_VERSION`, a dot, then base64url of the deck's name, its cards as catalog numbers and a checksum. Since patch v0.2.0 `DECK_CODE_VERSION` is 2 and each number carries its set, since a [[§5]] index is unique only within one ([[R380]]): Core n, Classic 1000 + n, Classic+ 2000 + n, and since the patch that ships the Meditative set Meditative 3000 + n ([[R1410]]), still LEB128; a version 1 code, as every code minted before it is, is read as Core numbers. Input longer than `DECK_CODE_MAX_INPUT_LENGTH` (512) is refused unread, as are a wrong prefix, a version other than 1 or 2 and a failed checksum, each with its own sentence. An import always makes a new deck: numbers the catalog does not have and Tokens are dropped, copies past `MAX_COPIES` and cards past `DECK_SIZE` are dropped, every drop is reported, and cards the player does not own are kept and marked, since a deck is a draft ([[R250]]). The code is the client's: the server checks the saved deck like any other
