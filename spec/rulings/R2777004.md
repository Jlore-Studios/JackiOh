**Why.** The owner asked on 2026-11-04 for `/stats` to open on all game modes, always. The page opened on Constructed, and production had no Constructed games yet, so it showed an empty table with 12,000 All Random games one choice away.

**The page.** `/stats`' match-type picker offers five choices:
1. **All modes**, first, and what the page opens on. An address with no `mode`, with `mode=all`, or with a mode the page does not offer reads it, and the address names `mode` only when it is another.
2. **Constructed**.
3. **All Random**.
4. **Best of 1**.
5. **Conquest**.

The Cards tab, the Sets tab, the Game figures and the drill-down read the mode picked. A rate under All modes mixes chosen decks with dealt ones, which is why [[R2777001]] took it off the page. The owner chose that mix for the page's opening view, with the two kinds still one choice away. The routes do not change: no `mode`, or `?mode=all`, already answered every mode.

Rejected:
- Opening on All Random only while Constructed has no games. The opening view would change on its own with the first Constructed game, and the owner asked for one default, always.

No Hearthstone rule is involved.
