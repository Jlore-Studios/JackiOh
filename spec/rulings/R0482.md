[[R386]] declares a card's tunable numbers as `params` and writes them `{key}`. Every number a Classic or Classic+ card's "Tunes:" lists ([[§8.6]], [[§8.7]]) is one param `{ key, base, radiant, better, step, min, max? }`: `better` "up" when more is better for the card's controller (an item with no arrow is its effect's own strength, "up"); `step` as stated, else `PARAM_DEFAULT_STEP` from the base value (1 up to 5, 2 for 6–12, a quarter above); `min` as stated, else 1, or 0 for a number printed 0, and never so low that the effect stops (Argusland's divisor stops at 2); `max` only when stated, 100 for a percentage. The ten AI generated cards have no "Tunes:" and declare none: their numbers are printed, and Degrade has fewer options on them. The number is written in each face's text that shows it and nowhere as a literal: `{key}` for the number alone ("Deal {damage} damage."), `{key|singular|plural}` for a count and the words that agree with it ("Draw {draw|card|cards}." prints "Draw 1 card." and "Draw 2 cards."), and a sentence after a count that would need an agreeing pronoun says "Each …" ("Each costs (0)."), so a text reads right at every value a Degrade or an Upgrade can move it to; a Radiant-only number is written in the Radiant text alone, with the same value on both faces, unless it declares `tunedOn: "radiant"`: a number the base face leaves out of its text at a value of its own (C #46's multiplier, C #54's repeats) is tuned on the Radiant face only, so the base face never does more than it says ([[R749]]); a number only the base face writes declares `tunedOn: "base"`, so the Radiant face never carries a change its text does not show ([[R1426]]). A numbered keyword (Armor, Lucky, Brittle, Spell Damage) and an Echo, Tribute or Activate count is no param: [[R386]]'s X change tunes those. `fill_params` (`crates/engine/src/wire/catalog_types.rs`, and the client's `fillParams`) fills a face from its printed values or an instance's current ones, and [[R277]]'s diff, [[R276]]'s check and the text tests read a face through it
