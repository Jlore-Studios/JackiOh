The designer's "Training-grounds", "Training-Grounds" and "Tutorial-Grounds" (TG #36 Training Dummy) in a card's text are the one set, written "Training Grounds" in the catalog's text. "A random Training-Grounds card" (TG #20, #36, #38, #39's entries 3, 5 and 6) is a pool that names the set (`{ "set": "Training Grounds" }`), so it reaches the set's cards while the set is held ([[R1420]]), never the card that makes it ([[R387]]) and no token unless it asks for tokens; once part 2 (#2195) lands the snapshots #41–#60 it holds them too, as cards of the set. Legendary and Mythic cards are in it in every game but a tutorial lesson that holds them out (#2201). A pool that names no set (TG #40's "a random card", TG #39's "a random Call to Chaos") draws from the sets that ship ([[R380]]), so it holds no Training Grounds card until the set ships.
