[[R1431]]'s mirror. [[R749]] marked C #46's and C #54's numbers and left every other number only the Radiant face prints tuned on both faces: thirty-one, on the cards above but C+ #41 (C+ #32.3 Blade Storm has two). On a card that is not Radiant, a Nerf, a Buff or C+ #41 KY's Constant could land on one, spending a draw on a number its text does not show or, for Blade Storm's round cap, which its base face uses unprinted ([[R652]]), changing what the base face does. Each now declares `tunedOn: "radiant"`: on the base face it reads its printed value whatever the tuning, a Nerf or a Buff never draws it (with nothing else to change nothing is drawn, [[R129]]), KY's Constant does not list it, and no changed number shows ([[R513]]); on the Radiant face it is tuned as any number is. Blade Storm's base face always stops after `BLADE_STORM_ROUNDS` (30) rounds. As in Hearthstone, a change reaches only what the card's text says. `catalog check` refuses such a number unmarked, a new card's included.
