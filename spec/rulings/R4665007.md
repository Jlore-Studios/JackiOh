Stinkyscape+ Balance Changes VII: Tranquility "gains Tradable; Radiant gains Replenish 2 mana". Both faces print Tradable, a catalog keyword. The Radiant face's list opens with "Replenish {refresh} mana", the `refresh_mana` S #8.1 Rosemary Triscuit's is, of the declared `refresh` 2, a number the Radiant face alone prints ([[R1431]], [[R386]]), then grants the immunity and exiles itself as before. The number is read with `param_or` at 0, so under a definition that declares no `refresh`, as every one through v0.6.12c, it replenishes nothing and a replay needs no kept script ([[R2657006]]).
