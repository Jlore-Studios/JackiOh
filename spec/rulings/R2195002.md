A card's text that names a Core card by the name its Training Grounds snapshot shares ([[R2195001]]) names the Core card alone, as R381's rules words name no card: S #88 Siva 2's "Bigots", C+ #61 Bauble Bubble's "Stockpile" and Core #76 Field of Dreams' "Reminisce" keep making and listing the Core cards (`refs`, [[R279]]), before and after the set ships. No text names a snapshot.

Amended by issue #2511 ([[R2511000]]): a Legacy card is named `Legacy: <its Core card's name>`, so the name these texts print is the Core card's alone and no exception is left to read.
