A 1v1 finalist's score takes half of the learned network's correction ([[R1012001]]), and the network has no row for a card it was never fitted on: such a card is read only through what it is, its type, cost, tags, keywords and stats, as any card like it. [[R3038003]] found the same network, fitted before a set existed, flipping a removal choice by 27 points on a board it could not read, and kept the hand evaluation for a decision that holds a Starship. No Hearthstone rule is involved: the evaluation changes no game.

**What changes.** At a decision's root (`plan`), beside the Starship fact, the AI counts the copies of cards its redacted view names by id ([[R3112002]]'s count, `unknown_cards` over `features` of that view: its own hand, both fields and the backrow it can read) and how many of them name an id the network has no row for (`Learned::known_card_ids`). When more than `LEARNED_MAX_UNKNOWN_SHARE` of them do (`mostly_unknown`, `unknown_root`), the fact rides with the root's prices (`Prices.unknown_root`), and with it set `finalist_score_with` returns the hand evaluation for every line of the decision, on every determinization, as it does for a Starship root, so the lines stay comparable. A card is unknown by the network's own keys alone: no set, card-id prefix or catalog version is named in the rule or its code, so a card from a set released after the network was fitted counts as unknown from its first day, and one the network is refitted on counts as known with no edit. The threshold is a share of the copies named, so it holds however many sets the network never saw and however large they are.

**Reach.** A Duos duel ([[R1010002]]), the tutorial's opponent ([[R1012003]]) and a finished game keep the hand evaluation as before, and the Starship fact is its own and unchanged. A view that names no card sets no fact. The enemy's hand, both libraries and a face-down card the seat cannot read are hidden cards ([[R185]]) and never counted, so two states that differ only in hidden cards give the same fact. A call outside a decision (`Prices::NONE`) reads no fact, so the probes, the baselines and the tools are as they were. Everywhere else the network's correction is taken at its share, as before.

**The screen.** It was set down in the issue's plan before it ran: one arm, the threshold at a half, 400 games on the improve lane's dev set (`cargo jackioh arena --a self --b bin:<control> --set improve-dev`: deals `improve-dev:1` to `:200`, each played twice with the seats swapped, [[R850000]], [[R850001]]), against a control built from `3f8896c61d`, the commit before this change. Its compiled-in `weights.json` names `catalog: v0.3.17`, so the threshold was picked before any retrain on the sets the issue counted, Stinkyscape and Training Grounds. A second arm, at three quarters, was to run only if the first lost. The arm won 204 games to the control's 196, with no draw and none aborted, over 200 deals: edge +0.020, its 95% interval −0.017 to +0.057. In 14 deals one side won both games, the switch in 9 and the control in 5, and no game failed its replay, caught a search panic, fell back or threw. The rule set before it ran read a gain when the interval's low end is above 0, a loss when its high end is below 0 and even otherwise, and shipped the arm unless it lost. The screen is even: no gain was measured. The switch ships on [[R3038003]]'s ground, that the network's correction of a position it cannot read is no evidence, and the screen rules out, at 95%, a loss larger than 0.017 of edge on the dev set.

**Rejected.** Listing the sets, card-id prefixes or catalog versions the network lacks: the next set to reach the AI's decks would need an edit to be caught, and a retrain another to be released. Folding the fact into the Starship one: that one covers a mechanic the hand evaluation prices differently, not only cards the network never saw. Reading the fact off each position scored rather than the root: a line that played or removed cards would change evaluation in the middle of a decision ([[R3038003]]). Counting hidden cards: the AI decides from what its seat may know ([[R185]]). A continuous blend, the network's share falling as the unknown share rises: a second knob no screen measured. Screening several thresholds and keeping the one that read best: `training/improve.md` forbids keeping the best of several arms of a knob.
