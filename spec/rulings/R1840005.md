Credits are a count each player has, `PlayerState.marketCredits`, public on both seats as the view's `marketCredits` ([[§10.8]]), and absent until first gained, so a game without them serializes, hashes and views as before, as the Jade Counter is ([[R961]]). A sale ([[R1840001]]) and `gain_market_credits { amount }` (Paycheck, Megabase) raise it and report the new count with the public `marketCreditsChanged`; a gain of 0 or less changes and reports nothing. The Marketplace spends them (#1853). Jlarna's credit line owns `credit` on a seat's view ([[R1223]]), so these are named apart from it.
