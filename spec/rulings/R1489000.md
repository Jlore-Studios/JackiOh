**Why.** [[§9.9]]'s gates fail a game that is not clean, and in the browser a caught panic is a trap that loses the decision. The arena counted only "no move", and `promote` counted only wins.

**The arena.** It counts per seat: an agent's "no move" and an AI decision off the fallback path each count a fallback, and each seat's caught search panics are summed, the first keeping its message. A `bin:` seat is counted from its verbose answers (`reason` and `stats.simPanics`), and a build that sends neither field counts none. The duel line reports both seats' totals as `fallbacks` and `simPanics`.

**The promotion gate.** It fails on any refusal, throw, fallback, caught panic or replay mismatch on either seat. The parent's seat counts too, since it is `main`'s AI. Each such game is named by its seed and the candidate's seat. A game without a result is still only a lost win.

**Self-play.** It keeps one line per game ([[R1006001]]) and marks a faulted game with `faults`. `positions` leaves that game out, counted `unclean`, beside [[R1006003]]'s drops, so the learned evaluation never learns a move the AI did not choose. Throws keep [[R1006005]]/[[R1006007]]'s no-result path.
