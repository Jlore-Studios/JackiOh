"For the rest of the game, … at the end of each of your turns" is [[R458]]'s rest-of-game player effect with `atEnd` (`forRestOfGame { atEnd: true }`): the same `never`-expiry modifier on the player, the same badge in both views ([[R169]]), resolving with no `self` whatever became of the card that made it ([[R127]]), but re-entered in the end of turn's delayed stage ([[R62]]) instead of the start's, once at the end of each of that player's turns and never at the other player's. It comes due first at the end of the turn it is made on, when it is made before that turn's end-of-turn stage begins (a Death in the main phase, as Hearthstone's "at the end of your turn" counts the turn it is made on); one made inside that stage waits for the player's next end of turn. It runs in creation order with the end-of-turn delayed effects ([[R68]]), and several stack, each running once a turn.
