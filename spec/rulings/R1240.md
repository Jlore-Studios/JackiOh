Call to Chaos (Meditative Edition) is the third card with the Call to Chaos tag, after #95 and C+ #73, and a third table on #95's roll, as C+ #73's is: `CHAOS_MED_EFFECTS` (`subsystems/call_to_chaos_meditative.rs`) holds its ten entries, each built as it resolves, so each reads the board after the ones before it ([[R87]]) and a prompt parks the rest ([[R113]]), and its card file is C+ #73's one-liner. Every rule written for the two editions reads every edition: "cast a random Call to Chaos" ([[R28]]), C+ #73's deck replacement ([[R387]]) and every other Call to Chaos pool draw uniformly from all three; `CALL_TO_CHAOS_CHAIN_CAP` counts casts of all three, a Call a random cast makes included ([[R593]]); the Radiant face's three different entries resolve in the list's order, the recursion where it falls ([[R423]]); a recursion rolled at the cap resolves into nothing ([[R87]]); and both players are told what each roll drew (`chaosRolled`, [[R436]]). A pool that names no set reaches Meditative #95 only once its set ships ([[R380]], [[R1420]]): until then the Call to Chaos pool is #95 and C+ #73, for Meditative #95's own recursion too. The Calls a recursion casts are base Calls ([[R28]]).
