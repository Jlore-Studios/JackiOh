A win gives `RANK_WIN_PIPS` pips and a loss takes `RANK_LOSS_PIPS`; a draw moves nothing. A game played a division or more (`RANK_CONVERGENCE_GAP_PIPS`) away from the rank the player's new rating calls for leans `RANK_CONVERGENCE_PIPS` pip harder toward it when the game's own move already heads that way — a win below the called-for rank gives one pip more, a loss above it takes one pip more — so the visible rank converges on true skill without big point swings; a game heading away moves its usual pip. A win streak of `RANK_STREAK_LENGTH` or more earns `RANK_STREAK_BONUS_PIPS` bonus pips per win below Mythic Grape; a loss ends the streak and a draw neither extends nor ends it
