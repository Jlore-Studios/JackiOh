In one handicapped game, Core #99 Craft a Card fused two Discovered Units into a (0) card in its caster's hand. That gave the hand its third (0) card, so an immune C+ #49 Jay Fungus ("Evolves when your hand has at least 3 (0) Cost cards") evolved at the settled state check ([[R3536001]]), inside Craft a Card's run. The fuzz monitor's I21 (issue #4508) blamed the `evolved` on the Spell.
**The evolving is the Unit's own.** A standing "Evolves when …" is the Unit's own text, which the state check reads after every effect list ([[R3536001]]). The Spell changed only the hand, which it may reach, and [[§6.1]] keeps a Spell's effects off the Unit, not the Unit's own text off itself. The `evolve` verb, the only other way a Unit evolves, aims through the targeting point, which passes an immune Unit by for a Spell ([[R4453000]]).
**What I21 allows.** I21 allows an `evolved` of an immune Unit in a Spell's run when its own text holds an "Evolves when …" condition. One with no such condition evolves only by the verb, so in a Spell's run it is still a reach.
Rejected: marking the settled state check's evolutions with an event of their own. That would change the event stream every client and replay reads, to tell the monitor what the script already says.
