The Jade Counter is a public count each player has. It starts at 0 and only rises. The player who
resolves a Jade or a Red Jade adds to their own counter, and both seats see it beside that player's
hero. The state holds it absent until it first rises, so a game without a Jade serializes as before
it existed. The event is `jadeChanged`, public on both seats. "Jade Counter" is a rules phrase
([[R381]]): the "Jade" inside it names nothing, so neither Jade nor Red Jade lists a `refs` for the
Counter alone.
