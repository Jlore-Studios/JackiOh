Three Jlockeed cards add "a random Starship Piece" to their caster's hand: S #124 three at once, S #125 one an Activate, S #126 one at each start of turn for the rest of the game. No tag names the pieces, and the catalog query had no keyword field (ST-S19-1).

- **The filter.** The catalog query takes `keywords`, a list of keyword kinds a card must print on its base face, every one of them, as `stats` reads the printed base face ([[R1080]]). A keyword a card gains in play (granted, lent by its Embiggened version, [[R1878001]], or given by an aura) is not printed, so no pool reads it, and a card whose Radiant face alone printed the keyword would not be in the pool (no card is). Like every other field it narrows the pool and leaves tokens out unless the query takes them.
- **The pool.** "A random Starship Piece" is `query::starship_pieces()`: every non-token card that prints Starship Piece. The Dormant Starship prints none, so it is never one ([[R1857001]]), and no token is, so a Stinkyscape Golem or an AI card that prints it stays out. The pool names Stinkyscape, the one set that prints the keyword, so it reaches the pieces while [[R1420]]'s gate holds the set and reads the same once the set ships ([[R380]]).
- **The draws.** Each card is one draw of the match rng ([[R60]]), repeats allowed, and a full hand burns what does not fit ([[§2.4]]). None of the three is a piece, so none needs [[R387]] to leave itself out.
