IA #4 Wave Spawner's "End of turn: If you played a Created card this turn" reads the cards its controller played this turn (the turn log's `played_ids`, a cast counting as a play, [[R70]]) and asks of each whether it is Created ([[R943]]), where the game holds it as the end of turn runs. A Created Wave Spawner played this turn is one of them. A token that has ceased to exist since it was played ([[R11]]) is held nowhere, so it is no longer read; a card that left the field for a pile still is.
