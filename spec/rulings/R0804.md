"Prime indexed" (Meditative #14 Prime Time) means the card's catalog index is a prime number (2, 3, 5 … 101), in any set: indices repeat across sets, so Core #2 and Meditative #2 both count. It does not mean a position in the deck, whose order is hidden. A token's "N.k" or T-name index, and a transient card's index (which is its id), are never prime. Each draw takes the topmost match ([[R801]]); the Radiant face takes every match, and the hand cap burns the overflow.
