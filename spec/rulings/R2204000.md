A set reaching `SHIPPED_SETS` ([[R1420]]) is a major and opens the next release line ([[R1365000]], [[R1366000]], [[R1369000]]), unless the owner wraps it into the line of an earlier set. `WRAPPED_SETS` in `crates/tools/src/classify.rs` lists each wrapped set with the set whose line it joins (CLAUDE.md rule 9). A wrapped set's arrival is no major: every card of it plays differently once it ships, whether or not its catalog entry moved while it was held, so it earns the tier its cards do, a patch for any set of `PATCH_MIN_CARDS` families or more. `patches ship` then names it `v0.Z.(X+1)` within the line, and records the tier `patch`, so the Patch notes page and `technical.rs` (which read the recorded tier first) open no line for it. The line it joins is renamed for both sets and carries a summary sentence and the technical changes of each.

An unwrapped set is still a major. Wrapping is the owner's decision, never a builder's: the owner wrapped **Training Grounds** into Stinkyscape's v0.5 on 2026-10-28 (issue #2204), so it ships as a v0.5.X patch and the v0.5 line is "Stinkyscape & Training Grounds". It is still the newest set ([[R1371]]): the version a set ships under does not change which set is newest.
