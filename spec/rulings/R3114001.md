The AI's shadow ban ([[R186]]) holds a set's cards only when the set's row of the set table ([[R3114000]]) gives it a share, `(part, whole)`, and holds at most that share of the set's non-token cards, rounded down (`shadow_ban_ceiling`): half for the Meditative set ([[R732000]]), the Meditative+ set ([[R1186000]]) and the Training Grounds set ([[R2203000]]), a fifth for the Stinkyscape set ([[R1885000]]). `cargo jackioh sweep --write` refuses reports of record that ban more, counting the set's non-token cards in the catalog as it is, so the ceiling follows the set when its size changes rather than a number worked out by hand: Stinkyscape's fifth is 35 of its 178 cards, as it was 35 of its 175. No ceiling changes.
