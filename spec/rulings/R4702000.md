**Why.** [[R4701000]] removed what ran the AI's retired training lanes and left the Rust they ran to a session that could build it. An audit of the AI for code nothing reads (2026-11-24) found that Rust, and beside it the unban lane's deck shaping, which no deal had asked for since [[R976000]].

**What is removed.**

- `cargo jackioh positions` (`crates/tools/src/positions.rs`) and the features it wrote (`crates/ai/src/features.rs`, `FEATURES_VERSION`), with `decide::decision_prices_at` and `AI_DECISION_PRICE_NODES`, which only `positions` read. [[R1006000]], [[R1006003]], [[R1006004]], [[R1006006]], [[R1012004]], [[R3112000]] and [[R4070000]] are retired; [[R1171000]] and [[R3112002]] were already.
- `cargo jackioh stats from-selfplay` (`crates/tools/src/selfplay_records.rs`), which filed the learn lane's exports as development records ([[R1676000]]). `stats --series` keeps refusing a series that begins `selfplay:`, so no run takes an id those records hold.
- `AiDeckOptions::shape`, `shaped_weight`, `DEALT_Q` and `UNBANNED_PREFER` (`crates/ai/src/shadow_ban.rs`), and `cargo jackioh stats fit-dealt` (`crates/tools/src/dealt_fit.rs`), which refitted the table from the unban lane's arena records. Every deal is unshaped, as it was ([[R976000]]): the option was off in every caller.
- `docs/learned-eval.md`, the record of the retired learned evaluation ([[R4159000]]). An earlier ruling that cites it, the features, `positions` or the shaping table says what stood until this one; git history holds the file (`git show 3a83bd7:docs/learned-eval.md`).

**What stays.**

- `cargo jackioh selfplay` ([[R1006001]], [[R1006002]], [[R1006005]], [[R1006007]], [[R1489000]]). Issue #4702 listed it, but `cargo jackioh classify` runs it: its AI check plays the head and its base with the command and compares the logs ([[R1365000]], `classify::start_selfplay`), which CI's `rust (classify)` runs on every pull request that changes the AI. Its games are written as before, and nothing folds them back.
- `cargo jackioh promote`, CI's `rust (training gate)` and the rulings that describe them ([[R850000]], [[R850001]], [[R1012000]], [[R1679000]], [[R732001]]): #4702 removes them unless an AI change still gates through `promote`. No promotion has been written since generation 13 (2026-10-21), and `sweep --due` reads the generation it writes ([[R1678000]]).

No decision of the AI changes: no line removed here was reached by `decide`, a gate, the sweep or a deal.

**Rejected:** removing `selfplay` and giving `classify` another way to play its check, which would change a required check to delete a command that works; keeping the shaping table for a later decision on practice's decks, since its rows are the win shares of an AI four sets and one evaluation ago and nothing can refit them.
