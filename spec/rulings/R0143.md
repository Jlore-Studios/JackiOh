title: Who chooses a match's seed
cards: "§9.3, §9.5"
proven_in:
  - crates/server/tests/api/e2e.rs
---
The server mints it; a client never supplies one. In end-to-end mode the room and queue endpoints accept an optional seed and use it verbatim so a networked spec can be seeded, and outside that mode the field is rejected. [[§9.3]] makes `(seed, log)` the truth without saying who picks the seed, and BUILD requires every spec to set one, so the exception is confined to the test mode
