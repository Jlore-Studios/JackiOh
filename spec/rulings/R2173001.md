[[R1846003]] owed a script change that moves a card across a threshold counted as a change to how the cards that read the lists play: `classify` ([[R1365000]]) reads a script's code without its `use` lines or its layout, and so misses a move a `use` line or a reflow makes, while the count ([[R1846000]]) takes both.

So `cargo jackioh classify` reads every card script on each side of the change, with each side's `BUSTED_CODE_LINES` and `COMPLICATED_CODE_LINES`, and makes each side's lists as the build would. When a card whose script reads the lists ([[R2173000]]) ships on both sides, and the lists differ between the sides on any card a pool can draw (a card of a set that ships, or of a single-player set, which an `everySet` pool takes, [[R1846001]]), every such reader's family plays differently. A script edit across a threshold, a long card added or removed, and a moved threshold all count, and `--claims` asks a pending fragment for each reader ([[R1370000]]). A move by a card of a set held before it ships ([[R1420]]) counts for none, since no pool draws it.

Until a reader ships, which the Stinkyscape release (#1884) does, the rule is inert, and the release's own change is not counted by it: a set that ships is a major already.
