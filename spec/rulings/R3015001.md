The owner's request (#3015, 2026-11-04) made every look a ladder of levels ([[R3015000]]) and left each
level's rarity to the plan, on the cosmetics' own scale, Common to Mythic ([[R1333000]]).

**The rule.** A variant's first level keeps the rarity its version had, and so does every level that was
a version before (Alt full art, Alt art's second); each new level is one tier rarer than the level below
it, and stays Mythic once there; a signed level is always Mythic. The registry's check holds it
(`level_problems`): a level not rarer than the one below it is refused unless it is Mythic, and so is a
signed level that is not Mythic, so the table cannot drift. Every level Legendary or Mythic carries the
chase mark ([[R1333000]]).

| Variant | Level 1 | Level 2 | Level 3 | Level 4 |
|---|---|---|---|---|
| Default | the normal face | Animated, Epic | | |
| Full art | Legendary | animated, Mythic | signed, Mythic | |
| Alt art | Rare | Alt full art, Legendary | animated, Mythic | signed, Mythic |
| Sketch | Rare | Sketch full art, Epic | animated, Legendary | signed, Mythic |
| Extended art, Pixel, Comic | Epic | animated, Legendary | | |
| Set showcase, Out of frame | Legendary | animated, Mythic | | |
| Immersive, Prismatic | Mythic | animated, Mythic | | |

Two levels have no level below them to step from, and take the nearest rarity the old model gave them:

- **The Default's Animated** (`version-animated`) is Epic, the Animated augment's rarity ([[R2725000]]),
  the normal face being no entry: the motion on the normal face is bought and pulled as it was, by an
  Epic token among others, and is no chase.
- **The Sketch's full art** (`version-sketch-full-art`) is Epic, one tier above the Sketch's Rare
  ([[R2940000]]), and no chase.

Of the fifteen new levels, thirteen are chases (all but those two), nine of them Mythic. No cosmetic
token buys a Mythic ([[R2728000]], [[R1305003]]): Full art's animated and signed levels, Alt art's third
and fourth, every signed level and the animated levels of Set showcase, Out of frame, Immersive and
Prismatic are pulled ([[§14.3]], [[§14.6]]) or bought with a full Chase Shard bar. A Legendary token buys
the animated levels of Extended art, Pixel and Comic and the Sketch's third, each as its card's next
([[R3015004]]).

Rejected: every animated level Mythic, which would make the motion on the normal face, an Epic augment
until now, as rare as the top chase and leave no token anything that moves, and lift an Epic one-art
variant's animated level two tiers; every animated level Epic as the augment was, under which an
animated level would be commoner than the Legendary or Mythic art it needs and pulled before it; and
re-rating the versions that shipped, which would move what drops at each tier and what each token buys
under the levels people already own. With more levels on each tier, each is rarer to roll; the tier
tables, pity, the token cycle and the Chase Shard stay as they are ([[R1339000]]).

Presentation only (CLAUDE.md rule 7).

Amends [[R2725000]] (the Animated and Signature augments' rarities pass to the levels that replace them:
the Default's Animated Epic, Full art's animated and signed levels Mythic), and [[R2942000]],
[[R2943000]] and [[R2944000]] (each version gains an animated level a tier above it: Legendary over
Extended art, Pixel and Comic, Mythic over the rest).
