`cargo jackioh classify` replays games recorded on the head against the base build to find what a
change to play code does ([[R1365000]]). A change to [[§2.6]]'s deck size ([[R1705000]]) records
games the base cannot set up: the base's `golden check` panics in `create_game` on the head's first
25-card deck ("deck must hold exactly 20 cards (§2.6 L2), got 25"), so it reports no divergence at
all, and classify failed with it, which held CI's `rust (classify)` red ([[R1370000]]).

When the base's check fails with that refusal, a deck the base will not deal at the head's size,
classify now reads the change as a rule (`checked.rule`): a divergence that touches no card, met by
every game, which makes the change a patch ([[R1365000]]). Any other failure of the base's check
still fails classify.

Hearthstone semantics: a change to the size of every deck changes every game, a rule of the game
rather than a change to any card.

Rejected: failing classify on the base's refusal, which would leave a change to the deck size
unclassifiable and its pull request red; and recording the head's games at the base's size, which
would replay games the change never plays.
