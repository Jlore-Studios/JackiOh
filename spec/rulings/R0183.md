A seat's start-of-turn draw is `DRAWS_PER_TURN` + `extraDrawsPerTurn` separate draws, each exactly a [[§2.4]] draw. Each has its own cast-on-draw chain under [[R58]] and its own hand-cap check, and from an empty library each is its own fatigue step, so a Hard seat with an empty library takes N and then N + 1. A prompt opened inside the first draw owes the rest to `state.work` like any "draw N" ([[R158]])
