`cargo jackioh positions <logs>… --out <file>` folds each self-play game from its seed under the catalog it was played on (`replay::catalog_for`, [[R767000]]) and checks the state it reaches against the game's final hash and result. A game is dropped, and its rows with it, when:

- an action of its log is refused, or the fold reaches another hash or result: the engine changed since it was played (`notReplayed`);
- it ended without a result, so it has no outcome to learn from (`noResult`);
- it was played on a catalog version this build neither is nor carries (`earlierPatch`).

The run prints each count beside the games read and the positions written, so an export the engine has outgrown shows as dropped games, never as wrong rows. A line that is not a game counts as `unreadable`.
