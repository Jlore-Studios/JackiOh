C+ #29's "your last game" is its caster's last finished game of the same kind — server matches for a server match, practice games for practice; a hotseat game has none, and the card fizzles. That game's board is every permanent on the field when it ended, on both sides, except the opponent's face-down cards, which the caster never saw, each as its card and face only: stats, buffs and damage are not carried, a fused card is kept by its id ([[R179]]), and a token may come back as a card in hand ([[R11]]). Each seat's last board is an input of `createGame` beside its deck and handicap and is frozen into the match, so the match still folds exactly from its inputs and log ([[§9.3]]); the server keeps it per profile and practice on the device. The base face Discovers among 3 different entries; the Radiant face adds 3 different random ones; each costs (0)
