Presentation only (CLAUDE.md rule 7): no rule, figure, endpoint or response changes. The client reads each card's `window.counted` and the patch list `GET /api/stats/cards` already sends ([[R1367000]], [[R1973002]]).

**Why.** While a card's own window is short of live games, its figures are its previous window's ([[R1367000]]). [[R3324000]] hides a collecting patch's figures on `/stats`, but the card's Statistics panel named no patch at all, so a new patch's panel read the previous patch's figures as its own, and `/stats`' games tile named the patch shown over games collected on the patch before. The owner asked in #3447 for the temporary figures to say which patch they were collected on.

**The patch they were collected on.** A card's figures were collected on the patch `/stats` lists that holds the first version they count (`window.counted`): its own window's patch, or, while it gathers its games, the patch before. A window a micro opened names the patch the micro is part of, as the patch tabs do. From a server with no list it is that version itself.

**Where it shows.**

- **The card's Statistics panel** (`CardStatsBlock`, from the collection and the Almanac, [[R3185000]]): beside its title, "Collected on patch X". A card with no window, as from an older server, names none.
- **`/stats`' games tile** ([[R1646000]]): "Games on patch X" names the patch its games were collected on. That is the patch before the one shown while the response's figures are the previous window's (its `source` is `previous`), and the version before from a server with no list. Otherwise it is the patch shown, as before. A collecting patch still shows no tile ([[R3324000]]).

Neither shows a data source, the gate or a count toward it ([[R661]]): the client reads `source` only to know whose games the tile counts, and shows neither it nor its label. Amends [[R2325000]] (the client read none of `source`) and [[R3185000]] (the panel showed nothing of the server's beyond its five figures).

Hearthstone semantics: a stats site labels its figures with the patch they were gathered on.

Rejected:

- A patch line in every row of `/stats`' tables, which repeats the tile on every card.
- Hiding a borrowed figure instead, which [[R3324000]] does only for the collecting patch and leaves the panel empty for every card a patch changed.
- Naming the version that opened the card's own window, which `/stats` offers no tab for when a micro opened it.
- A new field in the response: the cards' windows and the patch list already say it.
