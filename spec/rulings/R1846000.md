A card's code lines are the lines of its own script file above its tests (the `#[cfg(test)] mod tests` block, which is not its code) that hold code once its comments are taken out: neither a comment nor a blank line counts, and every other line does, a `use` declaration's included, as the designer counted "lines". `crates/cards/build.rs` counts every catalog entry's script, a token's included, on every build and compiles in the counts and two lists made from them, so both grow with the catalog and no table is kept by hand:

- **BUSTED**: more code lines than `BUSTED_CODE_LINES`, 100, the designer's number.
- **Complicated**: more code lines than `COMPLICATED_CODE_LINES`, 60.

A card on a number is not over it, and a BUSTED card is complicated too. Both numbers are engine constants, which the build script reads off `crates/engine/src/config.rs` as it reads `CODE_BLOCK_MAX_LINES` ([[R1183004]]), so each is stated once (CLAUDE.md rule 9). `register_all` hands the counts and the lists to the engine beside the catalog (`register_card_metrics`; `card_metrics`, `code_lines_of`, `is_busted`, `is_complicated` read them), so the pure crates read them at compile time only (CLAUDE.md rule 4).

The catalog query ([[§5.1]]) reaches them: `busted: true` asks for BUSTED cards only and `busted: false` forbids them, and `complicated` does the same for the complicated cards. Every other filter and rule stands: a pool that names no set draws from the sets that ship ([[R380]], [[R1420]]) unless it asks for every set ([[R1846001]]); a token is listed like any entry but joins only a pool that takes tokens ([[§5.1]], [[R382]]), and Glitch none ([[R674]]). When issue #1846 landed, 16 entries were BUSTED (14 cards and 2 tokens) and 67 complicated (61 cards and 6 tokens), all of sets that ship.

A fused or crafted definition has no count, since it has no script file of its own, and neither has a custom card ([[R1846002]]). The count is neither [[§5]]'s Lines of code (`loc`), which leaves `use` declarations out and has been frozen since v0.3.0, nor a code block ([[R1183004]]): it follows the script, so any edit to a script's code can move it. No card asks for either list until the Stinkyscape set ships: #109 xxFreshJack plays a random BUSTED card of every set, single-player ones too, and #111 Shockwave447 fills both hands from the complicated cards. Under a fold the lists stay the build's ([[R1846003]]).
