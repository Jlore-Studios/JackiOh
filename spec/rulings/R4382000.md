A carried catalog ([[R767000]]) runs a card's current script unless a kept script covers it, and its definitions are the old snapshot's, which may lack a number the current script reads. That read panicked ([[R386]]'s "a number a card never declared panics"), so the replay never opened: on the server its fold failed, and in the browser's module a panic is a trap the page cannot catch. Issue #4382 found it in Big D-fender's v0.2.5f (`armor`, read by its aura in each step's view), The True Sheep's v0.3.1 and v0.3.2b (`setCost`, in its Discover), and Outbreak's and Reoccurring Dream's v0.4.5 (`drawPer` and `chance`, whose kept scripts end at v0.4.4b, while their definitions declare the two only from v0.4.6). The first run of the sweep below found the same panic in 695 of 2,563 card eras, across 69 cards, 457 of them the Coin's `mana` on the versions before v0.2.6.

So while a fold runs under a carried catalog, a number its definition never declared reads off the card's definition as the build has it, moved by the instance's own tuning as any number is, as [[R3574001]] reads a past version's. Only the read that panicked changes: the carried definition still declares nothing, so `param_or` keeps its printed number ([[R2657006]]), `declared_or` its flag and the view prints only the numbers the carried definition declares. A number no definition of the card declares still panics. Where the card played then as its current script plays it, the replay opens; where it did not, its final hash refuses it as `rules_changed`, as [[R767000]] intends for a patch that kept no script.

`cargo jackioh carried` holds this: it plays every card's era on every carried catalog (each run of versions over which its definition and covering kept script stay the same, `jackioh_cards::card_eras`) through a fixed script that plays it, answers its prompts, ends a turn on each side and destroys it, then a few random turns, reading both seats' views after every step, and folds the log back as a replay pinned to the version, which must reach the live hash. The whole sweep runs daily, and a pull request's `fuzz` gate plays the eras of the cards it changes.

Rejected: a kept script for each card, since Big D-fender and The True Sheep have none to restore and the next patch that declares a printed number would open the same hole; and the fallback inside `param_decl_of`, which would move `param_or`'s cards' folds off their printed numbers. Hearthstone has no counterpart.
