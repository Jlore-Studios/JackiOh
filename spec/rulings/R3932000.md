Not a rule of the game (CLAUDE.md rule 7): the board's controls carry a way out to the Play menu.

In a dungeon fight the board had no Menu or Back button, and the shell hides its own navigation
while a board is up. Concede was the only control off the board, and conceding a fight ends the
whole run for good ([[§15.6]], [[R2972000]]).

**The Menu button.** The fight's `<Game>` controls carry a Menu button (`controlExtras`), labelled
as practice's is ("Menu", accessible name and title "Main menu"), navigating to the Play menu
(`paths.play`). This matches the dungeon run map's own Back link ([[R2972000]]).

Mid-fight, that move is held by the fight's leave guard ([[R1754000]], [[R2972000]]) to open the
"Leave this fight?" dialog: "Keep playing" stays, and "Leave fight" confirms navigation to Play,
with the unfinished fight waiting where it stood so the run resumes it later ([[R3476000]]).
Once the fight has reached its result the leave guard is released, so Menu navigates to the Play
menu directly without asking. Concede and Continue are unchanged.

Presentation only: the client sends intent and renders view (CLAUDE.md rule 7).

Hearthstone semantics: stepping away from a solo game mid-encounter keeps the encounter saved
without forcing a forfeit.

Rejected: navigating to the landing page (`/`) instead of Play (`/play`), since Play matches the
run map's back navigation; and drawing a back link in the board rail, which would compete for space
with the enemy name, run timer and modifier list.
