Practice's setup has a **Sandbox** box. A game started with it is a sandbox: the board carries a dev tools panel that spawns cards, sets numbers, draws and clears the field, so a player can build any board and try a card or a line on it. The spec made no such decision; this note makes it.

- **The flag is setup, not an action.** `createGame` takes `sandbox: true` and the state holds `sandbox: true`; a game that is no sandbox holds nothing, so its hash is what it was before the flag existed. A replay of a sandbox game passes the same flag (`ReplayInput.sandbox`), and a log folded without it refuses the tools.
- **One action, `sandbox`, carries every tool** as its `op` (`spawn`, `setHero`, `setMana`, `draw`, `destroy`, `remove`, [[R923001]] to [[R923003]]). Only a sandbox game accepts it; any other refuses it with "the sandbox's tools work only in a sandbox game". `legalActions` never lists it, so the AI, the random policy and every bot leave it alone, and the practice worker keeps it from the AI's fallback as it keeps a concession ([[R188]]).
- **Either seat, either turn.** The tools are the human's, sent as intent and logged as their action (`h<n>`), and they may act on either seat on either player's turn. A tool waits on what blocks any action between moves: the mulligan and an open prompt refuse it. The AI's next step can be held while the board is arranged ("Hold the AI's turn", one more reason the page's controller holds a step).
- **It counts for nothing.** A sandbox game is never a match: the server's match actor refuses a `sandbox` action before the engine sees it, and never creates or folds a sandbox game. In practice it records no statistics ([[R639]]), brings no last board and leaves none ([[R508]]), and is kept to resume ([[R668]]) only as a sandbox, picked up by a page that remembers one.
