---
id: R4581001
title: "Malformed Infinite Assault device data is ignored one key at a time"
cards: "issue #4581"
proven_in:
  - apps/web/src/assault/store.test.ts
---
An Infinite Assault attempt or records value on the device that is malformed or has another storage version is removed and read as absent. The other key remains independent. Valid records are kept only for the most recent `history_days` UTC dates.

Hearthstone semantics: none; this is persistence recovery at the client boundary.

Rejected: refusing the whole mode because one optional device value cannot be read, which would make local corruption permanent.
