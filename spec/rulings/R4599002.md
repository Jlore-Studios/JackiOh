Under M #99 Paranoia a Spell set face-down resolves as it is set, as a Trap ([[R3806000]]), so Immune to Spells does not stop it. The fuzz monitor's I21 read a card as set only when it stood face-down as the step began or ended. In the daily fuzz's plain seed 637 the Anomaly Found! token was set under Paranoia, resolved at once, replaced its side with a new board and exiled what stood there, an immune S+ #114 Reign among it, and was gone from the backrow by the step's end, so I21 read its run as a Spell's.
**It runs as a Trap.** A card whose `cardAnnounced` says `faceDown` is set as it is played; the `cardPlayed` that follows (under the card's id or the new id its play gives it, its `formerId` the announced one) begins a Trap's run, which no immunity stops.
**What I21 allows.** The run of a card announced face-down in the step, as the run of a card set as the step began. A card announced face-up is still a Spell's run.
Rejected: asking `restrictions` whether the effect is a Spell's, which I21 never does, so that it checks the engine's reading rather than repeating it.
