Under M #99 Paranoia a set Spell resolves as it is set, as a Trap ([[R3806000]]): Immune to Spells does not stop it. I21 read a set card as a Trap only when it was set as the step began or still set as it ended, and #88 Twisting Nether, set face-down in the daily fuzz's plain seed 5596, destroyed itself with every other permanent, so I21 read its run as a Spell's and named the immune Megabase it destroyed.

**It runs as a Trap.** A card whose `cardAnnounced` says `faceDown` runs as a Trap for I21, under its announced id and under the id its `cardPlayed` gives it (`formerId`).
