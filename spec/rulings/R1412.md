The patch that ships the Meditative set ([[R1420]]) carries a second migration, `0031_meditative_endings.sql`. The set adds two ways a game ends, both a win ([[R850]]): `alt-win`, a player holding an alternative win condition met it (Meditative #8's summit, #20's chosen condition), and `won-by-effect`, an effect won the game outright (Meditative #8). `public.results` and `public.rated_games` each check a finished game's reason against GameOverReason's strings as they stood, so the migration puts both checks back with the two endings added and nothing else changed; without it a game the set ended would fail its result write, and [[R1437]] would keep the match live. `voided` stays out of both, since a Glitch-voided match records no result ([[R679]]). The migration widens two checks and rewrites no row, so it is safe on any earlier database and safe to apply before the set ships. A `won-by-effect` game always has a winner, so it joins the decisive endings the server's record reads (`DECISIVE_REASONS`, `crates/server/src/db/pg.rs`): a loss to a winner who later deleted their account stays a loss, as it does after a concede. An `alt-win` game can be a draw (two holders), so it does not.
