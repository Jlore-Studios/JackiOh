A card played from its player's hand carries where it was there on its `cardPlayed` event, `fromHand: { index, of }`: `index` its place counted from the left, 0 the leftmost ([[R3558000]]), and `of` the hand's size then, the played card included. It is read as the announce takes the card out of the hand ([[§10.5]], after the play's costs are paid), so a card discarded to pay for the play is no longer counted. `query::played_leftmost(event)` holds when `index` is 0, `played_rightmost(event)` when `index` is `of` − 1, so the one card of a one-card hand is both (FvH #60.1's right-most, #60.2's left-most). A play from no hand carries none and is neither: a cast ([[R70]]), a cast on draw, a card played from a graveyard ([[R454]]). The place is public, as the hand's size and the card leaving it are, and the rules read it, so the event keeps it wherever the trigger loop holds it ([[§10.3]]). It is recorded only in a game holding a Felinors vs Humans card, either side's, in any zone (`recursion_log::fvh_kept`), as the recursion log is kept only for the cards that read it ([[R4589000]]): in any other game no play carries it and neither read holds, so no other game's hash moves ([[R768]]).
