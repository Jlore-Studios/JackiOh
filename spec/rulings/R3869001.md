S #4.6 The Big Crunch's "cast one of each Call to Chaos" reads the Call to Chaos pool (`query::call_to_chaos_editions`, the `call-to-chaos` pool of `spec/CARDS.md`), every card tagged Call to Chaos from the sets that ship ([[R380]], [[R1420]]), as S #149 Wildar and S+ #154 Chaos Accelerator draw from it; S #137 Starfleet Commander's and S #176 Preemptive Strike's "Discover a War Doctrine" read the War Doctrine pool (`query::war_doctrines`, the `war-doctrines` pool), the tokens tagged War Doctrine ([[R1857002]]). Through v0.6.0g each named its cards by id. The pools hold the same cards in the same order (§5.1's set by set, §5 index order), seven editions from Core #95 to S+ #142 and S #137.1 to S #137.4, so no game plays differently ([[R1870006]]), and an edition or a Doctrine a later set prints joins by itself.
