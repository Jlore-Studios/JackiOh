The patch that ships the Meditative set ([[R1420]]) carries one migration, `0029_meditative_set.sql`. It puts `cards_tags_check` back with Wincon, the one tag the set adds ([[§5]]: Meditative #8 Reach the Summit and #20 Aestheticize the Game), and nothing else changed, as each earlier tag patch did ([[R278]]). The check then lists exactly the engine's `Tag` union, in its order, so a tag that reaches the catalog before the schema fails `cargo test` and not a deploy. Nothing else needs widening: the set's types are [[§5]]'s five, its rarities the six every set uses, and neither `cost` nor `set_id` has a check, so every entry the catalog holds, of every set, is a row the schema admits.

`seed-catalog` needs no change of its own: it seeds the entries of the sets that ship, read off `SHIPPED_SETS` at seed time, so the release that lists the set is the first deploy that seeds its 102 cards and 30 tokens. The seed stamps the new catalog version, and 0016's grant hands every active account the cards that version adds ([[R481]]); tokens are never granted, as before. The migration widens a check and rewrites no row, so it is safe on a database that has seeded any earlier catalog, and safe to apply before the set ships.
