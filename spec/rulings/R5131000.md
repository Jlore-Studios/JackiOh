Presentation only (CLAUDE.md rule 7). The Infinite Assault set ([[§8.13]]) has been a single-player set since its release (issue #4597), so `SHIPPED_SETS` never lists it, and [[R1420]] kept every set it does not list off the Card Almanac's shelf ([[R630]]). The set's cards are the Assault's enemies, met every day, and the Almanac is where a player looks a card up, so it shows them: the Almanac's sets, `ALMANAC_SETS`, are the sets that ship, in catalog order, then the Infinite Assault's.

- **The shelf** holds every card and token of the set, as it does a shipped set's, Glitch still excepted. The static `/almanac` page, its description and the command menu's cards ([[R2118000]]) read the same shelf, so they list the set too.
- **The set chips** ([[R1380]]) are `ALMANAC_SETS`: the Infinite Assault's chip comes after the sets that ship, `db-filter-set-infinite-assault`. Sorting by set files the set after every set that ships.
- **The tag chips** ([[R1381]]) are the tags of the cards the Almanac shows, so the set's eight doctrines and Commander ([[R4596000]]) appear.

Nothing else changes. The deck builder's pool, set chips and tag chips stay the sets that ship and their tags, since no deck holds a single-player card ([[R1846001]]). The collection, the pools, the server's catalog and every game are untouched. Boss and Boss-X, the other single-player sets, stay off the Almanac.
