Meditative #31 The Conductor's Cry reads, as it begins, the ids of the Created cards in its controller's library, top down, and draws each (MD-B7). Each is a real §2.4 draw: a `drawn` event and [[R55]]'s counter, [[R4]]'s hand cap burning the overflow, a cast-on-draw card cast with its top-of-deck replacement draw ([[R58]]), [[R457]]'s draw limit stopping the rest. An id gone from the library by its turn fizzles, and a card that enters during the draws is not drawn. The Radiant face first shuffles a random Prime card into the deck — Created, so the same Cry draws it.
