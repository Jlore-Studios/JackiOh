`cargo jackioh classify` tells a change to a file's code from one to its comments, layout and tests ([[R1365000]]). A card script's code is still the lines `cargo jackioh catalog loc` counts, so a change to its `use` lines alone claims no card. Every other Rust or TypeScript file's code is the same lines with its `use` declarations kept: an import moved from one module to another can change which function a call reaches. So a change to only the imports of the engine, the cards crate outside its scripts or the AI is a change to play code or to the AI, which stage 2 checks against the base build and `--claims` then requires ([[R1370000]]). Comments, layout, blank lines and everything at or below a file's first `#[cfg(test)]` are still no code. We rejected dropping `use` lines everywhere, as before, because it passed a moved import as Internal without the base build's check. We also rejected sorting the declarations so that a reorder counts as no change, because that is more than the gap needs: a reorder costs only a stage 2 run that finds nothing.
