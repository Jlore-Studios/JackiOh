Library, then hand, then graveyard — the order [[§8]] names — and each card is its own exile. Which cards are odd-cost is read once, as the clause resolves ([[R66]]), so an exile that moves #100 Ceaseless Void's cost ([[R55]]) partway through does not change whether the Void goes, so [[R55]]'s counter moves once per card and anything watching an exile sees them one at a time rather than as a batch. The draw clause runs first, so a card drawn by it is never exiled by the same play
