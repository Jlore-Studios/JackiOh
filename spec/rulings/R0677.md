The engine's game does not change: `GameState.seatSwaps` counts the swaps, and while it is odd the account that began in each seat plays the other (`seatPlayedBy`). The server routes each account's views and actions by it and credits the match's result, stats and Elo to the accounts by it as the game ends ("their stats, not yours, from here on"); in a practice game the human takes the AI's seat and the AI the human's. Only the engine's state can swap seats, never a client message
