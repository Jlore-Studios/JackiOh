The AI lot is an `OpenIds` lot of the ten Stinkyscape cards, then Stinkyscape+'s seven (T-AI-1 to T-AI-7).
A card in it is offered only when its set is open ([[R1420]]): the set ships, a test previews it, or the fuzz
tool runs. While the set is held the lot is the ten in their old order, so shipped games roll as before, and
a replay of an older game, whose catalog lacks the seven, drops them as it drops any id it does not hold.
Its count stays 1 ([[R2250002]]), so the lot's share of a roll does not change, only the cards in it.
Rejected: a second lot, which changes the odds ([[R1853001]]); and a set check on every `Ids` lot, since the
named lots reach held cards on purpose ([[R1881006]]).
