The issue asked for a cosmetic track of its own tied to Stinkyscape, apart from the Stinkyscape set
track ([[§14.7]]), its every number a named constant. This rules what earns it and what it pays
([[§14.15]]).

**What earns XP.** Only a 1v1 game the server ran and records: a ladder game, an unranked game and a
game of a Conquest series. The server counts each seat's sources from its own fold of the game's
public log in the transaction that records the result, as proficiency counts plays ([[R3013000]]):
`FLEET_TRACK_XP_PER_STINKYSCAPE_PLAY` for each Stinkyscape card of the seat's own deck, as dealt, it
played from its hand, no token and no Created card; `FLEET_TRACK_XP_PER_PIECE_FUSED` for each Starship
Piece it fused, each `starshipFused` event of its own; `FLEET_TRACK_XP_PER_LAUNCH` for each Starship it
launched, each `starshipLaunched`; and `FLEET_TRACK_XP_STINKYSCAPE_WIN` for a win with a deck at least
`FLEET_TRACK_DECK_SHARE` Stinkyscape cards. Each source counts once per event. A practice game, which
the browser runs, a hotseat game, a tutorial, a sandbox game and a dungeon run, none of which the server
records, pay none; nor, yet, does a co-op game, whose log the server pays from without folding it
([[R1502000]]); nor a ladder bot ([[R1454]]).

**The cap.** An account's games pay it at most `FLEET_TRACK_XP_DAILY_MAX` Fleet XP in a UTC day: the
game that crosses it is paid the part that fits, later games nothing and no row, and the next day pays
again, read off the day's `game` rows under the account's economy lock, as the Jlore cap is
([[R1483000]]).

**Levels and rewards.** Every `FLEET_TRACK_XP_PER_LEVEL` XP is a level, from 0 to
`FLEET_TRACK_LEVELS`; XP past the last still lands ([[R1302005]]). Each level the track reaches pays,
once, the registry's reward for that level, a cosmetic ledger row with the reason `track` and the match
as its reference; a game that crosses several pays each, and one the account owns already writes no
second row. The registry's check holds the table: one reward at each level from 1 to
`FLEET_TRACK_LEVELS`, the last the Stinkyscape hull design, a Mythic flagship. The track is a
`fleet_tracks` row beside the append-only `fleet_track_grants` ([[§14.11]]), each readable by its own
account alone.

**Where it shows.** `GET /api/tracks` answers `fleet` beside the set tracks: the level, the XP, the XP a
level spans and the XP to the next (both `null` on the last level), today's Fleet XP and the ids of the
next `FLEET_TRACK_NEXT_REWARDS_SHOWN` levels' rewards. The Collection shows the track after the set
tracks, its next rewards drawn as they look ([[R3335000]]).

Hearthstone semantics: a reward track whose levels each pay once, earned by play, with a daily limit on
what play pays.

Rejected: a level curve that rises as a set track's does, which the issue did not ask for and would hide
the capstone behind months of play; counting cards created or cast without being played, which
proficiency does not count either; paying co-op from its unfolded log, which holds no per-seat events
to count; and a reward of several cosmetics at a level, where the issue asked for one.
