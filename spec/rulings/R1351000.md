[[§9.4]]'s block stopped requests, challenges, chat and replay shares between two players, but a match they met in still relayed their emotes, the portraits' voice lines among them ([[R1340]]). Now a block either way mutes them. A match's actor reads whether either of its two accounts blocks the other as it arms, which a restart's rebuild does again, and a block made while a match between the two is in memory mutes that match at once. From then on an emote either seat sends passes the sender's hand ([[R1342]]) and the rate gate ([[R643]]) as before, spending the limit, and is then relayed to no one. The sender is answered nothing, as a rate-limited emote is, and the opposing ladder bot's persona does not answer it ([[R645]]). A card that hears emotes still hears it, so the game plays on exactly as unblocked ([[R1127]]); the `emoted` event that answer makes is a game event in both views like any other, which the board shows as the sender's hero shaking and a log line that names no emote. A muted emote is relayed to nobody, so the play telemetry records none ([[R1442]]). The mute lasts until the match's actor goes: lifting the block mid-match does not unmute it, and the next match reads the blocks afresh. A read that fails as the match arms is logged, and the match then relays as unblocked. A block never changes who the queue pairs, since blocking a strong player must not dodge them.
