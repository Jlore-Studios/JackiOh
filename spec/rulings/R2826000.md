A deck holds no card twice ([[§2.6]]), so a card a side shows is not among that side's hidden cards,
and it says nothing about the other side's: two decks may hold the same card.

**The rule.** In a determinization ([[R185]]), each hidden card is resampled from the non-token cards
of every set ([[R380]]) that its own side has not shown and that this determinization has not yet
given that side. The opponent's hand, library and the backrow the seat cannot read are the opponent's,
and so is a card of the seat's library minted for the opponent's deck ([[R73]], #87's swap). Every
other hidden card of the seat's library (one it was never shown, [[R312]]: a dealt deck's, [[R433]], a
library swapped back, a card #83 put there) is the seat's own: it is sampled against what the seat's
side shows (its hand, field, graveyard, exile and the library cards it knows, [[R2691000]]), and may be
a card only the opponent shows. A side shows a card when the seat can read a card that side owns. Each
sample still takes one draw from the AI's stream, in the same order as before, so the same public
state and the same stream give the same world.

**Rejected alternatives.**
- One shared set, the opponent's, for every hidden card: the old sampler. It let a dealt deck's
  library hold a second copy of a card the seat shows, and never a card only the opponent shows.
- Every hidden card of the seat's library against the seat's set: a card swapped in from the
  opponent's deck could then repeat one the opponent shows.
- Every placeholder by the deck it was minted for, in any zone: it moves the worlds of every game with
  a steal or a board swap, which the issue does not ask for.
