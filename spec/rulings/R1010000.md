`AI_EVAL_KIND` (`crates/ai/src/config.rs`) is `EvalKind::Hand` or `EvalKind::Learned`, one line that turns the learned evaluation on or off. With `Hand`, the default, the AI plays exactly as it did: every score is `evaluate` with `AI_EVAL`. With `Learned`, the finalists are scored by the network's correction of the hand eval where the search finally scores a line (`docs/learned-eval.md` D6's option B): after the opponent's reply in `reply_score` (and the static score it gives a line that stopped on the seat's own prompt), for every determinization a finalist is scored on. The beam's pruning keeps the hand eval, so the network chooses among the lines the hand eval found.

The network is `crates/ai/src/learned/weights.json`, compiled in by `crates/ai/build.rs` as `LEARNED`, constant slices with no static set at run time (CLAUDE.md rule 4). The weights record `FEATURES_VERSION` and the dense features' names they were fitted on: a test fails when they are not this build's layout ([[R1006000]]). Features of another length get no correction at all, never a wrong one. The null network, whose correction is zero everywhere, makes `Learned` score exactly as `Hand`.
