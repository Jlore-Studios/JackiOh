The server closes a match socket with 4401 ("sign in first", [[R148]]) when its handshake's token does not verify, and the 1v1 and co-op clients took it, like 4403 and 4404, as final. But a page that wakes with an expired token replaces a socket that is not open at once ([[R1441]]) while the gate's renewal ([[R194]]) is still waiting on the provider, so a player in a live match was told it was not available while its grace ran. A 4401 is now final for the token that got it, not for the match:

- **A token different from the refused one opens exactly one more socket**: the next one the gate hands down, or at once one handed down before the 4401 arrived. The co-op socket takes the gate's token as the 1v1 socket does.
- **The refused token opens nothing**, and a 4401 on the new socket is final for its own token, so each token is tried once and nothing loops; a 4401 for an account the server cannot find ends the same way.
- **4403 and 4404 stay final** whatever token follows.

Rejected: leaving a token renewed before the 4401 arrived refused, which still strands a player when the renewal wins the race; one retry per match rather than per token, which strands a player whose first renewal is refused too; reopening on every renewal, which would also reopen a healthy socket that [[R194]] says a renewal leaves alone.
