A press of Claim all ([[§14.13]]) is not a route of its own: it claims every entry the panel shows
unclaimed, newest first, each through that entry's own claim ([[R2875000]]), one spend each with its
own `Idempotency-Key` ([[R2124000]]), while every Claim and Claim all wait ([[R2378000]]).

**Each answer** replaces the list, so the bookmark's count moves per answer ([[R2875002]]), never
before it. **The first refusal** stops the run and shows its reason, leaving the earlier claims
claimed and the later entries unsent. **The wallet** is announced once at the end of a run that paid
Jlore, not once per entry; a single claim announces as before, and a claim that paid no Jlore
announces nothing. Claim all shows only at two or more unclaimed entries.

Hearthstone semantics: a collect-all collects one reward at a time and stops at the first failure,
keeping what it already collected.

Rejected: a batch claim route, which would move one decision the server already makes per entry
([[R2875000]]) into a second one; a count cleared up front, which would disagree with the server
when a claim is refused; and a wallet announcement per entry, which would reread the wallet once
per claim for one run's pay.
