M #50 CN Tech adds "the highest win rate card": the best exact rate in the compiled table
(`crates/cards/data/win_rates.json`, [[R377]]'s in-deck wins and games per card id), never CN Tech
itself ([[R387]]). The rate is compared exactly, as `wins_a * games_b` against `wins_b * games_a` in
`i64`, so no float ever decides it. Only rows with at least `CN_TECH_MIN_GAMES` (20) games
qualify, and only ids the catalog still holds as deckable cards — which rules out tokens (Glitch is
one) and sets that do not ship. Ties break by more games, then by the catalog id, ascending. With
no qualifying card — a new patch, an empty table — CN Tech adds a random non-token card instead
([[R142]]).
