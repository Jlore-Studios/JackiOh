Each Training Grounds snapshot #41–#60 is its own entry and its own script: its catalog data (name, cost, type, tags, rarity, flavor, stats, keywords, both texts, params, `dealsDamage`, `refs`) is its Core card's, and its script a copy of the Core card's code, as both stood at the foundation's commit (PR #2241, 43cf977, for issue #2194), not a re-export. A later patch to the Core card does not move the snapshot; a patch meant for both claims both ids. A snapshot has no shipped history, so it copies no script a Core card keeps for its old replays ([[R767000]]: TG #49 reads its declared `chance` only, TG #52 steals an enemy Unit only). It plays exactly as its Core card: the same game played with either logs the same events and ends in the same state, its own id read as the Core card's. What another card reads off the snapshot's own number or its own code is its own: its element is its index's ([[R980]], #41 水 where Core #2 is 火, so Meditative #40 Feng Shui may judge the two apart), Meditative #14 Prime Time reads its number, and its `loc` is its own script's count (C #48 Hired Shrimp, C+ #44 Simplicity Audit and C+ #45 Complexity Audit), as are its code lines ([[R1846000]]).
