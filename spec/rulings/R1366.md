A card taken into the thief's hand (`stolen`) is a steal. A unit or a backrow card that changes sides on the field is reported by `controlChanged`, which since patch v0.3.X says which verb moved it: `how` is `steal` for [[§6.3]]'s Steal (a card taken to its taker's side) and `give` for [[R1423]]'s give (a card handed to the other player), and it is absent for a card a board move carried across (#87's board swap, [[R73]]; a rotation across the centre line; C+ #35's restore, [[R419]]), which is neither. Nothing else on the event or the view tells the three apart: the controller it lands with is the same whoever caused it. `how` says which way the move went and never which card moved, so it is public wherever the event is. It is the client's report, which no rule reads: the trigger loop holds the event without it (`GameEvent::as_rules_read`), so no state hash moves and a recorded game's replay keeps its final hash ([[R768]]).

Presentation (CLAUDE.md rule 7): a steal, `stolen` or `controlChanged` with `how: steal`, is a quick upward whip, the grab and a sly blip (`steal`); a give is a breath of air settling and a warm falling chime (`give`); a board move keeps the plain whoosh. The sound reads the event alone, never the card ([[R203]]), and comes from the unit's lane ([[R669]]).
