The learned network corrects the hand eval where the search finally scores a line ([[R1012001]]), and one of its dense inputs is each side's library count. In the games it was fitted on a library only shrinks from the deal, one card a draw, so it read the count as the game's stage: on the Hard positions of fullsend 3's sweep its correction rose by 0.55 to 1.1 points for each card added to the seat's library, near enough linearly to 40 cards. Forced Propagation (S+ #24, [[R3557001]]) shuffles 10 copies, 40 Embiggened, so a finalist that cast it scored 6 to 15 points higher after the opponent's reply than one that passed, while the hand eval had the same line 1.3 lower. A play the beam rarely kept to the finalists, but one that reached them would have been cast for a number the network made up. No game rule changes: the evaluation changes no game.

**What it reads.** `learned::fitted_view` is the seat's redacted view ([[R185]]) less every card in a library that carries the Created mark ([[R943]]), minted after the deal, and `finalist_score_with` takes the network's features of that view. The network so reads the library as the deal and the draws left it, and the hand eval prices what was shuffled in (`library_card`, and for the seat's own library [[R3575101]]). The Created mark is public wherever its card is, and the view is all that is read, so two worlds that differ only in hidden cards read alike. An enemy library card is hidden, its mark with it, so the enemy's count stays as the view has it. A dealt card a shuffle returns (a bounce into the deck) is no Created card and is read as before.

**Rejected.** Turning the network off for every decision that holds such a card, as [[R3479000]] does for unknown cards, which would also drop what it reads well of the rest of the board; capping the count at the deck's size, which still leaves up to ten cards read as a younger game; and changing `features` itself, which the replay pass that makes training rows shares and which a shipped network would then read apart from how it was fitted.
