## R1221 — A catalog query for a Tribute cost

Built (ME-TRIBUTEPOOL, Meditative #88 The True Sheep). The engine's `CatalogQueryArgs` carries a
`tribute` filter: `true` asks for cards with a Tribute play cost only, `false` forbids them. The
cost is a script flag, not catalog data, so the pool keeps up with every new Tribute card: it is
read off each definition's registered base face without state. It lives on the engine query only,
not on the wire `CatalogQuery`, since no client sends it. A pool that names no set still draws from
the sets that ship ([[R1420]]); one that names a set draws from that set, shipped or not.
