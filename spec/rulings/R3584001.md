`RunEventOption.hp` is `max_hp`: what the option adds to the run's permanent max-HP bonus for
the rest of the run, HP following the max through `with_max_hp` (a lower max takes HP with it,
a higher one heals by the rise). An option is refused with "not enough max HP", the state
unchanged, when it would leave the max below 1: the floor is the hero's minimum ([[R290]]), and
no new constant names it. The HP the move carries counts as damage taken or healing as ever.
The rename needs no serde alias: an event's content never persists in a `RunFile`, and a kept
run from before the change is #3496's ([[R3496000]]), not this ruling's. Rejected: judging the
option by HP, which is always the max outside a fight and so would refuse nothing a max HP
judge allows until the last point, and a floor above 1, which would strand runs whose max an
honest bargain spent. It takes R3584001, the second number of #3584's block.
