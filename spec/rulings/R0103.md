The stored power names are `recruit`, `draw`, `ping`, `burn`, `rush`, `felinor`, `discover`, since patch v0.1.1 `stitching` ([[R352]]), and since the Heroic Power patch `armor`, `insect`, `brainstorm`, `pluck` and `tricks` ([[R752]]); they are state, so they stay stable across versions — a reworked power keeps its name (Expedition Map is `recruit`, Life Tap `draw`, Steady Shot `burn`, Ranching `rush`, Cat Cafe `felinor`, Witness Value `discover`) — and a new power is added at the end. Each name is also the id of the power's Activate ability. A Heroic Power that has not yet rolled has no ability to activate. A use is refused as any Activate's is ([[R384]]): the game, the prompt, the turn and the phase first, then the uses, then the mana price; and the use is counted before the effects run, so a power that pauses on a prompt cannot be spent twice. Witness Value adds its pick to the hand, Radiant when the power is. Ping reaches any unit or hero on either side, declared with the activation ([[R81]]). A power that summons a token resolves it by catalog index and fizzles in silence if that token is absent
