`cargo jackioh classify` names the card families each divergence touches ([[R1365000]]). A fused card's definition is no catalog card ([[R77]], [[R468]]): read as one it named a family no card has (`t-2:core` for `t-2:core-067+(t-1:core-079+classicplus-074)`), which no fragment can claim ([[R1366000]], [[R1370000]]). A divergence that touches a fused card touches every card it was fused from instead, a fusion among them read the same way. Issue #1487's one divergence was such a card, whose Echo grant [[R1487000]] puts to sleep.
