Four of the Marketplace's lots ([[R1853001]], [[R1881006]], [[R2250002]]) named their cards by id through v0.6.0g. Each now reads them off the catalog through one lot kind, `MarketPool::Tagged`: the cards of the sets it names carrying its tag, the tokens alone or no token, in catalog order, of a set that is open ([[R1420]]), never a card only a rule makes ([[R1857001]]), and, where the lot says, by whether the English name holds a text ([[R3558005]]). The Weapons lot is Stinkyscape's Weapon-tagged cards but the Launchers, #50 to #61, the v3 to v5 Weapons. The Drone Cores lot is Stinkyscape's Drone Core-tagged cards, #27 to #36. The Launchers lot is Stinkyscape's Weapons whose name holds "Launcher", #140 to #143. The AI cards lot is the AI-tagged tokens of Stinkyscape and Stinkyscape+, each set's offered once it is open ([[R3571001]]). Each holds the cards it named in the same order, so no roll differs, and a card a later printing of the set adds joins its lot. The two Warp Disruptors and each Scanning Probe stay named: a lot of named cards is a lookup, not a category. Not taken here: the Stinkyscape+ set's nine v3 to v5 Weapons, which the Weapons lot does not offer. Naming its set keeps them out, since adding them would change every Marketplace roll of the games already played.
