The owner asked for the micros [[R3471000]] had put on a new line to be named by [[R3631000]]'s letters, so that v0.5.12's micros stay on v0.5.12. This overrides [[R3631000]]'s rejection of a retcon and, for these eight names, [[R646]]'s rule that a shipped version never reopens, as [[R2532000]] did for the v0.5 line.

- **The map.** `cargo jackioh patches retcon --from v0.5.13` computes it, as [[R2532000]]'s run did: every version before v0.5.13 keeps its name, tier and plays, and from v0.5.13 on each takes the name its tier gives now ([[R1366000]]). All eight are micros that changed no card, so each keeps its tier and plays: v0.5.13 is v0.5.12aa, v0.5.13b v0.5.12ab, v0.5.13c v0.5.12ac, v0.5.13d v0.5.12ad, v0.5.13e v0.5.12ae, v0.5.13f v0.5.12af, v0.5.13g v0.5.12ag and v0.5.13h v0.5.12ah.
- **Scheme 4.** The next patch takes v0.5.13 again, so old and new names will overlap, and `VERSIONS_SCHEME` is 4. A file marked 3 names this line the old way, and its reader maps it through `aliases.json`'s `marked` (`"3"`, the eight above). A downloaded replay's format version is its scheme, 4 now; a file of 1, 2 or 3 still opens when its name maps to the live version.
- **Three schemes in one map.** A scoped run carries every older marked scheme's names on to today's and adds the renames of the scheme it ran over under that scheme's number, so a file of any scheme is read through one map, once. A scheme's map holds only the names a retcon took from it: a file of scheme 1 or 2 names no version shipped after it, and these eight shipped in scheme 3, so neither older map changes. Migration 0068 keeps its records' marker 3, the scheme it left.
- **What moves.** In the repository: the eight snapshots and their card lists, `patches.json`, `shipped.json`, the catalog-version sites and the string literals that spell one of the names. In the database: migration 0087, generated from the map as 0068 was, renames every stored catalog version and record id of the eight, its records marked 4. Records outside the repository: `patches retcon --records <dir>` reads a directory marked `.jackioh-versions-3` as scheme 3 and marks it 4.
- **Not renamed.** Docs, comments, commit messages and the older issue and pull request titles keep the names they were written with. `docs/issues-and-patches.md` holds the map to translate them.

Nothing keys off a version's name ([[R105]]): the statistics read each patch's recorded tier ([[R3526000]]), and the eight are micros under either name.
