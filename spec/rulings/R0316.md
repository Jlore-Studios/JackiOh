[[R80]] had a card that would be shuffled into a full library either never created (#33's and #90's copies) or sent to its owner's graveyard (an existing card; a unit-token card ceases to exist, [[R11]]), and the first case emitted nothing at all. Every refusal now emits `libraryOverflow { player, instanceId, defId, outcome }`, with `player` the library's owner and `outcome` `notCreated`, `graveyard` (followed by the card's `enteredGraveyard`) or `ceased`, and `radiant` when the refused card is Radiant (#33's Radiant face), which a view hides with the card. No Core card shuffles an existing card into a library, so a Core card's refusal is always `notCreated`; C #30 Recycle does, and a card of it that does not fit stays in its owner's graveyard ([[R80]]), while `ceased` is [[R80]]'s rule made whole. The card is judged by [[R97]]: one sent to the graveyard reads while it is there. One never created is in no pile, so it is judged by the card it would have copied: #33 copies whatever its controller plays, a Trap set face-down included, and a refused copy of that trap names it to the other player no more than the trap does, until the trap is public. The event carries the copied card's id for this (`copyOf`), which the view never forwards. A card that copies nothing (#90's CN-Virus) reads openly to both, as the play that made it did. A refused existing card has moved, as a `shuffledIn` card has ([[R212]]); a copy never created has not. The copy still takes its instance id from the counter as it did before, so no later id moves
