An issue titled `Patch vA.B.Y: …` is a micro patch: going live through a pending fragment it keeps its `Y` until `patches ship` promotes it ([[R646]]), which names it after the then-newest version in the patch list (its last entry, [[R388]]), with the next letter — after v0.2.5 it is v0.2.5b, after v0.2.7c it is v0.2.7d — and refuses when that version is not an A.B one or has no vA.B.C form. Naming it (`versions.ts`) is the only place a version string is read, and only when a patch ships; everywhere else [[R105]] holds (equality only, never parsed or ordered). `vA.B.X` is replaced before the patch is made, by the next number ([[R743]])
