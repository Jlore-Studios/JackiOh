A tab nobody can see no longer keeps asking the server: every poll that holds nothing the server expires sends nothing while the tab is hidden, and reads once when it shows again. One helper, `pollWhileVisible` in `game/net.ts` beside `pageWake` ([[R1441]]), runs such a poll.

**The rule.** While `document.visibilityState` is `hidden`, the poll's timer sends nothing. When the tab shows again, or the network comes back, the poll reads once at once and its pace restarts, so the next read is a full period after that one. `online` still reads once while the tab is hidden, as [[R1441]] has it for the sockets: a network that came back is news whoever is looking. A page that starts hidden reads at its mount, as every poll does, and then nothing until it shows.

**Pauses.** The unread counts and the challenges (`SOCIAL_POLL_MS`, [[R1831000]]), the friends list (`FRIENDS_POLL_MS`), an open chat (`CHAT_POLL_MS`), the live-game banner ([[R765]], [[R1566000]]), the rematch status ([[R672]]), the series banner ([[§9.5]]) and the co-op Play again status ([[R2092000]]), each of the last four every `SERIES_POLL_SECONDS`. None of them holds a place: what a rematch or a Play again offer lapses by is the server's own clock, whoever polls, and the one read the tab makes when it shows says where things stand.

**Keeps running.** The reads below hold something the server expires, so a hidden tab sends them as a visible one does:
- The queue wait on `/play` and the queue follow in `net/liveGame.ts`: their `GET /api/auth/me` reads keep the ticket alive, and a ticket not read for `QUEUE_TICKET_STALE_MS` expires before it seats anyone ([[R897000]]).
- The series pick ([[R333]]): the pick clock expires the pick whichever tab is open, and the read carries the player into the game it starts.
- The co-op host's room wait (`DUOS_ROOM_TTL_MS`), for the same reason: the room expires, and the read takes the host to the game the guest's join starts.
- The social poll while this tab has an outgoing challenge open, or has just sent one (`follow.ts`): a challenge is a room that expires after `CHALLENGE_TTL_MS`, and the follow that takes the challenger to the board rides this poll (`ChallengeToast.tsx`). With no challenge of the tab's own open, the social poll pauses with the rest.
- The presence heartbeat (`together/presence.ts`), as it was; part 1 of #3203 changes it, and it stops once the tab has been hidden for `HIDDEN_QUIET_MS` ([[R3576000]]).

**Presentation only.** CLAUDE.md rule 7: the client asks for less and enforces nothing; a read it skips is a read the server never answers, and no hidden information is read or kept. Every period is an existing named constant ([[§9.4]]); the helper adds no number.

**Hearthstone semantics.** A client that is not on screen asks for nothing, and catches up when the player comes back.

Rejected: pausing the queue reads, which [[R897000]] would expire; pausing the series pick and the room wait, whose places the server expires too (a person who wants either to pause changes one call to `pollWhileVisible`); pausing the social poll with a challenge open, which would start a game the challenger's hidden tab never joins; listening to `visibilitychange` alone, which would miss a tab that starts hidden; a longer period for a hidden tab, which is still a request for nobody.
