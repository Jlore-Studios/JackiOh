Every token gain is a placement on a permanent on the field, never a dormant card. It is multiplied by the receiving card's multiplier (at least 1; a fused card's multipliers multiply). It emits `counterChanged` with `placed`, once per placement; a removal carries no `placed`. "Place N" with no card named is N placements, all on the one permanent a single prompt names ([[R689]]), with the rest of the list parked ([[R113]]) and the state check after the whole effect ([[R59]]). Tokens are public: a face-down card shows its count on its back to both players.
