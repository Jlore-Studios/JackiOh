The Training Grounds set (tracker #2193, issue #2194, `docs/training-grounds-set.md`) is built on `main` behind [[R1420]]'s gate, as the Stinkyscape set was ([[R1857000]]). `SetName::TrainingGrounds`, written "Training Grounds", is `CATALOG_SETS`' seventh, after Stinkyscape, and absent from `SHIPPED_SETS` until its release (#2204), when it is appended last and becomes the newest set ([[R1371]], the owner's choice). Until then everything [[R1420]] says holds: no pool that names no set reaches its cards, no deck holds one ([[§9.4]]'s L3 and `create_game` refuse it, "the Training Grounds set has not shipped yet"), no lean names it, it is never the newest set, no patch claims it, and it counts toward no total or tag census; a pool that names the set, or a card by id, reaches it, the testkit's `preview_sets` opens it on one thread, the fuzz tool previews it (its pool holds the set's deck-legal cards and the golden traces' pool none), and `catalog check` and the cards crate's fixture hold it to its shape alone. Its ids are `traininggrounds-NNN` and `traininggrounds-NNN-k` (token N.k), its scripts in `crates/cards/src/scripts/training_grounds/`: the first set name with a space, which an id's segment drops as it drops "-" and writes "+" as "plus". The set holds sixty cards, #1–#40 and the snapshots #41–#60, and one token, #39.1; it adds no tag.
