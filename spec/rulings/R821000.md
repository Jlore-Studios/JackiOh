A prompt option that offers a card its chooser may not read ([[R177]]: an enemy face-down trap) still carries no definition, and a
label and key that do not name the card, but it now carries the board position the card lies in — `player`, `row` and `lane`,
as a zone option does. The position is public already, since the card's back is drawn in that zone for both players, so
nothing hidden leaves the engine, and the option's `instanceId` stays the id the answer names ([[R227]]). It lets a
client answer a prompt from a click on the board: "Place N Plague Counters" ([[R689]], [[R471]]) offers every permanent,
face-down ones included, and its prompt is answered by clicking the target instead of reading a list of them. The answer
is the same `answer` either way, and a readable option is unchanged.
