"A number on a card" for Classic+ #41 KY's Constant (`numbers_on`, [[R386]]) is its cost, attack and health, its numbered keywords and its declared numbers as before, then a Temporary card's count (`NumberRef::Temporary`, its keyword's number or the count left, [[R2179001]]) and the Plague Counters it carries (`NumberRef::Plague`), each while the card has one. A set writes the count left, never below 1, and the counters outright, a set and no placement ([[R471]]), reported by `counterChanged`. A Nerf and a Buff move neither. And the Units and Traps that printed an amount as a plain number declare it ([[§5]]), as issue #1748 had the Spells and Field Spells do ([[R1748003]]): the Weapon Units' Discover count `weapons` (Radix, Phalanx, Halo, the Prototypes), Straaza's `cards`, Bear Honeypot's `tokens` on its base face, and The Maestro's `counters`; KY's Constant, Nerfs and Buffs reach them. Each script reads its number with `param_or`, which falls back to the number it printed when the definition a replay of an older version folds under declares none ([[R767000]]). The owner chose both halves. This is the owner's balance pass (issue #2657).
