- A guest leaves a private lobby ([[R3730000]]), `POST /api/lobbies/:code/leave`, and frees the seat; the host removes one, `POST /api/lobbies/:code/remove`. A removed guest may enter again: removing is a seat freed, not a ban, which a block is.
- The host leaving closes the lobby for everyone, as a room's host cancelling it frees its code ([[R110]], [[R1075000]]).
- Nobody leaves a lobby once its Start has landed ([[R3730002]]): it is what takes each member to the board when the countdown ends, so a Leave then would strand the other. A started lobby lapses with its TTL.
- A lobby closes after its format's room TTL from its last change, 15 minutes for 1v1 and 10 for co-op; every change runs it again.
- A host holds at most `MAX_OPEN_ROOMS_PER_HOST` lobbies not started of each format ([[R890000]], [[R1047002]]), counted apart from rooms.
- `GET /api/lobbies` lists the caller's lobbies not started, newest first, so a reload finds its lobby again, as the lobby once found a room ([[R1075000]]).

Rejected: a list of removed players kept with the lobby, which a block already does.
