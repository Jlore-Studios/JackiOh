Each seat in a game record keeps six counts ([[R376]]), all absent on records written before this change:

- `fatigueDraws`: the draws from an empty library the seat took ([[§2.4]], [[R3]]).
- `fatigueDamage`: the nominal pre-Armor hits those draws dealt — their `fatigue` events' `amount`s ([[R3]], [[R1362]]) added, not what Armor left over.
- `trapsSet`: the Traps the seat set face-down from its hand — its plays from hand whose `cardPlayed` carries a `formerId` ([[R227]]).
- `trapsFired`: the seat's Traps that fired — its `trapFired` events' `controller` ([[R154]]), so a Trap fired by the opponent's effect counts for its controller.
- `positionSwitches`: the position switches by units the seat controlled — each `positionSwitched` for its controller in the after-state, skipped when the unit no longer resolves there.
- `radiantUpgrades`: the cards of the seat's that an effect made Radiant — an instance's first `radiantSet` cue in a step whose after-state finds it Radiant and whose before-state did not, counted for that card's controller. The engine also cues a card that was Radiant already when it may be hidden from someone ([[R177]]: any hand card, a face-down Trap) and for a step-3 Radiant (Gifted Program), so the before-state decides, and a hidden card's re-cues dedupe to one. A card created Radiant (a Radiant copy or token) was not turned Radiant by an effect, so a later cue on it counts nothing.

`summarize_game` reads all six off the replay's events, which both seats see: no count names a hidden card beyond what [[R376]]'s fields already hold. A record whose count holds anything but a non-negative whole number is refused, as [[R1147000]]'s malformed fields are.

Rejected:

- A new `GameOverReason` for fatigue: it would widen the reason union, every consumer of it, and the replay hashes, for what the counts already answer. A "fatigue kill" in the notebooks is the stated approximation of a `hero-death` game whose loser took at least one fatigue hit, not a proven killing blow.
- Post-Armor fatigue damage: Armor is a property of the moment, and two games that drew the same fatigue would file different damage for it.
