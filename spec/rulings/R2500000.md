Classic #88 Siphon Squad's "When your opponent has no Units, Tribute this" ([[R403]]) is a condition the state check reads on every pass. Fused ([[R102]]) or granted onto a Unit that also carries S #112 Job Application's "Death: Resummon this at Stage 1" ([[R1865002]]), with the opponent holding no Units, it sacrificed the Unit as soon as the Unit returned, which returned it again: §4.5 never settled and the daily fuzz panicked on it (1v1 seed 7243, Duos seed 1231, where M #47 饕餮's end-of-turn fusing had built the Unit).

Run on a body that is not Siphon Squad itself (a fusion, a granted text) that arrived this turn, the condition now holds nothing: the terminator [[R2197005]] gave Floodgates' sweep on such a body, and REVIEW A3.6 asks one of every self-recursive Death. So a Unit that stood on the field before this turn is Tributed, returns once, arriving now, and stays until the next turn of either player, which `state.turn` counts, when the Tribute and the return come again if the opponent still holds no Units; a Unit played this turn is not Tributed until then. A printed Siphon Squad is never such a body, so it is Tributed the moment it is set, as before ([[R403]]), and so is its Radiant face. Patch v0.3.7b's script, which [[R767000]] keeps for those versions' replays, has no terminator, as it ran. Rejected: ending the loop in Job Application's Death, which [[R2197005]]'s own test needs to resummon a body a printed Floodgates sweeps again and again; and the state check skipping a Tribute it already made in the same check, a change to §4.5's loop that decides for every card what only this text needs ([[R1220]]'s Untributable guard being the only one the Tribute step has).
