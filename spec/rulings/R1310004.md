[[§14.12]]: practice and hotseat let a player use every card and every cosmetic whatever the
ledger holds, and so do the end-to-end tests, but the one that walks the economy itself.

- **Practice** never checked the collection, and still does not: its setup holds a saved deck back
  for L2, L3 and L6 alone, never L5 ([[§9.9]]), and the server's seed for a free game
  (`POST /api/practice/seeds`, [[R1303000]]) takes a deck of any cards, so a game on cards the
  account does not own pays like any other ([[§14.8]]).
- **Hotseat** runs in the browser, with no server and no account, so there is nothing to check.
- **Cosmetics.** Practice, hotseat and a practice game's replay print every full art, as the
  landing page's fan and the Almanac do ([[R1313000]]).
- **The fixtures.** The active fixtures `e2e-p1` and `e2e-p2` are granted every card at every
  reseed ([[R144]]), past the starter cards their activation grants ([[R1310000]]), so every spec
  that saves or queues a deck plays any card as before. `e2e-pending` stays pending for the invite
  gate's spec. A fourth fixture, `e2e-econ`, starts pending too and belongs to the spec that walks
  the economy (spec 45): its redemption is a new account's start ([[R1310000]]). It is a dev
  account in end-to-end mode, and only there ([[§14.10]]), for the spec's bar and quest tools
  ([[R1310003]]): a fixture's profile id is minted afresh at each reseed, so `DEV_PROFILE_IDS`
  cannot list it, and the server refuses end-to-end mode in production.
- **The full-art gate.** A production build gates full art now that the economy is live
  ([[R1313000]]). A development build, which `vite dev` and `build:e2e` make, prints every full art
  unless localStorage holds `"1"` under `jackioh.e2e.fullArtGated` as the page loads: spec 45 sets
  it before it visits, so it alone sees the gate, and every other spec, its screenshots and pixel
  comparisons included, sees every full art. A production build never reads the key.

Hearthstone semantics: Hearthstone's practice and its friendly challenges play the decks a player
owns, and it has no hotseat; the spec's practice and hotseat are its own, and §14.12 opens them to
every card.

Rejected: moving every end-to-end spec onto the starter cards, which would rewrite every spec's
decks and fixtures to test what they never meant to; and a server flag or a query string that turns
the full-art gate on, which a production build would carry or a player could set, where a key read
in a development build alone reaches neither.
