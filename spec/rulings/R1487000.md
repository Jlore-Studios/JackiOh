A Trap or Field Trap set face-down, neither revealed ([[R686]]) nor face-up, has its lasting text dormant: its auras ([[§10.4]] layer 5), hero Armor, draw limits, discard guards, Infinite Reserves, price rules, Echo grants and every other static text a reader takes off the board (a carrier's, [[R446]], a Tribute worth, a targeting cost, a Plague multiplier) act on nothing, so the other seat sees what a textless Trap would leave ([[R33]], [[§10.8]]). Revealed or face-up, they work. Its triggers stay live, and with them the count of a quest line it holds, which its own trigger answers, so a Trap with a fused lasting text (C+ #31, [[R77]], [[R102]], [[R1447]]) still fires as a Trap, and its self-Tribute is read face-down ([[R403]], [[R1149000]]). This extends [[R1149000]] to every card and replaces [[R403]]'s live reading, which let a Trap fused with #84 raise its hero's Armor as it was set and so name it; keeping that reading for fused cards was rejected, as [[R1180000]] gives nothing for a Spell Damage aura set face-down. Siphon Squad's v0.3.7b script stays live face-down (`Script::live_face_down`, [[R767000]]), and so does a fusion holding it; any other logged game this changes is `rules_changed`.
