Before each game both players pick at once, from their own decks that have not won ([[R330]]), the way the concurrent mulligan is answered ([[R265]], [[R266]]): a pick is final once made — a second pick for the same game is refused, and the same pick sent again is answered as the success it was, even after the clock ran out, so a retried request is harmless; a pick names the game it is for, and one naming another game is never applied, so a late duplicate of one game's pick cannot become the next game's — and until both are in, the other player learns only that it is in ("Opponent has picked"), never which deck. The pick that completes both starts the game at once. A pick is written to the series row before it is acknowledged, so a server restart keeps it ([[R263]]), and it leaves the server only in its owner's projection ([[§9.1]]).
