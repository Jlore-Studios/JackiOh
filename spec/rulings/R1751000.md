When a card has several Activate abilities (such as when cards with Activate abilities are fused together), each Activate ability's uses per turn and cooldowns are tracked independently on the instance (`memory.activations = { turn, count, abilities: { <id>: <count> } }`), amending [[R384]] and [[R1087]]. Activating one ability does not consume uses of another on the same card, allowing a player to trigger multiple distinct activate effects from the same card in a single turn if their costs and conditions can be met. On the client, a card with several abilities wears one Activate button; pressing it opens a choice panel (Discover chrome) to pick which ability to trigger (amending [[R510]]), narrowing the candidates to the chosen ability while leaving other usable abilities available for subsequent activations.
