Core #89 Corpse Eater's and TG #56 Legacy: Corpse Eater's gain from a death takes the Eater's Attack and max Health, as shown ([[§10.4]]), no higher than `MULTIPLIED_STAT_CAP` (999), each stat on its own: it gains what is left below the cap, and an Eater at or above the cap on both gains nothing and is not Buffed. Both faces stop there, the Radiant face's doubled gain included. Whatever else Buffs the Eater is unchanged. The scripts of v0.6.9l and before, which had no cap, are kept (`script_v0_6_9i`, [[R767000]]), so a replay on those versions still grows past it.

Why: the spec does not say, and Hearthstone has no cap. But an Eater in hand gains what a dying Eater gathered in its own hand, so copies played and killed in turn feed one another. A copy at 1,424/784 ate a Legacy Eater that died at 408/306, doubled on its Radiant face. In this patch's Radiant rotation of the fuzz gate (seed 6), the eaten Eaters took TG #56 to 2,230, past `GROWTH_NUMBER_BOUND` (2,000). That is the runaway doubling [[R4079000]] stopped for Unsecure System and Divine Spirit, and [[R884000]] for University, so it stops at the same number. The game fails the same way on the build before [[R4423000]], whose patch made these cards ones the gate deals. TG #56 changes with Core #89 because the patch is meant for both ([[R2195003]]).

Rejected: (a) raising `GROWTH_NUMBER_BOUND`, which would weaken the check that catches runaway scaling ([[R4079000]]'s reason). (b) A cap on every stat, which would change every Buff to fix two cards. (c) Capping only the Radiant face: the base face's copies feed one another too, each gaining what the last one gathered.
