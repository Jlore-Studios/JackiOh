Stinkyscape #118 Secure System reads "Set all Units' Attack to 0" and #119 Unsecure System "Double the Attack of all Units. All Units gain First Strike". The spec has no set of Attack alone, and [[§10.4]] floors a Unit's Attack at 0 only at layer 5, so a Unit Nerfed past its Attack carries a negative number under the 0 it shows. Both cards are Buffs of each Unit's Attack as it stands when the Spell resolves, on the existing primitives (ST-S14-7, ST-S14-8, S #10.1 Inner Fire's reading, [[R1867002]]).

- **Set to 0.** Secure System Buffs each Unit it reaches by minus its Attack before layer 5's floor (`unclamped_attack`, the number KY's Constant reads to set one exactly), so every Unit shows exactly 0, one Nerfed below 0 included, and a later Buff adds from 0, as after Hearthstone's set: a 4-Attack Unit Nerfed by 5, at −1, is Buffed by 1, and a Buff of +5 afterwards gives it 5. An Attack aura on it counts now, and when the aura leaves it takes its part with it: the Unit still shows 0, never below, with that part to make up before a Buff shows.
- **Not a set of stats.** It is not [[R1185002]]'s set (Meditative+ #21), which writes layer 1 and so also resets Health, damage and Buffs: Secure System leaves Health, damage and every other Buff as they are.
- **Double.** Unsecure System Buffs each Unit by its Attack as it is shown, floored at 0, so a 3/3 becomes 6/3 and a 0-Attack Unit, a Nerfed one included, stays at 0.
- **First Strike.** Unsecure System's First Strike is a granted keyword each Unit keeps for its stay ([[R78]]), not for the turn; the Radiant face grants it to its caster's Units alone.
- Both pass by a Unit Immune to Spells, and neither opens a prompt, so the Units read as it resolves are the Units it reaches.
