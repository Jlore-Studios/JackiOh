v0.1.1 shows a face-down Trap's cost to both players, and the view carries it on the face-down marker as `cost` ([[§10.8]]), the number [[R351]] fixes. The client draws that and nothing more (CLAUDE.md rule 7). A back in a backrow wears the cost as a gem where a face wears its cost, on both seats' boards, and is labelled "Face-down trap, (N) Cost"; a resting mouse or a long-press opens an overlay with the back, "Face-down trap", "(N) Cost" and that only the player who set it can see what it is, and draws no face. The showcase's back for a card the opponent set wears the cost its back shows where it landed, and the log's line for it ends ", (N) Cost", each read off the view's backrow while the card stands there face-down. A back the view gives no cost is drawn as before, and a back in a hand, which is no trap, shows nothing. A specific cost a player reads is written "(N) Cost", as card text writes one since patch v0.2.0 ([[R432]])
