R4589000 (the Recursion cards' memory, `recursion_log.rs`): each side keeps a `RecursionLog` of
this game — `played`, every face-up play as its `FaceUpRecord` (casts count, [[R70]]; countered
plays never do, [[R448]]; face-down plays never do, [[R451]]), and `deaths`, the Units that died
under that player, tokens included, each with the face it died on and the player-turn it died on.
The log is kept once the game holds an Infinite Assault card: either side's log is already `Some`,
or any card anywhere is of the set. Rejected: always on (it would move recorded games' hashes,
[[R768]]) and gating on `set_is_open` (never true for a single-player set, so the log would stay
off in the real Assault).
