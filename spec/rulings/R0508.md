A free practice game that ends gives the human the board [[R417]] takes from it: the worker reads `lastBoardFor` of the final state from the human's seat, so the AI's face-down cards are left out, and sends it with the game's last snapshot. The page keeps that one board on the device, each finished game's replacing the one before; a read that fails or finds anything malformed is no board, and a write that fails keeps the old one. The next free practice game hands it to the human's seat as its `createGame` input, and the game's debug record keeps that input, so the game still folds from its inputs and log ([[§9.3]]). The AI's seat never has a last board: its board would name the face-down cards the human never saw, which the device must not hold, so the AI's C+ #29 fizzles. A tutorial lesson neither takes the board nor gives one ([[R291]]), and a game left before it ends gives none. Hotseat passes none ([[R417]])
