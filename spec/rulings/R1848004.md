Stinkyscape #117 Core System and #118 Secure System end "lose 2 mana next turn" and "lose 1 mana next turn", and #120 Wild System "gain 1 mana next turn". The engine already holds both as [[§6.3]] Mana's "'next turn' mana is stored as a modifier for the next refresh": `next_turn_mana { amount }`, the rider #21 Hinder subtracts with and #24 Efficiency Dividend adds with. So the verb is that rider, `amount: -N` for a loss and `N` for a gain, and nothing new is stored; "lose all mana next N turns" ([[R844]]) is a different verb, a refresh that gives 0, and stays as it is. Hearthstone's Overload is the same thing: the crystals are locked on the next turn alone.

- **On the next refresh.** It changes what the player's next refresh gives, at the start of their next turn, whoever's turn it was made on: max mana plus the rider, never below 0, so a loss past max mana gives 0 and a gain may take current mana past 4 ([[§2.3]]). This turn's mana is untouched, and mana gained later in that next turn still adds. The refresh spends it.
- **Several.** Losses and gains sum on the one rider: Core System and Wild System in one turn leave "Next refresh −1 mana".
- **A lost refresh.** A refresh [[R844]] makes give 0 spends the rider with it, a gain included.
- **Seen by both players.** One badge per player, "Next refresh −N mana" or "+N", under `nextTurnMana`, which `modifierChanged` names as it appears, changes and is spent ([[R169]]).
