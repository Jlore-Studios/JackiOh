[[R4702000]] removed the commands only the retired training lanes ran and did not reach the unban lane's last one. That lane is retired ([[R4701000]]). It fitted `DEALT_Q`, each Core, Classic and Classic+ card's win share in the decks it was dealt into, with `cargo jackioh stats fit-dealt`, and `AiDeckOptions::shape` multiplied a deal's weights by `shaped_weight`: the table's ratio to `DEALT_Q_PRIOR`, sharpened (`DEAL_SHAPE_K`) and capped (`DEAL_SHAPE_CAP`), with the lane's unbans (`UNBANNED_PREFER`) preferred on top. No caller set the option ([[R976000]]) and the mulligan stopped reading the weight with [[R4110000]], so the table priced nothing.

All of it is removed: `stats fit-dealt` and its file `crates/tools/src/dealt_fit.rs`, the option, `shaped_weight`, `dealt_quality`, and the constants `DEALT_Q`, `DEALT_Q_PRIOR`, `DEAL_SHAPE_K`, `DEAL_SHAPE_CAP`, `UNBANNED_PREFER` and `UNBANNED_PREFER_BY`. Every deal is the one its seed always dealt: the option took no rng draw and was off everywhere, so [[R976000]]'s one rule for an arena's two seats is now the only rule there is.

Kept: `SHADOW_BAN` and `SHADOW_WATCH` and what reads them ([[R186]]), which the sweep decides. Hearthstone has no counterpart. A lane that shapes deals again brings the table back from git, with records to fit it on.
