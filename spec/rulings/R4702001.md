**Why.** The audit behind [[R4702000]] also found code in `crates/ai` that ran only for a value no build ships: a switch read in one place, set to one value, with a branch for the other. The owner's standing instruction for the audit was to trim as much as it found.

**What is removed.** Each switch is replaced by the value it shipped at, so no decision changes.

- `AI_SEARCH.replay_fill_steps` (0), and the fill it switched ([[R4447000]]): `fill_turn`, `ReplayFill`, the slice `decide` kept back for it on each other world, and `LineReplay.closed`. Its fork screen ([[R4397000]]; 3 against the control at 0, built from 3af8296300, 50 trunk deals on improve-dev) did not finish: stopped after 2 hours, nothing printed. A cut replay ends its turn where it stands, and `SearchStats.replaysCut` still counts the cuts.
- `AI_REPLY.open_lethal` (false), and `simulate_reply_with`, which took it (issue #1634): the reply's lethal that counted every attack it had left. Its screen read 203-197, edge 0.015 (-0.002 to 0.032), inconclusive ([[R4319000]]): 3 decided of 200 (won 3, lost 0). Issue #4246's, 400 games on improve-dev against the control at baa7cdb93f, read 200-200, edge 0.0, inconclusive: 0 decided of 200, 21 diverged. Neither kept it. The reply scores one hit on the hero at a time ([[R4187000]]).
- `AI_SEARCH.confirm_lone_win` (true): the lone-win confirmation is the one ranking of the finalists ([[R4608000]]).
- `AI_REPLY.spread_activations` (true): the spread order is the one order of the reply's visible tries ([[R4515000]]).

**What it does not decide.** Whether the fill or the open lethal makes the AI stronger: neither was measured to a conclusion, and issue #4447's plan left the fill's screen to a person. A screen of either restores it first, from `git show 16df1f7a:crates/ai/src/search.rs` (the fill) or `git show 16df1f7a:crates/ai/src/reply.rs` (the open lethal), and builds its candidate from there (`training/improve.md`, A screen).

**Rejected:** keeping the two that shipped on as rollbacks, since a rollback of a change two days old is a revert of its commit, and a screen's control is a build of the commit before, never a flag.
