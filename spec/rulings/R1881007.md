S #138 Pocket Peptides is a `wouldDie` replacement that casts M #36 CN Peptides at the Unit dying in combat ([[R1875006]]). A set Trap is spent as it fires. A Pocket Peptides that M #47 饕餮's Fuse took into a permanent is not: its text runs on the card it was fused into, every time. The check after the CN Peptides cast judges the Unit on the board the cast left ([[R460]]), and when neither the Buffs nor the destroy has settled it, that check finds the same Unit still dying in combat and asked the fused text again, inside its own cast, without end. The Duos fuzz found it (seed 21 of the emote search, once S21's Marketplace table moved its rolls).

So a Pocket Peptides that is not a set Trap answers no death while a CN Peptides its controller cast is still resolving: it answers once, and the check inside its cast lets the Unit die. A set Pocket Peptides is unchanged: it is spent as it fires, and a second set one still answers the check inside the first one's cast.
