An extra Cry reruns the play's own run with its declared targets and modes (MD-A13, Hearthstone's
Brann): each run is a whole effect list closed by its own state check ([[R59]]), and a target gone
since fizzles that part ([[R174]]). A Cry that C #54 Rewind triggers reuses the answers its prompts
got ([[R467]]), so it asks once and hits twice. The extra count is read as the Cry first runs, and
the extras end once the card has left its stay ([[R118]]). The Death hook ([[§4.5]] step 3) of a card
that died under its controller ([[R89]]) runs again on the same snapshot, in [[R68]]'s order; the
multiplier is read once the dying cards are off the field ([[R463]]), so a Double Counting dying in
the same pass doubles nothing. An extra run is parked on `state.work` only at a pause, never in
advance ([[R113]]), so a paused extra Cry survives a JSON round trip and answers to the same game.
