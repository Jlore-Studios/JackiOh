A seat no longer in the match may open its match socket onto the finished match it sat in only while no more than `REMATCH_OFFER_TTL_MS` has passed since the row's `finishedAt`. That is the window a rematch offer lives in ([[R672]]) and the one the reaper keeps a finished actor through. Past it, or on a finished row with no `finishedAt`, the seat is refused exactly as a profile holding no seat is: "you are not in that match", close code 4403 ([[§9.1]]). No actor is rebuilt, so no old log is folded and no report is filed for a game recorded under rules since changed ([[R1156000]], [[R767000]]). The game stays in Replays.

A finished match whose log is empty is not rebuilt: an attach answers not found (4404), as the co-op rebuild does ([[§13.9]]). The retention purge takes a finished match's log after `MATCH_ACTION_RETENTION_DAYS`, and the opening deal of a game that has a result is never shown.

A live match, and a match the profile is in, attach as before. Hearthstone semantics: a finished game's board goes when its end screen is left, and it is seen again only as a replay.

Rejected: no limit, which is the bug; a new constant for the window, since the rematch window already is one; the strict `finishedAt + REMATCH_OFFER_TTL_MS > now`, which disagrees with the reaper and the offers at the boundary; refusing a purged log with 4403 instead of the co-op rebuild's not found; checking the purge's cutoff instead of the empty log, which still shows a resultless opening deal inside it.
