"Evolves when …" is a standing condition of the card's own text, which the settled state check reads, or the card's own trigger evolving itself ([[R3536000]]). In the daily fuzz's handicapped seed 6107 Core #99 Craft a Card added a (0) Cost card to its caster's hand, and an immune C+ #49 Jay Fungus, whose text evolves it once that hand holds enough (0) Cost cards, evolved inside the Spell's run. I21 named the `evolved` as the Spell's.
**It is the Unit's own text.** The Spell changed its caster's hand, which it may; the Unit's text read the hand and evolved it, which Immune to Spells does not stop ([[§6.1]], [[R4453000]]). A Spell's `evolve` verb aims through the targeting and the field walks, which pass an immune Unit by.
**What I21 allows.** An `evolved` naming an immune Unit, in a Spell's run or not. Any other change the Spell's run makes to it after that is still a reach.
Rejected: treating `evolved` as a marker that begins the Unit's own run, which would also excuse the rest of the Spell's effects in the same run.
