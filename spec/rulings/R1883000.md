Presentation only (CLAUDE.md rule 7). Issue #1883 gives the Stinkyscape set ([[R1857000]]) its look and its sound while [[R1420]]'s gate still holds it, so nothing here reaches a player before its release (issue #1884) lists it in `SHIPPED_SETS`.

**The set mark** ([[R503]]). A Stinkyscape face wears a green planet in a deep-space disc, its ring tilted, a star beside it and three stink lines rising off it, named "Stinkyscape set" by its title and label, in place of the diamond a set with no glyph wears. It sits where every set's mark sits and follows [[R503]] in every other way.

**The chips** ([[R630]], [[R1380]], [[R1381]]). The deck builder's tags gain Drone Core, Weapon and Swarm, after Jelly Bean; War Doctrine, which only #137's four Doctrine tokens carry, joins the Almanac's alone, after Other-Origins, as Prime does. Each chip still shows only while a card of a shipped set carries its tag, and the set's chip only once it ships, so while the set is held none of them shows ([[R1857000]]); with the set previewed, as the release will show it, the Almanac shelves every card of the set, its set chip keeps exactly them, and the four tags have their chips.

**The intros** ([[R1352]]). The set's 29 Legendaries and 12 Mythics, the Dormant Starship among them, and its 24 tokens printed Legendary or Mythic, 65 in all, each have an intro of their own, rendered with the set rather than with its release, so the release owes none; the totality test still reads the sets that ship, so it holds them once the set does. The set's glint into the cadence is a crystal, a glassy synth bell, and four of its tags name families of their own after Acclaimed, which no shipped intro's recorded tags hold: a Drone Core a saw lead over synth strings, a Weapon synth brass over brass and orchestra hits, a War Doctrine a march, and a Terminus an organ under a choir pad.
