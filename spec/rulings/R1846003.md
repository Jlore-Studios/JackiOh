[[R1329000]] has every compiled table the engine reads while a replay folds answer from the shipped catalog the fold runs under first ([[R767000]]), or a ruling say why it does not. The card metrics ([[R1846000]]) stay the build's under every fold: `card_metrics` never reads the fold's catalog. No card of any carried version asks for a BUSTED or complicated pool, nor for every set ([[R1846001]]): the cards that do (Stinkyscape #109 and #111) were built behind [[R1420]]'s gate and ship only with the set's release (issue #1884), so no version before it holds them. So no fold of a game played on an earlier shipped version reads either list, and no final hash moves: a game recorded then folds to its recorded hash whether every card is in both lists or none is.

That changes once a card that reads them ships. Any edit to a script's code can move a card across a threshold and so change that card's pool, and with it a replay of a game played before the edit; and `classify` ([[R1365000]]) reads a script's code without its `use` lines or its layout, so it would not see every such move. So the patch that ships the first card asking for either list owes, before it ships: each shipped version's own lists, kept with its patch and read under a fold, as [[R1329000]] keeps each version's win-rate table; and a script change that moves a card across a threshold counted as a change to how the cards that read the lists play.

Rejected: keeping each version's lists now, while nothing reads them, since every version so far would carry lists no game ever read.

**Met** (issue #2173, before the Stinkyscape release ships #109 and #111): each shipped version that holds a card reading the lists keeps them in `patches/card_metrics/<version>.json`, which its folds read, and a version with none reads the build's ([[R2173000]]); and `classify` counts a change that moves a card across a threshold as playing every shipped reader differently ([[R2173001]]). Until the release, no version keeps lists, so every fold still reads the build's, as above.

From the release (issue #1884), some games of the build's own version play #109 or #111, so the swap of every card or none into both lists runs only over games that play no reader; those fold to the same hash under either, and a game that does play one folds under the build's lists, which are its version's. Since issue #2578 retired the 240 recorded golden games, the swap runs over the two committed logs, the hotseat fixture and the pre-Equip log (`crates/engine/tests/golden/`), neither dealing a reader.
