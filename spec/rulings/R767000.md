A replay folds under the catalog version its game was played on ([[R768]], [[R388]]). A game on the build's own version folds under the build's catalog, as before. Every shipped version but the newest is carried by the build. Its definitions are its snapshot's (`crates/cards/patches/<version>.json`, [[R646]]), in the catalog's order, rebuilt from the differences `crates/cards/build.rs` records against `catalog.json`. Its scripts are the build's own, except where one is kept for that version (`KEPT_SCRIPTS`, run as `<id>@<version>`, [[R388]]); the kept one a game uses is the earliest kept at or after the game's version. A game on any other version is refused as `earlier_patch`, before anything is folded.

The final-hash check stays. A game whose fold no longer reaches its recorded hash is refused as `rules_changed` and never shown as another game. That retires a game a change altered which the build cannot reproduce: an engine rule; a card patch that changed what a script does when no script was kept for it (none is kept yet, and scripts before v0.4.0 were Rust, so today's scripts stand in for them); and Meditative #50 CN Tech's win-rate table, which is always the build's.

A practice game keeps the setup it was dealt (its decks, handicaps, last boards and dealt seats), so it folds on a carried version without dealing again from this build's catalog. One kept before setups were kept folds only on its own version, and is otherwise `earlier_patch`. Since the browser folds only practice games, its module carries only the versions from v0.3.7 on (`crates/cards/build.rs`'s `BROWSER_CARRIED_FROM`): no game before v0.3.7b kept a setup, and carrying every version would break the module's size cap (issue #442, L12).

While a fold runs, the engine reads the carried catalog through a thread-local the fold sets for that call alone and puts back after it, a panic included (CLAUDE.md rule 4). It adds no field to `GameState` and changes no hash. `cargo jackioh patches check` proves that every carried version holds its snapshot's cards, entry for entry and in order, each with a script.
