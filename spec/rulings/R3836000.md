`cargo jackioh classify` tells a change to a file's code from one to its comments and layout by comparing the file's code lines with all white space taken out ([[R1365000]], [[R2050000]]). In a TypeScript file (`.ts`, `.tsx`) a comma that stands just before a `)`, `]` or `}` is layout too: it is the comma a formatter adds when it breaks a call, a list or an object over lines, and TypeScript reads `f(a,)` as `f(a)`, `[a,]` as `[a]` and `{ a, }` as `{ a }`. So breaking a line to put a comment inside a call, such as a Stryker disable comment above the one argument it names (issue #3836), changes no code, and under `apps/web/src/cards/` it is no change to how cards look ([[R2529000]]). Rust keeps the comma, since `(a,)` is a tuple there and `(a)` its element. We rejected reading every change of comments and layout under `apps/web/src/cards/` as no change to the cards' look by a TypeScript parser, because the comparison already ignored comments and white space and only this comma got through.
