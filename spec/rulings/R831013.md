Core #56 Jilliax's "Paid (3): Equip." is an embiggen price ([[R81]]) at which the card is also Equip ([[R1086]]): its `conditionalKeywords` give Equip to a card stamped embiggened. `legal_actions` reads the stamp each price puts on the card, so its Equip plays all carry `embiggen: true`, and the play's refusal reads the action's embiggen the same way, so an Equip play at (2) is refused. Played at (3) into an open zone it is a Unit that wears the keyword, which does nothing there. An Equip play fuses it into the host, which wears its own face ([[R77]]), so a plain host takes Jilliax's base 3/2.
