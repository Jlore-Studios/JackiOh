While a Mayor acts ([[R1200]]), each attack a seat may declare names the sentinel target `"random"` and the engine draws its target when it resolves, so no board names the unit or hero it will strike. The engine's combat forecast ([[R3100000]], [[R3477000]]) projects an attack on its target, and a drawn target has none to project on: the forecast carries no entry for such an attack, and an attack with no entry counts toward no lethal swing. Once the Mayor leaves, the same attackers' named attacks are forecast again.

So a daily game's read ([[R3855000]]) has an entry for each attack its `legal` lists except those whose target a Mayor draws. [[R3855000]]'s test, dealt from a random seed, failed whenever a Mayor was on the field when a seat first had an attack (pull request #4244's CI).

Hearthstone semantics: no prediction is shown for an attack whose target is random.

Rejected: an entry naming the sentinel with no outcome, which every board would have to learn to draw nothing for; forecasting each target the draw could pick, which reads as a choice the player does not have ([[R292]]: the forecast shows what the board shows).
