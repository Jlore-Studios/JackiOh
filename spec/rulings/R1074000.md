[[§13.5]] has each opposing seat see "only a card back leave one hand", and [[§13.6]] gives a seat nothing of an opponent's hidden cards beyond what a 1v1 `view_for` gives it. But a pass (B20) takes the card out of its duel's state without an event, and [[R97]] judges the events that named a card by where it is now: a card in no pile with no successor is one that ceased to exist, public when it went ([[R11]]). Judged so, a passed card's draw, its cost changes and every other event that named it while it sat in the passer's hand would read openly to the passer's opponent the moment it left. The spec did not say how a duel's events judge such a card; this note decides it as a Hearthstone hand card that leaves the game unseen is judged: as hidden as it was where it was last seen.

- **In a duel, a card in no pile with no successor reads to the player whose hand the events last show it in, and to nobody else**, a token as much as any other card: its draw, its arrival in that hand and every event that named it there stay as hidden from the opponent as they were while it was held, and read to the passer as they did (and to the passer's teammate, through the teammate's view, [[§13.6]]). It arrived in the hand by a draw, an add to hand, a bounce or a steal into the hand (a counter that sends a card to a hand steals it); a Transform or a Fuse in the hand carries its place to the card it became.
- **One that is no token and that the events show in no hand reads to nobody**: a card that came into the duel by a pass and left it by another, or whose arrival the log no longer holds, was never public there.
- **A card that left the hand by a public move is judged where it went**, as before: played, set face-down (whose old id follows the trap, [[R227]]: its draw reads once the trap is public), discarded, burned, shuffled away, exiled, sent to a graveyard or taken by a control change.
- **A token the events show in no hand reads openly**, as [[R11]] has it, judged by the definition the events last name it as, and so does a card a full library refused before it existed ([[R316]]). A unit token bounced off the field, or stolen off it or out of the resolving zone (a Thief Counter's steal), ceases to exist on its way to the hand ([[R11]]), so the event that names it going there leaves it in no hand, and its end was public.
- **Nothing reaches a 1v1 game**: a 1v1 side carries no Duos life, so its hand cards never leave by a pass, and a 1v1 view judges every event as before.
- `cargo jackioh fuzz --duos` runs the 1v1 fuzz's invariant monitor over each duel, and its hidden-information check (I6, [[R763]]) reads a passed card the same way, from the log.
