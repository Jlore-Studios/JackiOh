`DELETE /api/practice/seeds/:seed` deletes the caller's unclaimed seed: the row goes only while
it is the caller's and unclaimed, in one statement under the account's economy lock, so
[[R1483000]]'s count takes the release too and the freed place counts for the next issue at once.
It answers 200 `{ released: true }`; another account's seed, a claimed one or one never issued
answers 404 and changes nothing. A later claim of a released seed is refused as `unknown_seed`,
as a claim of a seed never issued is ([[R1303001]]).

The page sends it, as a keepalive request ([[R2119000]]), when an earning game is left without
saving ([[R765]]) and when starting a game drops a saved earning one. Save and leave keeps the
seed, and a game that earns nothing sends nothing. The next seed request waits for the release
to settle, so it never races it for the freed place. A release that fails leaves the seed to
lapse after `PRACTICE_SEED_TTL_SECONDS`, as before ([[R1303001]]).

A refused or unanswered seed request starts the game as before ([[R1303000]]), with a line from
its start, and in its result, that it earns nothing: the server's message when it refused one,
the page's unreachable sentence when it never answered.

No farming: a released seed pays nothing, and a junk claim already frees a place ([[R1483000]]).

Hearthstone semantics: a game abandoned earns nothing, and what was held for it is let go with
it, as leaving Hearthstone's queue frees its place.

Rejected: releasing on every leave of a finished game (its claim burns the seed, and a release
racing the claim could make it `unknown_seed`); an idempotent 200 for a seed not held, as custom
cards answer (the issue asks for 404); refusing a release while the economy is off (it pays
nothing); a release on the loading screen's Back or for a seed ask given up, which stay as
before, lapsing in an hour.
