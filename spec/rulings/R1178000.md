The Meditative+ set (`SetName::MeditativePlus`, written "Meditative+") is the next set [[R1420]]'s gate holds, as the Meditative set was while issue #496 built it: `CATALOG_SETS` orders it fifth, after Meditative, and `SHIPPED_SETS` does not list it until the last part of its patch (issue #1187). Until then everything [[R1420]] says of a held set holds of it, unchanged: no pool that names no set reaches it ([[R380]]), whatever tags it asks for, the set's own Potion included; a pool that names the set (`set: "Meditative+"`) or its cards by id does, so its cards find their own tokens and pools; no deck holds one (L3 says "the Meditative+ set has not shipped yet", [[§9.4]]); no lean names it and it is not the newest set ([[R1371]]); the Almanac and the deck builder show no card, chip or tag of it; no patch snapshot holds its entries and no fragment claims them ([[R646]]); the server neither seeds nor serves it ([[§9.11]]); no voice file is owed for its lines; and under the testkit `preview_sets(&[SetName::MeditativePlus])` opens it on one thread, as the fuzz tool's `preview_every_set` does on every seed. The golden traces deal from the shipped sets alone, so no card of it moves one.

Its entries are `meditativeplus-NNN` for card N (three digits) and `meditativeplus-NNN-k` for the token N.k, indexed "N" and "N.k", and its scripts live in `crates/cards/src/scripts/meditative_plus/` (the fifth set folder, after `meditative/`). `catalog check` and the cards crate's `MEDITATIVE_PLUS` fixture hold it to its shape alone while it is built ([[R1420]]): 26 cards and 4 tokens (M+ #1.1, #1.2, #16.1 and #20.1), 5 Common, 9 Rare, 9 Epic, 1 Legendary and 2 Mythic at most, every entry equal to its [[§8.9]] row and a row with no entry a card still being built; none counts toward the totals or the tag census until the release, when it is held to every count.

The set adds one tag, **Potion** ([[§5]]), on M+ #11 Living Mana Potion, #12 Living Armor Potion, #13 Living Health Potion and the potions M+ #16 Jazakus and #16.1 Jazakus Prime craft, read by the pools of M+ #14 Potion Pouch and #15 Book of Potions. It is a family tag and names no tribe ([[R1424]]), and no rule reads it. It is in the engine's `Tag` union from now, but the server's `cards_tags_check` admits it only with the release's migration, as [[R1411]]'s did Wincon: until the set ships, the check lists the union less a tag that only a held set's entries carry, and once it ships the check must list it.
