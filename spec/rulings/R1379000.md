The 1v1 (`/ws/match`), co-op (`/ws/duos`) and watch (`/ws/watch`) sockets carried the player's bearer token in their address as `?token=`, since a browser cannot set a WebSocket's `Authorization` header. The match screen already stripped the query from its diagnostic line, but an address is what a proxy, a load balancer or a browser's own diagnostics keep, so a reusable credential could outlive the socket there ([[§9.1]]). The token now travels on the handshake instead:

- **Two offered subprotocols.** Every socket offers `jackioh.v1` first and, beside it, `jackioh.bearer.` followed by the token's UTF-8 in base64url without padding. The encoding keeps any token, whatever its format, a valid protocol name. The address names only the match (and, for a watcher, the friend).
- **Only `jackioh.v1` is echoed.** The server reads the credential and answers with the protocol name alone, so the token is never reflected in the handshake's answer or in an error frame. A browser fails a handshake whose offer gets no name back, which is why the name stays first in every offer.
- **No usable credential is one refusal.** A socket that offers no credential, one that does not decode to a non-empty token, or one the auth provider refuses gets [[R148]]'s `forbidden` frame, "sign in first", and close 4401, exactly as a missing or refused query token did. An undecodable credential never falls back to the address.
- **Each socket is signed in by what it offers.** A reconnect offers the token the client holds when it opens, so a socket reopened after a renewal ([[R194]]) or after a 4401 for an older token ([[R1115000]]) carries the renewed one, and a healthy socket is still not reopened by a renewal.
- **The previous day's client.** Production's client can run up to a day behind the server (`docs/deploy-cloudflare.md` §7), so the server still reads `?token=` from an upgrade that offers no `jackioh.bearer.` credential at all, and only then. The fallback goes once production's client has been promoted past this change.

Rejected: a one-time upgrade ticket minted over HTTPS, which costs a round trip and server state on every reconnect, and is needed only where a proxy strips offered subprotocols, and none stands between the client and the server; the raw token as the protocol name, which a token format with a character outside an HTTP token would break; and dropping `?token=` at once, which would refuse every production tab still on the previous client until it reloads.
