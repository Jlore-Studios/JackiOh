A sandbox spawn ([[R923001]]) named only a card or a token of a set that ships ([[R1420]]), and a custom card is of the Custom set, which never ships ([[R915000]]), so a custom card reached a board built by hand only by being drawn. The spec made no decision for a sandbox game that carries custom cards; this note makes it.

- **What it may spawn:** every card and token of a set that ships, and each custom card the game was created with (`GameState.custom_defs`, [[R915006]]), for either seat, into any zone a spawn reaches. A custom id the game was not given is no card to spawn, refused as an unshipped card is; no other unshipped set opens. One spawned for the AI's seat is a card the AI may read, so it knows the card ([[R915007]]) and plays it as any card it holds; its deck still never holds one.
- **The game's own card.** A spawned custom card is placed, not played ([[R923001]]); from then on it is the card a deck deals: the game's definition under the board's auras, its script run on the host the game is lent, a failure said as [[R915004]] says.
- **Nothing else changes.** The panel lists the game's custom cards first, beside the shipped ones. `legalActions` never lists a tool, the AI never takes one and a server match refuses the action ([[R923000]]); no random pool, Discover or random deck finds a custom card; the game runs on the Luau module ([[R915009]]) and counts for nothing.
