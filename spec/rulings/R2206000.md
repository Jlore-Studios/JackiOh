§6.3's Summon of a fresh card may carry what the card's memory holds as it lands (`memory`, beside `statsOverride`), so a later hook can tell a body that summon made from one played or made another way. TG #25 Trigor's Death ([[§8.11]]) marks the Trigor it summons with the turn, and a Trigor whose mark holds this turn summons nothing when it dies, [[R2197004]]'s terminator. A stat override ([[R1181]]) was the mark until the M13 audit (#2206, REVIEW B-1), and it was no mark: §6.3's Set stats (TG #34 Dino-size, [[R2198000]]) and a Seance copy ([[R2198001]]) give a played Trigor one too, so a played Trigor set to 10/10 that died that turn summoned nothing where §8.11 says a 13/13. Leaving the field clears the mark with the rest of the memory ([[R78]]), and a card in a hand starts with none, so only the chain's own body carries it. Rejected: a dedicated `CardInstance` field, a field for one card where memory is the card's own store ([[§10.1]]).
