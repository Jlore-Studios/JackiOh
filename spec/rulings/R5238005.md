Felinors vs Humans #40 recruits by set. [[§6.3]]'s Recruit filter read types, tags, costs and definitions, never the set.

**The rule.** `RecruitFilter.set` names one set or several: only a library card whose definition is filed under one of them passes the filter, read off its definition as a catalog pool's `set` is. Absent, any set passes. Everything else is Recruit's: permanents only ([[R43]]), top down, the (X)-cost skip ([[R690]]), the first match that can be summoned.
