A Reborn return lands as a reset instance at 1 health ([[§4.5]] step 4, [[R83]], [[R78]]): Loopback's trigger answers its own `summoned` when the return set `returned_by_reborn` — a kept Reborn counts too ([[R4589003]], [[R4589004]]) — and gains the reset body +N/+N with Reborn again, the first three returns of each instance a game, each on its own once-a-game key. A plain play or summon is no return and gains nothing; the regained Reborn returns the card again.
