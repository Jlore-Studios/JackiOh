The sweep of the carried catalogs ([[R4382000]]) found two cards whose replays on the oldest versions still panicked once their numbers read off the build's definitions. Both get the script those versions printed, kept as [[R767000]] keeps any.

#74 Adaptive UI printed "summon an X/X Rush Token" through v0.1.0d, and those catalogs have no Ghoul Token, so today's script, which summons one, named a card they lack. A kept script, `script_v0_1_0d`, summons the X/X Rush Token instead and is otherwise today's: its multipliers read off the build's definition, since those versions declared none. #97 Zephrys reached the same panic through it.

#51.1 KY's Empty Notebook printed "Draw 1" (Radiant "Draw 2") through v0.2.5f and declared `draw` only from v0.2.6, while its kept script, which draws `draw` through v0.4.9, read it on every version it covers; the build's definition declares `cards` instead, so nothing answered the read. The kept script now reads `draw` with the printed 1 and 2 standing in where the version declared none ([[R2657006]]), so every version from v0.2.6 reads it as before. #51 KY's Private Tutor and #57 Conjure KY reached it through a Notebook they put in hand. Hearthstone has no counterpart.
