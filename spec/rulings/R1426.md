[[R749]]'s mirror. Thirteen numbers are written on the base face alone, the Radiant face saying something with no number in its place: #22 Carnivorous Cube's copies ("fill your board"), #60 Bear Honeypot's cost limit ("a card"), #72 Reminisce's discount ("it costs (0)"), #98 Heroic Power's Life Tap damage (none), C #2 The Trickster's discount ("costs (0)"), C #11 Mind Melt's cards ("every card of that cost"), C #13 Boots on the Ground's draw (a Recruit), C #44 Back from the GY's budget ("every Unit"), C #52 Final Gambit's draw ("draw your deck"), C #56 Spell Tyrant's spells ("every Spell"), C #68 Small Card Lobbyist's surcharge (a lock), C #88 Siphon Squad's multiplier ("0 Attack") and C+ #8 Withering Storm's cards ("every card"). A Degrade or an Upgrade could still move that number on the Radiant face, where it does nothing, so a draw was spent on nothing and a tuned Radiant card carried a change its text does not show. Their params declare `tunedOn: "base"`: on the Radiant face the number always reads its printed value, whatever the card's tuning, so a Degrade or an Upgrade never draws it there (B3.4 rule 3's Number row finds no step, and with nothing else to change nothing is drawn, [[R129]]), KY's Constant does not list it (C+ #41), and a step or a value recorded by any other way changes nothing there. On the base face it is tuned as any number is. The Radiant face shows no changed number, so a client marks none ([[R513]]). `catalog check` refuses `tunedOn: "base"` on a number the Radiant face's text writes, and refuses a number only the base face's text writes without it, so every such number is marked, a new card's included.
