Both seats' portraits are fixed when the match's seats are, and the server tells each client both ids — a `{ type: "portraits", p1, p2 }` message on join and again on reconnect, since a portrait is a match row's data and never part of `PlayerView`. A Best-of-1 or Conquest game uses each seat's queued deck's, frozen into the ticket or the room with the deck (a Conquest game's is the picked deck's); All Random deals each seat one uniformly at random at match creation, independently; a practice game's human uses the deck's portrait — a random deck, a random one — and the AI takes a random one; a tutorial deals `vanilla` to both sides; a hotseat's seats use their decks'
