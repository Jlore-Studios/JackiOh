S+ #64–#67 are (1 embiggen 4) Walls reading "Embiggen: GIGA" with embiggened stats at four times
their face (0/6 to 0/24, 0/8 to 0/32, 0/4 to 0/16, 0/6 to 0/24; doubled on each Radiant face). The
spec has no such text, so it is read as follows.

- **The GIGA.** GIGA is lent by the text to the card stamped embiggened ([[R1878001]],
  [[R3546002]]): `conditional_keywords` lends it while the stamp holds, so the card enters GIGA.
- **The stats.** The stats are `EMBIGGENED_SCALE` times the face, lent at [[§10.4]] layer 2 (`set_stat`
  adds three times the face), read off `face_of`, never `unit_view`, or the layers recurse.
- **Vanilla.** A Vanilla returns the Wall to its printed stats ([[R115]]) and keeps its size
  ([[R3546002]]): the stamp stays, so it still fills four zones.
- **Immutable.** Immutable never stops its own text, so Phase Wall's holds.

Rejected: an embiggened stat line on the catalog face (a schema change across the wire and the
client for four cards); and a Cry that sets stats, which Phase Wall's Immutable would refuse
([[R1185002]]).
