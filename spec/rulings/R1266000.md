Under [[R767000]] the win-rate table stayed the build's while a replay folded under an older shipped
catalog, so filling it would refuse, as `rules_changed`, every earlier game that cast Meditative #50
CN Tech or Meditative+ #2 NA Tech: the fold would pick another card than the game did.

Each carried version keeps the table it shipped with. While a fold runs under a shipped catalog,
every reader of the table — [[R1100]]'s leader, [[R1183000]]'s trailer and the ladder bots' lean
([[R750000]]) — reads that version's table, before a test's table and before the build's.

The table's `patch` names the version it ships with. That version and every later one in
`patches.json`'s order carry it; every earlier one carries the empty table, as every version through
v0.3.7b shipped with. A refresh that replaces the table keeps the one it replaces for the versions that
shipped with it, as `KEPT_SCRIPTS` keeps a replaced script ([[R388]]).

The table changes only with a card patch ([[R1101]]), beside that patch's pending fragment, which never
claims it. Issue #1266 filled it for the first time, from a development run of v0.3.15's cards, so it
is `provisional`. Nothing of it is in `GameState`, and no hash changes.
