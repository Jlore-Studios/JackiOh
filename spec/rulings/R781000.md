Magnetic is now **Equip** (patch v0.3.X): only the name changes, and the rule stays [[R1086]]'s. The keyword kind is `Equip` and the `play` action's flag is `equip`, in the engine, the server's parser and the client, and every identifier, refusal and test that named the old word names the new one. What was written before the rename cannot change: the shipped snapshots (v0.3.5, v0.3.6) print Magnetic, and the golden traces and any stored match log spell the play's flag `magnetic`. So the old names read as the new ones and are never written: the keyword and its kind take `Magnetic` as an alias of `Equip`, the play's flag takes `magnetic` as an alias of `equip`, and the server reads a client's `magnetic` the same. A log recorded before the rename folds to the state the same log renamed does, its Equip play accepted. The only traces of the old name are the shipped snapshots, these aliases, one history line in [[§6.1]]'s Equip row and the patch's player note.
