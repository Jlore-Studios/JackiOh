The fuzz monitor's I21 ([[R4453000]]) blames every event of a Spell's run on the Spell, and a play nested in a run is its own run until it resolves. Issue #4747's pull request had its changed cards' Radiant rotation deal a game in which a fused Unit carrying C+ #73 Call to Chaos (Classic+ Edition)'s text rolled "Destroy all enemy permanents", then "Cast a random Call to Chaos". A board-wide destroy only marks ([[§6.3]], [[R59]]), and the cast resolves before any state check, so the state check after M #95 Call to Chaos (Meditative Edition)'s own effect collected the Unit's marks, a Unit Immune to Spells among them. The collection has no marker of its own, so its `destroyed` landed in the Meditative Spell's run and I21 named the Spell.

**The mark is the casting card's.** [[§6.1]] keeps a Spell's effects off the Unit, and [[R4453000]] leaves Units reaching it. The Unit's destroy marked it; the Spell's state check ([[§4.5]]) only collected what was already marked, as the state check's other work is no Spell's ([[R4508005]], [[R4601000]], [[R4623000]]). The engine already plays it so: the Unit's walk marked the immune card, and the Spell's own walks pass it by.

**What I21 allows.** A `destroyed` that names no killer, in a play that a card that is no Spell cast while its own run was open. A death that names a killer is a hit's and is judged where the hit landed. A Spell played by a seat, or cast inside another Spell's run, still answers for every death in its run: there, no other card's mark can be waiting.

Rejected: recording which card set each mark, through a test seam at every destroy verb. It would tell a Spell's own mark from a casting card's inside the same nested play, but only a Spell cast by a card that is no Spell can meet both, and the test kit would then shadow every verb that marks.
