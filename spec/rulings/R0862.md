Fortify Mind's declared mode is judged against the secret named in its memory ([[§6.3]] Guess a secret), and only its own Mind Games writes that link: the link rides the instance `add_to_hand` hands the opponent. A copy carries no link, because copies keep no memory ([[§10.7]]); a Fortify Mind another card makes has none either; and one played after its secret resolved — the record removed — finds nothing. In all three cases it does nothing: no event, no penalty. The base face's discard clause answers its own `discarded` event, Temporary's included, whatever state the secret is in — played, resolved, or never kept — taking all three penalties at once. Being burned is not a discard ([[§2.4]], [[R4]]).
