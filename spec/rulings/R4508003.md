**It may.** The world is a rule of the game that every card is Radiant while it holds, not an effect reaching for one card, so "all cards" includes a Unit Immune to Spells, as it includes a Dormant one. The fuzz monitor's I21 (issue #4508) allows a `radiantSet` while `radiantWorld` holds; outside it the same event in a Spell's run is a reach.
