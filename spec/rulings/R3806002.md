Found by issue #3806's fuzz gate (seed 84 of its changed cards' wave; the same seed and cards fail on
`main`'s build). Core #93 Combo-Index, a Field Spell, was fused into Stinkyscape #159 Faction: ETHICS, so
the result is a Spell ([[R77]]) whose script carries Combo-Index's "End of turn: … go up a grade". Step 7
flagged the Spell for its end-of-turn return as it landed ([[R155]]), since the flag asked only for a
Spell with an `endOfTurn` hook. So the hook ran from the graveyard: it raised a grade counter on a card
there, which a card off the field never holds ([[R78]]), copied a played card into the hand and cut two
costs.

[[R155]] flags a Spell "whose resolving face declares an end-of-turn return", and [[R153]] lets a
graveyard answer that return alone. The spec does not say whose text a fused Spell's end-of-turn hook
is. This follows Hearthstone: a permanent's text works only while the permanent is in play. A fused
Spell is flagged only when every ingredient whose face (its Radiant face when the fusion or its own
mark is Radiant, [[R469]]) carries an `endOfTurn` hook is printed as a Spell; a fused ingredient is
judged by its own ingredients. A Spell lent a Unit's, a Field Spell's or a Trap's end-of-turn text is not
flagged: it stays in the graveyard, and that text never runs from there. A fusion of Spells, one of them
a return Spell (§5.1), still comes back as before.

Rejected: running only the Spell ingredients' part of the fused hook from the graveyard, which would
keep a Spell's return beside a permanent's end-of-turn text. The fused card has one `endOfTurn` hook,
which the trigger queue and its resumes re-read by name, so that needs a second, graveyard-only hook
through both. As ruled, such a mixed fusion stays in the graveyard.
