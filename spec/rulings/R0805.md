The card Meditative #21's end-of-turn line adds is a new, base API Key Fishing, even from the Radiant face: a generated card is not Radiant unless said ([[§5.2]]). A named card is not a pool, so [[R387]] does not stop it. The line fires from the graveyard on the turn the card was played (the return flag, [[R153]], [[R155]]), while the played card stays in the graveyard. Against an empty hand there is nothing to steal, so the card rolls nothing ([[R129]]).
