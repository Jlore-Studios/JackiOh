[[R376]] only logged a failed filing, so once the purge took the log (`MATCH_ACTION_RETENTION_DAYS`) the game was lost from the statistics. Before each purge, the retention loop now refiles every finished match with a result, a final hash ([[R768]]; the ceiling draws of [[R112]] and [[R1253000]] have none and file nothing), a held log and no record. A refile is folded as written ([[R1044000]]) and refused by id if the record exists, even emptied ([[R1044001]]). It tries each pass between `GAME_RECORD_REFILE_GRACE_SECONDS` (600) and `GAME_RECORD_REFILE_WINDOW_SECONDS` (86,400) after the end, and once more for each log the purge takes before its next pass. It names no build ([[R1367000]]), and an unfoldable log is reported as the first filing reports it.

Rejected: writing the record in the result's transaction, which costs a result whenever the record fails; trying every held log each pass, which re-alerts `bug.found` hourly for 90 days; trying only at the purge, which leaves a lost game out for 90 days, with one try; naming the filing deploy's commit, which credits a build that did not play the game.
