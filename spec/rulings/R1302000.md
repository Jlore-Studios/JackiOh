A drawn ladder game ([[§2.5]]: both heroes dead in the same check, an accepted draw, the turn
cap, the hard ceiling) pays each human side `JLORE_LADDER_LOSS`, never `JLORE_LADDER_WIN`, and
no side earns `XP_WIN_BONUS`: the game's XP is `XP_PER_ACTION` for each counted action alone,
up to `XP_GAME_CAP` ([[§14.8]]). A bot's side earns nothing ([[R1454]]), as in any other result.

Hearthstone semantics: Hearthstone has no draws to follow, so the ruling follows the earn's own
shape. A draw is not a win for anyone, so it cannot pay a win's Jlore or bonus; but both sides
played the game out, so it is not nothing either, and the loss rate is what a played game that
is not a win pays.
