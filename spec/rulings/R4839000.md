Refines [[R1850000]] and [[R3778000]]. S #20 Tnack Trav copying M #65 Keymaster Keenus or S #111 Shockwave447 held the Aura "Has {keywords|random combat keyword|random combat keywords}" and none of its keywords: the Aura's draw ran only as the card arrived or was fused, both past for a copier whose Cry copies, and [[R3778000]]'s top-up on a rising number waits for a list the copier never had.

- **The copy draws.** A copy whose copied text follows its number (`Script::combat_keywords_follow`, the Aura above) draws the copier's own keywords in the same effect, right after the text is written and before its `transformed`. It is the top-up a Fuse's kept card runs: what the number asks, read on the face copied (the target's face, or its Radiant face with `radiant: true`), beyond any list the copier holds this stay, by [[R781004]]'s rules ([[R21]]'s pool, none the copier holds from any source, no Taunt beside Indestructible, every one left when fewer remain). The target's own list is its draw, not its text, so it is not copied: each card holds its own.
- **A text with no such Aura.** A later copy of a text that follows no number draws nothing and shortens no list: the list stays on the copier for its stay ([[R3778000]]'s one list), given by no text, so the copier acts with none of it. A later copy of such an Aura in the same stay gives its first ones again and draws only past the list's end, as a higher number does (the Radiant text after the base one).
- **Nothing else moves it.** A copier made Radiant keeps the face it copied ([[R1850000]]), so its number, and draws nothing. A Buff's Number row and a number set outright reach the numbers the copier's own definition declares (Tnack Trav declares none), so as things stand none reaches the copied number; this ruling leaves that as it is. Leaving the field clears the list with the copy ([[R78]]). Nothing is drawn when nothing is copied (an Immutable copier, no target).
- **Replays.** The verb changes for every catalog, so a game played after v0.6.0c and before this change in which a copier copied such an Aura is refused by its final hash rather than shown with keywords it never had ([[R767000]]). Through v0.6.0c the kept scripts of the Aura follow no number, so the copy draws nothing, as it did then.

Rejected: copying the target's list, which is its draw rather than its text and would hand both cards one roll; clearing the list when a text without the Aura lands, which [[R3778000]]'s one list a stay rules out and which would roll anew on every copy back; running the copied arrival trigger, which [[R1850000]] does not run for a copy (as its Cry); and a kept Tnack Trav script behind a new argument to the verb, so that the replays between v0.6.0c and this change still fold, which is more code for a few replays.
