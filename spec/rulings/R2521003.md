Stinkyscape #26 ZolarKeth prints "A University can be Activated at most once each turn" on both faces, and its Cry now summons "a University", not a Radiant one. Its "Activate your Universities" ([[R1876001]]) runs each University's ability with `spendUse` (`ActivationOfArgs.spend_use`): the run happens only when that ability has not been used this turn (`ability_uses_this_turn`, B3.2 rules 1, 3 and 9, [[R1751000]]), and it then spends every use the ability has this turn (`uses_allowed`), written to the same record the `activate` action writes (`mark_use`). So the University's own Activate and every ZolarKeth share its once a turn: a University that used its own Activate this turn is passed by, one a ZolarKeth ran cannot then use its own, and a second ZolarKeth activated the same turn passes by every University the first one ran, so each University Buffs its other permanents once a turn however many ZolarKeths ask. A Buff that raised its Activate N ([[R386]], [[R884000]]) gives it no second run: a University ZolarKeth ran has every use spent, and one that used any of its own is passed by, so two Universities Buffing each other's Activate are still each Activated once a turn. The next turn starts it afresh. The run is otherwise as before: no cost is paid, no `activated` event names the University, it is no play ([[R384]]), and the refusal of its own use that ZolarKeth's Cry put on it ([[R1876000]]) is still not read, so that University runs once a turn through ZolarKeth and never by itself. The Cry summons the University on its base face from either ZolarKeth face (two Buffs on each other permanent, `times` 2), still refused its own Activate. `runActivation` without `spendUse` is unchanged ([[R1876001]]). This is the owner's balance pass (issue #2521). Rejected: a ZolarKeth-wide count of Universities run, which a University's own Activate would not share.
