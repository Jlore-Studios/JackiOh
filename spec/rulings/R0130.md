[[R32]] already rules that Lucky has "no effect where best is undefined"; this records why that matters mechanically. A re-roll draws again, and `rngCursor` is part of state ([[§10.7]]), so a Lucky that rolled twice and then discarded a draw would desynchronise a replay against a game that never had Lucky at all. So a verb either offers Lucky or does not, and a coin paying on both faces takes exactly one draw per coin ([[R129]]). A coin flip's better side is heads unless its card says otherwise, so a flip now offers Lucky, X more coins for Lucky X, and with no Lucky it still takes exactly one draw (revised by [[R1440]]).
