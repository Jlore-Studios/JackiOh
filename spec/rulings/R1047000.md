A co-op match ends as the engine's `ceiling` draw ([[§13.4]]) `MATCH_CEILING_MS` after its row's `created_at`: the deadline is derived from the row and never stored, so a rebuilt actor keeps the match's own deadline and no migration is needed. The actor arms it as it arms its other clocks and, when it runs out, applies one `ceilingReached` in duel 0 as a server action stamped a1 ([[R146]]'s convention: the ceiling is no seat's, as the clocks' actions are no seat's), under the nonce `srv-ceiling-<seq>`. The engine's own draw in that duel ends the whole game as `{"outcome":"draw","winner":null,"reason":"ceiling"}`, and the result is written once, as any end writes it ([[§13.9]]). It is an ordinary logged action, so `(seed, log)` still folds the match exactly. A rebuilt actor that arms past the deadline sends it at once, before anyone plays on; a ceiling whose action could not be logged is tried again `MATCH_SERVER_ACTION_RETRY_MS` later ([[R776000]]). The ceiling is the one clock the engine sees ([[R79]]); it is not carried by the `clock` frame.

Rejected: a stored ceiling column, which is a migration for what `created_at` already fixes; and one `ceilingReached` per duel, since the second is refused once the first has given the game its result.
