The network that ships is an integer one (`crates/ai/src/learned/int.rs`, `"format": 2` in `crates/ai/src/learned/weights.json`), made from the float network the native screen measured ([[R1010001]]) by `training/ml/jackioh_ml/quantize.py`. Its first layer takes the dense features as the integers `features` writes, the fit's standardizer folded into its i16 weights at the scale `A·2^shift` (`A`, a clipped activation's one, is 127). Each head layer and the output take i8 weights at a `2^shift` of their own. An i8 first layer would round most of its weights over 127 dense inputs of very different spreads to a handful of values; #1011 allows the precision a pull request states and defends, and an i16 table costs a few tens of kilobytes. Every sum is an i64, which no feature value can overflow; every layer ends in an arithmetic shift right (a floor) and a clip to `[0, A]`. The output's sum is divided once, in IEEE doubles, into the correction's logit, and mapped onto the hand eval's points as the float network's is ([[R1010000]]).

So the answer is the same on every target by construction. The parity fixture, `crates/ai/tests/fixtures/learned-parity.json` (a seeded random network, quantized, and 40 positions with the corrections the Python integer reference computes), holds both builds to it bit for bit: `cargo test -p jackioh-ai` natively, and the web's tests through the WASM module's `learned_parity` (`apps/web/src/wasm/index.ts`).
