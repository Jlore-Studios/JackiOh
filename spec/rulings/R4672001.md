**Why.** A Created card ([[R943]]) was credited to the seat that made it ([[R2089000]]), never to the card whose effect made it, so a Pancake token's figures mixed every card that makes Pancakes, and no figure could say what Mother Pancake's eight Pancakes or Jlockeed's Evil Blueprints' nine buildings each do.

**The record.** Each `createdUsed` entry names its `source`: the catalog id of the card whose effect minted the instance and whether that card ran its Radiant face; `createdUnusedSources` does the same for each `createdUnused` entry, in its order. It is `None` for a card a rule minted with no card behind it: The Coin, setup, a Resource or a Starship, and every card [[R1956001]]'s generators skip for the same reason. `createdUnusedSources` is absent when every entry is `None`, and both are absent from every record written before them.

**How.** The engine keeps `GameState.makers`, each Created instance's maker by instance id, written by the effect verbs that mint a card for a card as they mint (`generators::record_maker`, called by `record_generator`, `record_generator_of` and `credit_creator`): the card running the minting script (its definition when the instance has ceased, [[R127]]) and the face it runs. Unlike `generators`, which keeps the root generator for the client's dress, it names the immediate maker, and it is written whoever the card goes to. The first record of an instance stands, and a card set face-down under a fresh id keeps its maker as it keeps its generator ([[R227]]). It is the game record's alone: `replay::hash_state` leaves it out, as it leaves out `generators`, so no recorded hash moves; no view is told it; and the AI's redaction drops it whole, since it would name what made a hidden card. A continuation after a prompt (a Discover's answer) runs the same card's script, so it needs no marker of its own.

Rejected: following `hookResolving` markers, which no continuation, delayed effect or attack hook emits and which have no end, so a rule's mint after a hook would be credited to the hook's card; a `source` field on every minting event (`addedToHand`, `shuffledIn`, `summoned`, `transformed`), hundreds of literals for what one map holds; and carrying the source through the `PendingChoice`, which a mint with no prompt never has.
