**Why.** A card's figures ([[R377]]) walked the seat's decklist alone, and every card a seat played from its hand went into its record's `played`. So a Created card ([[R943]]: every instance minted after the decks were built, tokens, Discovered and generated cards, copies, cards shuffled in, Transform and Replace results and The Coin among them) whose id no deck held was never counted; a Created copy of a card the deck did hold counted as a play of the deck's card, skewing its played, drawn-but-not-played and face figures and its played delta; and a token that reached the field with no play from a hand (summoned or set by an effect, cast on its draw) was never recorded at all.

**The record.** Dealt cards and Created cards are kept apart. A seat's `opening`, `drawn` and `played` (with `playedTurns` and `playedRadiant`) hold its dealt cards alone, so The Coin leaves the opening hand ([[R376]]). Each Created instance is credited to the seat that made it, the controller of the card or effect that minted it: the minting event (`addedToHand`, `shuffledIn`, `summoned` or `transformed`) names that seat as its `creator` when it is not the seat the card went to, and otherwise the card is the seat's it went to, as The Coin and every card a rule mints with no card behind it is the seat's it was given to. `creator` is engine bookkeeping beside [[R1088]]'s `sourceId`: no rule reads it (`as_rules_read` drops it, so no state hash moves), no view forwards it, and the golden traces' event text leaves it out. It is not [[R1956001]]'s `generators`, which names the generating card and not the seat. Each seat's record gains three optional lists, absent when empty and from every record written before them:

- `createdUsed`: the Created cards the seat made that were used, one entry per instance at its first use, with its catalog id, the turn and whether it was Radiant then. An instance is used the first time it is played (from a hand or from anywhere else), cast ([[§2.4]], [[R70]]), summoned or set onto a field or a backrow by an effect, or takes a card's place on the field (a Transform), by either seat: an Ancient Curse Shade-iris shuffled into the opponent's library and cast on their draw is Shade-iris's player's. An instance counts once, so one bounced and played again, or summoned again, adds nothing, and a card set face-down under a fresh id ([[R227]]) is the same instance. Its face is the hand's as it was played from there ([[R1147000]]), and otherwise the card's as the step left it.
- `createdUnused`: the Created cards the seat made that no use reached before the game ended, one catalog id per instance: the baseline. A Created card burned on a full hand ([[R4]]) never reached the seat and is in neither list, as a burned draw is in no `drawn`.
- `createdPlayed`: every Created card the seat itself played from its hand, whoever made it, as `played` keeps a dealt card's plays. No card figure reads it; the daily quests ([[§14.9]]) count it beside `played`, so a quest moves for the plays it moved for before.

**The figures.** A Created card's figures are by its catalog id, under the same key as the deck's (patch, source, mode and the pilot of the seat that made it), each a win rate with its games beside it, a seat counting once a game however many copies it made: `createdPlayed`, the seat used at least one; `createdNotPlayed`, it made copies and used none; and, of the used, `createdPlayedRadiant`, one was Radiant at its first use, and `createdPlayedNormal`, none was. The Created delta is [[R377]]'s over `createdPlayed` and `createdNotPlayed`. They are folded with the deck's ([[R1044000]]) into the card's totals row, the four tallies absent while empty, so a deck row is stored and read as before and the store needs no migration (`card_totals.stats` is the row's JSON); the report reads them apart, as `created` beside `cards`, and a card no counted deck held still has no deck row. No back-fill: a record written before the lists adds no Created figure and folds exactly as it did.

**Where it shows.** `jackioh-server stats-cards` and `cargo jackioh stats report` (and the table a development run prints) print the Created table after the deck's, `--json` writes it as `created`, and `--card` keeps the card in both; `stats report --window` reads each Created card over its own window as a deck card is read ([[R1367000]]); `stats compare` adds each side's Created figures for the card when a seat on either side made one. `GET /api/stats/cards` answers `created`, tokens among them, under the deck table's filters (card, set, rarity, cost), enough games first, then the most games, then by name, its Created delta waiting for `CARD_STATS_MIN_SAMPLE` games on both sides ([[R654]]). The Cards tab of `/stats` shows them as a section of their own below the deck table, answering the same search box, each rate "—" below the sample floor, and names no source ([[R661]]).

**Unchanged.** CN Tech's and NA Tech's table, `crates/cards/data/win_rates.json` ([[R1100]], [[R1183000]]), stays the deck cards' figures, and a token stays ineligible: removing Created plays from the deck's figures is the change's only effect on it.

Rejected: a store table of their own, which needs a migration and a second read, add and write back for the same records; Created rows mixed into the deck table, which a reader of either would have to tell apart; counting every use rather than seats, which every other figure avoids ([[R1147000]]) and which would overweight a cheap token made many times; crediting the seat that used the card, which credits the opponent with Shade-iris's Curses; a `created` flag beside each `played` entry, which leaves a summoned token out; and keeping The Coin in the opening hand, which a dealt-cards-only `opening` cannot.
