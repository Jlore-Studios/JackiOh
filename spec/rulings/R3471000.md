A micro after a newest version ending in `z` opens the next line: after `vA.B.Cz` it ships as `vA.B.(C+1)` with no letter, the rollover a patch already takes ([[R1366000]]). After `v0.5.12z` a micro is `v0.5.13`, and the micro after that is `v0.5.13b` by the existing rule. The name's letter never tiers a patch: every later reader keys off the recorded `tier`, never the version ([[R105]]), so a micro wearing a patch-form name changes nothing downstream.

Why: the `v0.5.12` line holds 25 micro slots (`b` … `z`), and `cargo jackioh patches ship` refused on main with two honest visual-only micros pending and one letter left, naming neither and writing nothing, since every name is computed before anything is written ([[R646]], [[R388]]).

Rejected: merging the two fragments into one, which loses each pull request's record and recurs the next full line; and claiming a fake `rule` or `plays` to force a patch name, which `classify --claims` fails when the base build does not show it ([[R1370000]]).
