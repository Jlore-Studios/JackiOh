Since [[R2205000]] a lesson is built from moments the player finds, the first lesson's behind an opening `info` step ([[§9.10]]). No lesson built an `act` step, the kind that asked for one action and waited for it, so the kind is removed with its four builders (`playCard`, `attackWith`, `endTurn`, `keepHand`) and its turn-bound retirement, which retired an End turn step whose turn had passed before it showed. What [[R292]] and [[R314]] say of a step that asks for an action now holds of a moment's hints: the last hint points at the action, the coach offers it only while `legalActions` holds it, and a moment never holds the AI. Git history holds the act steps (`git show 0dd4f9f0:apps/web/src/tutorial/steps.ts`).
