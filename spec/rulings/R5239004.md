FvH #111 Vicious Fledgeling's Evolve Discovers a combat keyword it does not have. `discover_keyword` offers `count` keywords (`DISCOVER_OPTIONS`, 3, by default) from its pool ([[R21]]'s combat keyword pool by default), one of each kind, leaving out every kind the `lackingOn` card has now, read through the layers, and Taunt for an Indestructible one ([[R347]]). The offer is drawn by the match rng as the effect resolves, never as its hook builds it, since a hook is built again each time a paused list resumes ([[R113]]), so a replay draws what the game drew. Each option is the keyword's name, the Discover's pick is read back as any [[§10.6]] answer is (`chosen_options`), and `discovered_keyword` returns the keyword the offer held under that name, its number with it. With fewer kinds left than `count`, fewer are offered; with none left, or when `lackingOn` names no Unit, nothing is offered and the effect fizzles. The AI, the random policy and a timeout answer it as any Discover.
