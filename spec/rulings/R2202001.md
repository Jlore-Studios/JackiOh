Presentation only (CLAUDE.md rule 7). Issue #2202 gives the Training Grounds set ([[R2194000]]) its look and its sound while [[R1420]]'s gate still holds it, as [[R1883000]] gave Stinkyscape's, so nothing here reaches a player before its release (issue #2204) lists it in `SHIPPED_SETS`.

**The set mark** ([[R503]]). A Training Grounds face, and its pack, wears a straw archery target with red rings over two crossed wooden practice swords, named "Training Grounds set" by its title and label, in place of the diamond a set with no glyph wears. It sits where every set's mark sits and follows [[R503]] in every other way.

**The Almanac** ([[R1380]], [[R1381]]). The set adds no tag, so no chip. Its set chip shows only once it ships; with the set previewed, as the release will show it, the Almanac shelves every card of the set in its own art ([[R2202000]]) and mark, its set chip keeps exactly them, and the deck builder offers its cards and not its token.

**The intros** ([[R1352]]). Its three Legendaries (#37 Seance, #38 Tutorial Master, #39 Call to Chaos (Training-Grounds Edition)), its Mythic (#40 Goetzmann Game Design) and its token printed Legendary (#39.1 Training-Grounds Golem), five in all, each have a derived intro of their own, rendered with the set rather than with its release, so the release owes none; the totality test still reads the sets that ship, so it holds them once the set does. The set's glint into the cadence is a xylophone, wood struck like the yard's practice swords.

**Its lines** ([[§10.11]]). The foundation's `card-audio.json5` entries already give every Unit a play, an attack and a death line and every other card a cast line ([[R1448]]), #18 Knife Juggler's `play` the designer's "Put this apple on your head."; the voice files are rendered with the release.
