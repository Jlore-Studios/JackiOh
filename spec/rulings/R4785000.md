**Why.** [[R4552000]] reads a turn's row once its start has resolved (its draw and its start-of-turn triggers). A start-of-turn prompt (#65 Masochism Mask's choice, a start-of-turn Discover) parks the rest of the start behind it ([[R113]]): the action that began the turn stops in the `start` phase, before the draw and the trigger's effect, and the answer that finishes the start begins no turn. The fold read the row at the first of those and never again.

**The row.** The AI's fold holds a turn's row while the action it read left the turn's start under way (the phase is still `start`: the engine leaves it only once the start's last stage, the draw, is done, [[R62]]), and reads it off the state the first later action past the start leaves, ahead of any turn that action began. That action may end the turn too (one with nothing but ending it left to do ends by itself, [[R345]]; the autopilot plays one, [[R1183002]]): the row is then read off the state the action left, as [[R4552000]] reads every turn that begins and ends inside one action. A game that ends while a turn's start is still under way (a concession while its prompt is open, a loss to its trigger) writes no row for that turn, as none is written for a turn that begins on a finished game.

**The maker.** An answer continues the asking card's play or trigger, and the engine marks no hook for a run continued, so the fold begins an answer with the card whose script asked still resolving (an engine's own prompt names none): a Created card the answer puts onto the field names it as its maker ([[R4552002]]), the Mask's Spikey Pillow the Mask.

Records already filed keep their rows; nothing is backfilled ([[R4552000]]).

**Rejected.**

- **Writing the row at the prompt and correcting it after the answer**: the same row, with a second place that writes it.
- **A row for a turn whose game ended inside its start**, read off the finished state: its start never resolved, and no row reads a finished game.
- **Carrying the last resolving card from the step that asked**: a second memory in the fold, where the open prompt already names its card.

No Hearthstone rule is involved.
