Every play of a "… in the System" card (C #18 Glitch in the System, C #25 Lag in the System; `SYSTEM_CARD_DEF_IDS`) by either player, from a hand or a graveyard but not a cast, adds one to the match's count n (`GameState.systemPlays`; a fused card holding one counts once). From then on every card generated into a hand or a deck — added from a pool, shuffled in from one, a hand replaced (C+ #65.5), a deck replaced (C+ #73), a hand or deck card transformed at random — is Glitch instead with odds n × `GLITCH_ODDS_PER_SYSTEM_PLAY` / `GLITCH_ODDS_DENOMINATOR` (1/10000 a play), drawn as one more number of the match rng after the pick (`catalog.pickGenerated`), for either player's cards. A card generated to be summoned or cast at once, or transformed on the field, never is, since Glitch is a Spell that is only ever played. While n is 0 nothing more is drawn, so a match without a System play draws exactly as before. A reset ([[R676]]) starts n at 0 again
