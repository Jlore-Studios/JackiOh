title: Hidden information in the event stream (amended by R763, R764)

A view's event list is redacted, not truncated: an event that names a card the viewer may not read keeps its type and every field the animation table needs ([[§10.10]]) and shows the sentinel `"hidden"` in place of that card's `instanceId` and `defId`. Readability is judged by where the card sits **now**, not where it was: in a library never, in a hand only for its owner, in the backrow by [[§10.8]]'s trap rule, and anywhere else public. So a card drawn last turn and played this turn reads openly in both events, and a unit bounced into the enemy hand stops reading the moment it lands. `shuffledIn.position` is blanked for both players, since [[§9.1]] makes library order hidden without qualifying by player `trapFired` is the one exception: its `instanceId` and `defId` are keyed to the trap's **controller** as well as to the card's current zone, because firing the trap consumes it into a public graveyard and the event is what animates the flip ([[R154]]). The other player reads the sentinel wherever the card is; its controller reads them by the zone rule above, so the sentinel once the card is in a library or the other player's hand ([[R763]]). The identity is not thereby concealed — the graveyard shows it — the event simply does not name it. `stolen` (patch v0.2.0) reads to whoever could read the card where it was taken or can read it where it is now, the union of the two ([[R466]]). A card the state no longer holds reads as public, except in the events up to a Glitch's reset or boards, where it reads as the sentinel ([[R764]]).
