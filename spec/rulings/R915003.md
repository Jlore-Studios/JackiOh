A custom card's hook may ask its controller for one card or hero (`c:target(words)`) or one of several options (`c:choose`) wherever its script reaches the question ([[§12.4]]). A paused game is plain data ([[§10.6]], [[R113]]), so the script itself never pauses:

- The run stops at the question; the effects it recorded before it resolve, then the question is asked as a prompt (a target prompt, or a mode prompt).
- The answer runs the hook again from the top, with every answer so far. Each board reading the earlier runs made answers as it did then, so the run walks the same path; the effects that already resolved are not made again; the run goes on past the question to the next one or the hook's end.
- A word with nothing to choose answers nothing without asking, and the verbs aimed at it do nothing.
