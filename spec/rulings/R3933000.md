The spec was silent on the label under the opponent's portrait at a live online 1v1 table: it read "Opponent", though the match bar above the board names both seats, the match's replay names the opponent, a daily game's board does ([[R3855000]]) and a practice game names the AI.

The live `MatchRoute` board passes `<Game>` the other seat's username from the ranks read (`GET /api/matches/:id/ranks`, [[R604]]). The same read draws the match bar, so no new information reaches the client (CLAUDE.md rule 7). Until the read has come, or when the name is empty, the hero reads Opponent. The viewer's seat still reads You. The modifier list's You and Opponent headings stay ([[R169]], [[R3855000]]), and a watched game's labels stay as the watch screen has them.

Hearthstone semantics: the board's information is the same at every table.

Rejected: also renaming the modifier list's headings, which [[R3855000]] kept; a new endpoint or a name on the view, since the ranks read already holds it.
