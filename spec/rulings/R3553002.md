S+ #30 Yeah I'm a War Hero reads "The first card you draw each turn is replaced with a Warhero
Token", a Radiant one on the Radiant face. Only the first card drawn each turn, by any draw, is
replaced: the turn's first `draw_one` mints the §8 index "T-warhero-token" token to the hand
instead of taking the library top — a hand card, never a summon — and counts as the turn's first
draw, so the next draw is the library top in order. The source card's face selects the token: a
Radiant War Hero mints a Radiant token ([[R65]]). Minting starts the game-wide worth at 0
([[R3548002]]). The replacement reads the backrow like #75's ([[§3.2]]): a face-down source
sleeps, and destroying the Field Spell ends it. An empty library still fatigues ([[R3]]), a full
hand burns the token ([[§2.4]], [[R4]]), setup draws are no turn's ([[§2.1]]), only its
controller's draws are replaced, and a cast-on-draw card skipped on top stays uncast for the next
draw ([[R97]], [[R1420]]).

Rejected: replacing every draw of the turn; summoning the token; skipping the turn-draw count;
and a replacement that survives the Field Spell's destruction.
