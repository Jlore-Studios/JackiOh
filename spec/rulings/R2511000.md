The owner asked on 2026-10-30 (issue #2511) that the twenty Training Grounds snapshots of Core cards, #41–#60, be called Legacy cards and set apart from their Core cards. Each is named `Legacy: ` and then its Core card's name, exactly that prefix and casing (`traininggrounds-041` is "Legacy: Bigot", `traininggrounds-060` "Legacy: Rush Token Farm"); a card has one name, so its Radiant face shows the same. Its Chinese name ([[R1303]]) is its Core card's after the Legacy tag's word and a full-width colon, as the file writes its other labels ("传统：偏执者"). Every card's name is unique again ([[R381]], [[R739]]): [[R2194002]]'s one exception and [[R2195001]] end.

Each of the twenty carries a new tag, Legacy (`Tag::Legacy`, written "Legacy", in the union after Swarm and before Token, Chinese 传统), after the tags it already carries (#41 stays Human, #59 Fruit). It is a family tag no rule reads, as Drone Core and Swarm are ([[R1857000]]): no tribe, no pool takes its tokens, and a pool that names it holds the twenty. The deck builder and the almanac offer its chip; the census counts 20; the server admits it from migration 0069, which puts `cards_tags_check` back with Legacy added and nothing else changed, as 0065 did. [[R2194000]]'s "it adds no tag" is amended so.

Everything else about each stays: its cost, stats, text, keywords, rarity, set, flavor and script are the frozen Core card's ([[R2195003]]), and its picture is its Core card's ([[R2202000]]), drawn under the Core card's name and tags, so the `Legacy:` name and the tag are what set it apart on the face. A text that names a Core card names it alone ([[R2195002]]). A Legacy card is a Training Grounds card, none Legendary or Mythic, so the tutorial's opponent may hold and play one ([[R2533000]], which replaced [[R2433000]]'s Core-only bar).

Hearthstone semantics: a card reprinted into another set keeps its name only when it is the same card; a frozen copy kept beside the card it froze is named apart (Hearthstone's "Legacy" set).
