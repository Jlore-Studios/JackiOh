`createGame` takes a game's custom cards, each with its id, version, frame and source; the builder's model is the creator's and is dropped. The state keeps each card and its definition, so `hash_state` covers them, and `fold` with the same input (the custom cards with the seed, the decks and the log) folds the same game wherever a Luau host is lent: the browser's Luau module and `cargo jackioh replay` both lend the card kit's. A game with no custom card serialises and hashes as before: no golden trace moves. A practice game kept to resume ([[R668]]) or to replay ([[R768]]) keeps its custom cards in its setup, so a card edited later never changes a game already played.
