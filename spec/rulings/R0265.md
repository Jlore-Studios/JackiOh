[[§2.1]] step 3's two mulligans are open at once. Once the opening deal is done (a question it asked answered first, [[R224]]), both players' prompts open together, and either player may answer first. An answer changes nothing when it is given; the second one resolves both, always in seat order — Player 1's replacement draws and shuffle-back, then Player 2's ([[R9]]) — and then The Coin and the start-of-game effects follow ([[R244]], [[R43]]). So the game dealt is the same whichever player answered first, `(seed, decks, log)` folds it in either order ([[§9.3]]), and it is the game the one-at-a-time mulligan dealt before. The two prompts are not `state.pending`, which stays [[§10.1]]'s one prompt: they are one sealed-bid step (`state.mulligan`, [[§10.6]]), and while it is open nothing moves but a mulligan and the actions that end a game ([[R79]], [[R211]]); a game that ends then closes both, as it closes an open prompt ([[R216]]). Hearthstone's mulligan is simultaneous too
