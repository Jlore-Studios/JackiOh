A friend request names a player by exact `name#tag` ([[R1434]]), and its answer, a request sent or not found, tells whether the name exists, so it is a guessed value. It was limited per account only (`FRIEND_REQUESTS_PER_HOUR`), so a second account at the same address started a fresh allowance. Now `FRIEND_REQUESTS_PER_ADDRESS_PER_HOUR` (60) requests an hour are allowed per address ([[R190]]), across all its accounts, each counted on every attempt before the name is looked up, as the account's are; the next is 429 `rate_limited` ([[R192]]). A request carries one name: `username` must be a string, an array is 400.

Rejected: counting only requests that find no player, which would let a caller tell by the first 429 that names exist; and a per-address limit equal to the account's 20, which would stop a household of accounts behind one address (R190's address) from befriending one another.
