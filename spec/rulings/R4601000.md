S #115 Scornboi's "Every Unit that is neither Human, a Starship Piece nor a Starship is exiled" is a standing exile aura: the state check exiles each card it reaches ([[R1850002]]), with no marker of its own, since it is a Unit's lasting text and no hook runs it. A Spell can bring Scornboi in: S #150 Call to Chaos (Stinky Edition)'s "fill your board with random Human Stinkyscape Units" summons it, and the state check that follows exiles every other Unit, an Immune to Spells one included. I21 read a run as lasting until the next card's hook, trap or turn edge ([[R4577008]]), so it read Scornboi's exile of an immune Infinite Assault token as the Call to Chaos's, and failed the changed cards' Duos rotation of the fuzz gate once the Infinite Assault's cards joined the deal.
**The exile is the board's.** As the state check's other rules are ([[R4508005]]), an exile aura's exile is no Spell reaching for the card ([[§6.1]], [[R4453000]]). So I21 allows an `exiled` in a Spell's run while a card laying an exile aura acts on the field after the step.
Rejected: a marker event for the aura's exile, which would change every replay's events and hash for a check of the test kit.
