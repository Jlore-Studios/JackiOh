A finished co-op replay the server answered ([[§13.9]]) offers Download JSON: one file of the
seat's own views, each step's index and round, the seat and the build's catalog version, under a
format of its own, `jackioh-duos-replay` v1, versioned apart from [[R1141000]]'s 1v1 file. A replay
that is loading, refused or expired ([[R768]], [[R767000]]) offers no download.

No seed, log, state or deck leaves ([[§9.1]]), and no match id, no account id or name, no ping
([[§13.10]]), and nothing an opponent hid: only each step's view as the replay player is given it,
its fields named one by one so a field the server's answer gains is never carried by accident.

The file holds what the team shares ([[§13.6]]): the teammate's duel and hand as the seat saw
them. Sharing the file shares that with whoever reads it. Nothing in it names the teammate.

Nothing is uploaded or kept: the file is made in the page from the steps the replay holds, with
no request, and handed to the browser's downloads.

The recent games page's Open replay JSON ([[R1141000]]) opens such a file again in the page. It
reads a `jackioh-duos-replay` file as this shape: version 1, this build's catalog version, a Duos
seat, and steps numbered from 0 with no gap, each holding a view of that seat whose round never
goes back, under the 1v1 file's byte and step caps and sentences. A file it refuses mounts
nothing. A file that passes mounts on the co-op replay player, with no Download JSON and no
request.
