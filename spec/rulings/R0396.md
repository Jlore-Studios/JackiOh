An X-cost card on the field costs the X it was played for (the instance's `x`, which [[§2.3]] stores) wherever a rule compares or counts costs; anywhere else, and on the field when it arrived with no X chosen (a Recruit, a summon), it costs 0, as [[R65]] says. This amends [[R65]]'s "outside play … comparisons", which would otherwise read a field card at 0, so C #25 Lag in the System does not exile a C+ #69 Buff Billy played for 3; C #10, C #18, C #25, C #32 and C #39 read costs this way
