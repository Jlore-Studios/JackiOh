`cargo jackioh selfplay --games N [--from K] --seed <base> --out <dir>` plays games `K` to `K + N − 1`, game `n` on the seed `<base>:<n>`. Each is a development run's deal ([[R258]]: `dev_game_config`'s All Random decks, nothing banned), both seats this build's AI at full skill and `AI_GATE_BUDGET`, the browser's budget, through the arena's own play path, each seat seeing only `redact` ([[R185]]). It writes one line per game in game order to `<dir>/selfplay-<base>-<K>-<K+N−1>.jsonl`: the seed, the decks, the log, the final hash, the result, the turns, the catalog version and the commit.

Every game is a function of its seed, and the file of its games in order, so the same base and numbers give the same file byte for byte on one thread or many. An export can be sharded by `--from` across machines, each shard reproducible alone, and their files concatenated hold the same games one machine would have played.
