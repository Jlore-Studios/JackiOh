Once the game is over, each player's view carries the other player's hand face-up, the cards as they stand ([[§10.8]]), and a client shows the opponent's hand with the result. It reveals the hands and nothing else: libraries and their order and face-down traps stay hidden, and [[R97]] still judges the events, so an event that named a card while it was hidden stays redacted. The game is decided, so nothing a hand held can change it. It is a view rule, drawn by the client (CLAUDE.md rule 7)
