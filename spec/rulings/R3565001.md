The Reconstructors (S+ #128 to #131), Delta Definition and Operation Omega (#138, #139) add "a random Automa card", "an Automa-δ card" and "an Automa-Ω card". The spec has no pool of Automa cards, so it is read as follows.

- **The pool.** "Automa" is any of the six Automa tags (α, β, γ, δ, Ω, ζ). Its cards are the non-token cards of the Stinkyscape+ set that carry one, the pool naming its set so that it reaches them while the set is held and after it ships ([[R1420]]). A cost in the text, (0) or (1) or (2), is the card's printed cost read out of play ([[R65]]).
- **Tokens are out** ([[§5.1]], [[R382]]): no Automa-ζ fusion (S+ #133.1 to #133.5) and no Toxopid Leg is ever added by chance; the Automa-δ pool is Scepter, Antumbra, Quad, Sei and Vela, and the Automa-Ω pool Reign, Eclipse, Oct, Omura and Corvus.
- **When.** A Reconstructor acts at the start of its controller's turn, before their draw ([[R62]]), never at the opponent's. Each add is a draw from the match rng, and a card repeats only once the pool has run out, since `UNIQUE_RANDOM_DRAWS` is on ([[R3563000]]). A full hand burns it ([[§2.4]]).

Rejected: an Automa pool of every tag but a token's, which would add the ζ fusions the list calls tokens; and one of the cards the Automa-α/β ladder alone names.
