A cast is free and counts as a play for every rule that counts or reacts to plays, with cost paid 0 (Combo, Quickstriker, Unstable Clone Machine, Gifted Program, Bear Honeypot, Ceaseless Void); it fires the card's Cry or spell script; the caster picks its targets and modes. A cast never uses a cost discount, since it pays nothing, but a cast Spell does use Twinspell's Echo. The caster picks as the cast begins, before its announce ([[§10.5]] step 3a) and before the card is placed, as a play's choices are made with the card still in hand ([[R90]]), so a cast Unit is never offered as a target of its own Cry and a counter reads a cast's declared targets as it reads a play's (T-AI-9). The announce and step 4 are windows for a cast as for a play: every event so far reaches the traps there, which fire at once as responses, so a trap answering an earlier cast of the same draw chain fires before the next cast resolves, while Sheepish, which waits for a Unit to resolve, turns a cast Unit into a Sheep after its Cry ([[R17]], [[R427]]); the other triggers those events wake, and the work owed around the cast, wait for the loop of the effect that cast it ([[§2.4]], #95, [[R117]])
