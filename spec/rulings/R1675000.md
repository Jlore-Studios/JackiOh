[[R1186000]]'s `sweep --write` gives a card the row of the latest report of record that lists it. A report also lists, under `Cleared ids:`, each card it swept, neither banned nor watched, and affordable at some tier (not unswept, [[R186]]). By [[R600]] such a card is no longer on track to be banned, so `--write` gives it no row in `SHADOW_BAN` or `SHADOW_WATCH`, whatever an earlier report said; a later report that lists it gives it that row. A report printed before the list clears nothing, and one that both clears and lists a card is refused. So a sweep of some of a set's cards takes off those it clears without `SHADOW_UNBANNED` ([[R732001]]), and every card it did not sweep keeps its row; an id `SHADOW_UNBANNED` names that a later report cleared is no longer banned by any report, and `--write` refuses it as it refuses any such id. Hearthstone has no counterpart.
