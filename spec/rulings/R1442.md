Every live match the server runs leaves a record of how it was played, so the ladder bots (issue #636) can copy a person's pace, emotes and giving up. It is three server-only tables (migration 0029), each keyed by the match and a seat and none naming an account: `action_timings` (one row per move a person made), `emote_events` (one row per emote relayed) and `match_signals` (one row per seat). A row's `seat` is the seat its account began the match in, the one `matches.p1_profile_id` or `p2_profile_id` names, so a Glitch's swap ([[R677]]) never moves a row to the other account. Its `pilot` says who chose the moves, `human` or `ai`, as a game record's does ([[R376]]); every match the actor runs today is `human` on both seats.

**Think time.** A move's `think_ms` runs, in the server's own clock, from the push of the views that made it the seat's move to the arrival of the move: the delay the opponent sees. A seat owes a move while it holds the open prompt, else while it owes its mulligan ([[R265]]), else while it is the active seat, and no seat owes one once the match has a result. A seat that comes to owe a move, is newly put a prompt, or makes a move and owes the next starts its think time at that push; any other seat keeps its own running, so a seat that waited out its opponent's mulligan counts from where it began to wait. The opening counts from the match's creation, since no push came before it. A server action (a clock's expiry, [[R79]]) and `setAutoEndTurn`, a preference ([[R345]]), are no one's move and make no row. Beside the think time a row holds the action's kind, how many actions were legal to the seat (`legal_actions`, read off the true state on the server: nothing new reaches a socket, rule 7), the turn, the acting deadline the seat had left as the move arrived (`clock_left_ms`, none when no clock was running for it), whether it was the seat's first move of the turn, and `rank_bucket`, the ladder tier the player held when the actor armed ([[§9.12]]), read for an unranked match too and left empty when the read fails.

**Emotes.** An emote the relay passes (the sender's dealt hand, [[R1342]], and the rate gate, [[R643]]) is recorded with its turn, the type of the last game event a push showed before it and how long after that push it came, and, when it answers one, how long after the opponent's last emote. Emotes are recorded until the match's result, since the telemetry is written with it: a "good game" sent afterwards is not kept. They never enter the action log, the state or a replay hash, so [[R643]] holds.

**Signals.** Each seat's row counts the draws it offered and its clocks that ran out (the server's `timeout`, stamped with the seat whose clock it was, [[R146]]), and holds whether it accepted a draw, the turn it conceded on with how far behind it stood (`concede_eval_deficit`, the AI's evaluation of the state the concession was made on from the conceder's side, negated, [[§9.9]]), whether it offered a rematch, and whether its offer made one ([[R672]]). Both seats' rows are always written. The rematch route marks an offer on the finished match's row after it is answered.

**Writing it.** The actor gathers all of it in memory and writes it in one transaction right after the result commits ([[R1437]]), never action by action. A failed write is logged and dropped and never costs the result, as a game record's ([[R376]]). A row whose key is already held is left as it stands, so a write repeated after a restart changes nothing. A rebuilt actor replays its log into the same record before it carries on ([[§9.5]]), each logged action's `at` standing in for its push; that log's stamps are the store's, so after a restart a think time runs from one stored action to the next.

**Backfill.** `jackioh-server timing-backfill` folds every finished match whose action log is still held, and that has no action timing yet, the same way, under the deal the match was folded with ([[R258]]), and writes its `action_timings`. Its rows carry no clock and no rank bucket, which the log does not hold, and no emote or signal is backfilled, since none of them reached the log. A match whose log today's engine no longer folds whole is skipped, since its rows would describe another game.

**Fitting.** `jackioh-server timing-fit` reads the action timings, leaves out every `pilot = 'ai'` row, groups the rest by rank bucket, action kind and first move of the turn, and fits each group of at least `TIMING_FIT_MIN_SAMPLES` (30) moves with a log-normal, the maximum-likelihood mean and standard deviation of the think time's logarithm (a think time of 0 counts as 1 ms). It prints one row per bucket to paste by hand into the server config's `THINK_TIME_FITS` (CLAUDE.md rule 9), as `cargo jackioh sweep` prints its rows, so no number reaches a bot without a person reading it.

**Privacy and retention.** No client role reads or writes the tables: row-level security is on with no policy and no grant to `anon` or `authenticated`, as for the game records. The retention purge deletes a finished match's telemetry `PLAY_TELEMETRY_RETENTION_DAYS` (365) after the match ended, longer than the log's 90 days so the fits have a year of games; a match deleted outright, a void ([[R679]]), takes its telemetry with it. Deleting an account deletes the rows of every seat it held, the opponent's kept. The privacy policy names the telemetry, why it is kept and for how long ([[§9.11]]).
