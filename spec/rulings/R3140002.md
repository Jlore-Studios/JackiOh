C+ #16 Conjure Rush Token+ reads "Summon a Rush Token. Flip a coin: it gains 3 random combat keywords on heads, 2 on tails." (the designer's "2-3 keywords, 50% for each outcome") and its Radiant face "Summon 3 Rush Tokens. Each gains 5 random combat keywords." Through v0.5.11o both faces gave 3 keywords to each token and flipped nothing.

- **The coin** is a coin flip, so [[R1440]] holds: a luck-based roll whose better side is heads, flipped once as the Spell resolves, with the card's own Lucky (printed or given, [[R1438]]) and its controller's Luck ([[R987]]) flipping that many more coins and keeping heads. With neither it is one draw of the match rng. It is shown to both players before the token it decided ([[R2652001]]). It is flipped whether or not a unit zone is open; a summon with no open zone rolls no keywords ([[R129]]).
- **The numbers.** `keywords` is the heads count (3, Radiant 5) and `tails` the tails count (2), each its own declared number a Buff or a Nerf moves ([[R386]]); `tails` is printed on the base face alone and tuned there alone. The keywords are different ones from [[R21]]'s pool that the token lacks, as before. The Radiant face flips no coin: its `tokens` Rush Tokens (3) each gain `keywords` (5).
- **The pool.** The base text says "Flip a coin", so the card is Luck-based ([[R1444]]): Meditative #101 Gachaholic can add it to a hand.
- **Replays.** A game played through v0.5.11o folds under the script it ran, with no coin (`script_v0_5_11o`, [[R767000]]).

Rejected: a plain 50% with no Luck, which would make this the only coin on a card that Lucky X and Luck X do not touch ([[R1440]]); and a `tails` of "one fewer" worked out in the script, which the card's text could not print once `keywords` is moved.
