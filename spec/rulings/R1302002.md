A match the reaper resolves ([[§9.5]]) pays as the result the reaper writes, through the same
hook in the same transaction as its row ([[§14.8]]). A log that already ends is recorded as it
ended ([[R833000]]), and pays as that result: a win the win rate with the bonus, a loss or a
draw the loss rate. The reaper's ceiling draw ([[R112]]) is unrated, yet still pays: each
human side earns `JLORE_LADDER_LOSS`, and the game's XP counts the log's actions with no win
bonus, up to `XP_GAME_CAP`. A bot's side earns nothing ([[R1454]]).

Hearthstone semantics: the players played the log's actions whatever ended the match, so the
game's time-played XP counts them; but nobody won a ceiling draw, so it pays no win's Jlore or
bonus, as [[R1302000]]'s draws do. Rating and earning stay apart: the ceiling draw leaves both
ratings unchanged ([[R112]]) and still pays, since one is the ladder's memory and the other the
game's wage.
