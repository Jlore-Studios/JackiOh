Presentation only (CLAUDE.md rule 7): no rule, state, event, endpoint or response changes. Every figure is read off `GET /api/stats/cards`' `created`, as [[R2089000]] reads it.

**The Created tables' columns match the deck table's.** Both sections ([[R3324002]]), the Tokens and the Other created cards, show the deck table's columns in its order under its header labels: Card (the thumbnail cell, the cost badge coloured by rarity), Name, Games, Tier (the `TierChip`), Adjusted (the adjusted win rate) and Win rate (the raw win rate, [[R2370000]]'s rate of the seats that made one). They honour the tab's Columns toggle (`visibleCols.thumbnail`, `visibleCols.games`) as the deck table does. Used, Not used, Used Radiant, Used normal and Used vs not used are gone, with their sort keys. Every remaining header still sorts ([[R3184002]]), and each section still opens on Adjusted, best first ([[R4082000]]). The rows use the deck table's cell markup and classes, so they look the same, not merely hold the same figures; below the floor a row still reads "—" where it did, not the deck table's "not enough games".

**A row opens the card.** A Created row opens the same drill-down the deck table's rows open: `openDrillDown(card.id, opener)`, `?card=<id>` in the address, Back and Escape closing it ([[R2127000]], [[R3221000]]). The rows act as the deck table's do: `role`/`tabIndex`, Enter and Space, the pointer cursor and the name styled as `stats-card-name-link`. The choice is the drill-down, not the `CardDetail` inspect view: a catalog token's def renders its face, and The Coin, which the catalog holds as no card, still shows its figures with the deck-only sections' empty states (`No games recorded with this card played.` and the like), so no server change is needed.

**The explanatory paragraphs are gone.** The Cards tab's tiers note ([[R3022000]]), the ranges note ([[R2895000]]), the Created sections' hint paragraph and `CreatedTiersNote` ([[R3324002]], [[R4082000]]), the Games panel's counted line ([[R1994000]]), the Sets tab's intro and footnote ([[R1966000]]) and the Players tab's note are deleted, with their CSS, test ids and translation strings. Error, empty, loading and collecting states stay, as do the headings and the short `title` tooltips on the headers.

No Hearthstone rule is involved.
