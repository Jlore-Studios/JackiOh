A deck its player was dealt rather than built — All Random's ([[R258]]) and practice's fresh random deck — is no longer listed in full from the start, as [[R310]] had it: `createGame` learns which seats were dealt a deck, and for those no record is written for the starting deck ([[R311]]), so the view's list of the player's own library counts each such card as unknown, and a client draws it as a card back, until it leaves the library ([[R312]]). What goes in openly afterwards — a mulligan's returns, a shuffle-in both players watched — is recorded and listed as [[R311]] says, so the list shows only what its owner has been shown going in. A deck its player built is listed from the start as before. It is a view rule; the client draws what the view gives (CLAUDE.md rule 7)
