title: Fixture accounts are reseeded per run

  - crates/server/tests/api/e2e.rs

In end-to-end mode the server reseeds its fixture accounts and invite codes at boot, so a spec that activates the pending account or spends an invite code is repeatable. Without this the invite-gate spec passes once and fails on every later run, which is indistinguishable from a regression
