The public Patch notes page ([[R388]]) groups the card patch history by card set — Core,
Classic & Classic+, Meditative, and each set that ships after them — instead of one flat
newest-first list. The page opens on the newest set, whose bubble is selected; a bubble button
per set and a synced dropdown select the set on show. Each set shows its name and version range,
a release summary, a bulleted list of the technical changes since the preceding set (engine,
AI, systems, audio and visuals), and its sub-patches nested below: the minor card changes,
balance passes and b-patches that belong to it, each with a human-readable title and summary
that say what players see, never an AI pull request's commit title, a raw ruling citation or an
internal rulebook reference. A patch that ships before its note is written still shows, under
the newest set with its catalog title and notes, so no patch ever disappears. The newest
sub-patch of the set on show opens its cards on arrival ([[R507]]); every other card diff panel
stays shut until its toggle opens it. Presentation only (CLAUDE.md rule 7): the catalog
snapshots, their order and the card history read them unchanged.
