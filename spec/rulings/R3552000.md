S+ #154 Chaos Accelerator reads "When launched, cast a random Call to Chaos", and its Radiant face
"… a random Radiant Call to Chaos". The spec has no such pool or cast, so it is read as follows.

- **"When launched".** It is the Starship's launch ([[R1852003]]): `when_launched` runs only as part of
  the Starship the piece is fused into, after its fused Cries; the piece on the field does nothing.
- **The pool.** One uniform pick from every non-excluded card tagged Call to Chaos of the shipped sets
  ([[R380]]), the pool naming no set, so the held S+ #142 joins it only when the set is released
  ([[R1420]]). Tokens are asked for (`withTokens`, [[R382]]); none is tagged Call to Chaos today, so the
  flag changes nothing now. It never picks this card ([[R387]]).
- **The cast.** One `castRandom`, free, cast from no zone, every choice of the cast random so that nothing
  pauses for a prompt; a Call to Chaos it casts is a link of the Call to Chaos chain ([[R28]]), counted
  against its cap, as when Jogg's Box casts one. The Radiant face casts the card Radiant.

Rejected: a pool naming the S+ set (it would reach a held card before the release); the pick's choices
asked of the player; and a cast that skips the chain's cap.
