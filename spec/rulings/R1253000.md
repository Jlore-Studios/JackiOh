A live action whose `reduce` panics changes nothing: no row is logged, no state is kept and the log's next seq stays where it was ([[§9.3]]: `reduce` is pure, so the same action on the same state panics again). Its sender is answered `internal` under its nonce, and the actor keeps that answer, so a resend of the nonce gets it again without a second reduce; the next action of either seat is applied as any other. The server files the finding for the night bot once per match, as a rebuild's is filed: the match, the seq the action would have taken, its seat and its type, never the panic's message, which can name a card. A server action a clock's expiry becomes ([[R79]], [[R268]]: a timeout, a disconnect forfeit, the ceiling's draw) whose `reduce` panics is not tried again as [[R776000]] retries a row the store failed to take, since it would panic on every retry: the match ends at once with the result the reaper writes at the ceiling, a draw by `match-ceiling` with `turns = 0` and both ratings unchanged ([[R112]]), written as [[R1437]] writes any ending, and the actor lets go as the reaper's stop does. In a co-op match every server action is the AI's move or the ceiling's ([[R1047000]]), and the AI would make the same move again on the same state, so any of them that panics ends the match at once as the `ceiling` draw [[R1047001]]'s sweep writes. A ladder bot's move in a 1v1 match only gets its answer: its next try at the same seq is answered from it until its turn clock times it out.

Rejected: keeping the stall, a clock's action that panicked never tried again and the match held until the reaper's ceiling draw ([[R833000]]); ending the match on a person's or a ladder bot's action, which another action may yet get past; and a rated draw, which would rate a game the server could not finish.
