A Unit token in a hand may be set face-down by a Cloaked it prints, is given or is lent ([[R783004]]): Knowledge Breaker Prime, Solarius Prime or a Salvage Protocol drawn from a deck and Cloaked by Knowledge Breaker's Aura. Set, it is a Field Trap ([[R783004]]), and [[R783008]] sends a set card that leaves unrevealed to its owner's graveyard or hand as its printed card. The spec did not say which of that and [[R11]] rules a set Unit token. [[R11]] does: the printed card is a unit token, and no unit token leaves the field for a graveyard, an exile pile or a hand. So a set Unit token destroyed, exiled or bounced before it reveals ceases to exist ([[§3]]), as a face-up one does. The engine reads a set card's printed type for this (`zones::is_unit_token`), as the fuzz monitor's I11 reads a token by its definition. Found by the daily fuzz (issue #2855, seeds 617, 2202, 6635 and 8686).
