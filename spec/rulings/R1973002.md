The statistics page showed the newest patch and offered only the version before, which was often a micro of the same patch with the same figures.

- **The patches.** `GET /api/stats/cards` lists every patch the page can show, newest first (`patches`): each window the cards share ([[R1367000]], as [[R1973001]] reads it), with its versions oldest first, its games (every record filed under them) and its live games. A patch is named by the version that opened it and its figures are asked for at its newest.
- **The picker.** Above the tabs, a picker offers the `STATS_PATCHES_OFFERED` (5) newest patches with `STATS_PATCH_MIN_GAMES` (1,000) games or more, live and AI, and the patch shown when it is not among them. Choosing the newest patch asks with no `?patch=`.
- **Before and after.** Beside it, the patch before the one shown and the patch after it, each naming its patch, each disabled where there is none. The provisional banner's previous patch, the games tile's name and the Sets tab's change ([[R1966000]]) read the same list, so each steps by patch, never by micro. A server without the list shows no bar, and the banner and the Sets tab fall back to the version before.
