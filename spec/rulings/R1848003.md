Stinkyscape #102 Book of Nono-Words reads "Add 4 copies of No-No Words to your hand, their prices are set at 1, 2, 3, 4", and No-No Words is an (X) Spell. [[R65]] has an X-cost card cost exactly the X chosen at play time ([[R348]]); a set X is new.

- **The rider.** `add_to_hand`'s `fixedX` sets an X-cost card's X as it reaches the hand (`CardInstance.fixedX`), a price for the card in the hand like the other cost riders, so a full hand burns the card without it, and a card with no X takes none.
- **No X to choose.** Its player chooses no X: `legalActions` offers its play with no `x`, priced at the set X, and only while that is affordable; the reducer refuses a play naming another X ("its X is set at N"), and takes one naming the set X or none. The play is for the set X, which `cardPlayed` names, and the card's text reads it as it resolves (a Nerf's or a Buff's X step still moves what it reads, never below 1). A cast of it is for its set X too.
- **The price.** It costs exactly its set X, which no modifier reaches ([[R65]]: no discount, surcharge or Inflation), a floor or a ban still applying; [[R396]]'s cost reads it in the hand, the deck and on the field alike. The view prints it: the card's `cost` is the set X and `fixedX` says it is set, so the face shows the number where it would show X.
- **How long it lasts.** As `costOverride` does: through the hand, the deck and a Bounce, and off once the card reaches a graveyard or an exile pile ([[R766]]), so a card played from there again chooses its X. A copy of the card is a new card without it ([[R57]]).
- Absent on every other card, so no shipped game changes.
