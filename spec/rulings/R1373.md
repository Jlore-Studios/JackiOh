Practice's deck picker offers "More cards from the newest set" beside its Random deck ([[§9.9]]), naming the set as All Random's does ([[R1371]]). On, the human's random deck leans on the newest set that ships: at least half of it from the set, the rest dealt as without it ([[R1370]]). The practice worker deals it, as it deals every practice deck, and resolves the set when it deals ([[R187]]): the page sends only the switch, on the setup's deck choice. Only the human's random deck leans. The AI's own deck is dealt by its tier as ever, since the AI's deck never followed the human's pick, and a preset, a saved deck and a tutorial lesson's fixed decks ignore the switch.

The switch is part of the game's setup: a game saved to resume ([[R668]]) or kept to replay ([[R768]]) deals the same deck again when it folds, and "Play again" keeps it. The setup remembers the switch on the device, beside the difficulty and the deck, whichever deck was picked. A game a link starts (`?deck=random`) does not lean, so a linked seed always deals the deck it names.
