S+ #35 Scatter reads "Deal 0~2 damage to all enemies, if the unit is flying deal 8 damage instead"
(Radiant 1~3 and 10). The spec has no such sweep, so it is read as follows.

"All enemies" means every enemy Unit, then the enemy hero, as S #13 and S #40 read it ([[R59]]: one
state check after the sweep). Each target makes its own uniform roll just before its hit, as Flak's
targets do ([[R2521001]]): 0, 1 or 2 with equal odds, Radiant 1, 2 or 3. Lucky and Luck apply to
each roll ([[R987]]). A Unit that has Flying when its hit comes, read through [[§10.4]]'s layers,
takes the stated 8 (Radiant 10) in place of the roll and draws nothing. A hero is never Flying, so
the hero rolls. A roll of 0 is no hit ([[R63]]). The engine's `damageAll` carries this as
`keywordInstead`, a keyword and an amount, so the card's script states it in data.

Rejected: one roll for the whole sweep, which would hit every enemy for the same amount, against
"each" of Flak's reading; and rolling for the Flying Unit too and then taking the larger, which the
text's "instead" does not say.
