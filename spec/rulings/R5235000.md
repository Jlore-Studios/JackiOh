Felinors vs Humans is a set of the catalog, `SetName::FelinorsVsHumans`, written `"Felinors vs Humans"` ([[§5]]). Its row is appended to the set table after the Infinite Assault's ([[R3114000]]), so no set before it moves: its id segment is `felinorsvshumans` (`felinorsvshumans-016`, a token `felinorsvshumans-016-1`, a Jilliax Deluxe module `felinorsvshumans-112-1`), its scripts folder `crates/cards/src/scripts/felinors_vs_humans/`, its abbreviation `FvH` in a ruling's `cards` (`FvH #16`), and its shadow-ban share 1/5 of its non-token cards, as Stinkyscape+'s ([[R3114001]], [[R3535000]]). It follows Stinkyscape+ in the catalog order, the ninth set that order holds, so its deck- and trio-code offset is 8000 once it ships ([[R1410]]).

Its row's stage was `Held` ([[R1420]]) until wave 1's release (issue #5222) turned it `Shipped` ([[R5222000]]). While held, the catalog holds and orders its entries, and their scripts are built, registered and tested like any other, but its cards are in no pool that names no set ([[R380]]), in no deck, no random deck, no seed and no list a player meets, and its census entry counts toward no total and no tag. Only a pool that names the set, or a thread that previews it (the testkit's `preview_sets(&[SetName::FelinorsVsHumans])`, or `cargo jackioh fuzz`, which previews every set), reaches its cards. Unlike the Infinite Assault's single-player stage ([[R4577000]]), the set is one for every format: the release that ships it turned its row to `Shipped`, and nothing else of the table.

Its census entry and its fixture rows are written from the set's entries as they land, the census before the single-player sets' since it is a set the catalog orders. Its cards wear a set mark and a watermark of their own from the day they land ([[R2718000]]).
