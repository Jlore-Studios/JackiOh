The network (`learned.rs`, `Network::correction`) reads the dense features standardized by the fit's mean and spread and adds each sparse key's row times its count to a first layer `width` wide; a key the weights do not name is no input (`docs/learned-eval.md` D5). Each layer is a clipped ReLU, zero below zero and one above one, written as comparisons rather than `f64::max` so a signed zero never differs, and every sum runs in one fixed order, with no libm function: the determinism the hand eval's own `f64` already rests on (D7).

Its output is a logit, `a·hand/U + b + net(x)` (D4's skip connection), mapped back onto the hand eval's points as `hand + (b + net(x))·U/a`, so `unspent_mana`, the lethal constants and a ladder bot's `temperature` ([[R1452]]) keep their meaning. A committed tiny network gives, on committed positions, the outputs `training/ml/jackioh_ml/export.py`'s reference computes in IEEE doubles, to the last bits.
