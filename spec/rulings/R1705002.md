The three practice decks, Human Vanguard, Blitz and Fortress ([[§9.9]]), hold `DECK_SIZE` cards
([[R1705000]]), each still hand-built from Core cards outside the AI's shadow ban. Reaching 25 they
take eleven Core cards no preset held, core-002, -003, -010, -031, -034, -043, -047, -072, -080,
-089 and -091, and Human Vanguard takes core-073, which another preset already held. The starter
cards are their union ([[R1310000]]), so `STARTER_CARDS` grows from 39 to 50, and a new account
owns them on becoming active, as before ([[R111]]).

An account already active owned the 39, so queueing a preset that holds one of the eleven would
fail L5 for it ([[§9.4]], [[R253]]). Migration 0055 adds the eleven to `app.settings.starter_cards`, so
the grant reads them before `seed-catalog` next writes the list, and adds
`app.grant_starter_cards_to_active()`, which runs the activation grant (`app.grant_launch_collection`)
for every active person's profile and is run once there. That grant skips a card the profile was
already granted at activation, so each account gains one copy of each of the eleven and nothing
else, and a second run grants nothing. A ladder bot owns no collection and is passed over
([[R1454]]). The in-memory store reads `STARTER_CARDS` itself, and the store contract holds the two
stores to one answer.

Hearthstone semantics: the free cards an account starts with are the same for every account, an
old one's included, so a deck a new player can queue an old player can too.

Rejected: granting the new starter cards to new accounts alone, which would leave every account
active before the change unable to queue a preset that holds one of them.
