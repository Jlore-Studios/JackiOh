Core #82 KY's Trial works across every set that ships ([[R380]]): its Cry first Discovers one of 3 different sets among Core, Classic, Classic+ and Meditative, drawn from the match rng (a `mode` prompt whose options are the set names, which a client draws with each set's mark), then Discovers among 3 distinct random numbers of the chosen set's non-token cards ([[R247]]: the options are the numbers), and adds the Radiant card of that set with that number ([[R74]]). Its own card, Core #82, is never offered, whichever set is chosen ([[R54]]'s reroll of its own index), and no token's index is. The chosen set rides on the second prompt's resume data ([[R113]]), so a game paused between the two answers survives JSON. It amends [[R54]] and [[R247]], which read the numbers 1–100 of Core alone.
