"A version from their Past" is the card's entry in an older shipped catalog. Each card's carried
definitions from `BROWSER_CARRIED_FROM` on group into play-alike runs — consecutive versions equal
in type, rarity, tags, cost, params and both faces — and each run is one past version with id
`<card>@<last version>`. A past version runs the script its game version kept (R767000's covering
rule), else its card's own script. Minting one notes its definition into the state's
`transient_defs`, so the view ships it (R243), and the AI's `observe` keeps it only while it is
visible. A pool reads them through `past`: `also` draws the catalog's cards and their past
versions, `only` the past versions alone. A `defId` entry that is a card id names that card and its
past ids; one that is a past id names only itself — so R387 also keeps a card's past versions out
of its own pool — and a query with neither new field returns exactly what it returns today.
Rejected: one past version per shipped version, which would offer the same play many times over;
runs keep the latest of each play.
