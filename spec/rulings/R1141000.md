A row of the recent games (`/replays`) that can be watched ([[R768000]]) can also be downloaded as one JSON file, for a bug report. The file holds every step of the replay in order, each exactly as the replay player is given it ([[R768]]): its index, its turn and the seat's `view_for`. Beside the steps it holds only the row's own facts (a practice game's number on the device, or an online match's id, mode and seat; the result, the turns, the step count, when it ended and the portraits), the catalog version of the build that made it, a format tag and version, and when it was made.

No seed, log, state or deck leaves (CLAUDE.md rule 7), and no account: the opponent's name and profile id are left out, as a shared GIF names no account ([[R513000]]), since a bug report may be posted where anyone reads it.

Nothing is uploaded or kept: the file is made in the page from the pages the replay player would be given and handed to the browser's downloads. A row this build cannot show ([[R767000]]) offers no download, and a page that cannot be had saves nothing and says why on the row.

The recent games page opens such a file again (issue #1160), with an "Open replay JSON" control. It parses only the shape above: a `jackioh-replay` file of version 1 whose catalog version is the build's own, whose steps are numbered from 0 with no gap, never go back a turn and each hold a view object. A file of another format or version, another catalog version (an older build's, or a newer one's, whose views may differ), another shape, more than `REPLAY_JSON_MAX_BYTES` or more than `REPLAY_JSON_MAX_STEPS` steps is refused where it stands, with a sentence saying why, and no replay is mounted. A file that passes is mounted in the replay player through an in-memory source over its steps, the player's own controls and Back unchanged. Only each step's index, turn and view are taken from it, and it is read, mounted and let go in the page: it is never uploaded or kept, and the open makes no request. A step's view is checked only for being an object, as the client never enforces rules (CLAUDE.md rule 7); the catalog gate is what keeps a file's views the shape this build draws.
