Felinors vs Humans ([[R5235000]]) was held while wave 1 of tracker #5220 built it ([[R1420]]). Issue #5222, wave 1's release, ships it: the set's row of the set table says `Shipped` and nothing else of the table moves ([[R3114000]]), so it is the newest set in `SHIPPED_SETS` ([[R1371]]) and the ninth the catalog orders. Every pool that names no set draws from it ([[R380]]), a deck holds its cards, deck and trio codes number it 8000 + n and its offset is exported with the others' ([[R1410]]), the server's seed writes its entries (0102's check admits its three tags, [[R5235002]]), the census and the tag counts take its 232 entries (197 cards and 35 tokens), and one fragment claims all 232 and the shipped cards that play differently.

It ships gated for the AI's own decks ([[R1390]]), as the Stinkyscape+ set did from its release ([[R3535000]]): `AI_DECK_GATED_SETS` holds it alone, so a player's deck and a player's random deck hold its cards and the AI answers every one of them, while the AI's randomized decks deal none of it and a lean on it leans on Stinkyscape+, the newest set the gate leaves. Wave 2's sweep (issue #5223) measures the AI on it and empties the gate.
