Presentation only (CLAUDE.md rule 7): no record, total, store row, endpoint or response changes. Every figure is read off `GET /api/stats/cards`' `created`, as [[R2089000]] and [[R2370000]] read it.

**Why.** A Show tokens checkbox among the filters added a Tokens table above the Created cards ([[R2370000]]). The Created table still held every token, so each token stood in two tables with different columns, the toggle sat far from both, and "Tokens" and "Created cards" overlapped. The owner asked in #3324 for the tokens to stop being confusing.

**The sections.** Below the deck table, the Cards tab shows two sections, and no card stands in both:

- **Tokens:** the Created cards whose card is a catalog token (`CardDef.token`, [[§7]]).
- **Other created cards:** every other Created card (generated and Discovered cards, copies, transforms' results, The Coin).

Each section shows when it has a row and answers the same search box. Its title is above a line saying what it holds and what its figures mean.

**One table.** Both sections draw one table with the same columns:

- the card (headed "Token" in the Tokens);
- Games;
- Win rate: [[R2370000]]'s rate, the seats that made one, used or not, pooled as the Sets tab pools its cards' ([[R1966000]]);
- Used, Not used, Used Radiant, Used normal and Used vs not used, as [[R2089000]] has them.

A rate under `CARD_STATS_MIN_SAMPLE` games shows "—" ([[R654]]). Every header sorts its own table as [[R3184002]] has it. A table opens sorted by Win rate, best first, with a row under the floor last and ties in the server's order, as the deck table opens on its own headline rate.

**Gone.** The Show tokens toggle and its `tokens=1` address. An address that still carries it opens the page as any other, and the page drops it from the address. No source is named ([[R661]]).

**The drill-down.** A card's breakdown titles the tokens its text names "Tokens this card makes", so it does not read as the Tokens section.

Amends [[R2370000]] (the toggle, and a token standing in both tables), [[R2089000]] (the Created table holds no token) and [[R3184002]] (a table opens on Win rate, not in the server's order).

Rejected:

- Keeping the toggle with the tokens taken out of the Created table, which hides the tokens by default.
- One Created table with a kind column or filter, which keeps the overlap the issue complained of.
- Leaving out Win rate for the other Created cards, which would make the two tables differ again.
- Opening in the server's order, which no other table of the page does.
