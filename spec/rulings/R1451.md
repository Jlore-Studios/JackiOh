A game against a ladder bot ([[R1452]]) is a live game, and its human side counts like any live game's: in the card win rates ([[R376]]–[[R378]]), in the live games the publication gate counts ([[R654]], which [[R661]] only hides), and in the rated-game record ([[R611]]). Its play telemetry keeps the person's moves as any game's does, and none of the bot's ([[R1442]]).

The bot side is filed too. The game record gives its seat the `ai` pilot and, like every record, names no account ([[R376]]). Its seat is the one it plays as the game ends, as the result credits it, so after a Glitch's swap the `ai` goes on the seat the bot ended in ([[R677]]); the rated game records it as `ai` with its bot id ([[R611]]). It is read only when a query asks for it. `jackioh-server stats-cards` with no `--pilot` counts the human seats when it reads live data alone, and every seat when it reads development data (`--source=dev` or `all`); `--pilot=ai` reads the bot sides, and `--pilot=unified` every seat ([[R377]]). `cargo jackioh stats report` takes the same defaults over record files. Public card statistics count the human seats of live games and every seat of development records ([[R378]]), so a bot's play moves no public figure; `cargo jackioh winrates` counts record files the same way, so CN Tech's table (§8.8) moves no more than `/stats` does. The publication gate counts every live game on the patch, a game against a bot included, since its human side is a game a person played.
