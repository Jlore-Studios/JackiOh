A version 2 deck code ([[R255]]) or trio code ([[R339]]) carries each card as its catalog number, its [[§5]] index plus its set's offset. The patch that ships the Meditative set ([[R1420]]) gives it the next thousand in catalog order: Core n, Classic 1000 + n, Classic+ 2000 + n, Meditative 3000 + n (`CATALOG_NUMBER_SET_OFFSETS`, a server constant the client reads). The set holds 102 cards, so no number of it reaches another set's thousand. Its 30 tokens carry `N.k` indices, so no code names one, as no code names any token.

The versions stay where they are (`DECK_CODE_VERSION` and `TRIO_CODE_VERSION` 2), and no other set's offset moves: a code minted before the release is byte for byte the code the same deck writes after it, and reads back to the same cards. Hearthstone likewise keeps its deck string's version when a set is added, since a card's identifier is stable. A client from before the release reads a Meditative number as a number its catalog does not have, and drops it with the sentence [[R255]] gives every unknown number; so does any client against a catalog that does not hold the set, as the server's does not before the release, so a code can carry no card of a set that has not shipped into a deck ([[R1420]]). A set that ships after Meditative takes 4000 + n the same way.
