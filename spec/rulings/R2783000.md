A card's own animation needs a moment to anchor on, and nothing in the event stream said when a Death or a turn hook began (issue #2782). Hearthstone shows a triggered effect's card light up as it resolves; the spec says nothing of such a cue. The engine now emits `hookResolving` (`sourceId`, `defId`, `controller`, `hook`) as one of a card's hooks begins to resolve, a presentation marker that changes no rule.

**What is marked.** Each first run of a Cry (a Spell's effect is one, and each Echo repeat and each extra Cry a multiplier gives is its own run), a Death (each extra run a multiplier gives too), a start-of-turn hook (its controller's own turn's or the opponent's, both `startOfTurn`), an end-of-turn hook, a Whenever trigger once its printed condition holds ([[R99]]), and an Activate ability. The marker comes after whatever announced the hook (`cardPlayed`, `destroyed`, `activated`) and before any of the hook's effects, outside the run's own window of events ([[R136]]). A continuation after a prompt is the same run ([[R113]]) and emits none, so a hook that asks is marked once. `controller` is the seat that runs the hook ([[R467]]'s triggering controller included), and `defId` the card's own definition where it stands now (a Death's snapshot as it died, for a card no longer anywhere). A hook that runs with no card as its `self`, as a Cry out of a graveyard does ([[R127]], [[R467]]), still names the card it belongs to as its `sourceId`, so the view judges it by that card ([[R3182000]]); only a hook no card holds names its definition alone, `sourceId` `""` as `rolled` does for a card that is gone ([[R2652000]]).

**A hook that fizzles is marked.** A hook whose effects then do nothing — an empty list, a target that is gone, a prompt with nothing to offer ([[R61]], [[R90]]) — is still marked: the marker says the hook began, not that it did anything. A card whose own text is dormant, set face-down by its Cloaked and not yet revealing ([[R783004]], [[R1040]]), marks nothing: the play pipeline runs no Cry of a card it sets ([[R3806000]]), so a cue keyed on the marker never plays the card's Cry as it is set. Its Cry is marked as it runs at the reveal ([[R783006]]), and a Spell set under Paranoia's as it resolves at its set, hidden from the other seat like any face-down card's ([[R3806000]]).

**What is not marked.** A trigger the engine skips before running it: its card gone, its zone no longer registering it ([[R153]]), its controller changed, its announce dead, its condition declining ([[R99]]), or [[R453]]'s cast that found no zone. A Trap, whose `trapFired` already marks it ([[R2734000]]). Every other hook (`onPlayHook`, `whenAttacks`, `afterAttack`, `afterAttacked`, the ally hooks, `startOfGame`, `entersHand`, a delayed effect), for now.

**Nothing answers it.** Like [[R1361]]'s `damageAbsorbed` it is withheld from the trigger loop: no trap, trigger or quest sees it, it takes no number in [[R68]]'s order, and no state hash moves. A recorded game replays to the same hash, and a state round-tripped through JSON replays the same markers.

**Who sees it.** A seat that could not read the card where it stood as the hook began never sees the marker: the other player for a face-down backrow card, a Cloaked one included ([[R33]]), and for a hand card; both players for a library card. The marker records them (`hiddenFrom`, [[R177]]), which the view uses and never forwards. The exception is [[R2652000]]'s: that trap's own `trapFired` follows in the same action, and then the marker reaches both seats. A marker a seat does read names its card as the card itself is named now ([[R97]]), so a public card's hook that later went to a hand shows that hand's opponent the sentinel. **Rejected:** redacting the card as [[R154]] and [[R763]] redact a firing Trap, which the issue suggested: even a card back would tell the other seat that a hidden card holds a hook that just answered.

**The view's window.** A marker takes no room in [[R168]]'s floor: the window holds the events it would had no hook been marked, with the markers among them and those just before its first event. The golden traces' texts leave markers out (and [[R2783001]]'s `via`), as [[R1956001]] and [[R2646000]] leave out what dresses a view, so a trace recorded on either side of this change replays on the other. On the client the marker has a 0 ms `ANIMATIONS` row on its controller's hero and a silent `SOUND_CUES` row ([[§10.10]]), for issue #2782's cues to key on.
