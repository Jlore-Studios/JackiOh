C #46 Divine Favor's multiplier and C #54 Rewind's repeats are written on the Radiant face alone ([[R482]]): the base face says "as many" and "a Cry", which are 1, with no number. #88's checklist found that a Degrade or an Upgrade could still move that number on the base face, so a tuned base face did something its text does not say. Their params declare `tunedOn: "radiant"`: on the base face the number always reads its printed value, whatever the card's tuning, so a Degrade or an Upgrade never draws it there (B3.4 rule 3's Number row finds no step, and with nothing else to change nothing is drawn, [[R129]]), KY's Constant does not list it (C+ #41), and a step recorded by any other way changes nothing. On the Radiant face it is tuned as any number is. The base face shows no changed number, so a client marks none ([[R513]]). `catalog check` refuses `tunedOn` on a number the base face's text writes. Every other Radiant-only number is unchanged: C+ #32.3 Blade Storm's round cap is tuned on both faces ([[R652]])
