[[§8]] #82 Discovers "among 3 distinct random numbers 1–100", and the prompt offers exactly that: each option is a Core card's [[§5]] index, keyed and labelled by the number, and the answer adds the Radiant Core card with that index ([[R54]], [[R74]]). Neither the option nor anything the view attaches to it names the card behind a number ([[§10.8]]), so the chooser is shown three numbers and not three cards, and a client draws them as numbers. Nothing is hidden by it: the catalog, which prints every card's index, is public ([[§5.1]], [[§9.4]]), so a player may know which card a number is — knowing the Core set by number is the trial — and the options are simply what the card says they are. Every other Discover still offers the cards themselves, by name
