"Lower this card's Brittle by N" (`lower_brittle`) takes N off the count in force, never below 0; a card with no count in force has none to lower and nothing happens (a `gain_brittle` of −N would start a count from the printed Brittle, [[R441]], which a lowering does not ask for). A card on the field that it leaves at 0 crumbles at once, as B3.3 rule 3's tick crumbles one: the public `crumbled`, then an ordinary destroy that the next state check collects, so Indestructible ignores it ([[R46]]) and the count stays at 0. Waiting for the card's next start of turn was rejected: Hearthstone ends a card whose counter runs out when it runs out, and the spec's other crumble is the tick's own. "If Brittle destroyed this" is `brittle_spent`, the count in force at 0, read off the Death's snapshot, which is taken before [[R78]]'s reset drops the spent count: true after a crumble, the tick's or a lowering's, and false after any other destroy of a card with a count left.
