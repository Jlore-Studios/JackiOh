The set needs words the catalog did not have, and the foundation declared them so every part could build on one wire.

- **Keyword kinds.** `Evolve`, `Burn { n }`, `Toxic { n }`, `GIGA`, `Flexible`, `Frenzy`, `Evasive` and `Tipsy { n }` read and write their printed names as `kind` on the wire and the client's `KeywordKind`. Evolve, Burn and Toxic print on no card: Evolve is the engine's evolve verb's, Burn and Toxic the names of two counters the Burn and Toxic rules put on a card ([[R3540000]]). The rest are printed keywords whose rules the parts wrote ([[R3543000]], [[R3543002]], [[R3546000]], [[R3548000]]).
- **Tags.** Nine family tags: Mindustrial, Mineral, Paperclip and the six Automa tags (α, β, γ, δ, Ω, ζ). The tag census counts them once the set ships ([[R1420]]), the cards crate's `ALLOWED_TAGS` admits them, and the server's `cards.tags` check admits them in migration 0087, so seeding the set does not fail on its first entry.
- **Existing tags.** The set also carries tags the earlier sets own (Human, Fruit, Terminus, Weapon, Swarm, Starship, Resource, Jlockeed, Acclaimed and others); `catalog check` counts them with each set's ([[R278]]).
