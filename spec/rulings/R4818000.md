`/collection`'s quests panel, like [[R2035000]]'s bookmark, reads `GET /api/quests` again once per due time when the countdown reaches zero while it is open, through the `reread` that expires the kept answer first ([[R3206000]]). The new quest shows without a reopen, so [[R2210000]]'s Replace is offered on it at once. The reopen sentence is only for a caller that cannot read again. A failed reread offers Try again when nothing is kept, and keeps the quests and says nothing when an answer is kept ([[R2125000]]). It is presentation only: the server still tops the account up ([[R1304000]]), and the client enforces nothing (CLAUDE.md rule 7).

Hearthstone semantics: the quest log updates in place.

Rejected: polling or a background timer, and a read on every render.
