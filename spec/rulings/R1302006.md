title: "The reward hook's callers pay only while ECONOMY_LIVE is on (issue #1302)"

The economy was built behind the server's `ECONOMY_LIVE` switch ([[§14.12]]) without changing
what a player owned, so a caller of the reward hook ([[§14.8]]) pays nothing while the switch is
off: a finished ladder game writes its results row alone, no Jlore, no XP, no track row, no
level reward. Every ledger row is append-only and goes only with its account ([[§14.11]]), so
a payout made before launch could be undone only by an offsetting row, and the launch began
every account's economy at zero ([[R1310002]]). The hook itself does not read the switch; each
caller does, and the ladder's write reads `App::economy_live`, which boots as `ECONOMY_LIVE`.
The going-live sub-issue turned it on ([[R1310000]]), so every caller pays; with the switch
off, as this ruling's tests still set it, none does.

Hearthstone semantics: Hearthstone has no such switch; the spec's launch plan ([[§14.12]]) does,
and a decision it leaves open follows it.
