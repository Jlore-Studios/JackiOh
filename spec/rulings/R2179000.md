Since issue #2179 Indestructible also carries "Cannot be in Defense Position": a unit whose keyword set
holds Indestructible ([[§10.4]]: printed, granted or from an aura) is never switched to Defense, by an
action or an effect, and one standing in Defense switches to Attack at the state check, spending no
exertion, as Warp Disruptor's aura makes every Unit do ([[§4.5]] step 1, [[R1849006]]). The switch
action is never listed for it, so a turn whose only action left was that switch ends itself
([[R82]]). It never has Taunt either, which [[R347]] already made so. [[R46]]'s knock-down still
switches a unit to Attack when it would be destroyed; an Indestructible unit is in Attack already, so
the knock-down reports no switch ([[R91]]). It reads the keyword set, so a Vanilla that takes the
Indestructible away lets the unit switch again. Hearthstone has no positions; the issue wrote the rule
