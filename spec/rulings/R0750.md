The designer's answer on #355: C #20 The Power to Punish's Radiant face is marked as its base face is ([[R437]]). While its destroy of every enemy Unit waits for the start of its controller's next turn ([[R458]]), each Unit its scope names wears the red Destroy mark in both players' views. The scope is read again each time the resolution loop collects events — the read the destroy makes as it resolves, since [[R458]] takes the Units standing then — so a Unit that arrives meanwhile is marked as it lands, one that leaves loses its mark, each with a `marked` event, and every mark goes when the destroy resolves.
