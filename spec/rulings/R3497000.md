Hearthstone has no hidden-tab client, so the spec did not decide what a board does with the
animations it misses while its page is hidden, nor which cues a flushed burst keeps.

**The drain.** On an online board (a 1v1 game, a Duos seat's own duel, a watched game), while the
page is hidden each new view drains the animation queue, and a tab that turns visible with steps
still queued drains them then, so coming back shows the live board with its moves ready at once
([[§10.10]]). The queue is enqueued-then-drained, never skipped, so the effects layer still settles,
the sound director still owes then flushes on idle, and the game log still lists every event.
Practice, dungeon and opened-replay boards never drain: the practice AI already holds until the
board is idle, and a replay is paced by its viewer. A visible tab behaves exactly as before.

**The turn-start cue.** A flushed burst still sends the viewer's own turn-start cue, as it keeps the
game-over sting ([[§10.11]]): the last `turnStarted` of the viewer wins. An opponent's turn start
stays capped like every other sound. Whether a hidden tab can be heard at all is the browser's
autoplay policy; the guarantee is the cue is sent.

Rejected: always animating the backlog on throttled timers while the server's turn clock runs, and
dropping the turn-start cue in a long burst.
