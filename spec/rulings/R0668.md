After every answer the practice worker keeps a free game in progress on the device: its start config (its last board included, [[R508]]), its action log, the cursor of the AI's own stream (`${seed}:ai`), the catalog version and the state's hash, in the worker's own storage (IndexedDB), never sent to the page, whose log would name the AI's hidden cards (rule 7); the page keeps only the setup it chose (seed, seat, difficulty, deck). Opening `/practice` with no parameter that starts a game asks the worker to resume that setup's game: the log is replayed action by action under the same nonces and must reach the saved hash, and the AI picks its stream up at the saved cursor, so the resumed game plays on exactly as it would have. A save of another game, another catalog version, or one that folds differently is refused and the page shows the setup. New game and the menu give the game up (since [[R765]] they ask whether to Save and leave, which keeps it and shows the practice menu with a banner that resumes it, or to Leave without saving), a finished game clears it, and a URL that starts a game replaces it. A tutorial lesson is never kept (its coach reads the game from the deal, [[R292]]), and only a lesson in progress still asks before the page unloads. The player-statistics log ([[R639]]) of a resumed game counts from the resume on, and the AI's emote persona is dealt again, both cosmetic.
