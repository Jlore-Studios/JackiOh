Once the Training Grounds set ships, a pool that names no set holds each of the twenty Core cards that #41–#60 copy beside its snapshot ([[R2195000]]). The pool keeps both, as the owner called the snapshots "separate entities": a random add, summon, cast or transform can land on either, so those twenty are drawn twice as often as another card.

A single offer, a Discover from the catalog ([[§6.3]]), never shows both cards of a pair, since two options with the same name and text are one choice shown twice. The options are drawn as before, the pool shuffled once with the match rng ([[R60]]), and an option whose pair key (`catalog::pair_key`, the Core card's id) an earlier option already holds is passed over for the next; a pool with fewer distinct pairs than the count offers that many. Core #97 Zephrys' offer, the scorer's top three ([[R29]], `subsystems::top_three`), passes over a card whose pair a better-ranked card holds the same way, so it still offers three. A pool with no pair in it offers exactly what it did, so no game from before the release replays differently. The Discovers over real instances (a library, a graveyard, a last board) offer cards that are there, both of a pair included, as they show what is in the pile.
