A permanent's `Evolve:` text runs once, the first time it evolves: the `evolve` verb marks the instance evolved (`CardInstance.evolved`) before it runs anything, so a second evolve of the same permanent runs nothing, counts nothing and emits nothing ([[R1849001]]). The mark is a status of the card on the field, so [[R78]]'s reset takes it off with the card leaving the field: a card back from its hand, like any bounced card, may evolve again. A copy is a new card ([[R57]]) and may evolve, and so may a Transform's new card; S #91 and S #92 keep their printed text and evolve once too, a later attack copying them again but evolving nothing. A card with no Evolve text, or one that has left the field, still evolves into nothing. The verb's run stays the resumable one ([[R113]]), and a prompt in it still pauses the list that evolved it. Rejected: keeping the mark in every zone like `awakened`, since Hearthstone resets a returned minion's once-only abilities.
