The Felinors vs Humans set ([[R5235000]]) needs three tags no card carried before, declared with the set's plumbing so its parts share one wire, as [[R3535002]] and [[R4577001]] declared theirs:

- **Plagiarized**, on the set's 82 reprints of Infinite Assault cards, FvH #116 to #197 ([[R5235001]]).
- **Roblox-Tool**, written with its hyphen, on FvH #19 Trowel and #20 Bomb.
- **Golem**, on FvH #100.1 Felinor Golem and #100.2 Human Golem, the set's two Golem tokens. FvH #16.2 Travertine Golem prints no Golem tag, and no earlier card named Golem (Core #55 Lava Golem, the Golem tokens of other sets) gains it: retagging a shipped card is a catalog change, which no part of the set asks for.

They read and write their printed names, follow Commander in the `Tag` union and come before Token, which stays last. The cards crate's `ALLOWED_TAGS` and the Chinese terms (抄袭, Roblox工具, 魔像) admit them, and the tag census counts them (82, 2 and 2) only once the set ships ([[R1420]]). The server's `cards.tags` check admits them from migration 0102, which puts 0099's check back with the three added, so the check still names the whole `Tag` union the day the set seeds. The deck builder offers Plagiarized and Roblox-Tool chips, deckable cards carrying them, and the Almanac a Golem chip, a token's tag, each showing once a card of a set it shows carries it ([[R1381]]).

Plagiarized is a provenance tag, as Legacy is ([[R2511000]]): it marks frozen copies of another set's cards, not a family that plays together, so it is never a random deck's theme ([[R258]]), as Legacy and Quickdraw are not ([[R2511001]], [[R817000]]); `crates/ai/src/deck.rs` passes it over among the theme candidates. A pool that names the tag (the reprints FvH #126 Plagiarized: Generated Filler and #165 Plagiarized: Synthetic Data draw from it) reads it as any tag. Roblox-Tool and Golem are family tags no rule reads.
