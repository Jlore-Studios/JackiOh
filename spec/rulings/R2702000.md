A dungeon run keeps the cards it upgraded between fights, a card made Radiant at a campfire or a shop and a card Buffed there, while each fight is a fresh game. So a game's setup may deal some cards of a deck already upgraded. The spec made no such decision; this note makes it, as Hearthstone's Dungeon Run deals the cards its run upgraded in the deck.

- **A deck mark** is `{ index, radiant, upgrades }` in `createGame`'s per-seat `deckMarks`. It names the card at `index` of that seat's deck list as it was given, before [[§2.1]]'s shuffle.
- **Radiant:** the marked card is dealt on its Radiant face ([[§5.2]]), the flag [[R74]] sets on a library card, and its owner's list records that face, since the deck arrived with it ([[R311]]).
- **Upgrades:** once every deck is dealt, and still before the shuffle, the marked card takes `upgrades` Buffs ([[§6.3]], [[R386]], [[R1320]]): Player 1's marks first, then Player 2's, each seat's in the order given, and each Buff one change drawn from the game's rng as a Buff in play draws it. A Radiant mark is on before its card's first Buff, and a card no Buff can change (an Immutable one) is left alone with no draw. The draws come before the shuffle's, so a marked game shuffles otherwise than the same game unmarked.
- **Setup, not an action:** no event reports a mark, and nothing the opponent is shown names one. The opening record keeps the marks, so a Glitch reset deals the marked cards again ([[R676]]); its fresh deal draws their Buffs from the start of the rng again, so they take the changes they took in the first deal. A fold, a replay and a game's summary pass the same marks. A game made without marks, or with only empty lists, stores nothing, draws nothing and hashes as before.
- **Refusals:** an index past the seat's deck, two marks on one index and negative `upgrades` each refuse `createGame` with a reason, as a bad deck does. They are checked after the handicaps and the decks ([[R180]]), so a bad deck is named first.
