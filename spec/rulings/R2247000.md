An Anomaly Found! draws the Anomaly it lays as it arrives somewhere it can be looked at — a hand, a library or the field — by its start-of-game clause, as Heroic Power rolls its power ([[R43]], [[R151]]): one of its face's boards, each equally likely ([[R1879000]]: one of the seven on the base face, one of the three rich ones on the Radiant face), one draw of the match rng. It remembers the board's code (`WH`, `BF`, `AL`, `AT`, `SP`, `MT`, `DH`, `FO`, `AN`, `AA`) as its label (`effects::CARD_LABEL_KEY`), and a card that holds one draws no other as it moves. Its owner's view carries the label (`CardView.label`), which the client prints in place of the card's text; the other player reads a hand's count and so never the code, and the catalog's printed text is unchanged, naming no board ([[R279]]). Its Cry lays the board it holds, whatever its face is by then, so a card made Radiant after it drew lays the board it showed; one that holds none (a card laid with no arrival, a test's hand) draws as it resolves, as [[R1879000]] had every one do. A Scanning Probe's find (S #166, S #167, [[R1855003]]) and every other way into a hand is an arrival, so it reaches its owner with its code. The owner's first pass over the Stinkyscape set (issue #2247) asked for the code on the card, so its holder knows which board they play.
