Since balance patch 1, a revealed backrow Trap or Field Trap reads face-up to both players while it stays armed: it is no longer face-down, but it is not face-up either, so a Trap that has not fired still fires and a Field Trap keeps firing. No event is emitted; the next view shows the card. Revealed and [[R741]]'s "reveals" are two things: a revealed Trap still "reveals" when it fires (C #65's Radiant face reads "Revealed." and "On heads, this reveals:"), and C #88's "Start of turn: Reveal." is this reveal, while C #63 Crop Dusting's is its firing
