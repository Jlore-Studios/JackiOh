[[R109]]'s 300 requests a minute are per account, which an open endpoint and a request whose token did not verify do not have. Such a request is counted against its IP hash instead, in a namespace of its own, so an anonymous flood is bounded without ever sharing a bucket with a signed-in one. A single shared counter would let one caller spend everybody else's budget, which is the abuse [[R137]] refuses for the per-match half — and the account is keyed on the profile id rather than the auth user or the bearer token, either of which one account may hold several of
