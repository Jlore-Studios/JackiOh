Every catalog entry carries one `flavor` ([[§5]]), one of fifteen names: Physical, Brute, Beast, Fire, Dark, Holy, Nerd, Tech, Nature, Toxic, Snack, Hustle, Clout, Spirit and Chaos, chosen by `docs/polish/8-flavor.md`. Its Radiant face has the same one. `cargo jackioh catalog check` refuses a name not among them, and from part 5 of #1436 also an entry with none.

It is display only. It picks the card's projectile, cast, melee impact, summon entrance, death exit and trap reveal (#1436). No rule, pool, query, validator or AI reads it.

A transient or custom definition (fused, crafted, custom, the engine's stand-ins) carries none, so no game state that holds one serialises anything new and no replay or hash moves. The client draws Physical for such a definition, or for a fused one the first ingredient's flavor.

A patch reads the catalog without it, as it reads it without a held set's cards ([[R1420]]). So a flavor-only change claims no card, needs no fragment, is in no snapshot and ships no catalog version ([[R388]], [[R646]]). `changed_fields` leaves it out and `cargo jackioh classify` counts it with the wording, so a flavor-only change is no card change ([[R1365000]]).
