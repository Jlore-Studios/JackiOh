[[R1365000]] confirms a script-only claim by `FORCED_GAMES` games with the card forced into both decks, played by the random policy. A change to the card's Radiant face never diverged there: a plain game holds a Radiant copy only by an in-game upgrade — Core #2 Speciesist resolved in 36 of the 40 games, never on its Radiant face — so `classify --claims` read the change as playing as before and a fragment could not claim it. This amends that check.

- **Radiant second batch.** When the plain batch shows no divergence, the same seeds play again with the forced indices pinned Radiant: both seats' deck marks over the first indices, the forced cards' slots since `force_into` puts them first ([[R2702000]]). Divergences count as before, steered actors as [[R3935001]]: an actor the diff did not change replays identically on both builds, so it cannot explain one. Groups pin all forced indices. The second batch runs only after a quiet first one, so the common case costs what it does now.
- **Recording.** `golden record --radiant` pins the forced cards Radiant in every recorded game. A recorded game's `args` gains `deckMarks`, absent for a plain game; a replay passes the same marks ([[R2702000]]), so the file replays on any build like any other.

Rejected: pinning every forced batch Radiant from the start, which would move all 40 games' shuffles and cost the common case its byte-identical traces; and a hand-written claim `classify` cannot back, which would set a precedent for bypassing `--claims`.
