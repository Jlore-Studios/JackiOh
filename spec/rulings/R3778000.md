Refines [[R781004]]. The Aura "Has {keywords|random combat keyword|random combat keywords}." (Keymaster Keenus, Shockwave447, the Drone Interceptor and the Drone Corvette) drew its keywords once, as the card arrived, and kept them whatever its number did, so a Buffed Keenus read "Has 6" and had 5. Its keywords now always match the number its text shows.

- **One list.** Each stay on the field keeps one ordered list of drawn keywords (`memory`, as before), which nothing shortens while the card stays. The Aura gives the first as many of it as the card's declared number reads now ([[R386]]: a Buff or a Nerf of it, a number set outright, the Radiant face's number), so it is still read with no rng ([[§10.4]]).
- **The number goes up.** A Buff's Number row, a number set higher or the card made Radiant on the field (each a change to the card itself) draws only what the number asks beyond the list, appended to it, as that change resolves and never as the layers read. The draw is the arrival's ([[R781004]]): [[R21]]'s pool, never one the card holds from any source or has on its list, no Taunt beside Indestructible ([[R347]]), and every one left when fewer remain than it asks. A card whose arrival draw is still to come (made Radiant or Buffed by the effect that summons it) draws nothing then: its arrival draw reads the number as it stands when it resolves.
- **The number goes down, then back up.** A lower number takes the newest off first and leaves every other; the number back up returns the same ones, drawing nothing, and draws again only past the list's end. De-Radiant is a lower number, made Radiant again the same higher one.
- **Held from another source too.** A keyword on the list the card has since gained from another source still counts toward the number, and no replacement is drawn: sources stand apart, as in Hearthstone, so losing either source leaves the card the other's copy.
- **Leaving, and fusing.** Leaving the field clears the list ([[R78]]), so the card draws afresh, at its number, each time it arrives; a Buff stays on the card ([[R386]]). A Fuse that keeps another card (an Equip among them) has the kept card draw only what its number asks beyond any list it holds.
- **Replays.** A game played through v0.6.0b folds under the scripts kept for those versions, which drew once and kept their draw ([[R767000]]).

Rejected: a seed kept per arrival, whose sequence the Aura reads its first entries of, which keeps more for the same result; drawing again whenever a listed keyword is also held from another source, which Hearthstone's independent sources do not do; a trigger on each change, which queues an entry, and takes a number of [[R68]]'s order, on every Buff, set number and Make Radiant while the card is on the field, whatever card it names; and a pass of the state check over every card, which would run at every check for four cards.
