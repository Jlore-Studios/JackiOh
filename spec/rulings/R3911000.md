`moderate ban` sets an account's `profiles.status` to `banned` ([[§9.4]]). While it is, the account drops off the public Players list and its search (`GET /api/stats/players`, [[§9.12]]), as it drops off the ranked leaderboard ([[R3290000]]).

The database stores player statistics on their own table (`public.player_stats`), keyed by `profile_id`. A banned account's statistics row is kept unchanged, retaining the player's games, counts and favourite cards ([[R1142000]], [[R1771000]]). The public aggregates query `player_stats_list_public` joins `public.profiles` and excludes rows where `status = 'banned'`. The in-memory fake store similarly omits profiles whose status is `ProfileStatus::Banned`.

When the ban is lifted (`moderate unban`, setting `profiles.status` back to `active`), the account's row returns to the public Players list and search immediately on the next read, with no manual database edit or statistics recomputation required.
