title: Once per turn across a turn boundary
cards: "#98, R43, R103, R384"
proven_in:
  - crates/engine/tests/rules/rulings_c.rs
---
"Once per turn" is stored with the turn number the ability was last used on (Activate's `memory.activations`, [[R384]], which #98's powers use since [[R752]]), so it is spent only while the game is still on that turn. A player asking about the ability on a later turn is therefore told whose turn it is, not that the ability is spent: the turn is checked before the uses, and by their own turn the uses are back
