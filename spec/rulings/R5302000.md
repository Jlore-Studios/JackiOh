Outside a card script, `cargo jackioh classify` reads a Rust file with each `#[cfg(test)]` item left out and everything else kept ([[R2050000]] stopped at the first one, [[R1365000]] set the reading). An item is the attribute, any attributes after it, and the one item it marks: a line ending in `;` or `,`, a braced item on one line, or a braced or bracketed item up to the closing line at the attribute's indent (rustfmt puts it there). So a change after such an item is code: #5277's `#[cfg(test)] mod snapshot_fold;` at the top of `crates/cards/src/lib.rs` had cut `register_all`, `never_defense_kept` and `stats_as_it_died` from the reading, and a change to them classified as Internal. A change inside a `#[cfg(test)]` item, a mid-file helper or a trailing `mod tests`, is still no code. An item whose end is not found drops only its attribute, so a misreading counts test code as code, which costs only a stage 2 run that finds no card playing differently, never the other way. A card script keeps the reading [[R2050000]] describes, its lines stopping at its first `#[cfg(test)]`, because `catalog loc`, `CODE_LINES`, BUSTED and COMPLICATED rest on its counts. We rejected moving `mod snapshot_fold;` below the code, because nothing would catch the next file with a test item near its top; reading every line of a file, test modules included, because every test-only edit to the engine would then build the base; and changing `script_code`, because it also feeds the card metrics that cards read in play.
