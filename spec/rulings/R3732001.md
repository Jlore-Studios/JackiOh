`GET /api/friends` gives each friend three facts beside their status ([[§9.5]]), each left off while it does not hold, and each read for the caller's friends alone:

- `lastSeenAt` (ISO-8601): the time of an offline friend's last heartbeat ([[R3210000]]), when presence kept one; none while they are online or in a match, and for a friend who never beat.
- `turn`: the player-turn counter of the live 1v1 game a friend is in, while the caller may watch it, the number a watcher is shown ([[R2615000]]); none for a co-op game, between a series' games, or while the audience is full.
- `lobbyCode`: the code of an online friend's lobby ([[R3730000]]) that has not started and whose guest seat is empty, the newest of them. The code is what anyone holding it may already enter the seat with ([[R3730000]]), so a friend who is shown it learns nothing the friend could not hand them; the server still refuses an entry a block or a full seat refuses.

Rule 7 holds: a client draws the words and picks the button from these facts and from `status` and decides nothing, and every Join, Challenge and Watch is still the server's to refuse. The list stays a fixed number of set-based reads whatever the number of friends: the open lobbies of every online friend are one read.

Amends [[R3728001]], whose friends list is the panel as it was: the friends' rows now carry these three fields.
