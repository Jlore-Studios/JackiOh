A fight that a Glitch voids ([[R679]]) has no result ([[§2.5]]) and is none of [[§15.6]]'s "other ends": `run_fight_report` refuses it, so the run sends no `FightOver`, keeps its HP and stays on the fight. The fight's result panel says a Glitch voided it and offers Deal it again in place of Continue, which deals the same fight fresh from the same seed, the run's seed, row and column, as Try again deals a stopped fight ([[R2972000]]) and as a voided Conquest game is played again with its seed ([[R679]]). Nothing is kept to resume, so a fight left after its void is dealt fresh when the run starts it again ([[R3476000]]). The same seed means the player meets the same game up to the Glitch and may play it otherwise; a fresh seed was rejected, since a fight's seed is its node's and a second deal would need a count kept in the run and its log. The Infinite Assault's `assault_fight_report` still reads a void as a loss until issue #4576 rules on it.
