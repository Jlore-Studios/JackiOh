The newest set that ships is the last entry of `SHIPPED_SETS` in catalog order ([[R1420]]): Classic+ until the Meditative set ships, Meditative from then, and whatever set ships after it after that. The engine answers it (`newest_shipped_set`) and the client mirrors it (`newestShippedSet`) beside `setShips`. Nothing names it by hand: "More cards from the newest set" ([[R1372]], [[R1373]]) says which set it is from this function, so the option's words move on by themselves when the next set ships, and the dealer (the server for All Random, the practice worker for practice) resolves it when it deals, so a deck is never dealt from a set a client named.

A set previewed under the testkit is not shipped, so it is never the newest: a test or a tool that leans a deck on a set being built names that set ([[R1370]]).
