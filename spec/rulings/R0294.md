id: R294
title: Tutorial progress is kept on the device
cards: "§9.9, §9.10"
proven_in:
  - apps/web/src/tutorial/progress.test.ts
---
Which lessons a player has won is kept in the browser (`localStorage`, read and written inside try/catch); an active account keeps a copy on the server too ([[R320]]), merged with the device's ([[R321]]), and without one nothing is sent: the tutorial needs no account ([[§9.9]]) and none of it is a rule. Lesson 1 is always open, lesson n opens once lesson n − 1 has been won, and a won lesson stays won. A lesson counts as won the moment the view shows the human's victory. Storage that is blocked or fails to write keeps progress in memory for the session
