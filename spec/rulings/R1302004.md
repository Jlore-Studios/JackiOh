The game's XP counts `XP_PER_ACTION` for each action the player took ([[§14.8]]), and the
server reads them from its own log: a row counts for the seat it carries when it is a move of
the game, that is a mulligan, a play, an attack, a switch of position, an activation, an
answer to a prompt, a draw offered or answered, an emote a card hears (MD-D29), a concede or an
ended turn. The rows the server writes itself are not ([[R79]]: a clock that ran out, a
disconnect that expired, the hard ceiling), though each carries a seat; nor is the automatic
end of turn's setting ([[R345]]), which changes nothing on the board; nor a practice sandbox's
tool ([[R923000]]), which no game the server runs takes. A seat whose every row is the
server's took no action, and a loss of that kind earns no XP at all. The hook's
`is_player_action` names every kind of action, so a new kind is counted or not by a decision.

Hearthstone semantics: Hearthstone pays its track XP for time spent playing, and a turn the
clock ends for an idle player is not play. XP that counted the server's own rows would pay a
player who walked away, one timed-out turn at a time, and the setting is a preference sent
from either seat at any moment, so counting it would let a loop of toggles farm the game's XP
up to the cap the very way §14.8 means to stop. An emote counts because the card that hears it
makes it a move; R643's rate gate and `XP_GAME_CAP` bound it as they bound every move.
