With the switch on (`AI_EVAL_KIND = Learned`, [[R1010000]]), a seat whose handicap is the tutorial's (`AI_TUTORIAL`, [[R290]]) scores every position with the hand eval, as a Duos duel does ([[R1010002]], D9). The practice tiers' handicaps ([[§9.9]]) do not count. Easy sets none. Medium and Hard give the AI's seat more of the same resources: a larger deck, a crystal sooner, a higher cap, an opening card and, at Hard, a draw. So a practice game takes the network's correction at every tier.

The tutorial is the exception because its lessons are scripts. Each lesson's coach is written for the game its fixed seed and decks deal against this opponent ([[R293]]). A retrained network plays that game differently, and the script no longer fits it. With the switch on and a network retrained on all of run 5's games, following the coach no longer reached each lesson's steps: the basics lesson never came to its attack on the hero. Its game is also the furthest from the AI's own unhandicapped games the network was fitted on: a 12-card deck, at most 3 crystals and a hero at 20.

R290's "the AI's search, evaluation and budget stay every tier's" holds for the hand eval, which the tutorial keeps. With the switch on, the tiers take the network's correction and the tutorial does not.
