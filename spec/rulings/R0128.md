An effect that hits every unit and both heroes resolves the units in [[R68]] order, then one damage instance per scoped side's hero in that same order. The target list is fixed when the effect begins, so a unit summoned by an earlier hit in the same sweep is not struck and one destroyed by it is still struck ([[R59]]: the state check waits for the whole effect)
