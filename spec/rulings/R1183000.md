"The card with the lowest win rate" is [[R1100]]'s table read from its other end (`win_rate_trailer`): the same compiled table ([[R1101]]), the same eligibility — at least `CN_TECH_MIN_GAMES` (20) games, a card the catalog still holds as a deckable card of a set that ships, so never a token, Glitch or a vanished id — and the same tie-breaks, more games and then the catalog id ascending; only the rate is ranked the other way, compared exactly as `wins_a * games_b` against `wins_b * games_a`. It never names the card asking ([[R387]]) or the leader, so the two ends are two cards: with one eligible card, that card is the leader and the table names no lowest. With no eligible card, no lowest either.
