A Fuse unites its ingredients' tags ([[R102]]), but the fused card carries the `Token` tag only when it is a token itself, which it is only when every ingredient was one ([[R102]]'s `token`). A token fused with a real card makes a real card: it does not vanish off the field ([[R11]]), its rarity is the rarest ingredient's, and now it sheds the Token tag too, keeping every other tag the ingredients had. So on a fused card, as on every catalog card, `token`, rarity Token and the Token tag always agree, and its face tells the truth ([[R1177001]]).

Before patch v0.3.X the union was literal, and the tag outlived `token: false`: the card #85 made of a unit played onto a Sheep Token, a token Unit stacked onto C+ #33 Ivory Tower, M #59's Book fused with an AI generated card and a token in hand that C+ #31 Fusion Lab fused a card into were real cards that still wore the Token chip and counted as tokens wherever the tag is read (`CardDef::is_token`, "a token by the printed flag or by the tag"). What that changes: #85 Unlicensed Experimentation's [[R61]] check reads both, so a fused token and card the opponent plays as a permanent now sets it off as any real card's play does, where the tag kept it armed. Deck legality and the pools read `is_token` only over catalog cards, which no fusion is ([[§5.1]]), and #97 Zephyrs and C+ #27 read both only over the catalog, so nothing else moves. Tokens fused together (C+ #43 AI Slop's three AI generated cards) still make a token with the tag.
