The viewer's own open prompt clock ([[R79]]'s 30 seconds) counts down with the same beats as the last 30 seconds of the viewer's own running turn clock ([[R439]], [[R506]]): a heartbeat each second, then in the last 10 a tick sharper each second, through the effects bus; nothing while muted, at master or effects volume 0, before the first gesture, or while the tab is hidden. Only the prompt the viewer holds sounds: never the opponent's, never the mulligan clock, never a watch or a replay. Answering, expiry, or the prompt leaving resets the schedule, so no stray beat sounds. Presentation only: the server keeps every clock ([[§10.11]]).
