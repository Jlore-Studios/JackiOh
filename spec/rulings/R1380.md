The set chips of the Card Almanac ([[R630]]) and of the deck builder are `SHIPPED_SETS`, in catalog order ([[R380]]): a set the catalog holds that has not shipped has no chip, because none of its cards is in the shelf or the pool ([[R1420]]). Meditative's chip arrives with the patch that lists it in `SHIPPED_SETS`, with nothing else to change, and it keeps exactly the set's cards. Presentation only (CLAUDE.md rule 7).
