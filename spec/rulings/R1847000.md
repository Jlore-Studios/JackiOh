Stinkyscape #148 Alteran Reach's starscape map is the player's, not the card's, as a Hearthstone Excavate track is: every card that travels a map moves its controller's one map (`PlayerState.starscape`), and the map stays when the card leaves the field, so a bounced or a second Reach goes on from where the player stands. The map is charted once, at the player's first travel, from the match rng: `STARSCAPE_EDGE_TRAVELS` (20) nodes in one path, Meditative #8 Reach the Summit's shape, each node before the last drawn uniformly from `STARSCAPE_REWARDS` (Heal 3, Draw 1, Mana 1, Damage 2), the last the edge of the universe. The nodes are stored and never drawn again, so a replay or a simulation of a later travel sees the same map. The state holds no map until that first travel, so a game that never travels serializes, hashes and shows as before the map existed (D14). The map is public: both seats' views carry it (`SideView.starscape`), every node with its reward and amount and the node the player stands on (`at`, 0 the start), and neither carries the key before the first travel ([[§10.8]]). No card reaches it until the Stinkyscape set ships ([[R1420]]).
