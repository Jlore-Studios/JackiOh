[[R978000]] computes a patch the server does not ship on every request and keeps nothing of it, so a made-up `?patch=` could not push a real report out. But its window (`GET /api/stats/cards`' and `/games`') was read off every patch's totals, so each such request, which needs no account, loaded every record, game and card total of every patch and worked the whole report out again, on the pool the live matches write through; and every real key that missed, one per `?source=`, `?pilot=` and `?mode=`, did the same load again, as did each drill-down's history. This note keeps one load of every patch's totals and has a made-up patch read its own.

- **One snapshot.** The totals of every patch are loaded once when none was loaded in the last `CARD_STATS_CACHE_TTL_SECONDS`, and every miss reads them: once however many requests miss together, and a load that fails is kept for no one, so the next request makes it again. The windows `GET /api/stats/cards` and `GET /api/stats/games` read ([[R1367000]]) and the patch history of the card drill-down ([[R2491000]]) are cut from it, each by the counting its own load had.
- **A window expires with its snapshot.** A kept window or history carries the time its snapshot was first asked for, not its own, so it ends with the snapshot and no figure is older than one TTL, as [[§9.11]] says. The bound of `CARD_STATS_KEPT_REPORTS` ([[R978000]]) is unchanged.
- **An unshipped `?patch=` reads its own totals.** A patch that is neither in `patches.json` nor the current one has a window of that patch alone ([[R1367000]]), so its report and game figures are cut from that patch's totals, one small load; it is still never kept ([[R978000]]), so a record inserted since shows at once. Its list of patches comes from the kept window of the current patch, which is the page's own report and usually kept already. The first such request after the snapshot expired makes the one load of every patch's totals, which every request then shares.
- **The figures are the same.** For the same totals every response is byte for byte what it was ([[R654]], [[R1451]], [[R1044000]]). One difference can be seen: a report of another `?pilot=`, `?mode=` or `?source=` that misses within the TTL counts the records the snapshot held, where [[R978000]] read each key off the records as they stood when it missed; no figure is older than the TTL either way.

Amends [[R978000]], [[R1367000]] and [[R2491000]], whose notes say where.

Rejected: keeping a report for an unshipped patch, which [[R978000]] rejected for letting a script push the real ones out; raising `CARD_STATS_KEPT_REPORTS`, which holds more reports without saving a load; expiring a window by its own clock, which lets a figure built from a snapshot at the end of its TTL reach two TTLs old; and reading an unshipped patch's games from the snapshot, which would show them as old as the snapshot where its own report shows them as they stand.
