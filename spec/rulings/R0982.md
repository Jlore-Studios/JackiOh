MD-C7: every face-up play is judged and recorded, casts included ([[R70]]). A Trap, a Field Trap and any card set face-down is neither judged nor recorded, so the hidden rule never acts on or reveals a hidden card. The record holds the element of the player's last face-up card, is never cleared, and ignores [[R451]]'s AI-card skip.

The record was written only while the Meditative set was open. Rejected: always, which would have moved every golden trace before the release (D14); and "while any Feng Shui exists", which reads hidden zones ([[§3]], rule 7). The set shipped in v0.3.5 (issue #553), which re-recorded the traces, and the gate went: the record is written in every game since.

A countered play keeps what step 3 gave it, as Gifted Program's Radiant does ([[R448]]), but is not recorded and takes no damage: it never reaches steps 4 or 7. This corrects [[§8.8]]'s "neither judged" (D12), since step 3 precedes the announce.

Its two lines are `preview`s ([[R280]]) with the glyph as their display ([[R372]]), and "—" before any play.
