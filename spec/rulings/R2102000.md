New players often miss a lethal they have on board, so practice against the Easy AI teaches it: while
the human has a sure win this turn by what they can see, the board rings the enemy hero and End
turn's housing and says "You have lethal" among its notices. It says only that lethal exists, never
how. No Hearthstone rule is involved: the hint changes no game, only what the page shows.

**Where.** Only in a free practice game against the Easy AI, a sandbox game included ([[§9.9]]).
Never at Medium or Hard, never in a tutorial lesson, whose setup names Easy but plays the tutorial's
handicap ([[§9.10]]), and never in an online match, a hotseat game or a replay ([[R768]]): only the
practice route turns it on, and a replay's board shows none even when told.

**The check.** `jackioh_ai::lethal_hint(state, human, should_stop)` reads the true state only through
`redact(state, human)`, as the AI does ([[R185]]). It fills that redaction in as
`LETHAL_HINT_DETERMINIZATIONS` worlds drawn from a stream of its own (`LETHAL_HINT_SEED`) and asks the
AI's lethal solver ([[§9.9]], Search) for a line that wins on every one of them within
`LETHAL_HINT_NODES` nodes, the AI's own numbers. So it never reads the AI's hand, library or
face-down cards, and states that differ only in those give one answer. A face-down card the AI holds
is sampled from the traps of the cost it shows ([[R351]], [[R762]]): a sampled trap that stops the
line keeps the hint dark, and a trap the worlds did not draw can still foil a lit hint, which the
issue accepts. It is false outside the human's own main phase with no prompt open, once the game is
over, when the search panics or the call throws, and when the worker's wall-clock cap for it
(`PRACTICE_LETHAL_HINT_CLOCK_MS`, as the AI's decision has `PRACTICE_AI_CLOCK_MS`) stops it first: every
snapshot of the human's turn waits for it, and a board whose lines are slow to play out would
otherwise hold a click's answer back. A machine that slow misses a hint; it never shows a wrong
one. `decide` never calls it and it draws from no other stream, so the AI's decisions, its stream,
the save ([[R668]]), the fold and the replay are as they were.

**When.** The worker asks it for the human's seat with every snapshot of an Easy free game and adds
`lethal: true` while it says yes; nothing else about the line crosses to the page ([[§10.8]]). The
page shows it while the Lethal hint setting (Gameplay, on by default) is on, and only once the board
shows the newest view, as the board's moves wait for it, so the hint never lights over a board still
playing out the turn before. The setting is one of the gameplay switches, kept on the account with
them ([[R633]]).

**Rejected.** Reading the true state, which would build the hint on the AI's hidden cards. Ignoring
the AI's face-down cards, which would claim a sure win through any trap. A single world, which would
light on one lucky sample. A check on the page, which holds views and never a state, and would need
a second solver. Sending the setting to the worker, which would make the snapshot depend on a
preference; the worker answers alike and the page decides.
