The AI's random decks are a soft gate's: [[§9.9]]'s deck builder (`build_ai_deck`) never deals a card of a set in `AI_DECK_GATED_SETS` (`crates/ai/src/config.rs`) into a deck the AI plays, whatever sets ship and whatever a thread previews ([[R1420]]), so the gate holds before the Meditative set ships and after. The list holds the Meditative set until the AI is trained on its cards (issue #551's work, deferred): the AI plays by search and needs no card knowledge, but no sweep ([[R186]]) and no match has measured it on these cards yet.

The gate is the option `gatedSets`, whose default is that list, beside `banned`, whose default is the shadow ban: every AI deck leaves `gatedSets` at its default — practice's AI deck ([[R184]]), the quality gates' seats, the sweep's AI seat, the training arena's seats, and the development runs' All Random decks, which an AI pilots. A player's random deck passes `gatedSets: []` as it passes `banned: []` and is dealt from every set: All Random's deck ([[R258]]), practice's random deck for the human, and the sweep's greedy seat, which stands in for a human. A tutorial lesson's fixed decks are lists, not draws ([[R291]]). An `include` still forces a gated card in by name, as the sweep forces the card it measures, and the draw adds no other.

A lean on a gated set ([[R1370]]) leans instead on the newest set that ships and is not gated: Classic+ while Meditative is gated, before Meditative ships and after, when Meditative is the newest set that ships ([[R1371]]) and "More cards from the newest set" leans a player's deck on it. Lifting the gate is emptying the list: with no set gated the draw, its rng cursor and every lean are exactly what they were before this ruling, and before the set ships the gate removes nothing from any pool, so no deck any seed dealt moves.
