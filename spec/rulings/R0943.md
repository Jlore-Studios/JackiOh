ME-CREATED (MD-B6): every instance minted after the decks are built carries `created: true` — effect-made cards, tokens, The Coin — while dealt deck cards (and a Glitch reset's new deal) carry none. The mark was written only while the Meditative set was open ([[R1420]]), the same gate as [[R982]]'s last element, so a game of the shipped sets carried none and its state hashed as before (D14) until the set shipped. The set shipped in v0.3.5 (issue #553), the golden traces were re-recorded with it, and the gate went: the mark is written in every game since, The Coin included. A transform's new card is Created; a copy keeps the flag only as its instance does. It persists through [[R78]]'s and [[R766]]'s resets and every zone move, and survives a JSON round trip. It is public wherever the viewer may read the card (beside `chinese` in every view and prompt option), and nowhere else: placeholders drop it, and the owner's library list marks only cards the owner knows ([[R312]]). The client shows it as a small "Created" mark.
