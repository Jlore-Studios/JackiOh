A card's text names other cards and tokens — #90's CN-Virus, #41's Sheep Token and Lava Golem, #76's Reminisce — which a player could not read without leaving the card. The catalog lists them per card (`refs`, by id), and the list is proved against the texts both ways: every card or token whose name, or name before a parenthesis ("Call to Chaos", which #95 and C+ #73 share, so either edition's text names both), appears in a card's base or Radiant text, alone or plural, is in that card's `refs`, and every id in `refs` is named in one of its texts, a card naming itself included (#3, #65.1, #87, #95). Since patch v0.2.0 the proof keeps a named list of rules words — Exile, Burn, Echo, Recycle and the like — that it never reads as naming the card that bears the word (C #10 Exile, C #36 Burn, C #57 Echo, C #30 Recycle) unless that card's `refs` lists it, so a Core text's "Exile" or #79's "Echo 1" is no reference, and `refs` stay curated ([[R381]]). Every token is named by at least one card, or reached only through a pool a card's text names (C+ #12's Pancake tokens, the AI cards C+ #43 and C+ #78 hand out, C+ #65's and C+ #66's Grapes, C+ #42's KY's Gift, and C+ #23's every-token pool, [[R382]]); The Coin, which a rule deals ([[§2.1]], [[R244]]), is named by no card. A client marks each such name as a reference, and where the surface lets a reference be a control (the collection's detail view, the touch inspect sheet) a mouse or pen resting on it, a click, the keyboard focusing it, or a tap on a touch screen shows that card's face beside it — its Radiant face where the text calls it Radiant ("a Radiant CN-Virus"), its base face otherwise — the reference is focusable and describes itself to assistive technology, and Escape closes the face and not the view around it. Where it cannot be a control (a face inside a button, a hover preview that takes no pointer events) the name is only marked, and the hover preview shows the faces of the other cards the text names beside it. The faces it shows are printed catalog faces, public by [[§5.1]], so it reveals nothing; it is presentation, not a rule
