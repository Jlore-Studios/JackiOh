With the switch on ([[R1010000]]), a Duos duel's finalists keep the hand eval's score: the network was fitted on 1v1 games and has never seen a team's pool, which `effective_life` and the hero value read in a duel ([[R964000]], `docs/learned-eval.md` D9). A finished game keeps its won or lost score, which the network has no reason to move. Every 1v1 tier takes the network alike, since the tiers change resources and never the evaluation ([[R180]]).
