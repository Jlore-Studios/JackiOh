The reward is the caster's `next` start-of-turn delayed effect ([[R62]]'s delayed step, [[§6.3]] Keep a secret): it runs after the refresh and before the start-of-turn triggers and the draw, re-entering the card's `resume` step table carrying only the secret's id, never the choice. It waits through the opponent's turn whole — the secret stays filed, the choice still hidden. An extra turn counts as that next turn. It reveals the secret if it is still hidden ([[R864]]), then removes the record. As a card of a set that has not shipped, it reaches no shipped game ([[R1420]]).
