[[R1689000]] cancels the open live challenges between two players when either blocks the other or the friendship ends. A daily challenge is a friend's too, so the same ends cancel the open daily challenges between them, either way, in the same transaction as the block or the unfriending, and a challenge written while a block landed is refused as it is written. A daily game already running between them goes on to its end, as a live match does: it was started by two friends, either may concede it, and ending it for them would hand one a win or a loss neither played for. The suggestion is the issue owner's (#3727), checked against [[§9.8]].
