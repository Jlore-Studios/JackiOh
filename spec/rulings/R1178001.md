An embiggen card is a card that prints two prices, a `CardCost::Embiggen` ([[§5]]): its normal version costs the cheaper one and its Embiggened version the dearer ([[§6.3]] Embiggen, issue #1175's words). It is read off the definition's printed cost, never an instance's, so a cost override, a discount or a Tune never makes a card one or unmakes it (`is_embiggen_card`). The catalog query names the class `embiggen`: `true` keeps the embiggen cards, `false` leaves them out, and absent filters nothing; it narrows like every other field, so it names no set ([[R380]], [[R1420]]) and takes no token unless the pool asks for tokens ([[§5.1]], [[R382]]). Costs are still read out of play ([[R65]]), so beside `cost` or `costRange` an embiggen card is its normal price. Today the pool is the eight shipped embiggen cards, #46 Suppressive Aura, #56 Jilliax, #59 Unbiased Immigration, #84 Going Long, C+ #36 Conjure Bones, M #21 API Key Fishing, M #46 Conjure Intellect and M #81 Deadman's Hand; the Meditative+ set's own (#3 Wondrous Wand, #4 Supply Drop, #5 Spirit Lash, #19 Grubby Gloves and #23 Enormous Elderberry) join it when the set ships. M+ #23 Enormous Elderberry draws from it, and M+ #22 Mountaintop Garden's aura names the same class.
