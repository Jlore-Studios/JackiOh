`card-audio.json5` grows a `trigger` hook: a list of voice lines for a card whose effect summons, one picked by the client's own cosmetic rng, never the match's, as [[R645]]'s personas draw. It is spoken when the runner starts the `summoned` entry the card caused, which carries a new optional `sourceId`: the card whose effect summoned it. `sourceId` is the client's report, which no rule reads: the trigger loop holds the event without it (`GameEvent::as_rules_read`), so no state hash moves and a recorded game's replay keeps its final hash ([[R768]]), and a viewer who may not read the source card reads the sentinel there ([[R203]]). It replaces the summoned card's own line for that entry.
