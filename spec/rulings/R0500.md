Patch v0.2.0 asked for shorter Cry and Tribute reminder text. The keyword glossary the inspect views print beside a card copies SPEC [[§6]]'s Rule column verbatim ([[R373]] puts it into players' words), except two rows, which it writes as one short line each that is still true to the rule: Cry, "When you play this card or an effect casts it. Never when it enters play otherwise" ([[§6.2]]'s ruling, which it already stated in place of the Rule column), and Tribute, "Playing this also costs X of your Units, which go to the graveyard" ([[§6.3]]'s cost, without [[R41]]'s backrow clause, which [[R428]] removed). The glossary names the two rows as its short reminders, and a test pins their words, keeps each to one line of at most 16 words, and checks every other row against SPEC as before. Presentation only: no rule reads the glossary (CLAUDE.md rule 7)
