# R1108: a fusion may take one pick from each of several pools

- Date: 2026-10-09
- Status: accepted
- Decides: MD-D14 (docs/meditative-set.md M5)
- Spec: §6.3, §8.8 row 59
- Proven in: `r1108_one_pick_per_pool` (engine), `summons_a_4_cost_unit_and_fuses_a_book_and_an_ai_card_at_its_death` (M #59)

M #59's granted Death fuses "a random Book and AI card": `fuse_generated` with `pools` takes one
`pool_for` pick from each named pool, in order — the Book first, so the fused type falls back to
it (R102). If any pool is empty, nothing is fused (R142). Set, `count` and `query` are ignored.
