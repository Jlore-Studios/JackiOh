# Cards by keyword, tag and pool

Generated by `cargo jackioh spec index` from the catalog the build compiles (`crates/cards/catalog.json`) and the named pools of `crates/cards/src/query.rs` (`POOLS`), and rewritten on `main` every day by `spec fold` (`.github/workflows/spec-fold.yml`), so a card merged since is in the catalog and not here yet: edit the catalog, a script or a pool, never this file (#3804). The spec states the rule that decides each list and links its heading (`[[CARDS#jlockeed]]`); this file holds the cards the rule finds today.

A card is written as the spec writes it, its set's abbreviation and its index (`S #94`, a Core card's with no abbreviation, a shared token's index as it is, `T-rush`), then its name, in catalog order: set by set, each card in §5 index order with its tokens after it.
