## 7. Tokens

Fifty token definitions cover every token of the three sets that have shipped, and the Meditative set (issue #496) adds thirty more, which ship with the set ([[R1420]]). Eleven are Core's: the ten a Core card can generate, the Ghoul Token among them (a card of its own in patch v0.1.1, [[R353]]), and The Coin, which [[§2.1]]'s setup deals to the player going second ([[R244]]). Thirty-eight are Classic+'s (patch v0.2.0): the eight Pancake tokens (C+ #12.1–#12.8), the five Losers (C+ #19.1–#19.5), Otherworldly Removal's three (C+ #32.1–#32.3), Bone Storm (C+ #36.1), Solarius Prime (C+ #38.1), KY's Gift (C+ #42.1), Felinor Flagbearer Prime (C+ #46.1), the five Grapes (C+ #65.1–#65.5), Classic Golem (C+ #73.1), the J-lease J-Jungle EX-plorer Pack (C+ #75.1), Brother Ping (C+ #76.1), and the ten AI generated cards (T-AI-1 to T-AI-10). Classic's one is Glitch (T-glitch, issue #170), a hidden token that only [[R673]]'s roll ever makes ([[R674]]). Meditative's thirty ("M #N" is Meditative card N, [[§8.8]]) are Temporal Rift (M #19.1), Fortify Mind (M #22.1), Ancient Curse (M #28.1), Love Bomb (M #30.1), the Jade line's five (M #39.1–#39.5), Knowledge Breaker Prime (M #45.1), the YileGPT line's three (M #49.1–#49.3), Ready… I'm (M #70.1), The Cane (M #71.1), Windfurious Prime (M #91.1), the three Growing Felinor Srs (M #93.1–#93.3), CN Golem (M #95.1), Journey Complete (M #96.1) and the nine buildings of Jlockheed's Evil Blueprints (M #97.1–#97.9), each printing its rarity as a Classic+ token does. A token is only ever created by an effect or a rule that names it, or as a copy of one, with the pools [[R382]] names (a Fruit pool holds the Grapes, and with the Meditative set a Prime pool holds the four Prime tokens, [[R1421]]; C+ #23 Dropshipping's takes every token), and the records a card brings back (C+ #29's last boards, C+ #35's snapshots), which can hold one. Each Classic+ token row below is repeated with its Engine cell in [[§8.7]], and the AI generated cards are there too; each Meditative token row is repeated in [[§8.8]]. A unit token vanishes when it leaves the field; a spell token lives in hand and library like a real card and goes to the graveyard after it resolves.

Token rules:

- Stat overrides: Adaptive UI summons a Ghoul Token with X/X (or 3X/3X), its printed 0/0 being a placeholder as the Bread Token's is; Rush Token Farm radiant gives all your Rush Tokens +3/+3 as an aura. Implement as the token's definition plus a `statsOverride` on summon. A Radiant Ghoul Token doubles that X ([[R349]]); a Radiant Rush Token or Bread Token keeps it. Call to Chaos is NOT one of these any more: it summons the token's own Radiant face (6/6) rather than a bespoke 5/5, so the only card that invented a Rush Token size no longer does.
- Bread Token has no name in the source ("a X/X Token"). **Ruling:** name it Bread Token, no keywords, cost 0, and it counts as a Token for every filter.
- Spell tokens (Notebook, CN-Virus, Combo-Fodder, The Coin) live in hand and library like real cards and go to the graveyard after resolving; they are still excluded from random pools and from Discover unless named. **Ruling:** Reminisce can Discover a spell token from the graveyard because it discovers "a card in your GY", not from a pool.
- CN-Virus damage is a normal damage instance to your own hero (Armor and Anti-oneshot Armor apply). Its "shuffle copies" makes an opponent's deck grow without bound; the cast-on-draw chain cap ([[R58]]) keeps each draw finite and the turn cap keeps the game finite.
- "Fill your board" summons into every empty, unlocked unit zone left to right ([[R64]]).
- Zao Gao's Rush Tokens each roll 2 distinct keywords from the random-keyword pool (section 6.1), and its Radiant face's Radiant Rush Tokens each roll 3 ([[R354]]).
- The Ghoul Token is its own card, not #74's ([[R353]]): named, with a T- index, because the designer listed it as a new card rather than as Adaptive UI's token. It costs 0 like the other X/X token, and prints no Radiant form, so [[R349]]'s fallback is its Radiant face.
- The Coin's mana is [[§2.3]]'s temporary mana: it can exceed the cap and is gone at the next refresh. Playing it is a play like any other card's ([[R245]]).
