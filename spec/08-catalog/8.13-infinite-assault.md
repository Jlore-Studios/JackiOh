### 8.13 Infinite Assault

The Infinite Assault set (tracker #4576, the plan `docs/infinite-assault.md` IA11, "IA #N"): somewhere past the edge of the map, a generator was asked for one more card and never stopped, and the Infinite Assault is what it writes, an army made of cards, trained on every game ever lost, written mid-fight; its flavour reads like machine logs, patch notes and model-card disclaimers. Its ids are `infiniteassault-NNN`, a token a card defines `infiniteassault-NNN-k`, its scripts `crates/cards/src/scripts/infinite_assault/`, and ruling notes write a card `IA #N`. It is a single-player set, held while it was built card by card ([[R4577000]], amending [[R1846001]]) and live since the Infinite Assault's release (issue #4597): its row of the set table is `SinglePlayer`, so its cards join every `everySet` pool, while a pool that names no set keeps to the sets that ship and one that names the set (`set`, the text's "Infinite Assault card") or its cards (`defId`) reaches it. No deck a player builds and no random deck holds its cards; an Assault enemy's seat does, by naming the set ([[R4597001]]). The Card Almanac shows them, the set's chip after the sets that ship ([[R5131000]]). It counts toward no total. Every card of the set is an AI generated card and carries the `AI` tag ([[R1421]]), a token beside `Token`; the doctrines' cards add their doctrine's tag and the Commanders `Commander`, the nine tags issue #4577 declared for them ([[R4577001]]). "Created" in its text is the engine's Created mark ([[R943]]).

The plan's numbers: 240 numbered cards and 15 tokens on sub-numbers.
