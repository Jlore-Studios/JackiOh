### 9.8 Abuse surface

| Vector | Mitigation |
| --- | --- |
| Claiming unowned cards | The collection is server-owned; loadouts are validated against it (9.4) |
| Farming or forging the economy | Every roll and grant is the server's, seeded and logged; a game's XP is capped, and the Jlore an account's games pay stops at `JLORE_GAMES_DAILY_CAP` a UTC day; a game the server runs (ladder, unranked, Conquest or co-op) has its actions counted from the server's own log, and a practice game pays only once the server has replayed it, on a seed of which an account holds at most `PRACTICE_SEEDS_OPEN_MAX` open, a claim not yet settled still holding its place ([[R1483000]], [[R1502000]], [[R3500001]], 14.8, 14.11) |
| Deck swapped after matchmaking | Decks are frozen into the ticket (9.4) |
| Reading a Conquest opponent's pick or decks | A pick leaves the server only in its owner's projection, and the other side's deck names and lists never do ([[R331]], [[R336]]) |
| Illegal actions | `reduce` rejects them; client checks are UX only (9.3) |
| Reading deck order or the opponent's hand | Never sent; `viewFor` sends counts (10.8) |
| Stalling | Server clock, disconnect grace, hard match ceiling (9.5); in a daily game, the move's deadline, which loses the game for the player who held it, and the turn cap, so an absent player can neither hold a game forever nor drag it to a draw (9.13, [[R3727000]]) |
| A dead or unread match socket | Server ping and idle timeout start its grace; a bounded outbox closes a socket that stops reading ([[R1441]]) |
| Opening many replays to starve live matches | An opening not held in memory folds a whole game on a server that is a quarter of a processor, so those folds run `REPLAY_FOLDS_RUNNING_MAX` at a time for the whole server, 1v1 and co-op together; concurrent openings of one match share one fold; an opening that waits past `REPLAY_FOLD_WAIT_MS` for its turn is refused with 429 and `retryAfterMs`, as every refusal for going too fast is, and a replay held in memory waits for nothing, on top of the per-account allowance ([[R3500000]], [[R192]], [[R768]]) |
| Action flooding | Per-match rate limit in the actor, per-account rate limit at the API, which also counts every match, co-op and watch socket upgrade and refuses an account it knows is past it before the database is read ([[R2478000]]); refusals past [[R835000]]'s threshold in a match or [[R1717000]]'s at the API alert, `hello` repeats coalesce ([[R835001]]) and a socket's later hellos, a player's in a match or a co-op one and a watcher's, are answered once per `WATCH_HELLO_INTERVAL_MS`, a new socket's first at once ([[R2686000]], [[R2609000]]), malformed frames past [[R835002]]'s budget close the socket, a watcher's included ([[R2609000]]) |
| Invite code brute force | 80-bit hashed codes, per-account and per-IP limits (each a temporary block, [[R4131000]]), verified email (9.4) |
| Multi-accounting to farm rating | Invite codes; watch for clusters of accounts sharing an IP hash |
| Friend-request spam, or probing which names exist | Requests by exact username only, an hourly limit per account and per address ([[R4008001]]), and an unknown name answered as a block is (9.4) |
| Guessing a room, co-op room or lobby code | A limit on distinct codes tried, right or wrong, per account and per address, claimed before any answer, past which every code lookup is refused; a request carries one guess ([[R4008000]]) |
| Unwanted chat | Friends only, a per-sender limit, the profanity mask, report and block (9.5) |
| Ghosting through a watcher | A friend only, 1v1 or co-op, ranked or unranked, the friend's own seat only, `SPECTATE_DELAY_MS` behind, and the friend can unfriend or block, which ends a watch already running at once (9.5, [[R2615000]]); a watcher's emotes, one of five emoji at a time under a stricter limit about that delayed board, carry no more, an accepted cost ([[R2990000]]) |
| Challenge spam | A per-account hourly limit, and a challenge's row deleted once its `CHALLENGE_TTL_MS` has passed (9.5) |
| Replay-share spam | A per-account hourly limit, `REPLAY_SHARES_PER_HOUR`, counting every attempt, and a replay already shared with a friend tells them nothing again, so no loop re-lights their bell or floods their feed ([[R4391000]]) |
| Aiming the server's pushes at an address of the player's choosing | A push subscription is kept only for an https endpoint at a browser's push service (`PUSH_SERVICE_HOSTS`), never an address, a local host or another name, and a push follows no redirect (9.13) |
| Daily challenge and notification spam | A daily challenge goes to a friend only, one open at a time to each, and counts toward the live challenges' `CHALLENGES_PER_HOUR`; it lapses after `DAILY_CHALLENGE_TTL_DAYS`, and a block or an unfriending cancels it ([[R3727007]]); an account holds at most `DAILY_MAX_ACTIVE_GAMES` daily games, seeks and sent challenges together ([[R3727004]]); a "your move" email goes only for games waiting on its account, at most one per `DAILY_EMAIL_MIN_GAP_HOURS`, never to an account with email off, at most `DAILY_PLAYER_EMAILS_PER_DAY` a UTC day across every account, and carries a one-click unsubscribe (9.13) |
| Reading the other team in Duos | A seat's view adds only its teammate's own view, and a ping is shape-checked and relayed to the teammate alone (12.6, 12.10) |

Every rejected action is logged with its reason, and accounts with an unusual rejection rate raise an alert.
