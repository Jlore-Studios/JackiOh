**[[R2689000]] has the AI count a turn hook as many times as the engine fires it, and price Living Bomb's start of the opponent's turn (issue #2689, 2026-11-02)**: the AI priced each start-of-turn and end-of-turn hook by one firing whatever multiplied it, so a board with Meditative #9 Joint Filing on it was underrated, and it never fired a start-of-the-opponent's-turn hook, so Classic #62 Living Bomb's Radiant face read as a blank Field Spell. It now counts those two hooks 1 + the turn-hook multiplier's extra runs times, read for the card's controller on the state evaluated, so a line that removes Joint Filing loses the extra firings, and it probes the start of the opponent's turn by one firing, counted once, since no multiplier repeats it ([[R821]]). Multiplying the whole price, which would count Living Bomb's base face's start of the opponent's turn twice, was rejected. It takes R2689000, the first number of issue #2689's block, and edits [[§9.9]].
