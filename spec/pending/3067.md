**[[R3067000]] A patch the server does not ship reads only its own totals, and every kept window and history reads one snapshot of every patch (issue #3067, 2026-11-04)**: `GET /api/stats/cards` and `GET /api/stats/games` take any `?patch=`, and a name the server does not ship (neither in `patches.json` nor the current patch) was computed on every request and never kept ([[R978000]]), off a load of every game total of every patch, though its window is that patch alone ([[R1367000]]): a script looping over made-up names, signed in or not, could make hundreds of those loads a minute on the server that also runs every live match. Every real key missed the same way, one load each, and the kept cache's 256 slots hold fewer than its keys. The windows and the drill-down's history ([[R2491000]]) are now cut from one snapshot of every patch's totals, kept for `CARD_STATS_CACHE_TTL_SECONDS` and loaded once however many keys miss it, each ending with its snapshot; an unshipped patch reads its own totals alone, still never kept, and takes its list of patches from the kept window of the current patch. No figure changes, only the reads; a report of another pilot, mode or source that misses within the TTL counts the records the snapshot held. Keeping an unshipped patch, raising `CARD_STATS_KEPT_REPORTS` and giving each window its own clock were rejected. It takes R3067000, the first number of issue #3067's block, amends [[R978000]], [[R1367000]] and [[R2491000]] and edits [[§9.11]].
