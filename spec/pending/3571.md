# Pending rulings — issue #3571 (Stinkyscape+ S25: the seven AI cards)

**[[R3571000]] KY's Line Search Bot's line does not pierce (issue #3571, 2026-11-11)**: the Cry is E7's line, any enemy tile, every Unit on it hit for 2 (Radiant 4); Lancer, Vela and Corvus print Pierce and this card prints none, so Armor reduces its hits (`LineRules.pierce`). Rejected: every line piercing.

**[[R3571001]] the Marketplace's AI lot offers Stinkyscape+'s seven AI cards once the set ships (issue #3571, 2026-11-11)**: the lot is an `OpenIds` lot of the ten Stinkyscape cards then the seven, each offered only while its set is open; held, it is the ten in their old order, and its count stays 1. Rejected: a second lot, which changes the odds; and a set check on every `Ids` lot, since named lots reach held cards.

**[[R3571002]] Abacus Optimizer discounts the two ends of the hand, one card once (issue #3571, 2026-11-11)**: the first and last cards in hand as the Spell resolves take `costMod` −1 (Radiant −2), never below (0); a one-card hand's card takes it once, an empty hand nothing. Rejected: discounting a lone card twice; counting the Spell itself.
