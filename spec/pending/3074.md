**[[R3074000]] The dev dashboard: a separate app only a dev account reaches, behind three locks, strict on production, and an audit row for every dev and admin action (issue #3074, 2026-11-04)**: the owner asked for a dev dashboard, a separate admin panel on staging and production that only a dev account can open, "assuming all of this is safe". It is `apps/admin`, at `admin.jackioh.com` and `admin-staging.jackioh.com`, behind Cloudflare Access, the account's own sign-in and the server's `DEV_PROFILE_IDS` check on every route; the server's new `DEV_STRICT` (on for production, off for staging) makes every `/api/admin/*` route need the two-step code. Every dev tool and dashboard write leaves an append-only audit row, and each dev grant is capped by a named constant. The issue's open questions took its own proposals: "dev mode" is the Dev tools as they are, and `/account`'s Dev tools stay.

**[[R3074001]] A dev account may hand-set its own rating; a strict server keeps it off the public ladder until it is reset (issue #3074, 2026-11-04)**: a rating pairs, ranks and moves the percentiles and Jlorious, so on production a hand-set rating takes the account off the public leaderboard, the percentiles and Jlorious until a reset puts back the rating its games had earned; staging sets it freely. Every set and reset writes a rating ledger row marked `dev`. Restoring the season row with the rating was rejected, since a season may open between the two.

**[[R3074002]] The dev dashboard reads the whole ladder, each row marked person or bot (issue #3074, 2026-11-04)**: `GET /api/admin/leaderboard` answers a dev account every row of a ladder with its kind, its rating and a bot's strength and persona, the one exception to [[R1452]] and [[R612]]; every player route, a dev account's included, still carries no kind and no rating.

**[[R3074003]] A dev may post news with no reward from the dashboard (issue #3074, 2026-11-04)**: a reward mints currency for everyone, so a post from the dashboard has none: plain text checked as `news.json`'s entries are, listed beside them for the news days, its claim marking it read and paying nothing, and taken down at will. A post with a reward still goes through a pull request to `news.json`.
