**[[R3846000]] A wait's reads answered with a 5xx count as unreachable (issue #3846, 2026-11-13)**: amends [[R3792000]]. In production the edge Worker answers 5xx (500, 502, 503, 504) for a game server that is down, so those reads rejected as `ApiRequestError` and cleared the notice instead of raising it. A wait's account read now fails as unreachable when it rejects with `ApiUnreachableError` or with an `ApiRequestError` of status 500 or more (`FIRST_UNREACHABLE_STATUS`), and the two count together toward `LOBBY_UNREACHABLE_AFTER_READS`; a 4xx still proves the server was reached and clears the notice. Presentation only (CLAUDE.md rule 7). Rejected: listing four statuses only, counting 429, counting every rejection.
