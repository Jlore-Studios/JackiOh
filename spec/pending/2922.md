**[[R2922000]] A handicap's `heroArmor` (issue #2922, 2026-11-03)**: a dungeon run's Combat artifacts give the human's hero Armor for each fight, and a handicap had no field for it. A handicap takes one more optional field, `heroArmor`, the Armor that seat's hero starts the game with: the hero's own Armor, as C+ #46 leaves on a hero, which [[§4.4]] step 2 takes off every hit, which adds to every other source ([[R124]]) and which nothing spends, rather than Hearthstone's pool that a hit uses up. A negative value is refused; 0 means none, and it is serialized only when set and stored only above 0, as `heroHealth` is ([[R290]]), so no other game's hash, replay or golden trace moves. Only a run's fight sets it. It takes R2922000, the first number of #2922's block, and edits [[§4.4]].

**[[R2922001]] A dungeon run's curses and Combat artifacts change its fights (issue #2922, 2026-11-03)**: curses raised a run's score and changed no fight, so taking every curse was free score, and Combat artifacts did nothing in one. Each curse and Combat artifact may now carry a fight effect, which `run_fight_setup` folds into the fight's handicaps after Presence: each curse taken once into the enemy's (more hero health, more opening cards, or more crystals every turn, its bonus and cap together under [[R181]]), each Combat artifact held once per level into the human's (more opening cards, [[R182]], or starting Armor, [[R2922000]]). A negative amount counts as none, an enemy's own artifacts other than Presence change nothing, and a run with neither gets the setup it got before. The placeholders' numbers are strawmen ([[§15.13]]); Thick Skin's 3 Armor became 1 a level, since Armor cuts every hit. A Sandbox run saved on a device before this change resumes with its curses and Combat artifacts acting. It takes R2922001, #2922's second number, and edits [[§15.4]], [[§15.6]], [[§15.9]] and [[§15.12]].
