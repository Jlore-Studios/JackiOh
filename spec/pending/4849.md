**[[R1365000]] reads a pull request's change from its merge base (issue #4849, 2026-11-25)**: asked by #4849's audit of the project's own gates, which found `classify --base` on a branch behind `main` diffing `main`'s newer commits in reverse and attributing them to the branch. Stage 1 now diffs from `git merge-base` of base and head, and reads the base side and its fragments there, so the documented pre-push check names only the branch; a base that is already an ancestor is its own merge base, so CI's call reads exactly what it did. `--parent-bin` must be that merge base's build, which the `--claims` failure and the `--json` report's `merge_base` name; `classify --root` points it at a fixture repository for tests. Amends [[R1365000]] and [[R1370000]]; takes no new number.
