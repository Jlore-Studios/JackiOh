**[[R2050000]] reads a `use` line outside a card script as code (issue #2050, 2026-10-27)**: `cargo jackioh classify` dropped every Rust file's `use` declarations along with its comments and tests, as `catalog loc` does for a card script. A pull request that only moved an import in the engine, the cards crate's shared code or the AI was therefore Internal, and CI's `rust (classify)` never asked the base build ([[R1365000]], [[R1370000]]). A card script still drops them and every other file keeps them. We rejected dropping them everywhere, since an import decides which code a call reaches. It takes R2050000, the first number of issue #2050's block, and refines [[R1365000]].
