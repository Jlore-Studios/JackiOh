**[[R1933001]] Production's card statistics count the development lanes' games as staging's do (issue #1933, 2026-11-03)**: [[R1933000]] kept production's database to live games alone, the development lanes filing into staging's. The owner reversed it once production was live: with fewer than 100 players online at once a patch seldom reaches `PUBLIC_STATS_MIN_LIVE_GAMES` (1000) live games before the next ships, so `/stats` on jackioh.com would say "not enough games" nearly always, and CN Tech's and NA Tech's table could never cover a new set. The gather lane and the learn lane's import now file each file into staging's database and then production's (`PRODUCTION_STATS_IMPORT_DATABASE_URL`), each claiming it by its SHA-256 on its own, and the development rows filed before were copied into production once (`cutover.yml`, step `dev-stats`). Production's figures are padded below the gate as staging's are, labelled provisional ([[R661]]), and `STATS_DATABASE_URL` reads production through a read-only login no import uses. Pointing `STATS_DATABASE_URL` at staging, and a one-time copy without filing on, were rejected. It takes R1933001, the next free number of issue #1933's block, and edits [[§9.11]].
