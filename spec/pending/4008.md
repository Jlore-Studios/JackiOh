**[[R4008000]] A limit on a guessable value counts guesses, and the room, co-op room and lobby codes hold one (issue #4008, 2026-11-16)**: a request or frame carries one guess, and what a limit counts is guesses, not requests. A room's, a co-op room's and a lobby's code, six symbols, sat behind only the general request limit ([[R109]]); now each account may try `CODE_MISSES_PER_ACCOUNT_PER_HOUR` (10) and each address (R190) `CODE_MISSES_PER_ADDRESS_PER_HOUR` (60) distinct wrong codes in `CODE_MISS_WINDOW_SECONDS`, across every door that takes such a code, after which every lookup is 429 `rate_limited` ([[R192]]), a right code's too. A wrong code sent again counts once, a malformed one never, and the people of a room or lobby reading their own are exempt. Rejected: counting every 404, which would lock out a lobby screen re-reading a closed lobby; counting without refusing; and reusing `code_attempts`, which needs a migration. The README's Guessable values lists every door.

**[[R4008001]] Friend requests are limited per address as well as per account (issue #4008, 2026-11-16)**: a friend request tells whether a name exists, and was limited per account only, so another account at the address started a fresh allowance. `FRIEND_REQUESTS_PER_ADDRESS_PER_HOUR` (60) requests an hour are allowed per address ([[R190]]), counted on every attempt; the next is 429 `rate_limited`. Rejected: counting only the misses, which would let the first 429 tell that names exist.
