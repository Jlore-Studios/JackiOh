**[[R2195000]] to [[R2195003]] are the Training Grounds snapshots (issue #2195, part 2 of the tracker #2193, 2026-10-28)**: the designer asked for twenty Core cards to be snapshotted into the set as #41–#60, "separate entities", and the owner decided on 2026-10-28 that a snapshot keeps its Core card's name and that a deck holds one of the two. Each snapshot names its Core card (`snapshotOf`) and a deck, a random deck and the deck builder take one of the pair, never both ([[R2195000]]); the pair alone may share a name ([[R2195001]]); a text naming the Core card names it alone ([[R2195002]]); and each is a frozen copy that plays as its Core card did at the copy, what other cards read off its own number and code excepted ([[R2195003]]).
