**[[R3337000]] `boardReplaced` names the Anomaly a replacement lays (issue #3337, 2026-11-07)**: `boardReplaced` ([[R1855000]]) said only whose board was replaced, so the client could not tell Stinkyscape's ten Anomalies apart as one landed, and the owner asked for discovering an Anomaly to be an event of its own (#3330). The spec did not say what the event carries. The builder gave it an optional `anomaly`, the board's code, set by every preset of Anomaly Found! and Call to Chaos (Scape Edition) and absent for any other replacement, written only when set so older logs fold unchanged, and public on both seats, as the laid board is; the alternative of a new event beside it was rejected, since every reader of `boardReplaced` would have had to pair the two.

**[[R3337001]] An Anomaly Found! that holds a board draws its picture (issue #3337, 2026-11-07)**: every Anomaly Found! drew one spiral whatever it held. The builder gave the face model the held code, for Anomaly Found! alone and only where its label reaches, its owner's hand ([[R2247000]]), and ten pictures, one per board; the other seat and the collection keep the spiral, so a picture tells no seat a board it does not read ([[R202]]).

**[[R3337002]] A Scanning Probe's scan is drawn per seat (issue #3337, 2026-11-07)**: the probes played the shared `send` motif. The builder made their entry a bespoke recipe: the sweep at the probe's public play for both seats, and a find's ping and flight, with a Radiant one's flash, only where the seat's own `addedToHand` names Anomaly Found!; the other seat's names the sentinel and keeps its own row ([[R97]], [[R202]]).

**[[R3337003]] An Anomaly's lay is its set piece (issue #3337, 2026-11-07)**: the cast played a 500 ms board swap. Following the Starship's launch ([[R2801000]]), the builder made the replacement's run of exiles and landings one pinned entry, held as the action's set piece ([[R2785000]]) for a rift, a flare, a title card and the landing, in short, off and still forms, with a standing backdrop kept in the client's memory of the events (an aura, [[R2787000]]; engine state was rejected, since it would have moved every replay hash) and a sting per Anomaly in place of the whoosh.
