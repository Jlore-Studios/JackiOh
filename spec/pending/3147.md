It extends [[R666]] and [[R3025000]].

**[[R3147001]] An account with no address adds one on the code screen, as R663's email change (issue #3147, 2026-11-05)**: the owner asked that an account be able to add an email afterwards; §9.4 step 1 still asks for a verified address before a code, so the code screen asks a Roblox sign-up for one where it would ask for a confirmation, and R663's change confirms it.

**[[R3147002]] A pending account a provider made can be removed so the provider links to the account the player had (issue #3147, 2026-11-05)**: the owner asked for linking with existing accounts; a provider's identity can be linked to only one account, so the new pending account (which holds nothing) is deleted as "Delete my account" deletes, and the device remembers the provider to point the next sign-in at `/account`'s Link. Supabase cannot move an identity from one user to another, which rules out merging the two.
