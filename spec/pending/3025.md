**[[R3025000]] Linking and unlinking a sign-in provider on the account screen (issue #3025, 2026-11-04)**: a Google account with an address other than the JackiOh account's had no way to join it, since automatic linking matches verified addresses only. `/account` now links each provider the build names, through the auth provider's own linking with the session's token and a PKCE challenge, and unlinks it, never the account's last way in. The owner turned the projects' manual linking on for this.
