**[[R2116000]] fetches a screen's code, and a game screen's engine, on intent toward a control that leads there (issue #2116, part of #2036, 2026-10-27)**: a pointer, focus or touch on an in-app link or a navigating button prefetches that route's chunk once per page load, and the route renders from the same request with no loading panel. Prefetching every route when idle would spend metered data on screens never opened, and handlers on each of the roughly 45 navigating controls would scatter what one document listener does. It takes R2116000, the first number of issue #2116's block, and edits no section.
