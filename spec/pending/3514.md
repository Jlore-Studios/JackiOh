**[[R3514000]] A hand size set below 0 is 0: every card arriving is burned (issue #3514, 2026-11-10)**: the engine's mutation audit (#3490) tested `HAND_CAP_MAX` at, below and past it, and [[R1143]], which bounds a set hand size at 14, says nothing of one set below 0. `set_hand_cap` already holds a size to 0 or more, so a size set below 0 is 0: the hand has no room, every card drawn, added or taken into it is burned ([[R4]]), and the cards it holds stay. Refusing the effect, keeping the earlier size and reading a negative size as no cap were rejected. It takes R3514000, the first number of issue #3514's block, and edits [[§2.4]].
