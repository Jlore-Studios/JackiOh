**[[R3908000]] The state check judges the board Tears of the Kwzki Tree's sweep leaves before anything reads it (issue #3908, 2026-11-15)**: When [[R3569000]]'s sweep turns any card Radiant, the state check starts over at [[§4.5]] step 1, as it does after a card-on-card step that changed something. So the same check judges the board the sweep leaves before the standing evolutions, the hand syncs, the waiting pairs, the deck casts and the quests read it ([[R3536001]], [[R3558001]], [[R3558002]], [[R3558007]]). A Radiant face can carry what its base lacked ([[§5.2]]). A Unit in Defense Position whose Radiant face is Indestructible (C #33 Joro), has Can't Defend or is Evasive switches to Attack Position there, its `positionSwitched` after its `radiantSet` ([[R2179000]], [[R2657000]], [[R3543002]]). A Unit whose damage reaches its Radiant face's health dies there. The next pass finds no card left to sweep, so the check ends; a hidden pile's cue of a card already Radiant is no change. Before this, the resolution loop, which repeats the check while it emits events, judged the swept board within the same action, but a single check left it unjudged and ran its settled steps on it. A game that never casts Tears of the Kwzki Tree plays as before. As in Hearthstone, the state checks repeat until nothing changes. Rejected: running only the Defense switch after the sweep, which leaves a death or a tribute the new face causes to the caller's next check; and leaving it to the callers' repeat, so the evolutions and quests read a board not yet judged.
