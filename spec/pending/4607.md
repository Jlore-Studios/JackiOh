**[[R4607000]] A fork screen saves each finished deal and resumes where a cut stopped it (issue #4607, 2026-11-23):** `cargo jackioh arena --set improve-dev --forks --save <file>` writes one JSON header line naming the set, `--games`, `--extend`, the budget, `FORK_ROLLOUTS`, `FORK_MAX_PER_GAME`, the catalog version and each agent's label and `info` answer, then one JSON line per finished deal as soon as it is done: its duel line, game record, trunk hash, forks and each arm's win and fault. A rerun on the same file refuses a differing header by field name, replays the first saved deal's trunk once as an identity check (refusing on another trunk hash or other forks), then plays only the missing deals; `--extend` stops on the saved deals and the new ones together. A screen played in pieces prints the tally line one uninterrupted run prints, byte for byte; a finished save, run again, plays nothing and prints its tally again. Without `--save` the screen behaves exactly as [[R4397000]] reads it. It edits [[§9.9]].
