**[[R3840000]] An open daily board and the Daily list read again on a slow period and when the tab shows (issue #3840, 2026-11-15)**: amends [[§9.13]]'s client. The social read's `dailyWaiting` counts the games waiting on the player, so a daily game that ended on the opponent's move left it unchanged, and an open board or Daily list showed it as running until a reload; the board also ignored a change while the move was the player's. Both screens now read the server again every `DAILY_REREAD_MS` (60 seconds, a client constant) while the tab shows, and once when it shows again ([[R3205000]]); the board reads no more once its game is over, nor while its own action is in flight. Presentation only (CLAUDE.md rule 7). Rejected: a version number in the social frame (a new store query on both stores, a wire field and a contract test, for a result the slow read also gives), a reread on every social frame, and a guard that drops an older answer. It takes R3840000 and edits [[§9.13]].
