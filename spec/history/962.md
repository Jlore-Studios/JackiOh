**R962000 is a sandbox game's own custom cards (issue #962, patch v0.3.X)**: the sandbox spawned only cards of a set that ships ([[R923001]]), and a custom card's set never ships, so its author could not place it on a board built by hand. Now a sandbox game whose setup carries custom cards spawns those cards, and only those: a custom id the game was not given is refused like an unshipped card. It takes R962000, the first number of issue #962's block. It edits [[§9.9]] and §12.6. Custom cards are removed (issues #3096 and #2956): the Sandbox spawns no custom card, a custom id is refused as any id that names no card of a set that ships ([[R923001]]), and R962000's note is deleted with its tests.
