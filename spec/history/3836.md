**[[R3836000]] `classify` reads a TypeScript comma just before a closing bracket as layout (issue #3836, 2026-11-15)**: `cargo jackioh classify` compares a file's code lines with all white space taken out, so a change to its comments and layout alone is no change to its code ([[R1365000]], [[R2050000]]). In a TypeScript file a comma that stands just before a `)`, `]` or `}` is layout too, the comma a formatter adds when it breaks a call, a list or an object over lines, which TypeScript reads as no comma. So breaking a call's line to put a comment beside one argument, such as a Stryker disable comment for the mutation audit, changes no code, and under `apps/web/src/cards/` is no change to how cards look ([[R2529000]]). Rust keeps the comma, since `(a,)` is a tuple there. Rejected: a TypeScript parser for the comparison, since only this comma got through the comparison of comments and white space.
