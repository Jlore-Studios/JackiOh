**[[R1996000]] keeps the queue readout for a few seconds (issue #1996, 2026-10-26)**: every waiting client asks for the queue readout every `SERIES_POLL_SECONDS`, and the server counted the hour's claimed tickets and ended games again for each request. It now keeps what it counted for `QUEUE_READOUT_CACHE_TTL_SECONDS` (5 s) and answers every readout inside that time with it, so its numbers may be that much older. Readouts that miss together each count rather than wait for one, since the numbers need not be exact. Migration 0062's indexes, which let each count read only its hour, change no rule and are no ruling.
