**[[R4785000]] A turn whose start asks a question has its swing row read once the start has resolved; a game that ends inside the start writes none (issue #4785, 2026-11-25; clarifies [[R4552000]])**: the AI's fold holds a turn's row while the action it read left the turn's start under way (its phase still `start`, a start-of-turn prompt parking the draw and the trigger's effect, [[R113]]), and reads it off the state the first later action past the start leaves, which may end the turn too ([[R345]], [[R1183002]]). A game that ends inside a turn's start writes no row for that turn. An answer begins with the asking card still resolving, so a Created card it puts onto the field names that card as its maker ([[R4552002]]). Records already filed keep their rows.
