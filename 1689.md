# Plan (opus, strong)

## Goal

Ending a friendship ends the challenges it left open. `DELETE /api/friends/:profileId` cancels every open challenge between the two, in either direction, and frees each one's unexpired room, the way `POST /api/blocks` does. A join of a challenge's room is refused with exactly the answer an unknown code gets when the joiner is not the challenged friend, or when the two are no longer friends or either blocks the other. `POST /api/challenges` reads the friendship again in the transaction that writes the challenge, so a friendship that ends while the room opens leaves no open challenge. Block behaviour does not change. The spec does not make this decision, so it becomes ruling **R1689000**, the first number in issue #1689's block.
