   fn doomed_known_card(state: &GameState, opp: PlayerId, hidden: &IndexSet<String>) -> bool {
       state.players[opp].hand.iter().any(|card| {

               && temporary_number(&card_keywords(state, card)).is_some_and(|left| left <= 1)
       })

   /// R3696001: whether a play of `instance_id` guesses a secret of `seat`'s it may not read: the card's
   /// link names a secret `seat` owns that is not revealed (R862, R860).
   fn guesses_secret(state: &GameState, seat: PlayerId, instance_id: &str) -> bool {
       find_instance(state, instance_id)
           .and_then(|card| card.memory.get(SECRET_KEY))
           .and_then(|link| link.as_str())
           .and_then(|id| secret_of(state, id))
           .is_some_and(|secret| secret.owner == seat && secret.revealed != Some(true))
   }

   /// R3696001: `plays` with the plays of each card that `guesses_secret` cut to one, drawn on
   /// `AI_GUESS_SEED`'s stream beside the world's seed and the card, in the first one's place: the guess
   /// is made before any evaluation, so it never depends on the secret's choice (R185, R860). Every other
   /// play is kept as it is.
   fn one_guess_per_card(state: &GameState, seat: PlayerId, plays: Vec<ActionBody>) -> Vec<ActionBody> {
       let guessed = |play: &ActionBody| match play {
           ActionBody::Play { instance_id, .. } if guesses_secret(state, seat, instance_id) => {
               Some(instance_id.clone())
           }
           _ => None,
       };
       let mut settled: IndexSet<String> = IndexSet::new();
       let mut out: Vec<ActionBody> = Vec::with_capacity(plays.len());
       for play in &plays {
           let Some(card) = guessed(play) else {
               out.push(play.clone());
               continue;
           };
           if !settled.insert(card.clone()) {
               continue;
           }
           let guesses: Vec<&ActionBody> = plays
               .iter()
               .filter(|other| guessed(other).as_deref() == Some(card.as_str()))
               .collect();
           let stream = format!("{AI_GUESS_SEED}:{}:{card}", state.seed);
           let picked = Rng::new(&stream, 0).pick(&guesses).copied().unwrap_or(play);
           out.push(picked.clone());
       }
       out
   }

   /// (R3696001), `state`'s own when the end of turn is refused. `None` when the counter refused a node.
   fn judged(state: &GameState, opp: PlayerId, at_close: bool, counter: &dyn NodeCounter, prices: &Prices) -> Option<f64> {
       let closed = if at_close {
           simulate(state, opp, &ActionBody::EndTurn, counter, prices)?.ok()
       } else {
           None
       };
       Some(evaluate_priced(closed.as_ref().unwrap_or(state), opp, NextSwing::Enemy, &AI_EVAL, prices))
   }

## Risks

- **Determinism.** Both changes are pure (rule 4), and the guess's `Rng` is local. Replays fold actions, not the AI.
- **Hidden information (R185, R865).**
  - The shortlist reads the seat's own public entries.
  - `doomed_known_card` reads only cards not in `hidden`.
  - `guesses_secret` reads a secret's owner and `revealed`, never its choice.
  - The guess is drawn before evaluation; reply test 2 pins this.
  - Accepted limit: whether to play the guess at all is judged where the secret is real. A loss (one penalty) beats the discard (three), so only a Radiant Fortify Mind, which has no discard clause, could be kept on that knowledge.
- **Cost.**
  - At most one more reply, placed last, so a short counter drops it first.
  - While a doomed known card is held, each `known_play` step costs 1 + n `EndTurn` simulations, with n ≤ `AI_REPLY.known_plays`.
- **Rejected.**
  - The per-action cap for the extra line: it could never add a capped first action.
  - Putting the line first.
  - A larger reserve: it shrinks every beam.
  - Pricing delayed entries statically.
  - Judging every reply step at the turn's end.
  - Weighing all three guesses (it reads the secret) or averaging them (three times the nodes).
  - Drawing the guess from `options.rng`: it moves the decision's stream.
- **Where the reply tests go.** They go in `reply.rs`'s `mod tests`, not the issue's `tests/ai/reply.rs` or `secrets.rs`, because the functions they call are private.
