# Plan (sonnet, medium)

## Goal

When a pull request changes a deckable card, `play_changed_cards` plays a second, bounded rotation after the existing changed-cards wave. In it every game is a run-start game: each changed card is forced into both decks and its forced indices are pinned Radiant through `deckMarks`. The rotation goes through the same checks as the gate, the summary and `--json` name it, and a failing seed prints a `reproduce:` line that replays the identical game. With no deckable changed card there are no extra games and a line says so. `--from`, `--handicap`, `--cards`, `--json` and `--regress` runs behave as before.
