# Plan (opus, strong)

## Goal

An authenticated request costs half the Postgres round trips it does today, measured by a counting proxy in a Postgres test. Four changes do it. (1) A transaction remembers the subject it stamped, and `run_as` sends `set_config` only when a method's subject differs. (2) A connection is pinged at checkout only after it has sat idle past `POOL_PING_AFTER_IDLE_MS`. (3) `POOL_MIN_CONNECTIONS` connections stay warm, and a heartbeat keeps them from reaching the 10 s idle timeout, which stays. (4) `BEGIN` and the session statement go in one round trip, with only an `auth::is_uuid` subject written into the text. Security holds: every statement runs as `service_role` with its profile's `request.jwt.claim.sub`, nothing unvalidated reaches SQL text, the profile is read on every request so a ban applies at once, and the store contract passes on both stores. No SPEC rule changes, so no ruling.
