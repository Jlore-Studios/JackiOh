# Plan (opus, strong)

## Goal

The AI's turn-hook price counts a card's hooks as often as the engine runs them. Under its controller's Joint Filing (`meditative-009`), a card's start-of-turn and end-of-turn firings count 1 + `extra_runs(…, Multiplied::TurnHooks)` times. That count is read on the state being evaluated, so a line that removes Joint Filing loses the extra firings. Start-of-the-opponent's-turn hooks (Living Bomb `classic-062`) are now probed and priced too, and counted once, because the engine never multiplies them (R821). This is ruling R2689000, with its note, its pending §11 paragraph, the §9.9 edit and three tests named `r2689000_…`.

**Decision the issue did not settle (recorded in the ruling):** the issue proposed multiplying the whole price. That is wrong for Living Bomb's base face, which has both a `start_of_turn` and a `start_of_opponent_turn` hook. The engine multiplies only the first (`crates/engine/src/triggers.rs` `queue_hooks_in_trigger_order`, the `(StartOfTurn | EndOfTurn, Some(player))` arm; R821). So `TurnHookPrice` gets a second part, `opponent_turn`, which is never multiplied. Rejected: multiplying the whole price; firing each hook 1 + N times in the probe, which costs N more nodes and reads the root's board instead of each line's.
