# Plan (muse-spark-1.3-contributor, medium)

## Goal

When the runners are idle and the queue is empty, the night bot surveys for suggestions again, and the maintainer approves or rejects each suggestion by commenting `approve` or `reject` on its issue. Approving queues the issue for building (which strips its `bot:suggestion` label, as today); rejecting closes it. Since closed issues no longer count toward the open-suggestion cap, every vote frees room for a new survey, which is what brings suggestions back.

## Files to touch

| File | New / change | What changes |
|---|---|---|
| `bot/harness/events.py` | change | New `suggestion_vote` helper plus a branch in `on_comment`; add `LABEL_SUGGESTION` to the `harness.config` import |
| `bot/tests/test_flow.py` | change | Four new tests in `ReactionTests`, reusing its `ask()` / `reacted()` helpers |
| `bot/harness/deliver.py` | change | Footer text in `Deliverer._suggestions` naming comment votes beside the `bot:build` label |
| `bot/prompts/suggest.md` | change | "Buildable by the bot" bullet: approval by `approve` comment (label still works) |
| `bot/README.md` | change | Mermaid `S` node text and the "Giving it work" paragraph about approving a suggestion |
