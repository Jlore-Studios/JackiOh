## Risks

- **A trimmed list stands in for an engine divergence.** The reducer's `apply_trade`, `apply_market_buy` and `apply_market_sell` call the same `why_*_refused` functions `legal_actions` uses. A correct engine therefore never yields an accepted-but-unlisted deal, and the real fuzz stays silent. The tests make the divergence by removing one entry from the real list, as the existing `without(...)` I8 tests do.
- **Fuzz cost.** At most about 2 reduces per hand card plus one per offer, per I8 sample. I8 runs every 100th state in the gate, and a listed body costs nothing. Step 6 records the measurement. Do not change the stride.
- **Purity and determinism.** The probe state is a clone with `applied` cleared and reduces under `PROBE_NONCE`. It touches no rng, no I/O and no wire types, so nothing under `apps/web/src/wire` should change. If `git status -- apps/web/src/wire` shows a diff, stop and report it.
- **A genuine fuzz hit.** Report it with the seed and message. Never weaken the check, add an allow or skip a test.

## Risks

- **A trimmed list stands in for an engine divergence.** The reducer's `apply_trade`, `apply_market_buy` and `apply_market_sell` call the same `why_*_refused` functions `legal_actions` uses. A correct engine therefore never yields an accepted-but-unlisted deal, and the real fuzz stays silent. The tests make the divergence by removing one entry from the real list, as the existing `without(...)` I8 tests do.
- **Fuzz cost.** At most about 2 reduces per hand card plus one per offer, per I8 sample. I8 runs every 100th state in the gate, and a listed body costs nothing. Step 6 records the measurement. Do not change the stride.
- **Purity and determinism.** The probe state is a clone with `applied` cleared and reduces under `PROBE_NONCE`. It touches no rng, no I/O and no wire types, so nothing under `apps/web/src/wire` should change. If `git status -- apps/web/src/wire` shows a diff, stop and report it.
- **A genuine fuzz hit.** Report it with the seed and message. Never weaken the check, add an allow or skip a test.
