## Risks

- **Shards must agree.** Each shard job runs `changed-cards` itself (the base is fetched `--depth=1` over the checkout's credentials, as the fuzz job does). If one fetch fails, that shard sees `SMOKE` alone and deals differently, so an extra spec could land on no shard. It is logged, and the daily run still plays it. Accepted: no shared artifact is added.
- **Time.** A core-077-style change adds up to 480 s over 4 shards (about 200 s a shard). `WEIGHTS` are estimates and an unlisted spec counts 30 s, so a shard can run past the prediction. The job timeout is 10 minutes.
- **Over- and under-selection.** Fixture membership pulls in filler-card specs. Names miss specs that reach a card another way (specs 08 and 48 stay daily). Quoted names in spec comments count; accepted.
- A spec already broken on `main` now fails the card pull requests that select it, as a broken smoke spec does today.
- `changed_cards` is unchanged, so the fuzz gate behaves as before; no pure crate is touched.
