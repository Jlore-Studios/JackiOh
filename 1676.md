# Plan (opus, strong)

## Goal

Add `cargo jackioh stats from-selfplay <log>… --out <file>`. It files every game of `selfplay` logs as an R378 development `GameRecord`, one per line.

- **Replay.** Each game is replayed under its own catalog, as `positions` does (R1006003). A game on an uncarried catalog, without a result, with `faults` (R1489000) or missing its hash files nothing and is counted.
- **The record.** `source: "dev"`, `mode: "random"`, both pilots `ai`, and the patch its catalog names. Its build is the log's commit and the line's AI generation (R1367000).
- **The id.** `dev:<patch>:selfplay:<base>:<n>`. `stats --series` refuses a `selfplay:` series, so no `stats` run can take such an id.
- **Determinism.** The output is byte-identical whatever the thread count.
- **Readers.** `stats report`, `stats report --games` and `stats-import`'s parser read it.

Ruling R1676000 records this, and the docs say the development games now come from the learn lane's exports.

     pub(crate) fn record_of(game: &SelfplayGame, build_catalog: &str) -> Result<GameRecord, Dropped> {
         let shipped = catalog_for(game.catalog_now(), build_catalog).map_err(|_| Dropped::EarlierPatch)?;
         if game.result.is_none() {
             return Err(Dropped::NoResult);
         }
         if !game.faults.is_empty() {
             return Err(Dropped::Unclean);
         }
         let args = FoldArgs {
             seed: game.seed.clone(),
             decks: game.decks.clone(),
             log: game.log.clone(),
             ..FoldArgs::default()
         };
         let summary = catch_unwind(AssertUnwindSafe(|| {
             with_shipped(shipped, || {
                 let replay = fold(&args);
                 let reached = replay.errors.is_empty()
                     && hash_state(&replay.state) == game.hash
                     && replay.state.result == game.result;
                 if reached { summarize_game(&args) } else { None }
             })
         }));
         let summary = summary.ok().flatten().ok_or(Dropped::NotReplayed)?;

         Ok(GameRecord {
             id: dev_record_id(&patch, &format!("{SELFPLAY_SERIES_PREFIX}{}", game.seed)),
             source: GameSource::Dev,
             mode: GameMode::Random,
             patch,
             pilots,
             game: summary,
             build,
         })
     }
