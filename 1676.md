## Risks

- **Determinism.** Collect `par_iter` in order and never write inside the parallel map. The thread assertion holds this.
- **Replay.** Fold under `with_shipped(catalog_for(game.catalog_now(), …))`, never the build's catalog. A caught panic counts as `not_replayed`. `summarize_game` skips refused actions, so check `fold`'s `errors`, the hash and the result first.
- **Ids.** `forced_series` reads such an id's series as `selfplay:<base>`, never `dev-force-…`, so `stats-import` accepts it.
- **Size.** An export is about 100,000 records (about 180 MB), and `stats-import` reads its file whole. The command does not deduplicate, so name each shard once.
- **Formats.** Change no `SelfplayGame` field and no record format.
