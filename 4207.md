# Plan (opus, strong)

## Goal

A card that **dies** has still died, wherever a replacement sends it. This is ruling **R4207000**, for C #50 Voidwalker and Stinkyscape #105 Disintegrex, base and Radiant. It covers the state check's collection and, under Voidwalker, a Sacrifice or Tribute too. Such a card:

- fires its Death;
- returns by Reborn from exile at 1 health; a second death exiles it, and its Death fires again;
- reports and counts `destroyed`;
- fuses, if it is a Starship Piece;
- ends in exile.

These still fire nothing:
- moves that are not deaths (a discard, a Spell, a burn, a Trap, a mill);
- plain exiles.

A token dies as it does on any death.
