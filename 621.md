## Goal

Remove the separate `matches_finish` transaction from `MatchActor::on_terminal` so a failed `record_result` never marks a match row finished without its result or cleared player flags. When `record_result` fails, retry up to `MATCH_RECORD_RESULT_ATTEMPTS` times with `MATCH_RECORD_RESULT_BACKOFF_MS` delay, and if all retries fail, leave the match row live and drop the actor from `Registry` so subsequent client attaches or the reaper ceiling can heal the match and clear players' in-match state per SPEC §9.5 and new ruling R1437.

     - Replace the single `record_result` call with a retry loop:
       ```rust
       let mut recorded = false;
       for attempt in 1..=MATCH_RECORD_RESULT_ATTEMPTS {
           match crate::api::results::record_result(&self.shared.deps, input.clone()).await {
               Ok(_) => {
                   recorded = true;
                   break;
               }
               Err(error) => {
                   tracing::error!(
                       event = "match.recordResult.failed",
                       matchId = %self.match_id_str(),
                       attempt = attempt,
                       message = %error,
                   );
                   if attempt < MATCH_RECORD_RESULT_ATTEMPTS {
                       tokio::time::sleep(std::time::Duration::from_millis(
                           u64::try_from(MATCH_RECORD_RESULT_BACKOFF_MS.max(0)).unwrap_or(0),
                       ))
                       .await;
                   }
               }
           }
       }

       if !recorded {
           self.shared.deps.matches.forget(self.match_id_str());
           return;
       }
       ```
