## Risks

- The module caches states by exact text: `splitState` returns a substring of the answer, never a re-encoded value, so brace counting must be string- and escape-aware (an encoder that writes `{}` as `[]` is the failure the task names). The top-level member walk also ignores `"state"` text nested inside earlier string values.
- `memory.grow` can replace the buffer at any point: every `buffer.writestring`/`buffer.readstring` uses a fresh `memory()` call, including after the binding returns and after `growOnAlloc` fires inside `jackioh_alloc`. The three grow checks pin all three spots.
- The result buffer is the module's: the host never frees it, reads it before freeing argument buffers, and never touches the pointer when the length is 0 (pinned by `allocCalls`/`ptrCalls` counters).
- Freeing argument buffers on the trap path is a choice for a uniform zero-live rule against the mock; the translator's adapter (later issue) owns real post-trap behavior.
