# Plan (opus, strong)

## Goal

A room's ticket on `/play` gets **Copy invite link**. It opens `navigator.share` where the browser has it and writes to the clipboard otherwise. The link is `/play?room=CODE&mode=<mode>`. When someone opens that link, the lobby reads it once and removes `room` and `mode` from the URL with `history.replaceState`. It checks the code with the shared reading (`canonicalCode` against the server's `ROOM_CODE_FORMAT`) and ignores a code that fails without saying anything. A valid code fills the join input in upper case. The lobby then picks the link's mode (only a hint, since R264's refusal still decides), says what to pick, focuses that choice, and never joins on its own. A visitor who is signed out keeps the link in `sessionStorage` through sign-in, and the next lobby uses it once. SPEC §9.5 gets a sentence and the new ruling R767.
