## Plan

_Written by Claude (Opus 5.5) for #306's planning session. Edit it here to change it._

### 1. Goal

Create the integration branch `staging` and everything every other part builds into: the Cargo workspace, the six crate manifests with pinned dependencies, the purity `clippy.toml`s, every `lib.rs`/`mod.rs`/`main.rs` declaring the full module tree of PORT-MAP.md, an empty file for every module, the data copies, the cards registry `build.rs`, and the type freeze: the shared wire types, `state.rs`, `script.rs`, `config.rs` and `rng.rs` translated in full. After this part, every other Wave 1 part only fills files.

**How you work.** This part may build: it must end with a workspace whose only `cargo check` errors are unresolved names pointing into modules other parts will fill. It is the only Wave 0 part; nothing else starts before it is done.

**Pushing.** README §3.2: `git fetch origin staging && git checkout -B work origin/staging`, write, commit only your files, `git pull --rebase origin staging && git push origin HEAD:staging` (retry with back-off). Commit often. A session that is cut off leaves its work on `staging`; the next session for this part starts at the first file in the table that is missing or empty.

### 3. Steps

1. Create the branch: `git fetch origin main claude/relaxed-archimedes-i5fdah && git switch -C staging origin/main && git checkout origin/claude/relaxed-archimedes-i5fdah -- docs/v0.3.0 && git commit -m "v0.3.0 part 1: the plan" && git push -u origin staging && git tag v0.3.0-wave-0-start && git push origin v0.3.0-wave-0-start`. `staging` gets no branch protection until part 30's CI is on it.
2. Write the root files and the six `Cargo.toml`s (SURFACE §1–§2). Pin versions with `=` only for wasm-bindgen; the rest as written.
3. Copy the data, never move it (the TS engine must keep working for part 23): `mkdir -p crates/cards crates/server && cp packages/cards/catalog.json packages/cards/flavour.json crates/cards/ && cp -r packages/cards/patches crates/cards/ && cp -r apps/server/src/db/migrations crates/server/migrations`. Check `cmp` on each file.
4. Translate the freeze files by SURFACE §4.3, field for field, keeping every doc comment: `packages/shared/src/{catalog-types,actions,events,view}.ts` → `crates/engine/src/wire/*.rs` (types and their small helpers: `opponentOf`, `keywordKey`, `hasKeyword`, `fillParams`, `armorOf`, `paramPlaceholders`, the const lists); `state.ts` → `state.rs` (all of it); `script.ts` → `script.rs` (with `Hook`, `Effect`, `EffectContext`, `EffectPart`, `Memo` and the typed hook aliases of §6.6; `impl Default for Script` with every field `None`/empty; `CardScripts { base, radiant }`); `config.ts` → `config.rs`. Every wire type (and every type reachable from `PlayerView`, `GameEvent`, `Action`, `CardDef`, `GameRecord`, `GameState`) gets `#[cfg_attr(feature = "ts", derive(ts_rs::TS), ts(export, export_to = "../../apps/web/src/wire/generated/"))]` (SURFACE §5.1).
5. Into `config.rs`, also move the numeric constants research A §4 found outside `config.ts`, with their TS names: `VIEW_EVENT_LIMIT` (viewFor.ts:108), `RADIANT_SHEEP_TRIBUTE_VALUE`, `SHEEP_TRIBUTE_VALUE` (playChoices.ts:409-410), effects/lastBoard.ts:20,23, `STATE_CHECK_PASS_CAP` (stateCheck.ts:474), `MAX_WORK_STEPS` (work.ts:69), `MAX_PROMPT_ANSWERS` (prompts.ts:92), `MAX_MULLIGAN_SUBSETS` (reduce.ts:63), subsystems/lastBoards.ts:26, subsystems/callToChaos.ts:40-60, `SCORER_WEIGHTS`, `SCORER_LOW_HEALTH`, `SCORER_DRY_RUN_PLAYS` (scorer.ts:44-60, :210), subsystems/heroPower.ts:80-98, `AI_PLAYOUT_STEP_CAP` (aiPolicy.ts:22), subsystems/comboIndex.ts:30-38, subsystems/fuse.ts:87, :90; and add `TRAINING_GAMES = 100`, `TRAINING_IMPROVE { vs_random: 90, vs_parent: 85 }`, `TRAINING_UNBAN { vs_random: 90, vs_parent: 75 }` (SURFACE §14.2).
6. Write `rng.rs` (§6.3). Get TS's first ten `next()` values for seeds `golden` and `jackioh-fuzz-1`: `pnpm install --frozen-lockfile && pnpm exec tsx -e 'import {createRng} from "./packages/engine/src/rng.ts"; for (const s of ["golden","jackioh-fuzz-1"]) { const r = createRng(s); console.log(s, JSON.stringify(Array.from({length: 10}, () => r.next()))); }'`, and pin them in `rng.rs`'s `#[cfg(test)]` test with `assert_eq!` on the exact `f64`s. Check the Rust side now with a scratch copy (`rustc --edition 2024 --test`) in your scratch directory: part 1 may build.
7. Generate the module tree from `docs/v0.3.0/port-map.tsv`: every destination under `crates/` that is a `.rs` file gets an empty file (unless you wrote it) and a `pub mod` line in its parent (`lib.rs`, `mod.rs`, `tests/rules/mod.rs`, …). Card scripts are the exception: `build.rs` finds them, so do not create or declare them. Keep the lists sorted.
8. Write the glob re-exports: `lib.rs` `pub use` of every engine module (`pub use reduce::*;` …) and `pub mod effects; pub mod subsystems; pub mod wire;` with `pub use wire::*;`; `prelude.rs` re-exporting the modules card scripts read from (`query`, `zones`, `catalog`, `params`, `state`, `layers`, `mana`, `cost_rules`, `numbers`, `animated`, `plague`, `faces`, `script`, `effects::*`, `subsystems`, `wire::*`), `serde_json::{json, Value}`, `indexmap::IndexMap`, and a `pub fn json_as<T: serde::de::DeserializeOwned>(v: Value) -> T` (panics with the JSON on a mismatch: test-time only).
9. Write `crates/cards/build.rs` and `crates/cards/src/lib.rs` (§7.4): `register_all()` calls `jackioh_engine::catalog::register_catalog(defs, version)` and `jackioh_engine::scripts::register_scripts(map)` (part 2 writes those two); `catalog_version()` is the last `version` in `patches/patches.json`, read by `build.rs` and emitted with `cargo:rustc-env`. With no card files yet, `build.rs` must not fail on "catalog id with no file": make that check a warning while `src/scripts/` holds fewer than 318 files, and an error at 318.
10. Write `crates/tools/src/main.rs` (§12) and `crates/server/src/main.rs` (§11.1) with clap derive.
11. Run `cargo check --workspace 2>&1 | tee .fullsend/damage/part-01.txt`. The only errors allowed are unresolved names pointing into a module that is still empty (E0425, E0432, E0433, E0412, E0422, E0599 on an item of an empty file). Fix every other error in your files. Run `cargo fmt` on your files.
12. Commit (`v0.3.0 part 1: workspace, module tree, type freeze`), push, tag `v0.3.0-wave-0` and push the tag. Comment on this issue with the tag and the count of files created.
