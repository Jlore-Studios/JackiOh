## Risks

- **Fold behaviour.** `opening` only moves code; `replay_m1_gate` and `golden check` prove `fold` unchanged.
- **Hidden information.** Checkpoints hold whole states, so parts 2 and 3 must keep them in the worker or the server. Views come only from `view_for`.
- **Panics.** A refused setup panics, as in `fold`. The WASM binding checks the setup only when the versions match, so an old game with removed cards gets `earlier_patch`, not a throw.
- **Test time.** The fresh-prefix folds are O(n²) per game. 100 fixture games fold in about 6 s, so this takes seconds.
- **Clippy.** Use `is_multiple_of`. Add no `allow`.
- **Duplicate nonces.** `reduce` accepts a repeated nonce (`error: None`), so it counts as a step.
