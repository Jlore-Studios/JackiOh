````markdown
# Plan (opus, strong)

## Goal

On a seeded share of seeds, the 1v1 waves (the gate and `--handicap`) and `--duos` also play an **endings channel**. It is a small seeded per-step chance of sending an action in the policy's place. It sends two kinds of action:
- what §10.7's policy never sends: concede, draw offer and answer, emote;
- what only the server sends: `timeout`, `setAutoEndTurn`, `disconnectExpired`, `ceilingReached`.

These actions are logged like any other, so replay, the hash and the checkpoint fold them.

Done means four things:
- a fixed-seed test asserts that the logs hold concede, draw, emote and timeout actions;
- games ending by concede or by accepted draw pass the replay and hash checks;
- a failure still names its seed and decks;

const ENDINGS_TERMINAL_REASONS: &[&str] = &["concede", "draw-accepted", "disconnect", "match-ceiling"];

/// The actions `legal_actions` offers `seat` that `keep` holds, in its order.
fn listed(state: &GameState, seat: PlayerId, keep: fn(&ActionBody) -> bool) -> Vec<ActionBody> {
    legal_actions(state, seat).into_iter().filter(keep).collect()
}

/// What the endings channel sends at `state` in the policy's place, and from which seat, or `None`
/// when the policy acts (#1572). `player` is the seat the game waits on, `rng` the seed's
/// `endings-steps-` stream. An offer, its answer and an emote go only while `legal_actions` lists
/// them; the rest are the server's, which `reduce` takes from either seat while the game is live.
fn endings_action(state: &GameState, player: PlayerId, rng: &mut Rng) -> Option<(PlayerId, ActionBody)> {
    let seats = [player, opponent_of(player)];
    if rng.chance(ENDINGS_END_CHANCE) {
        let seat = *rng.pick(&seats)?;
        let endings = [
            ActionBody::Concede,
            ActionBody::DisconnectExpired { player: seat },
            ActionBody::CeilingReached,
        ];
        return rng.pick(&endings).map(|body| (seat, body.clone()));
    }
    // R36, R269: the seat with an offer to answer is the one the active player made it to.
    if let Some(&seat) = seats.iter().find(|seat| has_standing_draw_offer(state, **seat))
        && rng.chance(ENDINGS_ANSWER_CHANCE)
    {
        let answers = listed(state, seat, |body| matches!(body, ActionBody::AnswerDraw { .. }));
        return rng.pick(&answers).map(|body| (seat, body.clone()));
    }
    if !rng.chance(ENDINGS_ACT_CHANCE) {
        return None;
    }
    let mut acts: Vec<(PlayerId, ActionBody)> = Vec::new();
    for seat in seats {
        let offered = listed(state, seat, |body| matches!(body, ActionBody::OfferDraw | ActionBody::Emote { .. }));
        acts.extend(offered.into_iter().map(|body| (seat, body)));
        acts.push((seat, ActionBody::Timeout));
        let enabled = state.players[seat].auto_end_turn == Some(false);
        acts.push((seat, ActionBody::SetAutoEndTurn { enabled }));
    }
    rng.pick(&acts).cloned()
}
```
````

````markdown
## Risks

- **Determinism and replay.** The channel draws only from its own streams, and its actions go through `reduce` and into `log`. Seeds that don't draw it, and `GameSetup::plain` (the corpus), play the same games as before.
- **Refusals.**
  - `reduce` accepts the server actions and concede from either seat in any live state (`NON_ACTIVE_`, `PROMPT_OPEN_` and `MULLIGAN_OPEN_ACTION_TYPES`). The other actions are sent only while `legal_actions` lists them.
  - So any refusal is an engine bug: report it with its seed. Never lower a rate or exclude a card to hide it.
- **Probes.** The wrong-seat probe would wrongly fail on actions that either seat may send, so channel steps skip the probes.
- **Existing tests.**
  - Gate seed 1 and Duos seeds 1 and 7 don't draw the channel.
  - Duos seed 1427 does draw it, but no channel action fires before its game ends.
  - The new tests search ranges of seeds, so new cards joining the pool don't break them.
````
