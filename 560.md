     - If it names a `lets` entry and lies inside the body, add that let's range.
     - Exception: for `NAME.FIELD`, where `FIELD` is a hook field and the let is a `Script {` literal with key `FIELD`, add only that key's value range.
   - **Hooks:** the hook-field keys of every `Script {` literal in the region, skipping a `Script` that follows `::` or `->`.
     - If the region holds no literal and no `Script::default()` or `Default::default()`, return `Err(format!("the {face} face (\`{text}\`) names no \`Script\` literal in this file"))`.
     - `text` is the start range's first `FACE_TEXT_CHARS` characters, whitespace collapsed.
   - **Each face:** its hooks, plus `classify` over each region range. `elsewhere` is `classify` over the whole code minus base
