Make every game record readable outside Postgres and the Rust tools, so the notebooks (part 2) and anyone with Python can work on them:

- `jackioh-server stats-export` writes the records `stats-cards` reads, one `GameRecord` (R376) per line: the format `cargo jackioh stats --out` and the training lanes already write and `stats-import` reads.
- `cargo jackioh stats report <file>…` prints R377's `card_stats` over record files with no database, so a notebook's arithmetic can be checked against the Rust's.
- `analysis/`: a Python project (uv, pinned), a loader that turns record files into pandas tables, and a test that its win rates equal the Rust report on a committed fixture.
