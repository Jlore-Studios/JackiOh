## Goal

Two fixes in `apps/web`. First, the match client clears `error`/`errorCode` when a new socket delivers its first `view` frame. A "not connected to the match" alert set while the socket was down then goes away once the reconnect is proven. A socket only opening does not clear it, and later views on the same socket do not either. Second, the `useMatch` hook exposes `connect()`, which now cuts short a pending backoff. The connection line renders a "Reconnect now" button only while `connection` is `"reconnecting"`, and the button calls it. Unit and component tests cover both, and the web tests, typecheck and eslint stay green.
