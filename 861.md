# Plan (opus, strong)

## Goal

`GET /healthz` answers 200 with the catalog version and `x-deployed-commit` and never touches the store. `GET /readyz` gives the same answer, but only once the store answers `select 1`; until then it gives 503 `unavailable`, within `READINESS_PROBE_TIMEOUT_MS`. `render.yaml`'s `healthCheckPath` becomes `/readyz`.

On SIGTERM or Ctrl-C the server, all inside `SHUTDOWN_DRAIN_SECONDS`:
- stops accepting and aborts the loop handles it now keeps;
- lets in-flight requests finish;
- stops every match actor: sockets get close frame 1001, and queues drain so result writes land;
- waits for the sockets to finish, closes the store (`pg::close`) and exits 0.

Tests prove each part, and the deploy rehearsal checks `/readyz` and the exit code.
