````markdown
# Plan (opus, strong)

## Goal

The opponent's reply (`simulate_reply_with` in `crates/ai/src/reply.rs`) gets one more step. When the static trader finds no attack worth making, it tries switching each of its units that is in Attack Position and can still switch to Defense Position. It keeps the switch its own `evaluate` likes best, if that beats standing still. Otherwise it ends its turn as before.

A new named constant, `AI_REPLY.defense_switches`, caps the tries per step. Seeded reply tests show a unit with no positive attack switching when `evaluate` prefers Defense, and staying in Attack when it does not. Done means `cargo test -p jackioh-ai` is green and neither the gate smoke nor a paired screen shows a regression.

   /// Step 4, #1696: once no attack is worth making, so that every unit's best attack is worth nothing,
   /// the opponent's units in Attack Position whose switch `legal` lists (a unit that attacked has spent
   /// it, §4.1, unless it has Deft, R49) are switched to Defense on trial, at most
   /// AI_REPLY.defense_switches of them in legal_actions order, one node each, and the one its own
   /// evaluation likes best is kept if that beats standing still. A unit already in Defense is never
   /// tried: its switch back to Attack is `deft_switch`'s.
   fn defense_switch(
       state: &GameState,
       seat: PlayerId,
       legal: &[ActionBody],
       counter: &dyn NodeCounter,
   ) -> Known {
       let tries: Vec<ActionBody> = legal
           .iter()
           .filter(|action| {
               matches!(action, ActionBody::SwitchPosition { instance_id }
                   if find_instance(state, instance_id)
                       .is_some_and(|unit| unit_view(state, unit).position == Position::Atk))
           })
           .take(AI_REPLY.defense_switches.max(0) as usize)
           .cloned()
           .collect();
       best_try(state, seat.opponent(), &tries, counter)
   }
   ```
````
