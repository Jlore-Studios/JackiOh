## Goal

`cargo jackioh arena --set improve-dev --forks --save <file>` writes one JSON header line then one JSON line per finished deal (trunk game plus its forks' arms), flushed at once, so a killed run loses at most unfinished deals. Running the same command again refuses a mismatched file by field name, replays the first saved deal's trunk once as an identity check, plays only missing deals, and prints byte-for-byte what one uninterrupted run prints.
