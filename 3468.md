- Desktop keeps `B34` cap halving without shedding: a stranded desktop level can only come from shared-module tests, where the healthy path still drains it.
- `TileAura` and `motionSlots` subscribe to the level only, not the pointer, so they need no change; `CardFace`, tilt, pack, showcase, and gallery faces inherit the fix through the store.

## Open questions

None. The phone-only gate the issue left open is decided in steps 1-2 and 5-6 (shed publishes on phone viewports only; desktop keeps cap halving), and the budget question in steps 8-9 (reword to the actual mechanism rather than enforcing a cross-layer counter the code has no allocator for).
