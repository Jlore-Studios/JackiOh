# Plan (opus, strong)

## Goal

The fuzz monitor (`InvariantMonitor`, check I9 "the wire tells the truth") keeps a count of fatigue draws for each seat, built from the event stream. After the change it reports a named violation in three cases:
- **Wrong count.** A `Fatigue` event's `count` is not one more than that seat's previous fatigue draw (a skipped or repeated count): `I9 wrong fatigue count`.
- **Wrong damage.** A `Fatigue` event's `amount` is not `FATIGUE_DAMAGE(count)`: `I9 wrong fatigue damage`.
- **Silent move.** On the state an action leaves, a seat's `fatigue_count` differs from the count its events announced, either a count that moved with no event or an event with no move: `I9 silent fatigue`.

After a Glitch's reset (R676) the count starts again from the new game. Crafted streams prove each violation, and `cargo jackioh fuzz` stays green.
