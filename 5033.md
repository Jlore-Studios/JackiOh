## Risks

- **Rule 7 and 9.** The client only compares the integers the server sent. It never parses or orders version names. No new number or constant is added: the position is data, not configuration.

- **`SortedRow` type.** Adding `firstShipped?` must not break `CreatedPanel`'s rows (optional) or `sortCreated`'s generic use. Run the web typecheck.
