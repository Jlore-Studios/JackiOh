## Steps

**1. Install the tool and make the tree copy.** Run `cargo install cargo-mutants --locked --version 27.1.0` (the version `mutants.yml` pins; crates.io is reachable).

Do not use `scripts/mutants.sh` for the runs below. cargo-mutants 27.1.0 adds its "delete field … from struct" mutants without its name filter (cargo-mutants `src/visit.rs:747`), so `-F` would also pull in every field-deletion mutant of the set. Instead, make the copy that `mutants.sh`'s `cards_tree` makes, from the repo root:

```sh
TREE=$(mktemp -d)
git ls-files -co --exclude-standard | while IFS= read -r f; do [ -f "$f" ] && echo "$f"; done | tar -cf - -T - | tar -xf - -C "$TREE"
for file in $(git ls-files -co --exclude-standard -- 'crates/cards/src/scripts/*/*.rs'); do
  rel=${file#crates/cards/src/}; module=$(echo "${rel#scripts/}" | sed 's/\.rs$//; s|/|_|')
  printf '\n#[cfg(any())]\n#[path = "%s"]\nmod mutants_%s;\n' "$rel" "$module"
done >>"$TREE/crates/cards/src/lib.rs"
M=crates/cards/src/scripts/meditative_plus
run() { env -u CARGO_TARGET_DIR CARGO_INCREMENTAL=1 cargo mutants --dir "$TREE" -p jackioh-cards --jobs 2 "$@"; }
```

Why those settings:

- **`env -u CARGO_TARGET_DIR`:** the environment shares one target dir, and the two jobs would then wait on its lock.
- **`--cargo-test-arg=--lib`:** about 1.7 mutants a minute, instead of roughly a third of that for the full suite.
- **`--iterate`:** it then re-tests only the survivors with the full suite. The library tests are a subset of the full suite, so lib-pass kills plus full-pass kills equal the full measure.

Background commands stop after 2 hours, so keep each run under 100 mutants. Make the copy again after every edit: the runs read the copy, not the worktree.
