# Plan (opus, strong)

## Goal

When a host's wrap-up (`AiOptions::wrap_up`, R3498000) has already fired as the beam starts, the beam still tries every move of its root, however many nodes a surcharged move takes, so the AI keeps lines and does not fall back to End turn. The root's own End turn is tried too. The wrap-up's floor is counted in root moves tried, not in `root_branching + 1` nodes: the beam tells its slice when its root list is done (`NodeCounter::end_root`). The hard stop (`should_stop`) still stops everything. With no clock, or with a wrap-up that never fires, every decision stays node for node what it was.
