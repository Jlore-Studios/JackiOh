# Plan (opus, strong)

**Goal.**
The practice setup gets a **Play today's deal** button that starts a free practice game on the UTC day's deal:
- the seed `daily-YYYY-MM-DD`, which changes at UTC midnight;
- the human's seat, which the day sets;
- a random deck at the setup's difficulty and "More cards from" pick;
- no last board from the device.

Two devices with the same difficulty, pick and catalog then get the same decks and the same AI play (criterion 1). A day's deal depends only on its date, so it deals the same way again. A finished one is kept, replayed and downloaded like any free game (criterion 2, and the replay half of criterion 3). §9.9 states the catalog-version rule for saves (criterion 4). The change is recorded as ruling R2882000 plus one §9.9 paragraph.

The earning half of criterion 3 is **not met**: today's deal earns nothing. The server mints the seed for every earning game, and that seed is the primary key of `public.practice_seeds` (`crates/server/migrations/0047_practice_seeds.sql`). A seed that every player shares cannot be claimed without a server change and a migration, and the issue rules both out. See Open questions.

   /** A day's deal: its UTC day, the seed every device deals it on, and the seat the human plays. */
   export type DailyDeal = { day: string; seed: string; humanSeat: PlayerId };

   /** R2882000: the deal of the UTC day `nowMs` falls in, new at UTC midnight; the human is p1 on an odd day of the month, p2 on an even one. */
   export function dailyDealOf(nowMs: number): DailyDeal {
     const date = new Date(nowMs);
     const iso = date.toISOString();
     const day = iso.slice(0, iso.indexOf("T"));
     return { day, seed: `${DAILY_DEAL_SEED_PREFIX}${day}`, humanSeat: date.getUTCDate() % 2 === 1 ? "p1" : "p2" };
   }

   /** R2882000: the game a day's deal starts: a random deck on the setup's "More cards from" pick, at `difficulty`. */
   export function dailyDealConfig(nowMs: number, difficulty: Difficulty, lean: LeanPick | null): PracticeStartConfig {
     const deal = dailyDealOf(nowMs);
     return {
       seed: deal.seed,
       difficulty,
       humanSeat: deal.humanSeat,
       deck: lean === null ? { kind: "random" } : { kind: "random", leanSet: lean },
       dailyDeal: deal.day,
     };
   }
