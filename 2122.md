# Plan (opus, strong)

## Goal

On a phone (`(pointer: coarse), (max-width: 600px)`), every interactive element (`button`, `a[href]`, `[role="button"]`, `input`, `select`, `[tabindex="0"]`) smaller than 44×44 CSS px gets a hit area at least that big. The minimum is one custom property, `--hit-min` in `index.css`, and one TS constant, `HIT_MIN_PX` in the new spec. The hit area is a transparent, absolutely positioned `::before` centred on the control, so the layout does not move. Neighbours split the gap, so no hit area covers another control. Inline links in running text, cards, and controls under an open modal are exempt. The new e2e spec `47` measures the practice board and every menu spec `46` visits, at 390×844, and names each failing control by its testid. Spec `46` stays as it is.

The planner ran this design in Chrome with the CSS injected. Spec 47 failed on 11 of 29 tests without it and passed all 29 with it; 46 passed all 54 with it.

   - Right after that rule, before `:where(button, input, a):focus-visible`, add the block below exactly. Its comment explains it.
     ```css
     /* The hit area (#2122, R2122000): on a phone or under a finger, a control shorter than --hit-min
        takes a tap across --hit-min round its centre through a transparent ::before, so nothing in the
        layout moves. Top and bottom are half the shortfall while the box is shorter than --hit-min and
        50% (no box at all) once it is as tall, the clamp's middle term (the shortfall times a thousand)
        choosing; left and right reach out only by what the width falls short. Zero specificity, so a
        control's own ::before or position wins where it has one. Not here: a link in running text
        (exempt), a table row (its ::before would be a cell), and inputs and selects, which draw no
        ::before and take --hit-min as their height where they are small. */
     @media (pointer: coarse), (max-width: 600px) {
       :where(button, a[href], [role="button"], [tabindex="0"]):where(:not(:is(p, label) a, tr)) {
         position: relative;
       }

       :where(button, a[href], [role="button"], [tabindex="0"]):where(:not(:is(p, label) a, tr))::before {
         content: "";
         position: absolute;
         top: clamp((100% - var(--hit-min)) / 2, (100% - var(--hit-min)) * 1000, 50%);
         bottom: clamp((100% - var(--hit-min)) / 2, (100% - var(--hit-min)) * 1000, 50%);
         left: min(0px, (100% - var(--hit-min)) / 2);
         right: min(0px, (100% - var(--hit-min)) / 2);
       }
     }
     ```
