# Plan (opus, strong)

## Goal

Every save of a deck keeps a version of its name and cards on the account. A save within `DECK_VERSION_DEBOUNCE_MS` of the deck's newest version replaces that version, so a burst of edits makes one version. A deck keeps at most `DECK_VERSIONS_KEPT` versions and drops the oldest. In the editor, a History popover lists the versions newest first, each with its date and the cards in and out since the version before. Restore saves a version as a new version and never merges it, so the version it replaced stays. Deleting a deck or its account deletes its versions. RLS keeps another account from reading them, and the SQL suite proves it. The store contract covers both stores. The ruling is R2100000.

pub fn deck_version_step(newest: Option<&DeckVersion>, save: &DeckVersion, debounce_ms: Option<i64>) -> DeckVersionOutcome {
    match (newest, debounce_ms) {
        (Some(newest), _) if newest.name == save.name && newest.cards == save.cards => DeckVersionOutcome::Unchanged,
        (Some(newest), Some(window)) if save.saved_at - newest.saved_at < window => DeckVersionOutcome::Merged,

}
