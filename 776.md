# Plan (opus, strong)

## Goal

When the log write of a clock's server action fails (a turn, prompt or mulligan `timeout`, `disconnectExpired`, `ceilingReached`), the clock runs out again `MATCH_SERVER_ACTION_RETRY_MS` later. This repeats until the row lands, the match ends or the actor stops, and one expiry is never logged twice. When the store finds that a row already holds the seq the actor is about to write, it raises a new `StoreError::SeqClash`. The actor then lets go as R1437's `let_go_unrecorded` does, so the next socket rebuilds it from the log. The fake store answers a repeated (nonce, seq) the way Postgres does, a contract case proves both stores agree, and ruling R776000 records all of it.
