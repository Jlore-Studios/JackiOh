## Risks

- **Wiping the worktree.** Running `loop.sh` inside the worktree resets it; see the warning above step 1.
- **Breaking the live lanes.** `improve` and `unban` must behave exactly as before. The gather lane adds only an early `return` in `cycle()` and the `$lane != gather` guard, and every other line stays as it is. A syntax error would crash-loop all three services, so `sh -n` and shellcheck are mandatory.
- **Duplicate records.** The cursor moves before the append, and the batch file is deleted before each run. A killed or failed batch is therefore never appended twice. `stats-import` also skips ids it already holds.
- **Database growth and public stats.** A record is about 1.8 KB and a game about 4 s, so the cap keeps one patch near 9 MB. With `DATABASE_URL` set, dev games feed R654's provisional public figures, which is what that ruling intends.
- **Mixed AI generations.** If the AI is promoted in the middle of a patch, that patch's games come from more than one AI generation. The README says so.
