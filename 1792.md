# Plan (opus, strong)

## Goal

The browser tab reads "Your turn · JackiOh" exactly when the game waits on the viewer, in a 1v1 match and at the co-op table. Concretely:
- During the opening mulligan, a seat that still owes its answer is flagged and a seat that is ready is not, whatever `active` says.
- A prompt the viewer holds (`pending.forYou`) flags the tab on the opponent's turn.
- A prompt waiting on the other player keeps the tab plain even on the viewer's turn.
- With no prompt open, the viewer's own turn flags it, as today.
- A finished game is never flagged.

One pure helper, `awaitsYou`, decides this from the view alone (CLAUDE.md rule 7). Both routes use it, and each route gets tests.
