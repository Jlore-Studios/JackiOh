   - Each rewriter has the signature `fn rewrite_<kind>(text: &str, names: &Names) -> (String, Vec<String>)`. It returns the new text and a list of problems.
   - Split with `text.split('\n')` and rejoin with `"\n"`, so the final newline survives. A line that is no entry is copied as is.
   - A problem is a line whose id is not in `names`. Leave that line untouched and add `"<file>: <id> is not a catalog id"`.

   **`rewrite_audio`.** It only looks between the line `  cards: {` and the next line starting `  }`. An entry line is `    "<id>": {`, followed by nothing or by ` // …`. It becomes `    "<id>": { // <name>` (`{{` in `format!`). Lines at six spaces are not entries.

   **`rewrite_yaml`.** An entry line is one that does not start with a space, `#` or tab, is not empty, and is `<id>:` followed by nothing or ` # …`. It becomes `<id>: # <name>`. Skip the id `emotes`.

   **`rewrite_fx`.** An entry line starts with exactly two spaces and a quote. The id runs to the next `"`, then comes `": `, then the value.
   - If the rest holds `", // "`, take the value from before its last occurrence (`rfind`). Otherwise, if it ends with `,`, drop that comma. Otherwise report `"<id>: no trailing comma"`.
   - Rewrite the line as `  "<id>": <value>, // <name>`. Header comments (`//…`), `{` and `}` are not entries.
