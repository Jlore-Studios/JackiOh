## Risks

- **Golden traces (D14).** Every new field is an `Option` that is skipped when absent, and no shipped card uses the new variants. A golden diff means something leaked into shipped games.
- **Determinism.** The presets read only the match rng. The compiler is a pure function of the recipe and uses no `HashMap`. The id hashes JSON whose field order is fixed.
- **`param` panics on an undeclared key.** The def compiler and the script compiler must number the `bK` params through one shared walk.
- **Hidden information.** The options go only to the prompt's holder. The hand card stays a sentinel to the opponent (R97). The AI's `redact` drops transient defs that nothing visible references (`observe.rs`:540–572).
- **Fuzz.** Fuzz previews every set, so the random policy will cast #17. Replay a failing seed with `fuzz --from <seed> --seeds 1`.

## Open questions

Nothing here blocks the build. These are the defaults, each with the alternative it rejects:
- **Id.** It is always a digest, and the def keeps the recipe. Rejected: spelling the recipe out in the id below `FUSED_ID_CAP`, which needs a writer that the def's copy makes redundant.
- **Targets.** Only Cry and When cast take targeted blocks. Rejected: aiming a reveal hat's block at the card that triggered it.
- **Armor and Echo.** They are not params. Rejected: new engine tuning for keyword numbers.
- **Waiting text.** The opponent sees the generic "Your opponent is choosing…". Rejected: adding `kind` to `PendingElsewhereView`.
- **Input.** Click, tap and keyboard; no drag. Rejected: HTML5 drag, which fails on touch and with the keyboard.
- **Names.** The two word lists are the planner's choice; the designer may replace them.
