# Plan (sonnet, medium)

## Goal

A replay labels the other side as the replays list and the live game do, not as a bare "Opponent".

- `ReplayPlayer` takes an optional `opponentLabel`. It goes to `Game`'s `enemyLabel` (the opponent hero's seat label) and to `ModifierList`'s `opponentLabel`. Without it, both stay "Opponent".
- The replays list fills it from the row. An online row gets the username, or "a deleted account" when the username is empty. A practice row gets the AI's label.
- A practice game's result replay uses the live board's label. A match result's replay uses the opponent's name from the match screen's ranks read.
- A long name is cut with an ellipsis in `.hero-seat`.
- A friend's shared replay (`TogetherRoute`), the shared GIF, JSON-opened replays and co-op replays are unchanged.
