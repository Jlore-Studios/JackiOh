## Risks

- **Hidden information (rule 7):** the tile shows only the validator's existing verdict; it reads no new data.
- **i18n patterns:** each new key has at least two words of its own, so `t()` may try it as a pattern on other sentences. None of the engine's or the server's sentences has their shape, and the tokens match in English and Chinese (the `i18n.test.ts` token check).
- **The tile's `aria-label`:** it grows only on a tile in error. No test or e2e spec finds a tile by its accessible name: tests use test ids, and B38's deck has no per-card error.
- **CSS:** the B30 test in `browse.test.tsx` forbids sticky or fixed positioning, and the new rules add neither. The button rule keeps the `.deckbuilder.app-shell` scope.
- **Conflicts:** no open pull request touching these files is known, but the planner has no GitHub access to check.
