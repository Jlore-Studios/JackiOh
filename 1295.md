# Plan (opus, strong)

## Goal

A player picks three per-card cosmetics in settings: a foil, a finish and a border.
- **Storage:** the picks live in a `cosmetics` settings group, synced to the account like the other groups (R633).
- **Who wears them:** only the viewer's own cards, on a board the viewer plays. Every other face, the opponent's included, draws as it does today.
- **Registry:** `crates/server/cosmetics.json`. Rust checks it and generates it into `apps/web/src/wire/generated/cosmetics.ts`.
- **On the face:**
  - Each cosmetic has its own attribute; none uses `data-foil`.
  - No border uses a Radiant gold.
  - Every foil has a still version for reduced motion.
  - A named cap limits how many faces animate at once.
  - An unknown id draws as its kind's default.
- **Ruling:** R1295000.
