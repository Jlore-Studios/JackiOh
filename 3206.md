- Add `type Flight = { controller: AbortController; waiting: number; answer: Promise<unknown> }` and `const flights = new Map<string, Flight>()`.
- `async function sharedGet<T>(path, token, outer)`:
  1. If `outer?.aborted === true`, `throw new ApiUnreachableError(outer.reason)` and send nothing.
  2. `key = \`${String(writeEpoch())}\n${token ?? ""}\n${path}\``. The epoch means a read asked after any write never joins one sent before it. The token means never across tokens.
  3. No flight for the key: make `controller = new AbortController()` and `made = { controller, waiting: 0, answer: send<unknown>(path, { token, signal: controller.signal }) }`. Store it, then `const settled = () => { if (flights.get(key) === made) flights.delete(key); }; void made.answer.then(settled, settled);`.
  4. `waiting += 1`.
  5. Build `aborted = new Promise<never>((_, reject) => { onAbort = () => { … } })`. `onAbort` does `waiting -= 1`; at 0 it calls `controller.abort()` and deletes the key if it is still this flight; it then rejects with `new ApiUnreachableError(outer?.reason)`, which is what an aborted caller got before.
  6. `outer?.addEventListener("abort", onAbort, { once: true })`.
  7. `try { return (await Promise.race([flight.answer, aborted])) as T; } finally { outer?.removeEventListener("abort", onAbort); }`. This race pattern is already in `send`.
- The shared flight runs on its own controller, so one caller's abort never reaches the fetch while another still waits. Callers share the answer object, as they already share the kept one.
