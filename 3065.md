# Plan (sonnet, medium)

## Goal

`cargo jackioh run-sim --seeds N [--from K] [--skill S] [--budget tiny|full]` plays seeded whole dungeon runs on the real catalog's content. Each fight comes from `run_fight_setup`. The player's seat is the AI at R747000's skill, and the enemy is the AI at full skill with the same budget. The result goes back through `run_fight_report`. Map, pack, shop, campfire and event choices follow a small seeded policy. The command prints, per skill:

- win rate, HP lost and turns, by node kind
- HP entering each boss
- rows reached
- score and Embers

To make that possible, `MatchSetup` gains an optional `deck_marks` (R2702000) that `play_match` and `fold_args` pass through. Without marks, every game is created and folded exactly as today. No strawman number in `crates/run/src/config.rs` changes.
