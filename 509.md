# Plan (opus, strong)

## Goal

The practice worker keeps each finished free game. It does not keep a tutorial lesson or a game Glitch voided. It keeps the newest `PRACTICE_REPLAYS_KEPT` games, in the same store as R668's save. Each kept game holds its config, log, catalog version, final hash, the seat the human ended in, and a summary: when it ended, the human's result, turns, steps and both portraits.

Two new requests are added:
- `replays` returns the summaries, newest first. A game played on another catalog version, or one that no longer folds to its hash, is marked `unavailable` with part 1's reason.
- `replay { game, from, count }` returns a page of the human's steps from part 1's `replayOpen`/`replayPage`, plus the total.

Both are refused while a game is in progress. A request for an unavailable game is refused with its reason. Nothing kept ever crosses to the page: no log, seed, deck or state.

R768 lists the new tests in its `proven_in`. Nothing on screen changes, and neither do R668's save and resume, the snapshot, or how a game plays.
