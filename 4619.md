## 6. Risks.

- **Spent history entries:** In browsers without `CloseWatcher` (Safari, Firefox), closing via corner arrow leaves a spent history entry. `net/backLayers.ts` already steps over spent entries (`answerPop()`); the dedicated corner arrow test ensures no regressions.
- **Link-opened replay navigation:** A replay opened via `?replay=` link uses replacing navigation on leave (`navigate(sharedWithMePath(), { replace: true, force: true })`). `moveOverBackEntry` in `backLayers.ts` replaces the entry cleanly so first Back stays on Shared with me and second Back leaves.
- **Mounting position:** Mounting `<BackLayer>` at each host call site rather than inside `ReplayPlayer` avoids double-layer bugs and ensures loading and failure states in `OpenedReplay` are properly covered with exactly one layer.

## 6. Risks.

- **Spent history entries:** In browsers without `CloseWatcher` (Safari, Firefox), closing via corner arrow leaves a spent history entry. `net/backLayers.ts` already steps over spent entries (`answerPop()`); the dedicated corner arrow test ensures no regressions.
- **Link-opened replay navigation:** A replay opened via `?replay=` link uses replacing navigation on leave (`navigate(sharedWithMePath(), { replace: true, force: true })`). `moveOverBackEntry` in `backLayers.ts` replaces the entry cleanly so first Back stays on Shared with me and second Back leaves.
- **Mounting position:** Mounting `<BackLayer>` at each host call site rather than inside `ReplayPlayer` avoids double-layer bugs and ensures loading and failure states in `OpenedReplay` are properly covered with exactly one layer.
