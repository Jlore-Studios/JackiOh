## Risks

- Headless CI timing flake: mitigated by the 5× headroom recipe, durations in seconds (not frame counts), judging only p95 + long-tasks, and keeping the spec out of the PR smoke list (daily-only, like other statistical suites).
- Cypress `trigger("mouseover")` does not always engage CSS `:hover`: the idle phase dispatches real `MouseEvent`s on the minion and records that hover-driven costs are approximated, not pointer-exact.
- Ten 1–4-cost units plus traps exceed one turn's mana even with `manaBonus`: the fixture sizes the handicap for a two-turn setup and asserts counts, so a bad seed or catalog change fails loudly in setup, not in measurement.
- `document.getAnimations()` counts compositor + CSS animations alike: reported only, never judged, so browser animation-count differences cannot flake the gate.
