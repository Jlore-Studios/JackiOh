## Risks

- **Hashes and golden traces.** Every new field is an `Option` that is skipped when `None`. The flag is only `Some(true)`, and the memory key is written only for a cooldown ability. Never write `Some(false)` or `Some(0)`.
- **Double halving.** The flag must be cleared on the recursive call; the redirect paths reuse `args`.
- **Hidden information.** `tribute_mod` is cleared in every placeholder. The Discover options go only to the chooser, as every Discover's do. The resume data rides no view.
- **Determinism.** Draws use `ctx.sink.rng` only, over `catalog::query`'s ordered list.
- **Generated files.** CI's `rust` fails if `jackioh.luau` or `wire/generated/` differs.
- **Shared surfaces.** `state.rs`, `script.rs` and the effects are edited by other phase-0 issues (M01, M03, M06). Keep each edit local.
