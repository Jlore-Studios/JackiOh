````markdown
## Goal

A match socket that dies without a close is found and dropped, so its seat's 60 s grace starts and the opponent is shown it. Done means:

1. `pump` sends a ping every `WS_PING_INTERVAL_SECONDS`. It drops a socket that has sent no frame of any kind for `WS_IDLE_TIMEOUT_SECONDS`, through the normal transport-closed path.
2. The outbox is capped at `WS_OUTBOX_MAX_FRAMES`. Overflowing it closes the socket instead of growing the queue.
3. When the tab turns visible or the network comes back, the client replaces a silent socket, and the new socket sends `hello`. The reconnect backoff gets jitter.

/// Queues one frame for the transport. False when the outbox is full (§9.8, R1437): it is let go,
/// so the transport sends what it holds and ends the connection. A transport already gone counts
/// as queued; its own close reports it.
fn queue(&self, frame: SocketFrame) -> bool {
    let mut out = lock(&self.inner.out);
    let full = matches!(
        out.as_ref().map(|sender| sender.try_send(frame)),
        Some(Err(mpsc::error::TrySendError::Full(_)))
    );
    if full {
        *out = None;
    }
    !full
}
```
````
