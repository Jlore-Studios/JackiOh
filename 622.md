A match socket that dies without a close is found and dropped, so its seat's 60 s grace starts and the opponent is shown it. Done means:

- **No rule is touched:** the probe is a `hello`, which the actor answers with a full view and no side effects (`match_actor.rs:391`).

## Decisions

- **Probe rather than replace.** Browsers hide pings from the page, so to JS a healthy socket in a quiet turn looks silent. Rejected: replacing it at once, which would flash the opponent's grace countdown on every tab switch.
- **Drop, not close, on idle.** A dead peer cannot finish a closing handshake. Rejected: sending a close frame and waiting out `CLOSE_HANDSHAKE_TIMEOUT`.
- **An overflow lets go of the sender.** Rejected: aborting the pump task, which would need a stored `AbortHandle`.
- **Heartbeat in `pump` only.** In-memory sockets get no pings, so the paused-clock actor tests are unaffected. Rejected: a transport trait (the server has no traits).
- **All three constants are exported**, as the acceptance criteria ask, though the client reads only the interval.
- **Jitter only adds time**, so the first retry stays at 250 ms or more.
