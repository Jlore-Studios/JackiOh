## Design decisions (so far)
- TheirCopyContext lives in cards/cosmetics.ts (beside OwnershipContext) to avoid a runtime import cycle
  cosmetics.ts <-> loadouts.ts; it carries the owner's whole SeatLoadout (seat picks + cards map), and a
  face reads `cards[face.defId]`, so a related face in an overlay keys on its own def (as own copies do).
- "viewer's own" with the setting off = the wearer on a live board, else the view's viewer (bottom seat)
  on replay/watch: only the top half goes plain.
- net.ts keeps seat picks and card picks privately so a cardLoadouts frame before loadouts is not lost;
  snapshot.loadouts null until the first loadouts frame.
- opponent playmat: real element `.field-their-mat` (first child of .field) since .field::after is the centre line.
