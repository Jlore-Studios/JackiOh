1. **`config.ts`: add three constants** beside `LOG_HISTORY_LIMIT`, each with a one-line comment citing #4614: `LOG_OVERSCAN_ROWS = 10` (mounted rows past each viewport edge; rows not viewport-multiples, since row heights vary — rejected `POOL_OVERSCAN`-style multiples as the wrong unit); `LOG_ROW_ESTIMATE_PX = 24` (unmeasured-row estimate, corrected on measure); `LOG_PIN_TOLERANCE_PX = 8` (how close to the bottom counts as pinned).
2. **`logWindow.ts` (new): pure arithmetic, no DOM writes.** Types: `LogWindow = { first: number; last: number }`. `logWindow(count, heightAt: (index: number) => number, scrollTop: number, viewport: number, overscanRows: number): LogWindow` — walk cumulative offsets from `heightAt` (measured height or the estimate), find the visible range, extend by `overscanRows` rows each side, clamp to `[0, count-1]`. `logSpacers(count, heightAt, window): { head: number; tail: number }` — summed heights before `first` and after `last`. `sameLogWindow` / `fitLogWindow` (copy `sameWindow`/`fitWindow` from `poolWindow.ts`). `readLogViewport(list: HTMLElement): { scrollTop: number; clientHeight: number } | null` — return `null` when `clientHeight === 0` (no layout, e.g. jsdom), so callers draw everything, mirroring `readShape` returning `null`. Row heights are read by the hook (step 3), not here. Nothing here touches the pool's grid arithmetic.
3. **`useLogWindow.ts` (new): copy the shape of `usePoolWindow.ts`.** Signature: `useLogWindow(ref: RefObject<HTMLOListElement | null>, keys: readonly string[], heldKey: string | null): LogWindow | "all" | null`. State `view` starts `null` (mount everything on first render, as the pool does with `POOL_FIRST_CARDS`-equivalent full draw — here just all rows, since 1000 plain rows paint once cheaply). `measure(reshape)` reads `readLogViewport`; on `null` sets `"all"`. Otherwise builds `heightAt` from a `Map<key, height>` ref (missing keys use `LOG_ROW_ESTIMATE_PX`) plus the divider allowance below, and returns `fitLogWindow(logWindow(...))` with the held key's index unioned in (held always mounted, the `CardGrid` precedent). Listeners: the list's own `scroll` (the `ol` is the scroller) plus document-capture scroll (popover ancestors), window `resize` with `flushSync` (copy the pool), and a `ResizeObserver` on the list. Per-row measurement: a layout effect queries `li[data-log-key]` in the list, records `getBoundingClientRect().height` into the map (adding the matching `li[data-log-divider]` height for turn-divider rows), observes each row with the same observer, and re-measures when `keys` change. Return `"all"` handling identical to the pool.
4. **`Log.tsx`: wire the window around the existing `shown` array.** Compute `shown` exactly as today. Derive `keys = shown.map(line => line.key)`. Track `heldKey: string | null` with `onFocus`/`onBlur` on the `ol` (copy `CardGrid`: focus sets from `event.target.closest("[data-log-key]")`, blur clears when focus leaves the list) so a row with an open inspect sheet or focus stays mounted; rejected alternative was unmounting it, which would drop focus and close the sheet. `const window = useLogWindow(listRef, keys, heldKey)`; mount indices `first..last` when windowed, all rows when `null`/`"all"`. Render order inside the `ol`: head spacer `li`, mounted rows, tail spacer `li`. Spacers: `<li className="log-spacer" aria-hidden="true" style={{ height: N }} />` with `display: block` (the existing `.log-divider` precedent, which keeps them out of the `decimal` numbering). First mounted row's `LogItem` `li` gets `value={wholeIndex + 1}` so visible numbers keep whole-log numbering; dividers keep their current sibling-`li` form but gain `data-log-divider={line.key}`, and `LogItem`'s `li` gains `data-log-key={line.key}` plus an optional `value` prop. Keep `useDeferredValue`, the memoised `lines`/`faces`, `useLogHistory`, and the announcer reading `shown`'s newest (not the mounted slice). Pinning: keep the existing `useLayoutEffect` on `[view.events, revealed]`; add a `pinnedRef` set in the scroll handler (`scrollHeight - scrollTop - clientHeight <= LOG_PIN_TOLERANCE_PX`) and a layout effect on the window that re-pins (`scrollTop = scrollHeight`) only when pinned, so arrivals extend the tail spacer without jitter.
