## Risks

- **Deadlock or held lock.** `drop(core)` must come before `on_reduce_panicked` and before any `.await`.
- **The checkpoint.** Never put a panicked nonce into `acks`.
- **Hidden information.** The panic text goes only to the private `*.action.panicked` log line; the report carries seq, seat and type only.
- **Determinism and replay.** Nothing is logged for a panic, so `(seed, log)` is untouched. `with_shipped` restores its catalog through a drop guard, so it is sound after an unwind.
- **Ladder bots.** A bot's retry at the same seq gets the kept answer until its turn clock times it out; this is intended (see the ruling).
- **What players see.** A match ended this way has no result in its state, so a reconnecting client sees the board as it stood, as after a reaper draw today.
- **Co-op test overrides.** They are scripts only, on the test thread; `deck_where`'s catalog is unchanged, so the room's deck checks still pass.
