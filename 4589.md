1. Create `crates/engine/src/recursion_log.rs`. It is pure; its header cites R4589000, R4589001 and R4589004.
   - **Types**, with the same derives and ts export as `GameLog`:
     - `pub struct RecursionLog { pub played: Vec<FaceUpRecord>, pub deaths: Vec<DeathRecord> }`, deriving `Default`, each field `#[serde(default, skip_serializing_if = "Vec::is_empty")]`;
     - `pub struct DeathRecord { pub def_id: String, pub radiant: bool, pub turn: i32 }`.
   - **Gate** `fn kept(state: &GameState) -> bool`. It is true when either player's `recursion` is `Some`, or when `crate::state::every_instance(state)` holds a card whose `crate::catalog::find_def(Some(state), &card.def_id)` has `set == SetName::InfiniteAssault`.
     - Doc: games of shipped sets never hold an IA card, so no recorded game's hash moves (D14, R768).
     - Do **not** gate on `set_is_open`: it is never true for a single-player set, so the log would stay off in the real Assault.
   - **Writers.** Each returns at once unless `kept(state)`. The first write creates `Some(RecursionLog::default())` on **both** players.
     - `pub fn note_play(state: &mut GameState, player: PlayerId, record: &PlayRecord, type_: CardType)` pushes `FaceUpRecord { def_id, radiant, type_, chinese: None }`.
     - `pub fn note_death(state: &mut GameState, died: &GameEvent)`: for a `GameEvent::Destroyed { def_id, controller, radiant, .. }`, it pushes `DeathRecord { def_id, radiant: *radiant == Some(true), turn: state.turn }` onto `controller`'s log.
   - **Reads**, each taking `(state: &GameState, player: PlayerId)` and returning empty when there is no log:
     - `played_this_game -> Vec<FaceUpRecord>`;
     - `deaths_this_game -> Vec<DeathRecord>`;

     - `deaths_since_last_turn -> Vec<DeathRecord>`: records with `turn >= state.turn - SINCE_LAST_TURN`.
