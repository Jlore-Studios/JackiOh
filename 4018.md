## Tests

All tests are in `crates/server/src/username/mod.rs`, `mod tests`. `use super::*;` already covers the names used.

**`r1434_the_key_of_a_name_is_stable_when_applied_twice`.** For every `c` in `(0..=0xFFFF_u32).filter_map(char::from_u32)` (surrogates drop out) and each `typed` in `[c.to_string(), format!("a{c}")]`:
- skip `typed` when `normalize_username(&typed)` is `Err`, otherwise count it as accepted;
- property 1: `username_key(&username_key(&typed)) == username_key(&typed)`;
- property 2: `normalize_username(&stored)` is `Ok(again)` with `again == stored` and `username_key(&again) == username_key(&stored)`.

Failures go into a `Vec<String>` and are reported together, so the message names every character:

```rust
failures.push(format!("U+{:04X} {typed:?}: key {key:?} is not its own key", u32::from(c)));
// and, in the property-2 mismatch arm:
format!("U+{:04X} {typed:?}: stored {stored:?} normalizes again to {other:?}", u32::from(c))
```

Then two asserts:
- `assert!(accepted >= 1_000, "only {accepted} names were accepted");` guards against a vacuous pass, since 2,840 are accepted today.
- `assert!(failures.is_empty(), "{} of {accepted}: {failures:#?}", failures.len());`.

Write the body as:

```rust
let mut accepted = 0_usize;
let mut failures: Vec<String> = Vec::new();
for c in (0..=0xFFFF_u32).filter_map(char::from_u32) {
    // R1434's stability is held on the character alone and after a base letter.
    for typed in [c.to_string(), format!("a{c}")] {
        let Ok(stored) = normalize_username(&typed) else { continue };
        accepted += 1;
        let key = username_key(&typed);
        if username_key(&key) != key { failures.push(/* as above */); }
        match normalize_username(&stored) {
            Ok(again) if again == stored && username_key(&again) == username_key(&stored) => {}
            other => failures.push(/* as above */),
        }
    }
}
```
