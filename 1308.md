````markdown
# Plan (opus, strong)

## Goal

On `/account`, tearing or tapping a sealed pack sends `POST /api/packs/open`. Once the server answers, the pack glows in its best rarity and its cards turn over one at a time. Epic and above turn only after a hold. Each card says what it became, with a stinger and fx. A panel shows the odds and pity from `GET /api/packs`, before an opening and after it. The scene has:
- skip-all;
- a Reduce Motion path;
- batch opening;
- a failed open that leaves the pack sealed.

No route lists the unopened packs held, so `GET /api/packs` will also list them.

/// The unopened card packs the account holds (§14.3), for the pack screen's batch opening: one
/// `{ pack, count }` per kind it holds any of, the global pack first, then each shipped set's.
fn unopened_from(inventory: &[InventoryEntry]) -> Vec<Value> {
    std::iter::once(PackKind::Global)
        .chain(SHIPPED_SETS.into_iter().map(PackKind::Set))
        .filter_map(|pack| {
            let (item, key) = inventory_of(pack);
            let count = inventory
                .iter()
                .find(|entry| entry.item == item && entry.key == key)
                .map_or(0, |entry| entry.count);
            (count > 0).then(|| json!({ "pack": pack.name(), "count": count }))
        })
        .collect()
}
```
````
