# Plan (opus, strong)

## Goal

A watcher's socket on `/ws/watch` gets the same two guards a player's socket has, and both live in a `SeatGuard` of its own:
- **Hellos:** a burst of later hellos gets back a bounded number of view frames. At most one is answered per `WATCH_HELLO_INTERVAL_MS`, and the players' actions keep landing meanwhile.
- **Junk:** frames that are not a hello count against `MALFORMED_FRAMES_PER_WINDOW` and still get no reply. The eleventh closes the socket with 1008, and the players hear the new watcher count.
- **Ruling:** this is a new decision, so it gets ruling R2609000. The existing R1103000 tests keep passing.
