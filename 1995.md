# Plan (opus, strong)

**Goal.** The practice AI counts what a countdown on the board will do: its own as a payoff, the enemy's as a threat, discounted for each turn still to wait. A countdown is an effect "in N turns" that shows a public badge (R1181000); today only Meditative+ #4 Jlockeed's Supply Drop makes one. There is no engine change. Done means:
1. Holding Supply Drop with 2 mana against three enemy units with 3 health, the AI casts it in Combat mode. On `main` it ends its turn instead.
2. Facing an enemy Combat countdown due at the enemy's next turn start, or the one after, the AI scores a 3-health unit on its field below the same unit held in hand.
3. With no countdown waiting, every score, node count and decision is as before.
4. `cargo jackioh sweep meditativeplus-004` and the timing gate have been run and their results reported.

**How it works.** `reply::reply_score` scores every finalist after the opponent's reply. Its callers are `decide.rs:510` and `search.rs:393`.
- **What is already priced.** The state it starts from (`end`) is already past the enemy's next turn start. An enemy badge reading "in 1 turn" has therefore already fired, so it is priced today. The reply then stops at the seat's next turn start.
- **The second reply.** When the state after the reply (`after`) still holds a countdown, the reply runs again on a copy of `end`. In the copy, those entries come due at the seat's next turn start. Only public badges count (`jackioh_engine::has_countdown`, R169, R185). The engine runs each entry as its owner (`turn.rs` `run_due_entry`).
- **The blend.** The two scores are blended as `first + share^wait · (second − first)`. `wait` is how many turns the farthest entry still waits past its owner's next turn start.
- **Resulting weights.** The AI's own fresh cast weighs 0.5. An enemy blast landing right after the AI's next turn weighs 1.

I built this design on a scratch copy of `main`, and everything under **Tests** passed there.

   ```rust
       let after = simulate_reply(end, seat, counter, hidden)?;
       let first = replied_score(end, &after, seat, unspent);
       // #1995: a countdown still waiting at the seat's next decision is scored a second time, fired.
       let Some((fired, wait)) = countdowns_due(end, &after, seat) else {
           return Some(first);
       };
       let refired = simulate_reply(&fired, seat, counter, hidden)?;
       let second = replied_score(end, &refired, seat, unspent);
       let share = (0..wait).fold(1.0, |share, _| share * AI_REPLY.countdown_share);
       Some(first + share * (second - first))
   }

   /// A passed line's score at `after`, where the reply from `end` stopped: the finalists' evaluation
   /// with whoever swings next, less the crystals the line left `unspent`.
   fn replied_score(end: &GameState, after: &GameState, seat: PlayerId, unspent: i32) -> f64 {
       let next = if after.active == seat {
           NextSwing::Seat
       } else {
           NextSwing::Enemy
       };
       // R844, §2.3: the coming refreshes count as the line's end priced them (`coming_mana`): what the
       // reply's refreshes spent (lost, or moved by a rider) still counts, and what the reply set does not.
       let spent = if after.result.is_none() {
           coming_mana(end, seat, &AI_EVAL) - coming_mana(after, seat, &AI_EVAL)
       } else {
           0.0
       };
       finalist_score(after, seat, next) + spent - AI_EVAL.unspent_mana * f64::from(unspent)
   }

   /// #1995: `end` with every countdown still waiting at `after` (an entry with its public badge, R1181000,
   /// R169: nothing hidden, R185) due at the seat's next turn start, where the reply ends, so the reply
   /// fires it through `reduce` as its owner; and how many turns the farthest of them still waits past
   /// its owner's next turn start, which `AI_REPLY.countdown_share` is raised to. `None` when none waits.
   fn countdowns_due(end: &GameState, after: &GameState, seat: PlayerId) -> Option<(GameState, i32)> {
       if !after.delayed.iter().any(has_countdown) {
           return None;
       }
       let mut fired = end.clone();
       let mut wait: Option<i32> = None;
       for entry in fired.delayed.iter_mut().filter(|entry| has_countdown(entry)) {
           let Some(due) = after
               .delayed
               .iter()
               .find(|waiting| waiting.id == entry.id)
               .and_then(|waiting| waiting.due_own_turn)
           else {
               continue;
           };
           let past_next = (due - after.players[entry.at.player].turns_started - 1).max(0);
           wait = Some(wait.map_or(past_next, |farthest| farthest.max(past_next)));
           entry.at = DelayedAt {
               phase: Phase::Start,
               player: seat,
           };
           entry.due_own_turn = Some(end.players[seat].turns_started + 1);
           entry.not_before = None;
       }
       wait.map(|wait| (fired, wait))
   }
   ```
   Keep the fold. `f64::powi`'s precision is unspecified, so the native and WASM builds could diverge.
