## Risks

- **Re-running #2834's jobs** rebuilds the same broken merge commit and stays red. Close the issue instead (step 3).
- **A shared target dir fools cargo.** If you reproduce this locally with `git archive` trees in a shared `CARGO_TARGET_DIR`, cargo can reuse stale artifacts. `git archive` stamps files with the commit's time, older than the artifacts already built. Cargo's fingerprints then see them as fresh, and the hash of a path package is relative to its workspace. I got a spurious `E0432 DeckMark` this way. Give each tree its own `CARGO_TARGET_DIR`. I cleaned what my runs left in the shared target (`cargo clean --release --target wasm32-unknown-unknown -p jackioh-engine -p jackioh-cards -p jackioh-ai -p jackioh-run -p jackioh-wasm-core -p jackioh-wasm`) and removed the trees.
- **If `main` breaks again** before the new promotion's CI runs, that promotion gets stuck the same way, and the watch opens a new issue for it.
- **No determinism, replay, hidden-information or README contract is touched**, because nothing in the repository changes.
