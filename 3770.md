## Risks

- **Existing callers.** `reap_stuck_matches` and `seats::reconcile` keep their signatures, so the tests in `tests/api/results.rs`, `tests/actor/*` and `tests/api/seats.rs` are untouched. Do not change `SeriesSweep` or `SweepReport`.

- **Restarts reset the count.** The streak lives in the loop's future, so a restart or the container's idle sleep resets it, as `ALERT_WINDOW_MS` is per process. A purge failing on a server that keeps sleeping is not caught. Persisting it would need a table, which is out of scope.
- **Noise.** One alert per streak, plus the hourly `ALERT_WINDOW_MS` cap per event.
- **Decisions the issue left open:**
  - Recovery is logged only after a streak that alerted. Rejected: a line for every blip, which is noise next to the existing warning.
