## Risks

- **A negative check passes vacuously.** `s.plays_of` and `s.can_play` ask the owner. A "not offered" check that asked another seat must keep `plays_in` with that seat (step 6's shorthand rule).
- **A def id names only the first copy:** the active player's, hand first, then the field and the other zones. Where the old code looped over copies or found the card by a hand lookup, keep the instance.
- **The card is gone.** The new methods panic on a card in no zone, as `card()` does; old code that held an id did not. Switch any such site to `plays_in`.
- **Merge conflicts** with open card PRs. Each step is green on its own, so a run that is cut off resumes at the next step.
- **Build time.** `jackioh-cards` compiles about 1,000 scripts, so finish a whole tree before compiling. Subagents may edit disjoint files in this worktree, but only you run cargo.
- **Determinism, replay and hidden information** are untouched: the helpers only read `legal_actions`.
