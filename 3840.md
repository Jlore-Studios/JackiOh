## Risks

- **Existing tests that count reads.** Intervals fire only after 60 s of real time, so tests that count reads do not move. Fake-timer tests in the new describes restore real timers in `afterEach`.
- **Read racing a send.** The board skips a tick while its own POST is in flight. A read that started just before a send can still return after the send's answer and show the older `seq`. This is rare and heals on the next read or on the `stale` refusal that rereads (`DailyBoard.tsx` `send`). A seq guard was not added, to keep the change minimal.
- **Load.** One `GET` a minute per visible daily tab is far under R109's 300 requests a minute per account. A hidden tab sends none (R3205000). A board reads the game by loading and folding it, which is the same cost as any board read.
