## Risks

- **Signature leak.** Never read `trace` in `signature_of` or in grouping. The planted-grower test asserts this.
- **Cost on passing seeds.**
  - Build traces only in the failure branches.
  - The before-step action comes from a closure.
  - The branch events are cloned inside the finding loop only.
- **Flood.** A thousands-event step serializes only the head and tail slices. Counts use `event_type()` without serializing.
- **Determinism.** The by-type sort (count descending, then name) and the numbering are seed-pure, so a replay prints the same bytes.
- **Borrowing.** In the after-step site, `log` must have the action pushed before `after_step`, and `result.events` must not have been moved yet. Keep `last_events = result.events` last.
- **Other callers.** The `listed_refused` and `listed` signatures stay, so the cards' and engine's tests compile unchanged.
