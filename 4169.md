# Goal

Enable live co-op and 2v2 matches to checkpoint their engine state on shutdown drain and periodically during play, so server restarts and crashed actors resume by folding only later actions rather than the entire action log. The checkpoint is verified on rebuild against rules fingerprint, catalog version, log position, and payload hash (falling back to a full log fold on any refusal), and is removed when the match ends.
