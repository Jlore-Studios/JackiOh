# Plan (sonnet, medium)

## Goal

Uncached replay opens, 1v1 and co-op together, run through a server-wide fold permit (`REPLAY_FOLDS_RUNNING_MAX` = 1). An open waits a bounded time (`REPLAY_FOLD_WAIT_MS`) and is then refused with 429 `rate_limited` carrying `retryAfterMs` (R192). Concurrent opens of one match share one fold. The practice open-seed count (`PRACTICE_SEEDS_OPEN_MAX`) then covers a claim that is burned but not yet settled, in both stores, and stops at the seed's lifetime. The retention sweep skips a claim whose settle is still running in this process. Two rulings, R3500000 and R3500001, and §9.8, §14.8 and the server README state all of it. Cached replay pages and an honest player's one-at-a-time claims behave as today.
