# Meditative and Meditative+ card animations (#2796)

The per-card table of #2796's pass over `meditative.json5` and `meditativeplus.json5`, every card of
both, tokens included, in file order (`meditative.test.ts` holds it to the tables). **Census** is
`cargo jackioh fx census --format json` (#2788) on this branch's build: each hook's suggested motif.
**Scale** is `motifScale` at intensity 1 (rarity × cost, `fx/motifs/build.ts`). **Why** names what the
motif reads, the palette's sub-look line (docs/polish/9-card-animations.md, Sub-looks) and any override
of the census, lettered as the pull request lists them:

- (a) the census picked `bolt` or `vanish` from a few hits that were fatigue, the turn's draws or another card's;
- (b) the card's own commonest event wins;
- (c) the play shows nothing, so `cast` names the motif of the card's own hook or of its aura's family;
- (d) a Trap's hits are combat damage, which `readEvents` skips, so `snap` reads its `trapFired`;
- (e) the census never saw the hook;
- (f) each Felinor rises where the last one stood;
- (g) the R2784000 examples are kept.

Set piece candidates, each with a motif for now: Meditative #34 高考 (`wipe`), #78 Occidentless Mandate
(`vanish`) and #45.1 Knowledge Breaker Prime (`wipe`).
