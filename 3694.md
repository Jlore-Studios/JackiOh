## Goal

When a finished match's rematch window ends (`finished_at + REMATCH_OFFER_TTL_MS`), each reaper tick closes the match's open seat and watcher sockets with a new final close code, `MATCH_OVER_CLOSE_CODE` (4411). The same tick evicts the actor, so the match leaves memory and the server can sleep. This covers 1v1 (`finished_at`, R672/R1285000) and co-op (`ended_at`, R1398000). The 1v1 clock is the actor's `finished_at`, which is reset when a finished match is rebuilt.

The clients never reconnect on 4411 (as with R679's 4410). They keep the result panel with no error line and no rematch offer. A new ruling R3694000 records the rule, and its note names its tests.
