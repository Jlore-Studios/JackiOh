# Plan (opus, strong)

**Goal.** In a Duos duel, `starting_health_of` answers the own HP the seat started on, which is its team's `own_health` (20 on every real team's rules), whether or not the seat is spent. So Stinkyscape #18.2 BALTHASAR votes only below half of 20 (at 9 or less). The seat's starting own HP is stored on `DuosLife`. `duos_seat` writes it, so a Glitch reset writes it again. The field is serde-defaulted, so stored co-op states still load. A new ruling, R4831000, settles what a *spent* seat's starting health is (still its own start, not the pool's cap) and amends R1866002.
