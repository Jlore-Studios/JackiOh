# Plan (opus, strong)

I've finished the plan. The change is client-only plus one ruling, so medium fits. I made three scope decisions that a person may overrule; they are listed under Open questions.

## Goal

`InspectSheet`, `FaceDownSheet` and `CardListSheet` close on a touch swipe down. A drag may start on the grip, on the pile sheet's header, or anywhere while nothing under the finger is scrolled down. During the drag the sheet follows the finger and the scrim fades.

On release the sheet closes if it went past `SHEET_DISMISS_DISTANCE` of its height or moved faster than `SHEET_DISMISS_VELOCITY`. It closes through `useModalOverlay`'s `close`, the same path as Close, so focus goes back. Otherwise it springs back.

- Up, sideways and scrolled content are left alone.
- Under Reduce motion (the media query or the settings switch) the sheet never follows, and a swipe past a threshold closes it at once.
- The sheets stay inside the safe-area insets.
- `Prompt` and the mulligan get no swipe.
- Ruling R2121000 records all of this.

   function mayDrag(target: EventTarget, sheet: HTMLElement): boolean {
     // A portalled child (R279's tooltip) bubbles through React but is not in the sheet.
     if (!(target instanceof Element) || !sheet.contains(target)) return false;
     if (target.closest(HANDLE_SELECTOR) !== null) return true;
     for (let node: Element | null = target; node !== null; node = node.parentElement) {
       if (node.scrollTop > 0) return false;
       if (node === sheet) return true;
     }
     return false;
