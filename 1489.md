# Plan (opus, strong)

## Goal

The training arena counts each seat's fallbacks and the panics its search caught. Two things count as a fallback: an agent's "no move", and an AI decision whose `reason` is `fallback`. A caught panic keeps the first panic's message for this build's own AI; a `bin:` seat's counts come from its verbose answer. The duel line reports both. `promote` fails on any game with a refused action, a throw, a fallback, a caught panic or a replay mismatch, on either seat, whatever the wins, and names the seed and the candidate's seat. Self-play marks a game in which a seat had an action refused, fell back or caught a panic (`faults`), and `positions` leaves it out and counts it (`unclean`). The ruling R1489000 records all of this.

   /// panics its search caught, each line naming the seat. Empty when there is none.
   pub(crate) fn faults(&self) -> Vec<String> {
       let mut faults = Vec::new();
       for seat in [PlayerId::P1, PlayerId::P2] {
           let refused = self.rejected.iter().filter(|rejected| rejected.seat == seat).count();
           if refused > 0 {
               faults.push(format!("{}: {refused} refused actions", seat.as_str()));
           }
           if self.fallbacks[seat] > 0 {
               faults.push(format!("{}: {} fallbacks", seat.as_str(), self.fallbacks[seat]));
           }
           if self.sim_panics[seat] > 0 {
               let first = match &self.first_sim_panic {
                   Some(first) if first.seat == seat => format!(", the first: {}", first.message),
                   _ => String::new(),
               };
               faults.push(format!("{}: {} search panics{first}", seat.as_str(), self.sim_panics[seat]));
           }
       }
       faults
   }
