- Component `Tabs<T extends string = string>({ ... }: TabsProps<T>)`:
  - Maintains `tabRefs = useRef<Map<T, HTMLButtonElement>>(new Map())`.
  - Computes `activeItem = items.find((item) => item.id === value) ?? items[0]`.
  - Keyboard handler `onTabKeyDown`:
    - Reads enabled tab items: `const enabled = items.filter((item) => !item.disabled)`.
    - Finds current index: `at = enabled.findIndex((item) => item.id === (activeItem?.id ?? value))`.
    - Handles keys:
      - `ArrowRight`: `(at + 1) % enabled.length`
      - `ArrowLeft`: `(at - 1 + enabled.length) % enabled.length`
      - `Home`: `0`
      - `End`: `enabled.length - 1`
    - When handled, calls `event.preventDefault()`, invokes `onChange(nextItem.id)`, and focuses `tabRefs.current.get(nextItem.id)`.
  - Renders `<div className={`tabs ${className ?? ""}`.trim()}>`:
    - Tablist: `<div role="tablist" aria-label={label} data-testid={testId} className={`tabs__tablist ${tablistClassName ?? ""}`.trim()} onKeyDown={onTabKeyDown}>`.
    - Tab buttons:
      - `type="button"`, `role="tab"`
      - `id={`${idPrefix}-tab-${item.id}`}`
      - `aria-controls={`${idPrefix}-panel-${item.id}`}`
      - `aria-selected={item.id === value}`
      - `tabIndex={item.id === value ? 0 : -1}` (roving tabindex)
      - `className={`tabs__tab ${tabClassName ?? ""} ${item.className ?? ""}`.trim()}`
      - `data-testid={item.testId}`
      - `disabled={item.disabled}`
      - `onClick={() => onChange(item.id)}`
      - `ref={(node) => { if (node === null) tabRefs.current.delete(item.id); else tabRefs.current.set(item.id, node); }}`
    - Panels (if any `item.panel` is defined):
      - If `panelsClassName` or `panelsRef` is provided, wraps inside `<div className={panelsClassName} ref={panelsRef}>`.
      - If `keepMounted`: renders all items where `item.panel` is defined, with `hidden={item.id !== value}`.
      - If not `keepMounted`: renders only the panel for `activeItem` when `activeItem.panel` is defined.
      - Panel element: `const PanelTag = item.panelAs ?? (panelAs ?? "div")` with:

        - `data-testid={item.panelTestId}`
        - `className={item.panelClassName}`
