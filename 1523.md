# Plan (opus, strong)

## Goal

An in-process seat ledger (`seats.rs`, `App::seats`) holds each profile's one game across 1v1, Conquest and co-op. Every claiming door (queue pair and ladder-bot starts, room join, rematch, series game, co-op join) reserves all its seats in one step, fences its seat writes on `app.seat_epoch` and commits once its game stands. A loser gets R1065000's 409 at once; a fenced claim gets 503 and nothing is written. Advisory doors read `seats.of`, endings release their seats, boot bumps the epoch and hydrates before serving, and the reaper tick reconciles (`seats.drift`). 1. **`seats.rs`** (module doc: R1523000; the mutex never crosses an `.await`). Data types derive `Clone, Debug, PartialEq, Eq`.
   - **Types:**
     - `pub enum Seat { Match(String), Series { id: String, game: Option<String> }, Duos(String) }`
     - `pub struct Taken { pub profile: String, pub seat: Seat }`
     - `pub struct Drift { pub profile: String, pub ledger: Option<Seat>, pub record: Option<Seat> }`
     - `pub struct SeriesSeats { pub id: String, pub sides: [String; 2], pub games: Vec<String> }`
     - `pub struct DuosSeats { pub id: String, pub people: [String; 2] }`
   - **The ledger:**
     - `#[derive(Default)] pub struct Seats { inner: std::sync::Mutex<Inner>, epoch: AtomicI64 }`
     - `#[derive(Default)] struct Inner { held: HashMap<String, Held>, clock: u64, changed: HashMap<String, u64>, leases: u64 }`
     - `struct Held { seat: Seat, lease: Option<u64> }`, where `Some` means pending.
     - `Inner::touch(profile)`: `clock += 1; changed.insert(profile, clock)`.
     - Lock the mutex the way `rematch.rs::offers` does.
   - **`fn admits(held: &Held, seat: &Seat) -> bool`:**
     - false when the entry is pending;
     - true when `held.seat == *seat` (a retry);
     - true for `Series { id: a, game: None }` → `Series { id: b, game: Some(_) }` with `a == b` (its next game);
     - false otherwise.
   - **`pub fn reserve(&self, profiles: &[&str], seat: Seat) -> Result<Lease<'_>, Taken>`:**
     - Walk `profiles` in the order given. The first one whose entry fails `admits` answers `Err(Taken { profile, seat: held.seat })` and nothing changes.
     - Otherwise: `leases += 1`; set each profile pending with that id; keep its previous committed seat in `prior`; touch it.
   - **`pub struct Lease<'a> { seats: &'a Seats, id: u64, prior: Vec<(String, Option<Seat>)>, done: bool }`:**
     - `pub fn commit(mut self)`: entries still pending with `id` become committed and are touched; `done = true`.
     - `Drop`, unless `done`: entries still pending with `id` get their prior back (committed, or removed when there was none) and are touched.
   - **Reads and releases:**
     - `pub fn of(&self, profile: &str) -> Option<Seat>`: pending seats count too.
     - `pub fn release(&self, profile: &str, seat: &Seat)`: removes a committed entry only when it is the same game. `Match` and `Duos` compare by id; `Series` compares by `id` alone, whatever its `game`.
     - `pub fn end_game(&self, profile: &str, match_id: &str)`: a committed `Match(match_id)` is removed; a committed `Series { id, game: Some(match_id) }` becomes `game: None`.
     - `release` and `end_game` both touch the profile.
     - `pub fn epoch(&self) -> i64`, `pub fn set_epoch(&self, epoch: i64)`, and `pub fn mark(&self) -> u64` (answers the clock).
   - **`pub fn fill(&self, record: HashMap<String, Seat>)`:** drop every committed entry, then insert each record seat as committed unless that profile is pending.
   - **`pub fn settle(&self, record: &HashMap<String, Seat>, since: u64) -> Vec<Drift>`:**
     - For each profile in held ∪ record: skip it when `changed[p] > since` or when it is pending.
     - Where the committed seat differs from the record's, take the record's (remove the entry when the record has none) and push a `Drift`.
     - Then `changed.retain(|_, at| *at > since)`.
   - **`pub fn held_seats(seated: &[SeatedProfile], series: &[SeriesSeats], duos: &[DuosSeats]) -> HashMap<String, Seat>`:**
     - Each `seated` row → `Match(match_id)`. This takes every set flag, as the compare-and-set sees it.
     - Each series side:
       - holding `Match(m)` with `m` in `games` → `Series { id, game: Some(m) }`;
       - holding nothing → `Series { id, game: None }`;
       - holding anything else → left unchanged.
     - Each co-op person holding nothing → `Duos(id)`.
   - **`async fn read_record(app: &App) -> Result<HashMap<String, Seat>, StoreError>`:**
     - One `app.db.begin(None)` transaction.
     - Read `profiles_seated()`.
     - Read `series_active()`; `games` is each game's `match_id` plus `next_match_id`.
     - Read `duos_matches_live()`, then `duos_matches_get` for each id; `people` is `[a1, a2]`.
     - Commit, then answer `held_seats`.
   - **`pub async fn boot(app: &App) -> Result<(), StoreError>`:** `seats_bump_epoch` inside `one_tx!`, then `set_epoch`, then `hydrate`.
   - **`pub async fn hydrate(app: &App) -> Result<(), StoreError>`:** `fill(read_record)`.
