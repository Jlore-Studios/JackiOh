# Plan (sonnet, medium)

## Goal

Each of the three pointer followers handles the newest `pointermove` in one animation frame, not once per event:

- **`artLive.ts` (art aim):** reads its box and writes `--art-aim-x` and `--art-aim-y` once a frame.
- **`tilt.ts` (host, window and drag modes):** the same, for its pose.
- **`FxLayer.tsx` (shed pointer):** the same, for `setShedPointer`.

Ten moves inside one frame give one write of each aim property and at most one `getBoundingClientRect` per box, and the written aim is the last move's. A pointer leave or an unmount cancels the pending frame, so nothing is written after it.

The frame source never uses a timer (R200): a source that never fires where there is no `requestAnimationFrame`, and `FxLayer`'s `seams.frames` in its own tests. Aim, pose, hover, press and focus values are unchanged. A pointer-driven write now lands in the next frame, not inside the event.
