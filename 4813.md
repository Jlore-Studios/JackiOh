# Plan (opus, strong)

## Goal

When an AI seat's answer arrives after the game has moved on from the state it was asked on (`self.next_seq != job.version`), the Duos host drops the answer and asks the seat again on the current state, if the answer is either:
- a `Pass`, or
- an End turn while the seat's hand is no longer the hand it held when it was asked.

Every other stale move (a play or an attack inside the seat's own duel) is still played whenever the engine accepts it. A dropped move keeps the AI rng cursor it read back, so the stream moves on as it does after a refused move. The engine leaves this decision open, so it gets ruling R4813000. That ruling is proved by host tests in `crates/shared/tests/duos.rs`: both seats are asked on one state, and their answers are delivered in each order.

   fn hand_ids(state: &DuosState, seat: DuosSeat) -> Vec<String> {
       state

           .get(seat.duel())
           .map(|duel| {

   /// moved past the state it was decided on: a pass, which reads the teammate's duel, or an end of turn once

   fn decide_again_when_stale(
       state: &DuosState,
       seat: DuosSeat,
       body: &DuosActionBody,
       hand: &[String],
