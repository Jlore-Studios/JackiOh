# Plan (sonnet, medium)

## Goal

No log line of the server or the Worker keeps a socket URL's query string, so a `?token=` can't land in them, and tests hold it. The `?token=` fallback stays, because only a person may say that nothing outside this tree still uses it (CLAUDE.md rule 13). The server gains one log line for each use of the fallback: it names the path and never the query. A person can count that line to decide when the fallback goes.

**What the survey found (for the issue):**
- **Server:** every `tracing` call in `crates/server/src/actor/ws_server.rs` logs only an origin, a limit or a path. Nothing logs a `Uri`.
- **Worker:** `apps/edge/src/index.ts` and `routing.ts` never pass a request URL to `console.*`.
- **Callers in the tree:** nothing sends `?token=`. A grep of `apps/web`, `apps/edge`, `apps/admin`, `e2e`, `scripts`, `bot`, `docs`, `.github` and `crates` (outside the server's own tests) found no sender. Only `crates/server/tests/actor/ws_server.rs` sends it, on purpose.
- **Callers outside the tree:** unknown. R1379000 says production's client can run up to a day behind, and the only possible user is that older client.
- **Gap the tree cannot close:** Cloudflare's own logs. `wrangler.jsonc` sets `observability.enabled`, and Workers Logs and any zone-level Logpush record the request URL. Only a person can change that (see Open questions).

## Risks

- **Test pollution:** `with_default` is thread-local and the tests call `upgrade_token` synchronously, so no other test's logs mix in. Do not use `set_global_default`.
- **Secret scans:** the log line takes `uri.path()` and never `uri` or `uri.query()`. `tests/api/secret_comparisons.rs` scans `src/` for `==` beside token names, so write no such comparison.
- **Purity and determinism:** none of this touches the engine, the cards, the AI or hidden information.
- **Alert layer:** the new line has no `alert = true`, so `AlertLayer` ignores it.
- **Cloudflare's own logs:** the tests cannot cover them (see Open questions).

Until then, `ws.upgrade.query_token` in the server logs shows whether any use remains.
2. **Cloudflare's logs.** `wrangler.jsonc` has `observability: { enabled: true }` for production and staging. Workers Logs invocation logs, and any zone Logpush, record a request's full URL, query included. The tree cannot close that. A person may either:
   - set `observability.logs.invocation_logs: false` in `wrangler.jsonc` (this loses request-level logs), or
